# 素材依頼｜銘柄パート（⑩〜⑯）

> 保存先：`企画ネタ/`（ファイル名の例：`日米株価_銘柄_20261013.md`）

---

## 0. ★この企画で銘柄が果たす役割（ここを外すと素材が使えない）

**今回の軸は「どのセクターが儲かるか」ではない。**

台本は①〜⑨で、こう説明する。

> 戦争が株を壊すのではない。戦争が「原油 → 物価 → 金利 → 企業の利益」の鎖を伝って、最後に銀行を壊したときだけ、株は暴落する。いま、その鎖は原油のところで止められていて、銀行は壊れていない。しかも、AIがなくても利益が出ている場所がある。

⑩以降の銘柄は、**この説明が口先だけではないことを、金額で証明するために置く。**

| ✕ こういう選び方 | ○ こういう選び方 |
|---|---|
| 今から上がりそうな銘柄 | **そのセクターの代表企業**（誰もが名前を知っている、規模が最大級） |
| 株価の上昇率が高い銘柄 | **マクロの追い風が、売上や利益に金額で表れている**銘柄 |
| 割安に放置されている銘柄 | **「原油が上がったから、この企業の利益が◯◯億円増えた」と言い切れる**銘柄 |
| 比率の改善が大きい小型株 | **動く金額が大きく、指数を実際に押し上げている**銘柄 |

**いちばん欲しいのは「追い風が、いくらの金額になったか」。**
「利益率が2ポイント改善」ではなく「**営業利益が◯◯◯億円増え、そのうち◯◯◯億円が資源高の寄与**」という形の数字。これが無いと、台本が「たぶん効いている」で終わってしまう。

## 2. 選定の条件

1. **代表性が最優先。** そのセクターで名前を挙げたときに「ああ、あそこね」と分かる企業であること
2. **マクロの追い風が、金額で開示されていること。** セグメント別の利益、感応度の開示、受注残など。これが取れない企業は、どれだけ良い企業でも外す
3. **東証プライム上場**（日本株）。**新NISAの成長投資枠の対象かどうかも記載**
4. **過去作で使った銘柄は外す**（§3の除外リスト）
5. **基準日を統一する。** 日本株＝**2026年1月5日終値 → 直近終値**。米国株＝**2025年12月31日終値 → 直近終値**。基準日を必ず明記
6. **年初来の騰落率がプラスの企業を優先する。** ただし今回の銘柄は「推奨」ではなく「証拠」なので、**代表性のほうが優先。**年初来マイナスでも代表企業なら候補に入れてよい（その場合は株価ではなく受注・利益のほうで語るので、**なぜ下げているのかの理由も一緒に書いてほしい**）

## 5. セクター別｜「金額インパクト」として取ってきてほしいもの

### ⑩ 銀行・金融（金利正常化）2社
- **貸出金利と預金金利の差**（利ざや）の推移と、**それによって資金利益が何億円増えたか**
- **コア業務純益**の推移と増加額（日銀の2026年4月金融システムレポートが「円金利上昇と経費率改善でコア業務純益が改善している金融機関がある」と書いている。その実例にあたる企業）
- **政策金利が0.25%上がると純利益が何億円増えるか**（感応度の開示があれば最優先で取る）
- **保有債券の含み損（評価損）**の金額 ←★注意点として必ず必要
- 与信関係費用（貸倒れ）の推移、政策保有株の削減の進捗
- ※1社目＝メガバンク級、2社目＝金利の影響がより純粋に出る銀行

### ⑪ 商社・資源（原油高の受益側）2社
- **★原油価格が1ドル（またはLNG1ドル）動いたときの、年間純利益の感応度**（◯◯億円。多くの商社が開示している。**これが今回いちばん欲しい数字**）
- **資源・エネルギー部門の利益の額**と、全体に占める割合
- 非資源部門の利益（資源だけの企業ではない、と言うために必要）
- 自社株買いと増配の実績 ←商社はここが厚い
- ※1社目＝総合商社の最大手級、2社目＝資源・エネルギーの比率がより高い企業（石油開発などでも可）

### ⑫ 国内の実需・旅行 2社
- **★国内の旅行需要が戻ったことで、売上が何億円増えたか**（セグメント別の売上・利益）
- **客単価**と**稼働率**（または輸送人員・客数）の推移 ←値上げが通っているかを見る数字
- 値上げ後に**数量・客数が落ちていないか**
- **インバウンド比率と、国内客の比率** ←観光庁の7兆5,361億円は日本人の国内旅行。インバウンド専業では紐づかない
- 人件費・燃料費の影響 ←注意点
- ※1社目＝鉄道・ホテル・レジャーの最大手級、2社目＝国内客の比率が高い企業

### ⑬ 防衛・再軍備 2社
- **★受注高・受注残高の金額**と、その推移（防衛はここが最重要。「何年分の仕事が積まれているか」まで分かると最高）
- 防衛・宇宙関連の売上が全体に占める割合と金額
- 契約の確度（確定受注か、枠組みか）
- 輸出規制・認証・納期・生産能力の制約 ←注意点
- ※1社目＝重工の最大手級、2社目＝防衛の比率がより高い企業
- ※**「NATOのGDP比5%は目標であって、予算の実行と企業の契約を保証しない」という留保を必ず添える**

### ⑭ 省人化・人手不足 2社
- **★受注高の金額**と、省人化・省力化に関わる製品の売上比率
- 顧客の投資回収期間（導入すると何年で元が取れるか）
- 人手不足を裏付ける公的な数字（有効求人倍率など）を1つ
- 設備投資の意欲が落ちたときの影響 ←注意点
- ※1社目＝FA・物流自動化の最大手級、2社目＝人手不足がより直接に効く企業

### ⑮ 米国エネルギー 2社（1社あたり短く扱う）
- ティッカー・取引所・何をやっている企業か（2行）
- **★直近四半期の売上・営業利益・前年比**と、**原油価格との連動のしかた**（生産か、精製か、パイプラインか、サービスか。**性格の違う2社**を選ぶと台本が組みやすい）
- 株価：2025年12月31日終値 → 直近終値、年初来騰落率、PER、配当利回り、時価総額
- 自社株買い・増配
- 注意点2〜3つ
- **新NISAの成長投資枠で買えるか**（日本の主要ネット証券での取扱い）

### ⑮ 米国金融 2社（1社あたり短く扱う）
- 同上の項目
- **★純利ざや（NIM）の推移、貸出残高の伸び、純利益の額** ←FDICの「Q1純利益805億ドル・貸出+7.1%」と接続
- 商業用不動産向け融資のリスク ←注意点
- ※銀行1社＋保険または決済1社のように性格を変える

### ⑯ ETF・投信 3本（新NISA用）
- **1本目：つみたて投資枠**で買える全世界株または米国株のインデックス投信。信託報酬・純資産・ベンチマーク
- **2本目：米国エネルギーセクターETF**（成長投資枠）。ティッカー・経費率・純資産・組入上位5社・配当利回り・日本の証券会社での取扱い
- **3本目：日本の銀行または高配当のETF**（成長投資枠）。銘柄コード・信託報酬・純資産・組入上位5社・配当利回り
- 3本とも**新NISAの枠の対象かどうか**を明記

## 6. 数字の扱いで守ってほしいこと

- **出典と公表日を必ず付ける**（決算短信・決算説明資料・会社四季報・観光庁・日銀・NATO・FDIC など）
- **推計・予想・目標と、確定した実績を分けて書く**
- 一過性の利益（資産売却益・評価益）が入っている場合は、**必ずその旨を書く**
- ドル建ての数字には**円換算を添える**（レートと基準日を明記）
- 同じ指標を複数ソースで拾った場合は、**値が違う理由（集計方法・基準日）**を書く
- **感応度や寄与度は、企業自身が開示しているものを最優先。**推計する場合は「推計」と明記する
