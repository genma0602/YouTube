## 0. ★素材そのものが付けている留保（ここを外すと嘘になる）

素材は「確認できた事実」「学術研究の一般的な発見」「分析者の推論」「未実施の定量検証」を分けて書いている。**台本では推論を事実として語らない。**

| 留保 | 内容 |
|---|---|
| **回復期間の表** | 日次データで高値・再突破日を統一抽出した回帰分析ではなく、**同じ「高値から高値」の概念で再整理した概算**。「史上最速」などとは言わない |
| **CAPE 約41倍** | 系列・観測日で値が違う。**収録前に原データを再照合** |
| **HY OAS 2.68%→3.15%** | 前の会話で引用された値。**収録前にFREDで再照合** |
| **S&P500のQ2利益+52.4%** | Amazon・Alphabetなどの投資関連の大きな利益計上を含む。**全額を本業の成長と言い換えない** |
| **円キャリー約40兆円** | 正確な計測は困難とBIS自身が明記した概数 |
| **NATOのGDP比5%** | 目標であって、予算の実行や企業の契約を保証しない |
| **3シナリオの発生確率** | 素材は確率を付与していない。**台本でも確率を言わない** |
| **米中首脳協議のテールリスク低下** | 素材の著者自身の推論。直接の増産合意ではない |

## 2. 戦争と株価（③で使う）

| 研究 | 内容 |
|---|---|
| **War Puzzle**（Bruneら） | 戦争の確率が高まる間は株価が下がるが、十分に予想された開戦では不確実性が解消して株価が上がることがある。予想外の開戦では下げが大きい |
| **Berkman & Jacobsen** | 1918〜2002年の**440件**の国際政治危機。危機は平均的に株式リターンを押し下げ、直後のボラティリティを高める。ただし**大国の関与と暴力の規模で影響が大きく変わる** |
| **Caldara & Iacoviello** | 地政学リスク指数の上昇は、その後の投資・雇用の低下と下方リスクの増加を予測する |
| **Rigobon & Sack** | イラク戦争前。war risk上昇が株安・原油高・ドル安・低格付け社債スプレッド拡大と結びついた |
| **UBS Global Investment Returns Yearbook 2026** | 1900年以降126年。長期の投資成果を壊してきたのは単発の政治危機ではなく、戦争がインフレ・景気悪化・金融危機・バブル崩壊につながったケース |

**鎖の形**：戦争 → 原油・LNG／貿易・供給網／信用・金融市場／企業の利益 → 物価 → 中央銀行と長期金利 → 株価。

## 3. 原油と備蓄放出（④で使う）

| 時期 | 事実 |
|---|---|
| 2026年3月 | IEA加盟国が**4億バレル**規模の協調放出を決定。米国は約**1.72億バレル**を担う方針 |
| 3〜4月 | DOEが戦略備蓄から段階的に緊急交換・放出 |
| 9月下旬 | 中東原油の輸出が一時**戦前水準を上回る** |
| 10月初め | G7が約**1億バレル**の原油・石油製品の緊急放出で協調 |
| 9月 | 米中首脳協議でイラン情勢・国際水路を協議（※直接の増産合意ではない） |

**日本側の事実**：日銀は日本の原油調達の**9割超を中東に依存**していると指摘。原油高は交易条件を悪化させ、企業利益と実質所得を圧迫する。**米国以上に日本の実体経済に効く。**

**それでも**：OECDは2026年の日本について、エネルギー価格上昇を逆風としつつ、賃金上昇・エネルギー補助・高い企業利益・政府補助による設備投資が国内需要を支えると予測。IMFも民間投資と消費の底堅さを見込む。**原油ショックは「不況」ではなく「成長率を削るショック」として処理されている。**

**限界（本文に必ず置く）**：備蓄は一回限りの在庫で、恒久的な供給ではない。精製能力や輸送の制約は解消しない。

## 4. リーマンとの違い・銀行の耐性（⑤で使う）

| 項目 | 2007〜09年 | 2026年 |
|---|---|---|
| ショックの中心 | 住宅信用・銀行 | 原油・地政学・物価・国債金利 |
| 銀行の資本 | 不十分、損失の把握も困難 | 規制資本は大幅に強化 |
| 資産の値段 | MBS／CDOなど、価格が分からない | 国債・原油など価格が見える |
| 短期の資金 | 銀行間・レポ市場が凍結 | ストレスはあるが全面凍結ではない |
| 家計 | 住宅の借金が大きい | 米家計の住宅エクイティは比較的厚い |
| ストレステスト | 制度の前 | **32行すべてが最低CET1以上** |
| ヘッジファンド | 問題はあった | **レバレッジは過去最高圏**（反例） |
| 生保 | 通常 | 最大手のレバレッジは歴史的に高い水準帯（反例） |
| 国債市場 | 安全資産への逃避 | 財政懸念で国債自体の金利が上昇（現在特有） |

**FRB 2026年ストレステスト**：商業用不動産価格−39%、住宅価格−30%、失業率10%という仮定の下で、全**32行**が最低CET1要件を上回った。総損失**7,080億ドル超**（1ドル157.7円で約**111兆円**）を吸収しても、総合CET1比率の最大低下は**1.6ポイント**。

**日銀『金融システムレポート』2026年4月21日**：日本の金融システムは全体として安定し、金融仲介機能も維持。**世界金融危機に匹敵するストレスに加え、原油高・AI期待の急減・金利の大幅上昇が重なる複合シナリオでも、銀行の基礎的な資本・資金調達の耐性を確認。**ただし不動産関連融資、海外ファンド向け融資、海外ノンバンクからの波及を重点監視。

**FRB『Financial Stability Report』2026年5月**：
- 株式の予想PERは歴史的な高水準圏、社債の信用スプレッドは比較的低い
- **米家計と企業の債務合計の対GDP比は2000年代初頭以来の低水準**
- 大手銀行は歴史的に高い自己資本比率、国内銀行の流動性資産も概ね潤沢
- ヘッジファンドのレバレッジは高く、最大手生保のレバレッジも歴史的に高い水準帯
- カード・自動車ローンの延滞には懸念

**2020年の実証**（⑤か⑦で使える）：NY連銀の2020年10月20日の講演。FRBの社債信用制度の発表後3か月で信用スプレッドがコロナ前の水準へ約**90%**戻り、改善の約**3分の2**は実際の買い入れ開始前を含む**政策発表日**に起きた。→ 制度は、使われる前から効く。

| **S&P500の中身** | 2026年10月12日のReuters。S&P500は年初来約**14%**上昇したが、**構成銘柄の4割超は年初来で下落**し、構成銘柄の中央値の上昇率は約**4%** |
| **Bubbles for Fama**（Greenwood・Shleifer・You、2019年） | 産業株の急騰は、その後の平均リターンが必ず下がるという予測にはつながらない。**ただし大幅な暴落の確率は高まる。**上昇局面の変動率・売買回転率・株式発行・上昇の経路に、暴落を予測する情報が含まれる |
| **Goldman Sachs Research**（2026年7月10日） | 現代の米大型株は1990年代末より強い利益とバランスシートを持つ。**ただしAI関連の巨大な時価総額を正当化するには、将来利益に楽観的な仮定が必要** |
| **2000年との違い** | ITバブル期は利益が確立していない企業も多かった。いまは利益とキャッシュフローの裏付けがある企業も多い。ただし利益の集中には注意 |

**台本での扱い**：⑥は痛みの承認パート。**打ち消さずに認める。**ただし「高いこと」と「明日崩れること」は別、という1点だけで受ける。

### 日本 日経平均

| 起点 | 下落 | 元の高値を回復するまで |
|---|---|---:|
| 2007〜09年 世界金融危機 | 2007年高値 約1万8,261円 → 2009年3月安値 7,054.98円 | 2015年ごろ、約**7年7か月** |
| 2020年 コロナ | 2020年3月に約1万6,553円へ | 2020年11月ごろ、約**9か月** |
| 2024年7〜8月 円キャリー巻き戻し | 8月5日に大幅下落 | 2025年8月、約**13か月** |

**最強の反例（必ず自分から出す）**：**1989年のバブル高値から2024年まで、約34年**。「すべての暴落はすぐ戻る」への最も強い反証。

### 回復が速く見える理由（5つに分解）

1. **危機の質が違う**（2008年型の信用収縮と2020年型の活動停止は比べられない）
2. **政策の反応速度が上がった**（制度の存在と発表そのものに効果がある）
3. **銀行の損失吸収力が改善した**
4. **投資家が当局の反応を先に織り込む**（ただし高い物価の下では動けないことがある）
5. **持ち高の調整で起きた下げは、巻き戻しも速い**

**素材の留保**：1987年・1990年にも短期の回復がある。**回復が時代とともに単調に短くなっているとは言えない。**「2008年以降の政策の学習がすべての回復を早めた」という因果関係は証明されていない。

**Jordà・Schularick・Taylor「When Credit Bites Back」**：1870〜2008年、先進14か国・200件以上の景気後退。**景気後退の前の信用膨張が大きいほど、後退は深く、回復は弱くなる。**金融危機を伴う不況は、通常の不況より損失が大きい。

- **Goldman自身が、急な円高が2024年のような日本株の調整を起こすリスクを明示している**

## 9. 追う4つの数字と、崩れる条件（⑮で使う）

### 追う4つ

| # | 数字 | なぜ見るのか | 危険になる変化 |
|---|---|---|---|
| 1 | **原油**（Brent） | 鎖の入口。日本は中東依存9割超 | 現物の供給不足が長引く。ホルムズの通航停止、タンカー運賃の高騰 |
| 2 | **長期金利**（米10年・日10年） | 株価の倍率を直接押し下げる | 物価が高いまま中央銀行が動けず、金利だけが上がる |
| 3 | **企業の利益予想** | 倍率が縮んでも、利益が伸びれば株価は保つ | 全業種に下方修正が広がる |
| 4 | **信用スプレッド**（米ハイイールド社債のOAS） | 株安が金融危機に変わる瞬間に鳴る警報 | 短期間の急拡大、発行市場の停止 |

### 信用スプレッドの説明（用語）

- **信用スプレッド**＝企業に貸すときに、国債より余分に求められる上乗せ金利。米国債4%・社債7%なら差は3パーセントポイント＝**300ベーシスポイント**。1ベーシスポイントは0.01パーセントポイント
- **ハイイールド社債**＝格付けが投資適格を下回る企業の債券。景気と信用環境の悪化に敏感
- **OAS**＝期限前償還などのオプションを調整した上乗せ利回り。**OASが3.15%でも、倒産確率が3.15%という意味ではない**
- **実際の値**：ICE BofA US High Yield Index OAS は2026年9月18日の**2.68%**から10月8日の**3.15%**へ約**47ベーシスポイント**拡大（※要再照合）。市場のストレスが増えた兆候だが、この値だけでリーマン級とは言えない

### 金融ストレス指数（補助。使うかは本文で判断）

セントルイス連銀 STLFSI4。18の週次指標の合成。ゼロが長期平均程度。2026年9月18日 **−0.7029**／9月25日 **−0.8091**／10月2日 **−0.4681**。

### 本当に崩れる条件（素材の順）

1. 中東の原油供給が再び急減する
2. 原油高と米金利上昇が同時に進む（物価が高くてFRBが緩められず、倍率が縮む）
3. AIの利益期待が下方修正される
4. 急激な円高
5. 信用市場のストレス（ここで「原油の問題」が「金融危機」に変わる）
6. 日本国債の無秩序な金利上昇
7. 外国人フローの反転（34%超を持つ海外勢の評価が逆回転）
8. 自社株買い・M&Aの減速

**素材の結論**：「戦争のニュースが増えたかどうか」より、**「原油・金利・利益予想・信用スプレッドの4つが同時に悪化したか」**を見るほうがはるかに重要。
