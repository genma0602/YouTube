### つなぎ（400字）

- 4つ出て、4つとも答えか期限が付いた。知らない悪材料が、あとから出てくる状態ではない。これが「ある程度出尽くした」の意味
- 二度目の不安：「でも、耐えただけでしょう。それだけで強いとは言えない」
- 答え：耐えられたのには理由がある。利益が出ているからです。後半はその話

### ⑥ 耐えられた理由：利益が出ている（3,000字）

1. 米国：主要5社の2026年設備投資予想は年初4,850億ドル→7月7,300億ドル。**減額ではなく上方修正が続いている**。使う側（マイクロソフト・アマゾン・グーグル・メタ）と受け取る側（エヌビディア・TSMC）。**その装置と材料を日本が受け取る。日本は「受け取る側の、さらに受け取る側」**
2. 日本：主力5社はすべて営業黒字。アドバンテスト営業利益+53%（通期を8,460億円に上方修正）、東エレク+46%、ディスコ+42%。反例：レーザーテックは減益、最高益予想でも市場予想に届かず売られた
3. **山場：キオクシア（800字）**
   - 6/12に時価総額でトヨタを抜いて国内トップ。6/22に高値11万2,700円。9/4は5万4,460円で半分
   - 4-6月の営業利益 約1兆2,700億円で29倍、営業利益率72%。7-9月は1兆8,900億円、79%を見込む。データセンター向け売上は前年の5倍超
   - 8,000億円の自社株買いを6営業日で終えても株価は下がった。需給の問題でもない。**市場が疑っているのは「この利益がいつまで続くか」だけ**
   - 続く理由：AIが「学習」から「推論」へ。24時間動く計算にはデータを出し入れするSSDが要る。HDDより速く、HBMより安く、電源を切っても消えない。データセンター比率を5割未満→6割以上へ。技術は競合に「4年先行」。9/3の説明会（DRAMの一部をNANDで補う技術、エヌビディアと日常的に協議）で翌日+5.4%
   - 反例：利益の急増は単価の高騰（前四半期比+70%）。会社予想にわずかに届かなかっただけで売られた。2027年後半以降に各社の増産が需要を上回れば価格は下がる。**「割安」「戻る」は言わない**
     3.5 **銅（ユーザー素材 `企画ネタ/copper_ai_investment_summary.md`・9/6）**：AI投資の5段階で裾野を下りる。①計算（エヌビディア）→②記憶（キオクシア、直前の段落）→**③運ぶ（フジクラ・古河電工・住友電工）→④電力→⑤原材料（銅）**。「AI半導体が脳なら、銅は血管」。**AI用データセンターは同じ電力で銅を2倍以上使う（1メガワットあたり47トン、普通は21トン）。アマゾンは鉱山大手リオ・ティントから銅を直接買う契約を結んだ。**銅は史上最高値圏、1年で5割高。日本：フジクラ 4-6月 営業利益+155%・利益率26%、古河電工+205%。銅の値段がそのまま利益に効くのは鉱山の権益を持つ住友金属鉱山（100ドルで35億円）。AI向けの銅材料でシェアを持つのが三井金属（極薄銅箔98%）。**反例：①銅高はAIだけではない（供給制約・電動化・関税・中国）②電線・銅箔の会社にとって銅は原材料。利益の源は転嫁とシェア ③電線株は半導体と同じ揺れ方（8/19 古河電工13%安・フジクラ10%安、高値から3〜4割）**。推奨の言い回しは使わず役割で分ける。**600〜700字。`materials.md` §17-6・17-7**
4. 反例（全体）：UBS「伸び率は2026年+76%→2027年+25%→2028年+6%」。額は減らないが伸び率は鈍る。株は伸び率の鈍化だけで下がれる。だから調整はまた来る。ただし投資が消える話ではない
5. 締め：見るべきは4社が一斉に投資を削るかどうか（⑧へ）

### ⑦ 日本に工場が来て、国が予算を投資に変えた（2,600字）

1. 工場：熊本はTSMCが2028年から3ナノ（ソニー・デンソー・トヨタも出資）。広島はマイクロンのHBM（進捗のみ、金額は再掲しない）。横浜は**サムスンが日本に来る**。千歳はラピダス2ナノ。**北上と四日市はキオクシアとサンディスクが2032年までに約5兆円。K3棟は8/27に土地整備を始め、2029年度稼働。この25年で国内9兆円を投資してきた会社が、次の6年でさらに5兆円**
2. ゴールドマン：TOPIX 12か月目標4,500。ロイター短観 製造業+13→+18
3. 難しくなるほど日本の出番：微細化→工程増→検査増→積層→研削・接合・テスト増
4. **国の予算（理由の最後）**：9/4 財務省。来年度の概算要求143.1兆円。**「20兆円増えた」ではない**。補正で毎年繰り返していた分を当初予算に入れた。比べるなら141兆円と143兆円。変わったのは作り方：**「強く豊かな日本」投資枠 約14.2兆円。要求の上限なし、複数年度が基本、民間投資を呼ぶ効果で査定。財務相は戦後初と説明**
5. なぜ株の話か：「今年は支援があるが来年は分からない」では工場を決められない。複数年度なら5年・10年の投資を決めやすい。政府の支援そのものより、それで動く民間の設備投資が大きい。波及：政府→半導体メーカー→新工場→装置・材料・建設・電力・電線・水処理
6. モデル：キオクシアとサンディスクの5兆円は「政府支援を前提」。「支援額を上回る納税で返す」
7. GPIF：8月に異例の会合。見直しの観測（決定ではない）
8. 反例：①概算要求は成立予算ではない。年末の査定で削られる分野が出る ②積極財政→物価→長期金利上昇→利上げ→高PER株に逆風。財務省自身が長期金利を「高い緊張感」で注視。**③の3%とつなぐ** ③ラピダスは歩留まり・顧客・コストが未確定
9. 締め：見るべきは9〜12月の査定で14.2兆円のうち何が残るか、12月下旬の予算案

### ⑧ 金利が上がる中で、どう動くか（4,000字）

導入：「じゃあ、金利が上がっている今、何をすればいいのか」

**(0) 金利上昇の両面（400字）**

- 高PER株には逆風（②③で見たとおり）。ところが守りの側には追い風。**個人向け国債の変動10年は9月募集で年1.95%**。1,000万円なら年19万5,000円。株価が揺れても値下がりしない置き場所に利回りが付いた
- 「金利上昇＝株を全部売る」ではない。**攻めは器と日付で決め、守りは利回りの付いた円資産で固める**

**(a) 日付を4つ持つ（1,000字）**

- 9/11 米物価、9/15-16 FRB、9/17-18 日銀、11/3 中間選挙（＋10/27-28 FRB、12月下旬 予算案）
- **この日付を通過するまで、値動きで判断を変えない。**判断を変えるのは日付の結果を見てから。揺れの正体が外側にある以上、答え合わせの日は決まっている

**(b) 僕が考えを変える条件を3つ、先に言う（1,000字）**

1. マイクロソフト・アマゾン・グーグル・メタの4社が**一斉に**設備投資を削る（⑥が崩れる）
2. ホルムズ海峡が封鎖され、原油100ドルが定着する（④が崩れる。2018年型）
3. FRBか日銀の利上げが2回以上になる（③が崩れる）

- **これが出たら、僕は今日の話を撤回します。**出ていない限り、揺れは揺れです

**(c) 器は、すでに何を持っているかで決まる（1,600字）**

- ⑥で見たとおり半導体の中で選別が起きている（アドバンテスト上場来高値、キオクシア半分）。個別で当てにいくより、器で持つ
- 既保有別：
  - **NASDAQ100／FANG+を主軸** → 半導体の二重投資。日本株を足すならTOPIX側、攻めの枠は増やさない
  - **S&P500／オルカン主軸** → 日本のAI半導体の色を足す余地。日経平均か、日経半導体株指数に連動する商品（信託報酬0.165%）か【決定待ち】
  - **日経平均／TOPIXをすでに持っている** → 日付ごとに分けて買い足す。揺れに強いのはTOPIX、AI半導体に乗るなら日経平均（再説明はしない）
  - **何も持っていない** → まず土台（オルカン／S&P500）、日本株は次
- 時間分散：日付を4つ持っているなら、**その日付ごとに分けて買う**理由になる
- 個別で持つ人へ（事実だけ）：キオクシアは10/1に1株が3株になり、最低投資金額が約400万円から3分の1。「買いやすくなる」で止める
- 商品は推さず基準3つ（信託報酬・純資産・自分の証券会社）。1段落

### ⑨ 「買い時」の本当の意味（1,000字）

1. タイトルに正直に：「AI半導体株、ついに買い時か」。**値段の底を当てる意味での買い時は、僕にも分かりません**。キオクシアは利益が29倍でも半分になった
2. 再定義：今が「買い時」だと言えるとしたら、**「器と日付を決められる時」**。悪材料は4つ出て、全部に答えか期限が付いた。利益は増えて、そちらに期限はない。両方が見えている今だから決められる
3. サムネの「転換期」：転換しているのは3つ。金利だけで半導体が売られなくなった市場の反応（②）。世界が日本に工場を建てに来る流れ（⑦）。国が予算を1年ごとから複数年度の投資に変えたこと（⑦）。**値段は揺れているが、この3つは揺れていない**
4. ①の迷いに戻る：「売るか、耐えるか、買い増すか」は三択ではなかった。日付を持ち、条件を持ち、器を決め、守りに利回りを付ければ、揺れたまま持てる（方向は言わない）
