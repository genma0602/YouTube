### 17-5. 反例（必ず内蔵）

1. **銅は景気の体温計。**中国の需要が鈍れば下がる。AIだけで決まる値段ではない

3. **電線株は半導体株と同じ揺れ方をする。**8/19に古河電工が1日で13%、フジクラが10%下げた。高値から3〜4割安は半導体と同じ

### 15-2. なぜ株の話になるのか（台本の論理）

- 「政府がいくら使うか」ではなく「**政府の支援で、民間の設備投資がどれだけ増えるか**」
- 企業が大型投資を決めにくかった理由の1つが「今年は支援があるが来年は分からない」（予算は1年ごと）。**複数年度が基本になると、5年・10年の投資を決めやすくなる**
- 半導体工場は土地→建屋→装置→電力→水→量産で数年。**予見可能性が投資を生む**
- 波及：政府 → 半導体メーカー → 新工場 → **装置・材料・建設・電力・電線・水処理・空調・物流**。政策の本命企業だけでなく、その設備投資を受注する会社まで

### 15-5. 反例（理由6に必ず内蔵する）

1. **概算要求は成立予算ではない。**要求上限がないことは、要求した額が全部通ることではない。年末の査定で削られる分野が出る
2. **積極財政 → 需要増 → 物価・賃金上昇 → 長期金利上昇 → 追加利上げ観測 → 高PER株に逆風。**財務省自身が9/4時点で長期金利上昇を「高い緊張感を持って注視」。**§6-2 の長期金利3%とセット**
3. 効果の低い基金・補助金は国庫返納。**去年の国策銘柄が来年も国策とは限らない**
4. 「国策＝無条件で買い」ではない。政策で利益がどこまで伸びるかと、それが株価にどこまで織り込まれているかは別
