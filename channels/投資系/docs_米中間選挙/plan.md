## 2. ブロックごとの流れ

**①（導入）** 希望から入る。11月は、アメリカの中間選挙と日本企業の決算が重なる月です → 痛みの承認：「共和党が負けたら、AIの株は終わるのではないか」と不安になるのは自然です（15%以内の承認） → 結論の先出し：どちらのパターンでも、AIへの投資は簡単には止まりません。理由は法律にあります → 目次：2つのパターン／株式市場の動き／変わらない法律／追い風を受けるセクター／過去の日本株／そして11月に決算を迎える日本の優良株11社。①の社名フックとして「その1社目はフジクラです」まで言ってよい（マクロ軸ルールの例外範囲）。

**②（ねじれのパターン）** 頭に固定の3文（「早く儲かる銘柄を〜考え方のほうを解説します」）。→ 上院と下院の違いを1回で定義（下院435・2年で全部入れ替え／上院100・人事の承認権）。日本でいえば衆議院と参議院、と対比 → 法律は両院で同じ中身を通し、大統領が署名して初めて変わる。大統領は2029年1月までトランプ氏 → 民主党が下院だけを取ると、新しい大型の減税や予算は止まりやすくなる。一方、決まった法律は残る → 2018年の実例：前の年に法人税を35%から21%に下げ、翌年の選挙で民主党が下院を取った。それでも21%は残った（★⑥で回収する伏線）。

**③（民主党が両院）** 両院を取っても、法律を変えるには大統領の署名が要る。拒否権を覆すには、各院で3分の2 → 変わるのは「議題を決める力」「人事を承認する力」「行政を調べる力」。医療保険、データセンターの電気代、住宅などが交渉に上がる → 共和党の大統領のもとで民主党が両院を取った先例は1954年と2006年の2回。1年後のS&P500は+33.2%と+6.7%。2回しかないので、ここから確率は言えない、と一言で認める。

**④（市場はどう動くか）** 民主党が下院を取ることは、すでに相当織り込まれている（Amundi・Barclays）。オプション市場も大きな動きを見込んでいない → 2018年、民主党が下院を取った翌日、S&P500は+2.12%、NASDAQは+2.64%。迷いが消えると株は買われやすい → 2006年は医療と防衛の一部が売られたが、指数は上がった。つまりセクターごとに反応が分かれる（★⑨への伏線） → 1950年以降の19回、選挙から1年後のS&P500はすべて上昇、平均+15.1%。ただし3か月で見ると2002年と2018年は下げている。選挙直後の1日と、1年は別物（★⑩で回収）。共和党が両院を維持すると「予想外」になり得る、とBarclaysは見ている、まで1文。

**⑤（AI投資が終わらない理由）** 反例を先に出す：データセンターへの反発は両党の支持者に広がっていて、「AI相場のリスク」と報じられている → 解釈：止まるのではなく、場所と速さが変わる（Morgan Stanleyの「条件つきの建設拡大」） → 理由1：お金を出しているのは民間の企業。Morgan Stanleyは2027年の大手クラウド企業の設備投資を約1.5兆ドル、日本円でおよそ237兆円と見ている（ドル→円はここで1回だけ） → 理由2：データセンターの電気は2025年の485TWhから2030年に950TWhへ（IEA） → 理由3：米中の技術競争。計算する力の確保は、党に関係なく国の安全の話になっている → 用語のあと300字以内に日本企業へ降ろす：その配線を作っているのが、このあとフルで見るフジクラ。

**⑥（恒久的に変わらない法律）** 2025年の法律で、設備を買った年に全額を経費にできる仕組み（100%即時償却）が期限なしになった。国内の研究開発費も同じ → 即時償却は「補助金」ではなく、税金を払う時期が後ろにずれる仕組み、と1文で正確に → だから、サーバーや光の配線を買う企業は、選挙の結果に関係なく、買った年に税金が軽くなる → 法人税21%も期限なし。②の2018年を、覚えていない人向けに言い直して回収 → 次への橋：この仕組みで、いちばん注文が増えている部品の1つが光の配線です。

**⑦（フジクラ・フル）** 役割：AIのデータセンターで、サーバー同士をつなぐ光ファイバーと接続部品を作る企業、証券コードは5803です → 直近の決算：4〜6月で売上4,020億円（+50.1%）、営業利益1,048億円（+155.1%）。情報通信の利益980億円で利益率は約37%、全社の利益の約9割 → 伸びた理由は数量と値上げ。一時的な要因も含む、と一言 → 日米で光通信に最大3,000億円の設備投資。佐倉の新工場は2030年稼働の予定 → 海外の運用会社：Artisanが新しく買い、William Blairは「値上げが利益に出ている」、Brock Miltonは買い増し → 財務の段落：自己資本比率・手元の現金・ROE（**素材に無い。検索で補い【要確認】**）、PER約20.5倍、PBR約11倍、配当は会社予想で年38円 → 株価：10月23日の終値4,037円、去年の年末から+38.9%。年内の高値からは約半分（承認は1〜2文で、解釈は前向き：数量と値上げは決算で確認できる） → 決算は11月10日。見るのは情報通信の利益率と、通期予想をもう一段上げるか。

**⑧（期限まで残る法律とお金）** ⑥の「期限なし」と対にして、期限がついているものを並べる。半導体工場の税額控除35%は2026年末までに着工した工場が対象。国防の追加資金約1,562億ドルは2029年9月末まで契約に使える。国内製造の控除は2033年まで段階的に縮む → 反例：法律で枠が決まっていても、半導体の補助金で実際に払われたのは約42%（GAO）。解釈：枠は消えないが、払われる速さは変わる → 日本側も独自に動いている：防衛力整備計画は5年で約43兆円。アメリカの議会が変わっても、日本の計画は消えない。

**⑨（日米のセクター）** 共和党が勝った場合：アメリカは金融・資本財・エネルギー・防衛。日本ではメガバンク・商社・重工・電力設備・半導体装置 → 民主党が勝った場合：アメリカは病院などの医療サービス、住宅・REIT、送配電。日本では金利が落ち着けば不動産・内需、原油が落ち着けば航空・陸運・電力・食品 → どちらでも追い風が残るもの：電力・送配電、半導体の実需、防衛・宇宙・サイバー、重要鉱物 → ★「共和党なら金融、民主党なら再エネ」という単純な分け方では説明できない、を1文。過去12か月で強かったのはIT・一般消費財・通信だった（Ameriprise）。

**⑩（過去の日本株と今回）** 1982〜2022年の11回、選挙から3か月の日経平均は平均+3.3%、上がったのは11回中6回。アメリカほどきれいには上がらない（承認は1文） → 2018年と2022年の1か月：銀行は−8.5%と+5.0%、電力・ガスは+7.2%と+2.7%。差を作ったのは党ではなく、原油とアメリカの利上げ、物価の発表だった → 今回の見通し：効くのは選挙より、アメリカの10年国債の利回り（5.34%前後から4.97%前後へ低下）と原油（115〜117ドル台）とドル円 → だからこそ、同じ11月に出てくる企業の決算のほうが、自分の持ち株には直接効きます（⑪への橋）。**方向の言い切りはしない（決めてほしいこと3）。**

**⑪（11月の決算で見る3つ）** 1つ目：為替・関税の還付・売却益などを除いた利益。2つ目：受注や客数といった「量」。3つ目：会社が通期の予想を上げるかどうか → 11社は「AIの設備」「アメリカの制度に関わる」「海外で稼ぐ消費」「国内」の4つの型に分けて並べる、と予告だけ（点呼しない）。
