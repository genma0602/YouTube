## 1. 出力先を分ける（★最初にやること）

`convert.py` は **自分が置かれたフォルダの `PNG/` に固定で書き出す**（`convert.py:69`）。
`スライド/` 直下でそのまま実行すると、**前作の `スライド/PNG/slide_01〜278.png` を上書きする。**

対策：

```
スライド/
├─ 日経平均10万円は近いか.html / .pdf     ← 前作。触らない
├─ PNG/                                    ← 前作278枚。触らない
└─ メモリ編/                               ← ★新規作成
   ├─ convert.py                           ← スキルの assets からコピー
   ├─ AI半導体はまだ序章.html
   ├─ AI半導体はまだ序章.pdf
   └─ PNG/slide_001〜400.png
```

実行：`スライド/メモリ編/` で `python convert.py "AI半導体はまだ序章.html"`

> なお `convert.py` の連番は `slide_{i:02d}` のため、100枚超では `slide_100.png` が `slide_97.png` より前に並ぶ。**編集ソフトへの読み込み順が狂うので、3桁ゼロ埋め（`{i:03d}`）に直したコピーを `メモリ編/` に置く。** 前作の `convert.py` は変更しない。

## 4. 落とし穴（このデッキ固有）

### 4-1. 基準の違う数字を同じ棒に並べない
- **キオクシアの下落率は3種類ある**：単日 −18.33%（7/28）／3営業日 −31%（7/24→7/29）／週間 −16.98%。**t-vbarsで横に並べると誤読される。t-steps で時系列に置く。**
- **主要10社の −12.1%（7/28単日）と −10.61%（週間）も期間が違う。**同じスライドに並べない。
- **マイクロン −54%（2018）と −50%（2022）は期間が違う。**主張は「どちらも半年〜1年で半減した」なので、**勝敗に見えるt-vbarsではなく t-metric を2枚**。
- **DRAM設備投資 537億→613億ドルは"増えている"のに、供給は"ほとんど伸びない"。**棒2本で並べると「増産＝供給増」と誤読される。**t-fx（投資は増える → クリーンルームが足りない → 供給は伸びない）で描く。**

### 4-2. ネタバレしない（1スライド＝1ビート）
- ③でキオクシアの決算日に触れるスライドに、**決算の数字（5倍・28倍・46倍）を出さない**。初出は⑦。
- ③の foot-bar に「だからTOPIX」と書かない。**回収は⑦角度2。**
- ①の「主要10社 −10.6% vs TOPIX −0.2%」は事実の提示まで。**「だから分散」の結論は③まで出さない。**
- ②のPERスライドに④の6項目比較の結論を先出ししない。

### 4-3. 用語（CLAUDE.md の恒久ルール）
- **「メモリ不況」＝市況（価格・業績）。供給過剰から始まる。／「株価の下落」＝それより先に始まる。**
- **✕「暴落は値崩れから始まる」というノードを t-flow に作らない。**②の流れ図は「メモリ不況の流れ」と明示し、**「株価は先回りする」を別ノード（または別スライド）に切る。**

### 4-4. 方向を語らない
- スライドのタイトル・`note`・`foot-bar` に「上がる」「買い場」「仕込む」を書かない。**銘柄は役割で書く**（例：キオクシア＝NANDフラッシュメモリとSSDを作る会社）。

### 4-5. 反例スライドを削らない
台本は各理由に「ただし」を内蔵する設計。**枚数調整で真っ先に削りたくなるのがここだが、削ると承認の効果が消える。**
必ず独立スライドに立てる：⑤理由1のキオクシア −17% ／ 理由2のルネサス・ローム ／ 理由3の「いずれ供給は立ち上がる」／ 理由4の中国向け規制は両刃 ／ ⑥のSCREEN・KOKUSAI・アドバンテスト ／ ⑧の3つの「ただし」 ／ ⑨の「高配当株でも減配はある」。

### 4-6. レイアウト（スキルの既知の落とし穴）
- `t-rank` 7行超・`t-agenda` 5項目超 → `.compact` 必須。②③の下落率ランキングと⑥の16社一覧が該当。
- `t-vbars` は棒の高さと `padding-bottom` を調整してフッター帯と被らせない。
- `t-numline` はラベルが重なる。⑧の購買力（84/71/60万）は **t-numline ではなく t-steps**。
- `t-prop` の細いバーは中の文字が折り返す。%はバーの右隣に黒文字で出す（⑩の配分が該当）。
