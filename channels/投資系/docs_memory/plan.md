## 3. 執筆ルール

### ★銘柄の扱い（今回追加）

> **銘柄は「役割」で語り、「方向」は語らない。**

| 可否 | 例 |
|---|---|
| ○ | 「キオクシアはNANDフラッシュを発明した、日本唯一のメモリ完成品メーカーです」（役割） |
| ○ | 「7月24日、キオクシアは9.49%下げました」（起きた事実） |
| ○ | 「東京エレクトロンは前工程の塗布・現像で世界トップです」（役割） |
| ✕ | 「キオクシアはここから上がります／下がります」 |
| ✕ | 「今が買い場です」「仕込むなら今です」 |

**個別株の話題そのものは自由に出してよい。禁止するのは方向の断定のみ。**

> **★これは相場・セクター・指数レベルでも同じ。** パート間の橋渡しでも「上がる」と言わない。
>
> - ✕ 「では、なぜここから上がると言えるのか」
> - ○ 「では、そもそもなぜ、世界はこれほどメモリを奪い合っているのか」
>
> ⑤⑥は**「値段が上がる理由」ではなく「需要・構造・必要性の理由」**として立てること。⑤まとめ・⑥まとめ・⑩でも同様。

### 型固有の8ルール（前作から継承）

1. **承認ファースト**：強気を語る前に、不利な事実を自分から数字付きで先に認める
2. **不安は否定せず、共存させる**：「その警戒は正しい。警戒したままこう動ける」
3. **各理由に反例を内蔵**：強気の根拠を語る最中に、反するように見える事実を自分から出してその場で解釈する
4. **ネガティブ情報の多毛作**：不都合な事実を、信頼の担保→チャンスへの反転→後半の伏線と複数回働かせる
5. **抽象度が上がるほど数字を濃くする**
6. **二度目の不安**：最長パートの直前で疑いをもう一度代弁し、本論を「答え合わせ」に変える
7. **処方箋は「既保有主軸別」で切る**（二重投資の視点）
8. **着地は一段ズームアウト**（資産全体の枠組みで返す）

### 文体

- 基本の心拍：**「ところが」（落とす）→「ただし」（戻す）→「つまり」（畳む）→「だからこそ」（動かす）**
- **「正直にお伝えします」は1本で3回以内**（多用すると価値が下がる）
- **「気のせいではありません／これは事実です」**はデータで裏付く実感にだけ使う
- 短く言い切るテンポを維持。回りくどい自己言及・メタ要約を避ける
- 番号での振り返り（「②で〜」）は不可。「さきほど」等に統一

### 出典ルール

前作は「証券会社・情報媒体は7社まで」で運用（ロイター／ゴールドマン・サックス／UBS／ブラックロック／モルガン・スタンレー／JPモルガン／内閣府）。

**今回は枠の再設計が必要。** 新素材にTrendForce・IDC・BCG・Omdia・NBER・総務省・日銀・金融庁・JPX が登場するため、旧ルールのままでは破綻する。

**再設計の方針案**：
- 公的機関（総務省・日銀・金融庁・JPX・内閣府）は**枠外**
- 企業の自社発表（マイクロン・サムスン・NVIDIA・日本の各銘柄）は**枠外**
- 証券会社・調査会社・報道媒体を**7枠**に収める

→ フェーズ1で確定させること。

## 6. この構成で意識的にやっていること

| 設計 | 狙い |
|---|---|
| 前作への言及ゼロ | 新規視聴者が100%理解できる |
| ②で「金曜の下げは本物」と認める | 承認ファースト。認めた人の「ただし」だけが聞かれる |
| ③で「日本株が売られたのではない」と反転 | ネガティブ情報の多毛作（信頼→反転→⑦の伏線） |
| ④で歴史の暴落を自分から出す | 二度目の不安。⑤⑥を「答え合わせ」に変える |
| ④＝下値の証明、⑤⑥＝上値の証明 | 役割を分けることで各パートの論点がぼやけない |
| ⑥の入り口に居酒屋フック | 85分の中盤で最も離脱しやすい地点に絵の浮かぶ場面を置く |
| 全理由に反例を内蔵 | 反例を処理できる理論だけが信頼される |

### 10-3. 未達・要修正（4件）

#### A. ②に「物差しの教育」がない ★要修正

元台本②は **疑いの最大化 → 承認 → PERという物差しの教育 → 相対化（今20倍 vs バブル期60〜70倍） → 恐怖の再定義** の5手が1ブロックで完結し、「言い聞かせるのではなく、物差しを渡して視聴者に自分で測らせる」が成立していた。

今回の②は **疑いの最大化 → 承認 → 引き金の種明かし → 恐怖の再定義 → 反例** で、物差しと相対化がない。相対化に相当するもの（過去の暴落との6行比較表）は④に置かれているため、**②〜④の3ブロックを通せば型は満たす**が、②単体では「で、今は高いのか安いのか」に答えないまま次へ進む。しかも本企画は「バブル警戒」が視聴者の主因なので、**バリュエーションへの回答が動画のどこにも存在しない**状態になりかねない。

→ **対処**：②の3手目と4手目の間に150字で、日経平均の予想PER（欠損#3）を1つ置き、「高いか安いかは、このあと過去と並べて自分で測ってもらいます」と④への予告を明示する。プロット草案には反映済み。

#### B. ④の「ニュースの再定義」が②へ前倒しされている ★問題なし（記録）

元台本④は **ニュースの再定義（動いているのは出来事ではなく原油と金利という土台）→ 二度目の不安 → 結論再提示 → 目次** の順。

今回は再定義（「AIは儲かるのか」→「いつ儲かるのか」＝主語を出来事から回収時期へ差し替え）を**②4手目に前倒し**し、④は「二度目の不安 → 承認 → 相対化 → 畳み → 反例 → 目次」になっている。順序は違うが、**再定義・二度目の不安・目次の3機能はすべて揃っている**。

前倒しは妥当。今回の「出来事」＝アルファベット決算は②で扱う対象そのものなので、②で再定義しないと②が説明不足で終わる。

#### C. ④が「元台本の理由5」を担っている ★問題なし（記録）

元台本の⑤は **理由1〜4＝押し上げる力／理由5＝下を支える力** で、上下両面を1ブロック内で揃えていた。今回は下値の証明を④に独立させ、⑤⑥は上値のみ。

**両面が揃うという要件は満たす。** ただし④が2,600字と重いため、④7手目の橋渡し（「ここまでは下を支える力の話。では、なぜここから上がると言えるのか」）を必ず入れること。これがないと④が単独の暴落史解説として浮く。

#### D. 「不作為の封じ」が最後の一撃でなくなった ★要注意

元台本では、為替19%目減りによる「日本株を持たないこともリスク」が**⑦着地の中の最後の決定打**として置かれ、その直後に比率→再定義→CTAで終わっていた。「一番効く札を最後に置く」原則。

今回は不作為の封じを⑧（2,400字）として独立させたため、決定打のあとに⑨（1,400字）⑩（800字）が続く。**⑧の熱量が⑨の配分論で薄まるリスク**がある。

→ **対処**：⑧10手目の末尾に⑨への橋を1文置く（「では、その長期資金の中で、日本株はどれくらいが妥当なのか」）。⑨を1,400字、⑩を800字に厳守し、⑨で新しい論点を持ち出さない。プロット草案には反映済み。
