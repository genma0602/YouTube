### ④で使う数値（過去のメモリ暴落と構造比較）

**過去の暴落3回**【全て要検証・このブロックの中核】
- **1996年**：DRAM価格 前年比 **-51%**／1997年 さらに **-65%**／メモリ大手の株価はピークから **60〜80%超** 下落（アジア通貨危機と重複）
- **2018〜19年**：マイクロン株価 2018年5月高値 → 12月 **約-56%**／主要各社は2018年夏ピーク〜2019年末底で **概ね-50〜60%**
- **2022年**：マイクロン 年初から半年で **約-50%**／SKハイニックスは2023年通期で営業赤字
- サイクル周期：**6〜8四半期**

**構造比較（過去 vs 現在）**

| 項目 | 過去（2010年代まで） | 現在（2020年代） |
|---|---|---|
| 供給側 | 多数のメーカーが乱立（東芝・Elpida・Qimonda等） | 3社寡占（Samsung/SK/Micron）で**DRAM約90%**＋新興中国勢 |
| 需要の中心 | PC・スマホ（人の買い替え） | クラウド・AI・DC・車載（機械の処理量） |
| 取引形態 | **長期の取引関係はあったが、価格は1か月〜四半期（3か月）ごとに見直し**。市況悪化で即・値下げ圧力 | **HBMは価格・数量を年次（約1年）で決める契約が基本。**一般DRAM/NANDも長期化し、マイクロンの戦略的契約は通常5年・自動車向け3年＝**交渉間隔が12〜60倍に伸長**。価格は上限/下限のレンジ内で調整し、顧客に購入義務・メーカーに需要保証 |
| 在庫 | 通常8〜10週、悪化時に崩壊 | 低位で推移 |
| 設備投資 | 価格追随型・政府支援は限定的 | 政府補助＋長期計画型 |
| 技術ノード | 平面DRAM・2D NAND | DDR5・HBM・176層超3D NAND |

**残るリスク（反例として使用）**
- 中国勢（CXMT/YMTC）のシェア拡大による価格競争
- クラウド大手の投資縮小
- 代替技術（MRAM/ReRAM）※ただし現時点でDRAM/NANDを置換する規模・コストには未到達

**監視指標（視聴者に渡す物差し）**

### ⑤で使う数値（メモリ編）

**理由1：ボトルネックの移動**
- HBM＝3D積層SDRAM。TSVとマイクロバンプで高帯域・省電力・省面積
- Micron「AIシステムにおいてメモリが**戦略資産**へ変わった」
- BlackRock：AIインフラに必要な希少資源＝**memory, chips, data centers, power**
- 「メモリウォール」＝GPUがメモリからデータを待つ時間が大半

**理由2：推論時代の新需要層**
- TrendForce：**KV cache需要**と**CPU RAM／SSD POD需要**が新しいメモリ需要層を形成
- 役割分担：HBM＝帯域／DRAM＝主記憶・文脈保持／NAND・SSD＝容量・KV cacheのオフロード先
- 用途拡大：クラウド、エンタープライズ、自動車、エッジAI

**理由3：供給の時差**
- Micron：「顧客需要を満たせない」と認め、**2026年CapExを200億ドルへ増額**。装置発注の前倒し・クリーンルーム増設・広島DRAM投資
- Micron：**2026年供給分のHBMは、2025年12月時点で価格・数量とも合意完了**（※旧記述「2026年通期のHBMは契約完了済み」を更新）
- TrendForce 3Q26予想：**DRAM契約価格 前期比+13〜18%／NAND +10〜15%**
- Samsung：1Q26にメモリ事業が過去最高の四半期売上・利益。**HBM4の初期量産販売開始**
- SK hynix：AI需要による高付加価値製品販売増で過去最高業績

**理由4：国家間競争**
- **韓国**：2026年6月末に **5,760億ドル** 規模のAI・半導体プロジェクト。7/24〜25に SK Group×Nvidia **5,000億ドル超** のAIデータセンター/次世代メモリ構想、Samsung×Broadcom 最大 **2,000億ドル** 規模の連携
- **中国**：CXMTが **86億ドル** を調達し **7月27日に上海上場**（アジア最大級IPO）。CXMT/YMTCが価格決定力を強化
- **台湾**：TSMC元幹部を技術流出容疑で起訴（国家安全法・営業秘密法）。シリコンシールド
- **米国**：H200の対中出荷開始。商務省高官が追加規制を示唆
- **日本**：**2026年7月21日に「日本成長戦略」を閣議決定**（※旧記述「骨太方針2026」は**誤り**。内閣官房の名称は日本成長戦略）。Tower Semiconductorの日本事業は**総事業規模6,000億円超／日本政府の支援 最大約1,600億円／政府支援を除いたTower側の投資 最大30億ドル**（※旧記述「30億ドル投資・うち10億ドル政府補助」は**誤り**）。**Towerはメモリメーカーではなく、増強対象はシリコンフォトニクス・シリコンゲルマニウム・先端パッケージング**。台本では「メモリ工場への投資ではない」と明示すること
- **歴史**：日本のDRAM世界シェアは**1987年に約80%でピーク**／1986年 日米半導体協定／1987年 NANDフラッシュ発明（旧東芝・舛岡富士雄氏ら）・TSMC創業
  - **★衰退の原因を日米半導体協定だけに帰さないこと。**協定は要因の1つ。実際にはシェアのピークは協定の翌1987年で、その後に韓国勢の大型投資・PC時代への対応の遅れ・円高・メモリ価格下落・ファブレス／ファウンドリ型への移行が重なって進んだ
  - **★TSMCを「メモリの次の主役」と書かないこと。**TSMCはロジック半導体のファウンドリ。**メモリの次の主役はサムスン電子・SKハイニックスなど韓国勢**
  - **★「40年続く争い」は「メモリをめぐる争い」ではなく「半導体産業の主導権をめぐる争いが、形を変えながら約40年」**と書く（DRAM→ファウンドリ／ロジック→AI半導体・HBM・先端パッケージ・材料／装置）

- **2026年7月末、中国の国有企業が国産の液浸型DUV露光装置の製造を開始したと報道**
- 露光装置＝シリコンウエハー上に回路を焼き付ける装置。**先端分野はASMLが圧倒的**（※⑥-1の「EUV露光装置はASMLが世界で唯一」と整合。矛盾しない）
- **最先端のEUVではなく、一世代前の液浸型DUV**
- 計画：**2026年に約5台、2027年に約20台**。納入先は**SMIC／華虹半導体／CXMT**
- **★必ず添える留保**：装置を数台組み立てられることと、工場で安定稼働することは別。**解像度・重ね合わせ精度・処理能力（枚/時）・稼働率・歩留まりはいずれも未公表。**ASMLと同等になった、代替可能になった、とは**書かない**
- **本当の意味**：研究室の試作段階 → **実際の工場で検証する段階へ進んだ可能性**。実工場で回せば故障箇所・精度不足・処理速度・歩留まりの運転データが集まり、改良が回り始める。脅威は「2026年の5台」ではなく**改良し続けられる体制ができること**
- **露光装置だけではない**：エッチング／成膜／洗浄／熱処理でも中国企業が製品投入、一部は量産ライン採用済み
- **競合関係**：液浸DUVと直接競合するのは**ニコン・キヤノン**。間接的に東京エレクトロン（エッチング・成膜）、SCREEN（洗浄）、KOKUSAI ELECTRIC（成膜・熱処理）
- **時間軸の整理**：短期的に日本・欧米製をすぐ代替する可能性は低い。**中長期の構造的リスク**（中国市場でのシェア低下・価格競争激化）
- **7/28急落における位置づけ**：この報道**だけ**で暴落したのではない。AI設備投資への不安／高いバリュエーション／韓国市場の急落／メモリ需給懸念が重なる中に、**新たな悪材料として加わった**

> **★台本での使い分け**：②＝「なぜ装置・検査株まで10%超下げたのか」の説明に必要な最小限のみ。④の反例1（中国勢のシェア拡大）＝中長期リスクの本質（試作→実工場→改良の循環／露光以外の工程／ニコン・キヤノンが直接競合）。⑥-1の両刃（中国は日本の装置の大口顧客）＝ここに接続。
