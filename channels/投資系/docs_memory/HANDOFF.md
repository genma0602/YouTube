## 3. 執筆ルール（すべて厳守）

### ★1. 銘柄も相場も「方向」を語らない

- ○ 役割・事実：「キオクシアはNANDフラッシュメモリとSSDを作る会社です」「7月24日に9.49%下げました」
- ✕ 方向・推奨：「ここから上がります」「今が買い場です」
- **★これは個別銘柄だけでなく、相場・セクター・指数レベルでも同じ。パート間の橋渡しでも「上がる」と言わない。**
  - ✕「では、なぜここから上がると言えるのか」
  - ○「では、そもそもなぜ、世界はこれほどメモリを奪い合っているのか」
- **強気の論証パートは「値段が上がる理由」ではなく「需要・構造・必要性の理由」として立てる。**

### ★2. 各理由に必ず反例を内蔵する

強気の根拠を語っている最中に、反するように見える事実を自分から出して、その場で解釈する。現在すべての理由に内蔵済み。

### ★3. 「正直にお伝えします」は3回まで → **すでに上限到達**

②（金曜日の下げの承認）／⑦（日経優位の実績）／⑧（インフレなら株が上がるは正しくない）。**⑪では使わないこと。**

### ★4. 【要検証】は裏取り完了まで断定しない

現状は本文に書いたうえで、各セクション末尾に `> **【要検証】**` のメモを残してある。フェーズ1で全件処理すること。

### ★5. 文体

- 基本の心拍：**「ところが」（落とす）→「ただし」（戻す）→「つまり」（畳む）→「だからこそ」（動かす）**
- 「気のせいではありません／これは事実です」はデータで裏付く実感にだけ使う
- 番号での振り返り（「②で〜」）は不可。「さきほど」に統一
- 1文1行では書かない。**段落にまとめて、口で読める流れにする**

## 12. 競合・自チャンネルの設計原理（要点）

型の系譜は、競合「投資のすゝめ」→ 自チャンネルの高値更新型（13万再生）→ 今回。

### 投資のすゝめの原理（抽象化版より）

感情の旅程は **共感 → 転覆 → 論証 → 誠実 → 委譲** の5段階。論証だけでは動画にならず、**論証の前に共感と前提破壊、論証の後に自己批判と判断の返還**を必ず置く。

3つの心理レバー：**当事者化**（これは自分の話だ）／**知的更新**（自分は賢くなった）／**自己肯定**（自分は間違っていない）。

可変パラメータは1つだけ：**悪材料をいつ・どれだけ・何回見せるか**。視聴者の感情温度で決まる。今回は「痛み＋恐怖（過去のメモリ暴落）」なので、**冒頭側で悪材料を承認し、全編で反例を処理し続ける**配置。

### 高値更新型（自チャンネル）の8ルール

1. **承認ファースト**：強気を語る前に、不利な事実を自分から数字付きで先に認める
2. **不安は否定せず、共存させる**：「その警戒は正しい。警戒したままこう動ける」
3. **各理由に反例を内蔵**
4. **ネガティブ情報の多毛作**：信頼の担保→チャンスへの反転→後半の伏線
5. **抽象度が上がるほど数字を濃くする**
6. **二度目の不安**：最長パートの直前で疑いをもう一度代弁する
7. **処方箋は「既保有主軸別」で切る**（二重投資の視点）
8. **着地は一段ズームアウト**（資産全体の枠組みで返す）
