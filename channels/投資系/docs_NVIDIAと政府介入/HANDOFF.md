## 1. 企画の骨格

- **型**：イケガミ投資塾「中間選挙後の異常事態」（98万回）の形＋このチャンネルの企業分析（5社）
- **1本の線**：11月の株価を動かしたのは業績ではなく、お金を貸す側の不安。NVIDIAはAI産業の借金の保証人で、社長の辞任で貸す側の不安が強まり、復帰で和らいだ
- **たとえの世界は「商店街」1つ**（§6）。ほかの世界のたとえは持ち込まない
- **道具**：信用の上乗せ（企業が借りる金利＝国債の利回り＋信用の上乗せ）／お客さんの入る店（セクターローテーション）／借りて建てる側・自前で建てる側（＝保証人が要る側・要らない側）
- **主張**：政府は景気後退を防ぐために動いた。原則（政府は企業に口を出さない）を破った。税金は使っていない
- **視聴者**：個別株を持っている人が主。インデックス（積み立て）の人もいる。冒頭と⑬は「持ち株→積み立て」の順
- **企業5社**：高配当4社＋「インフレが落ち着くと期待できる銘柄」1社（ライオン）

## 6. たとえの対応（商店街）

| 言葉 | 意味 | 出る場所 |
|---|---|---|
| 商店街 | 株式市場 | ①⑥〜⑭ |
| 店 | 業種（⑥で「半導体の店、自動車の店、医薬品の店と、業種ごとに店が並んでいます」と定義）。②③では1つ1つの企業の意味でも使っている | 全体 |
| お客さん・人通り | 株式市場のお金 | ①⑥〜⑭ |
| 保証人の店主 | NVIDIA（フアン）。半導体の店にいる | ①（「1人の店主」とだけ言う）③⑥ |
| シャッターを下ろす | 黒字でも資金が回らず店が閉まる＝信用収縮・景気後退 | ②③⑭ |
| 町内会長 | 政府 | ②⑭ |

商店街以外の世界の言葉は「AI産業の中央銀行」（③・引用）と「ワシントンの割引」（⑤・引用）の2つだけ。

## 7. これまでの直しの要点（別のチャットで同じ提案を繰り返さないため）

1. **並べ替え**：1社目を住友電工から第一三共に。⑦の橋と各社の橋を書き直した
2. **通しのカット（約1,370字）**：④1907年を5文に／⑦ガソリンに届く順番と補助金／⑤「行き先は3つ」／1回しか使わない用語名（モラルハザード・逆資産効果・分割政府・ブロードニング・投資部門別売買動向）／企業5社の海外投資家を各1文に／第一三共の市販薬売却・住友電工の設備投資の配分・きんでんの教育施設／「借りて建てる側か、自前か」は第一三共で1回だけ言い切る
3. **通し点検の直し（48か所）**：説明なしの語に説明／①に約束／②に前向きな文を先出し／③保証人が企業か人かの説明と、上乗せの物差し（100億円なら利息が年4,200万円増える）／上乗せは「大きくなる・小さくなる」に統一／⑥人通りの食い違い／⑦方向の言い切りを事実の言い方に／⑧⑨⑩に視聴者の気持ちを受ける文／⑪で配当利回りの回収／⑫事業利益の説明／公聴会の日に見るものを⑤⑬⑭でそろえた
4. **①の書き直し**：サムネに合わせた入り、認めてから安心、保証人は言わず「1人の店主」、事実を2段落に分けて「ところが」×2、数字を減らした
5. **11月25日の大引けを反映**：①に「3,000円下がったと思ったら2,200円戻し、また1,600円売られました」、⑥に11/25の段落、⑬に「AIへの不安そのものも残っていて〜」
