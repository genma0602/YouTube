**④の言い方（確認済みの事実に基づく）**

- 似ているのは入り方（景気が強く、物価が上がり始めたところで先回りして上げた）。分かれ道は、外からのショック（原油）が重なるかどうか → ⑩(c)

## 6. 金利の仕組み（②で使用済み・⑩の説明素材）

| 項目 | 台本で使った／使う言い方 |
|---|---|
| 金利は株のライバル | 国にお金を貸すだけで年3%が入る時代。就活でライバル会社が給料を上げてきた（②済） |
| 政策金利／長期金利 | 政策金利＝銀行どうしが1日だけ貸し借りする金利＝「今日のお金の値段」（日銀が決める）。長期金利＝10年ものの国債の利回り（市場＝銀行・生保・年金・海外投資家が決める。投資信託を通じて僕たちのお金も）（②済） |
| 国債が売られると金利が上がる | 去年1%で預けた定期預金の権利をいま売るなら値引きが要る（②済） |
| 市場は先回りする | 上げすぎ→投資と消費が弱る→景気悪化→物価が落ち着く→数年後に利下げ、と読めば10年金利は下がる。政策金利＝現在の金利、長期金利＝先の予想（②済・ユーザー案） |
| ただし | 物価への警戒・国債の買い手不足・国の借金への不安で、利下げ予想でも長期金利は上がる（②済） |
| 実質金利 | 金利−物価の上がり方。政策金利1.25%と物価1.5〜2%でゼロかマイナス。下りのエスカレーターを歩いて上る（③済） |
