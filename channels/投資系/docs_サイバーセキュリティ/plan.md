### ① サイバーセキュリティが、AI投資の最後の主役になるかもしれません（1,000字・0〜4.9%）

**冒頭8要素を全部入れる。①には出典名も社名も置かない（TOPIX 3-b）。法律名は出典ではないので可。**

**★10/7 ユーザー指示で希望ファーストに変更。** 法律から入ると入口が「怖い話」になるため、1行目を希望に置き、**その直後に大企業の情報漏洩の一言**を入れる。光電融合の①（「日本株がさらに上昇するかもしれません」）と同じ形。
- **「銘柄が上がり続ける」とは書かない**（方向の断定）。主語を値段ではなく役割に置いて「主役になるかもしれません」にする
- **「直近で」は使わない**（相対的な時間表現。動画の寿命を縮める）。時間の言葉なしで「止まりません」と現在形で言い切る

1. **希望**：サイバーセキュリティが、AI投資の最後の主役になるかもしれません。半導体やデータセンターと同じように、AIを動かすために欠かせないものとして見られ始めている（**希望語2つをここで使う**）
2. **★事実＝大企業の情報漏洩が止まらない（一言）**：アプリの会員情報、予約サイトの個人情報、社員のメール。一度で1,000万件を超える漏洩も出ている（**社名は出さない。数字は1つだけ**）
3. **視聴者の状態**：この流れは株式市場にも出ていて、関連する日本の企業の株が**一日で9社そろってストップ高**になった。何が起きているのか分からないまま終わった方もいる
4. **迷いの二択**：もう上がってしまったから見送るのか、それでも今から見ていくのか
5. **決着宣言＋結論先出し**：この動画で決めます。答えはどちらでもありません。**上がった順に追いかけるのではなく、攻撃のどの工程を守っている企業かで分けて見る。** それが第三の道です
6. **不利な事実＋承認**：一日でストップ高が9社並ぶような値動きは、普通ではありません。急いで買ってください、という話をするつもりはありません
7. **目次（品書き・数だけ）**：攻撃がどういう順番で起きているか／**会社四季報の秋号と決算資料をもとに、まず3社**／見るべき数字が3つ／**残りの6社。合わせて9社**
8. **約束**：見終わるころには、ニュースで企業の名前が出たときに、その企業が攻撃のどこを守っているのかで見分けられるようになります

> **★10/7 ユーザー指示：2026年10月1日の法律の段落は①から削除した。**①では法律に一切触れない。
> → **⑥-1は「①で予告済み」の前提で書かない。** 制度の名前と中身を、初めて出す事実として1から説明する。いちばん強い事実を中盤まで使わずに取っておく形になる。
> → ①の伏線は「9社」「見るべき数字は3つ」（→④⑨⑧）と、約束の1文だけ。
> ★「最後の主役」「欠かせない」は⑪の再定義（半導体→データセンター→電力→通信→セキュリティ）の予告。**⑪で全部を並べ直すので、①では2つだけに留める。**

- **反転**：ただ、支出が増え始めたのは、あの日ではありません。警察庁が2026年9月に公表した資料では、**2026年上半期のランサムウェア被害は123件で、半期としては過去最多**。**被害の約6割が中小企業**で、**業種でいちばん多いのは製造業**。あやしいアクセスは**1日・1つのIPアドレスあたり13,687件**で、前の年の同じ時期より**50.7%増**
- **種明かしの予告**：増えているのは件数だけではありません。**同じ資料の中に、生成AIを使ってランサムウェアを作る手口が確認された、と書かれています**

### ③ 攻撃は、どういう順番で起きているのか（2,200字・11.8〜22.5%）★前提知識

**いちばん離脱しやすいブロック。小見出しを3つ入れて割る。** 教科書に「3社がなぜその数字なのかを知るため」という目的をつけた状態で聞かせる。

#### 3-1. 侵入から恐喝までは、6つの段階に分かれています
偵察 → 侵入 → 強い権限を奪う → 社内を横に移動する → データを探す → 外へ持ち出す。そのうえで暗号化して「元に戻したければ払え」（**ランサムウェアの定義はここで1回だけ**）。
最近は暗号化すらせず、**「データは盗んだ。公開されたくなければ払え」**だけのものもある。
→ **用語を説明したら、その場で日本企業名に降ろす**：アサヒグループホールディングスでは、約10日前から社内に侵入され、管理者の権限を奪われ、受注・出荷・物流・経理・決算業務まで影響した。工場の生産は10月2日までに再開（ロイター）。**攻撃者が主張した流出量（9,300超のファイル・約27GB）は、会社側が確認したものではない**

#### 3-2. 払っても、戻ってくるとは限りません
JIPDECの2026年の調査。国内1,107社のうち**507社が被害を経験**、**222社が支払い**、そのうち**復旧できたのは83社**。
→ だから企業にとって、この支出はIT費ではなく**事業を止めないための支出**になった。山一電機（海外子会社のサーバーが暗号化され、ログまで消されて侵入経路が特定できなくなった）／コタ（決算の確定と監査が遅れた）を1行ずつ。
※マイナスを言いすぎない：**被害の列挙はここで閉じる。**④以降では被害企業の名前を出さない

#### 3-3. AIが入ると、1人が攻撃できる会社の数が増えます
②で予告した警察庁の資料を回収。**生成AIでランサムウェアを作る手口のほか、入り込んだ端末の情報をAIに送り、利用者が何もしなくても不正な命令を実行させる新種も確認された**。
Anthropicの実験。AIに専用の道具を持たせたところ、**試した10のネットワークのうち5つに完全に侵入し、4つに部分的に侵入**した。**道具を与えなければ、ほとんど失敗した**。つまり危ないのは賢いAIがあることではなく、**AIと道具と権限がそろうこと**。
2025年9月、Anthropicは約30の組織を狙った攻撃を検知し、**作業の80〜90%をAIが実行していた**と公表した。
→ **橋**：「この6つの段階のどこを守るかで、会社の性格はまったく違います。まず、入口を守っている3社を見ます」

> 伏線：「AIと道具と権限」→⑤で回収（AIに権限を渡す話）。「6つの段階」→⑨の並び順で回収。
> 行動指示：「ご自分が使っているサービスから、同じ形の連絡が来ていなかったか、あとで確かめてみてください」

**TOPIX版④と同じ型。** 1社あたり1,000〜1,200字。**株価は2026年最初の取引日である1月5日の終値と、収録日前日の終値を比べる（冒頭に1回だけ断る）。**

**入り**（予告を受け直す）：
> 「さきほど、入口を守る3社があるとお伝えしました。その3社を見る前に、見方を1つだけ足します。**攻撃が増えたから売上が増える、という会社ではありません。** 見るのは、**会社が毎年、予算をつけ続ける場所にいるかどうか**です。セキュリティは、去年入れたものを今年やめる、という使い方をしません。だから、続けて入ってくるお金が伸びているかが先に来ます。数字は、**会社四季報の秋号**と、各社の決算資料からです」

#### 4-1. パスワードを盗まれても入れない：ソリトンシステムズ（3040）

#### 4-2. ウェブサイトの入口で止める：サイバーセキュリティクラウド（4493）

### ⑤ AIが増えるほど、守らなければいけないものが増えます（1,800字・39.2〜48.0%）★理由1

- ③の「AIと道具と権限」を回収。**企業がAIに仕事をさせるには、AIに権限を渡さなければいけない**。メールを読む、ファイルを開く、社内のデータを見る、プログラムを動かす
- つまり、**守る相手が人間の社員だけではなくなる**。社員のアカウントが乗っ取られるより、権限を持ったAIが乗っ取られるほうが被害が大きくなる可能性がある
- 守る側もAIを使う。あやしい通信を探す、被害の範囲を調べる、直し方を考える、修正を当てる——この流れがそのまま新しい市場になる
- **日本の話に降ろす**：ソフトバンクグループとOpenAIは2026年6月16日、日本向けに**弱点を見つけて修正まで自動で行うサービス**を発表した。孫正義氏は「高度なAIを使ったサイバー攻撃は、広く行われるようになる」と話している
- **市場の数字（3つまで）**：AIを使ったサイバーセキュリティは**2026年の約7兆円から、2034年に約33.7兆円**（Fortune Business Insights）。全体の市場は**約39.3兆円から約110.6兆円**。**AIの部分だけが、全体より速く伸びる**。IDCは、世界のセキュリティ支出が**年率12%を超えて伸び、2028年に約59.6兆円**になると見ている
- **反例は1つだけ**：OpenAIやマイクロソフトのような会社が、この機能を自分たちのAIに標準で付けてくる可能性はあります（⑦と⑩へ渡す）
- **橋**：「ここまでは世界と、会社の話です。では、国はどうなのか」

> 希望語：追い風／欠かせない／主役（3回）
> ★**理由パートの主役をアメリカの会社にしない。** OpenAI・Anthropicの話は手短に、日本の支出に着地させる（AI半導体版が落ちた原因）

### ⑥ 10月1日から、国が守り方を変えました（1,600字・48.0〜55.9%）★理由2

**丸ごと日本。主語を日本にする。**
**★10/7 指示で、法律は①から外した。** ⑥-1が**この法律の初出**になる。「さきほどお伝えした法律」のような受け方をせず、制度の名前と中身を1から説明する。いちばん強い事実を中盤まで取っておく形。

#### 6-1. 攻撃される前に止めにいく制度ができました
**2026年10月1日に施行された「サイバー対処能力強化法」**（正式には「重要電子計算機に対する不正な行為による被害の防止に関する法律」）。2025年5月16日に成立し、1年以上かけて準備されてきた。
中身は3つ。**通信の情報を取得して分析する／攻撃の兆候が見えた段階で、実行される前に無害化する／警察と自衛隊が、独立した第三者機関の承認を得たうえでその措置を行う**。
重要インフラの事業者には、**攻撃を受けたときの報告が義務になる**。
→ つまり、**セキュリティが会社の判断でやる「対策」から、制度で求められる「義務」に変わった**。義務になった支出は、景気が悪くなっても削りにくい

#### 6-2. 国家が相手だと、作っている国まで問われます

## 7. この企画の執筆ルール（CLAUDE.mdに加えるもの）

### 使ってよい語／言い換える語

| ✕ そのまま使わない | ○ 言い換え |
|---|---|
| WAF | ウェブサイトの入口で不正な通信をはじく仕組み |
| SOC / XDR / MDR | 24時間、社内の通信を見張る／侵入されたあとに気づく仕組み |
| Identity Security / PAM | この人は本当にアクセスしていいのかを管理する仕組み／強い権限を厳しく管理する仕組み |
| Zero Trust | 社内だから安全とは考えず、毎回本人を確認するやり方 |
| Attack Surface | 攻撃される入口の数 |
| Platformization | 1社にまとめて任せる動き |
| ARR / NRR | 続けて入ってくる契約のお金／既存のお客さんが前の年より何%多く払っているか |
| Endpoint | パソコンとサーバー |
| エクスプロイト / 横展開 | 弱点を突いて入る／社内を横に移動する |
| 無害化 | （法律の言葉なので1回定義して使う。「攻撃が実行される前に止める」） |
| ランサムウェア | （初出で1回定義。ニュースで聞く語なので、そのまま使う） |
| 二重恐喝 | （定義だけ置いて、本文は「データを人質に取る」で通す） |
| インシデント / 脆弱性 | 事故／弱点（「脆弱性」は漢字で意味が通るので**1回定義すれば使ってよい**） |

### この企画の禁止項目

- **「会社」ではなく「企業」で書く**（2026-10-04 の指示。**会社四季報だけ例外**）。このプランの文案は「会社」で書いてある箇所があるので、**本文に起こすときに全部「企業」へ直す**。「会社が毎年予算をつける場所」→「企業が毎年予算をつける場所」、「日本の会社」→「日本の企業」。書いたあと `grep -n "会社" scenario_draft.md | grep -v "会社四季報"` で点検する
- **方向の断定をしない**。「上がります」「買い場」「仕込み時」は使わない（TOPIX版で2か所だけ許可された「ねらい目になるかもしれません」を使うかは§8の判断事項）
- **たとえ話は0〜1個まで**。素材にある「防犯カメラも警備員も全部ALSOKやSECOMに任せる」は、使うなら**⑧-2で1回だけ**。使わない選択でよい
- **海外の会社には役割を1語添える**（「アメリカ最大のサイバーセキュリティ企業、パロアルトネットワークス」）。日本に同業がないので「日本でいえば」は付けない
- **被害企業の列挙は③に閉じる**。④以降では被害企業の名前を出さない
- **相対的な時間表現を使わない**。「先週」「今月」は不可。「2026年10月1日に施行された」「2026年上半期」のように**年月付きの事実**にする
- **数字を羅列しない**。ストップ高9社の騰落率は並べない。「一日で9社がストップ高」と構造で言う。1パートで新しい数字は3つまで
- **マイナスを言いすぎない**。「ただし」の反例は1ブロックに1つ。弱気シナリオは⑩の「見方を変える条件」に1か所だけ
- **PER・EPSの定義を説明しない**。1文の言い換えまで
- **前作に言及しない**。半導体・電力・通信の話は「見てきて」ではなく「AIを動かすために必要なもの」として本文内で自己完結させる。過去動画への誘導は⑪に1文だけ
