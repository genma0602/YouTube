## 3. この企画の背骨（`deck.css` の追加）

### 3-a. 3条件ボード（**このデッキの背骨**）

```
［供給は止まったか］［利益の裏付けはあるか］［信用は壊れたか］
```

3枠を横に並べ、点検が終わった枠に「立っていない」を付けていく型。**④で初出 → ⑤⑦⑨の締めで1枠ずつ埋まる → ⑪で選挙を当てる → ⑱で毎日見る3つに置き換える**。全部で約8枚。

- 過去の暴落（1973／2000／2008）は「立った」枠を赤、2020／2025は全部灰
- ⑱の「見るのは3つ」では、枠の中身を「原油／長期金利／持ち株の通期予想」に差し替える

### 3-b. 戻るまでの時間の横棒（④と⑱で同じ図）

1973 7年7か月／2000 7年3か月／2008 5年5か月／2020 6か月／2025 4か月。**下げ幅ではなく時間で並べる**ので、横軸は年。下げ幅は棒の横に小さく。

### 3-c. 鎖のフロー（③⑤で使う）

原油 → 物価 → 金利 → 利益 → 株価。`t-flow` で5段。株価がいちばん右（いちばん後ろ）。

### 3-d. 企業4社の型（TOPIX・サイバーと同じ）

役割の1枚 → 数字の山場（大きな数字1つ）→ 中身の分解 → 注意 → 四季報 → 目標 → 株価 → 次の決算日。**冒頭の1枚に社名と証券コードを大きく**（8031／6383／4681／8306）。

### 3-e. 見出しの上余白（サイバー版の落とし穴）

`t-cards` `t-vs` `t-stats` は `padding-top` を足す（76／74／76px）。

## 5. 守ること

- **スライドに「上がります」を書かない。**⑫の見出し「だから、上がり続けると言えます」は本文どおり出すが、図に矢印の上向きを付けない
- **年初来の勝ち負けを1枚に並べない**（⑯の4社比較はPERだけ。騰落率の棒は作らない）
- 本文で普通の言い方に直した用語（感応度・キャッシュフロー・運転資本・持分法・粗利益）を、**スライドで元の専門用語に戻さない**
- 本文に無い数字をスライドに足さない。出典は各スライドの下に小さく
- 法律名・制度名（CARES法・TARP・BTFP）は出さない
- 「信用スプレッド」は使わない（「企業が借りるときの上乗せ金利」）

- `_parts/gen.py` に型ごとの関数（text / metric / metrics / vs / cards / stats / flow / steps / numline / prop / stack / rank / port / board / recovery / section / closing）。各パート `pNN.py` は中身だけを書く
