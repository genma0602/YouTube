## 1. なぜ先にイラストを作るか

この台本は、**部材の流れ（＝CPOの作り方）を2回歩く**構成になっている。

言葉だけで2回説明すると、⑥が「さっき聞いた話」に聞こえる。
**③で地図を1枚見せ、⑥では部材そのものの絵で工程を歩く。**地図は⑥では3回だけ戻す（いま全体のどこにいるかの確認）。
部材は、言葉（ガラスの土台／光の通り道／光ファイバーの束／つなぎ口）を聞いても形が浮かばない。**絵で形が分かれば、⑥の3,370字が「知っている物の話」になる。**

## 2. 絵のタッチ（ここが今回の変更点）

### 描き方

| 項目 | 決めたこと |
|---|---|
| 形式 | **手書きのインラインSVG**（ラスタ画像は使わない。スキルの「画像不使用・自己完結HTML」を守る） |
| 立体感 | **斜め見下ろしの立体で描く。**真横・真上の断面は、断面そのものが主題のときだけ（ガラスの土台の縦穴／光ファイバーの束の断面） |
| 線と面 | 輪郭は navy の細線、面はパレットの淡い面（白・`--graybox`・`--bluebox`）。**光だけ `--orange`**。影は `style.css` の `--shadow-sm` と同じ弱さ。**新しい色・トーンは足さない** |
| ラベル | **絵の外に引き出し線で出す。**絵の中に長い文字を入れない（絵が図表に戻ってしまう） |
| 描かないもの | キャラ・マスコット・人物・手。工場や建物のミニチュア。写実的な質感（金属光沢・反射）。新しいたとえ話 |
| 例外 | ③の自動車のたとえ（本文にある）だけ、車のシルエットを描いてよい |

### 部材を「形で分かる」ように描く（ここが本番）

| 部材 | 絵 |
|---|---|
| レーザー | 小さな箱から、細いオレンジの光の筋が1本出る |
| 光変調器 | その光の筋が、通ったあとで点線（点滅）に変わる |
| ガラスの土台 | 厚みのある透明な板。細い縦穴が等間隔に並び、穴の中に配線が通る |
| 光の通り道 | 板の上を曲がって走る1本のオレンジの溝。端でレンズに向く |
| 光ファイバーの束 | 断面＝大きな円の中に小さな円が整列。側面＝束ねたケーブルが広がって並ぶ |
| つなぎ口 | コネクタの形。四角い口が並び、面積の違いが大小で分かる |
| 受光部品 | 光の筋を受けて、出口が波形（電気の信号）に変わる小箱 |
| 光エンジン | スイッチのチップの隣に並ぶ、小さなブロックのまとまり |
| 反り | 板が湾曲する。矢印は「変形の向き」だけ（値動きの矢印ではない） |
| 検査 | 測る線が上から当たり、良品と不良が分かれる |

### 守るルール（スキルとHANDOFF §14-c）

- 文字は1280基準で**20px以上**、ストロークは**2px以上**（PNGは1.5倍に拡大されるため）
- 図の中の語は**本文の表記どおり**。「会社」ではなく「企業」
- 出さない語：ASIC・Tbps・PIC・EIC・RDL・SerDes・DSP・LPO・シリコンフォトニクス・ウエハー・InP・EML。海外社名はNVIDIA・ブロードコム・TSMCのみ
- 数字は**本文に出ている数字だけ**
- **工程が進む矢印は可。株価・値動きの矢印と「買い」の文言は不可**
- 証券コードは図に入れない。**新光電気工業にはコードを付けない**（非上場）
