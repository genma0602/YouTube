## 3. この企画だけの決まり

### 3-a. 7社の紹介は台本の順番のまま

社名とコード → 何をしている企業か → 決算 → なぜ伸びるか → 何が売れているか → 海外・計画 → 財務 → テーマとの関係 → 海外の投資家・証券会社の評価 → 株価 → 次の決算 → 次への橋。

- 社名のスライド：**7社とも画像が社名を出すので、画像がこの1枚を兼ねる**（🖼13・21・23・25・27・29・32）。`numviz t-metric` の社名スライドは作らない
- 財務は `t-stats` 1枚（自己資本比率・現金・ROE・PER・PBR・配当利回り）＋ 株価は `t-stats` 1枚。**株価は年初来の推移を先に出す**
- 証券会社の目標株価は本文が言っているので出してよい。ただし並べるだけにし、「上がる」方向の見出しは付けない
- 四季報の独自予想の数値は出さない（本文にも無い）

### 3-b. ネタバレしない

- **①に社名を出さない。**「7社を解説します」は数だけ。①の「巨大IT企業の幹部」にMetaの名前を添えない（名前が出るのは⑦の🖼11）
- ②の「この日に株価を上げた企業」「営業利益が約6割増えたのに年初来安値をつけた企業」に社名を添えない（三菱電機は⑬の最後、IIJは⑰で明かす）
- ⑥の「日本のある空調の大手」にダイキンの名前を添えない（⑭で明かす）
- ⑦の最後の「計算を動かす工程を受け持つ企業」にIIJの名前を添えない
- ⑫の「ある通信の企業」にIIJの名前を添えない（🖼22は「通信企業」なので問題なし）

### 3-c. ドルと円

本文どおり円で出す。ドルは本文が最初に言うときだけ小さく添える（例：⑤「800億ドル（およそ12.6兆円）」）。ユーロは④の「130億ユーロ（2兆円超）」だけ。
