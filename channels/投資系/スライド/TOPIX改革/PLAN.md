## 7. 台本との対応を崩さないための決めごと

- **1スライド＝1ビート。** 台本の1段落を2〜3枚に割るのは可。2段落を1枚にまとめるのは不可（情報密度が落ちる）
- **ネタバレしない。** ①で社名を出さない／②で3社の数字を出さない（社名と一言だけ）／③で株価を出さない／⑤で⑥の道具の結論を出さない／⑦の各社のフッターに他社の数字を書かない
- **台本の順序を変えない。** 前提→具体→結果の順を守る
- **数字は台本のまま。** 桁・出典の固有名詞を変えない。台本に無い数字を足さない
- **企業／会社の表記**：台本は「企業」で統一済み（固有名詞の会社四季報・証券会社・運用会社・親会社・子会社・会社予想だけ「会社」）。スライドも同じ

### 行があふれていないかの自動チェック

```bash
cd スライド/TOPIX改革
python - <<'EOF'
import re, glob, io
LIM = {'stmt':22, 'h-main':25, 'big':13, 'lead':42, 'note':46, 'ctext':22, 'ctitle':12, 'strong':20}
strip = lambda s: re.sub(r'<[^>]+>','',s)
for f in sorted(glob.glob('_parts/p*.html')):
    html = io.open(f, encoding='utf-8').read()
    for m in re.finditer(r'<div class="([a-z-]+)"[^>]*>(.*?)</div>', html):
        cls, body = m.group(1), m.group(2)
        if cls not in LIM: continue
        for seg in re.split(r'<br\s*/?>', body):
            txt = strip(seg).strip()
            if len(txt) > LIM[cls]:
                print(f'{f}:{html[:m.start()].count(chr(10))+1} {cls} {len(txt)}字 {txt[:50]}')
EOF
```

※ `h-main` `lead` `note` は2行に折り返しても成立するので、数字が上限を数文字超える程度なら直さなくてよい。**`stmt` と `big` だけは必ず直す。**

**`t-steps` は別に数える**（`.v` の行数が箱の高さを超えるとフッター帯を突き抜ける）。

```bash
python - <<'EOF'
import re, glob, io, unicodedata
w = lambda s, fs: sum(fs if unicodedata.east_asian_width(c) in 'WF' else fs*0.55 for c in s)
MAX = {'s1':1, 's2':2, 's3':3}
for f in sorted(glob.glob('_parts/p*.html')):
    html = io.open(f, encoding='utf-8').read()
    for m in re.finditer(r'<div class="step (s[123])">(.*?)</div></div>', html):
        vm = re.search(r'<div class="v">(.*?)</div>', m.group(0))
        if not vm: continue
        segs = [re.sub(r'<[^>]+>','',s).strip() for s in re.split(r'<br\s*/?>', vm.group(1))]
        n = sum(max(1, -(-w(s,50)//264)) for s in segs)
        if n > MAX[m.group(1)]:
            print(f'{f} {m.group(1)} {int(n)}行(最大{MAX[m.group(1)]}) {segs}')
EOF
```

※ `.c-v` `.r-v` `.mfig` は `white-space:nowrap` でカードのほうが横に伸びるので、長くても折り返さない。チェック結果に出ても無視してよい。
