## 3. この企画だけの追加（`deck.css`）

### 3-a. `lagline`＝注文が利益に変わるまでの時間差（**このデッキの背骨**）

この台本の背骨は「**注文は、いちばん先に動く数字。ただし利益になるまでに時間がかかる**」。④で「受注残は利益ではありません」と出して、⑤で芝浦機械の実物を見せ、⑬で2社に当てはめ、⑮で回収する。その流れを1本の帯にする。

```
［注文が決まる］→［部材・仕掛品］→［作る・納める］→［検収］→［売上］→［利益］
```

```css
/* 注文→利益の時間差。.on でいまどこを通過しているか、.done で通過済み */
.lagline{display:flex;gap:10px;justify-content:center;align-items:stretch;}
.lagline .lg{flex:1;padding:18px 6px;border-radius:14px;background:#eef2f7;color:#7c8798;
  font-size:28px;font-weight:800;text-align:center;line-height:1.25;}
.lagline .lg .n{display:block;font-size:20px;opacity:.75;margin-bottom:6px;}
.lagline .lg.done{background:#123a66;color:#fff;}
.lagline .lg.on{background:#e8732a;color:#fff;}   /* いま通過中 */
```

- **出る場所は8枚**：④16（初出・社名なし）／⑤19（芝浦機械＝通過中）／⑤21（現金に出た形）／⑫4（注文の残り）／⑬22（栗田）／⑬39（オルガノ）／⑬44（2社とも同じ形）／⑮3
- 6枠なので1枠あたり約190px。**6文字で折り返す前提**。折れたら `font-size` を24pxに下げる
- **最初に作るのはこの1枚**（④16）。8枚に効くので、形が決まらないと後が全部やり直しになる

### 3-b. `fourcheck`＝追うのは、4つだけです

⑫で視聴者に渡す道具。**⑫が初出。⑤より前には出さない**（台本の順序。⑤の時点ではまだ渡していない道具なので、先出しするとネタバレになる）。

```
［注文の残り］［売上に変わったか］［営業利益率］［PER］
```

```css
/* 追う4つ。.ok=増えている .wait=まだ .ng=下がっている */
.fourcheck{display:flex;gap:14px;justify-content:center;align-items:stretch;}
.fourcheck .fc{flex:1;padding:22px 10px;border-radius:14px;background:#eef2f7;color:#7c8798;
  font-size:30px;font-weight:800;text-align:center;line-height:1.3;}
.fourcheck .fc .n{display:block;font-size:20px;opacity:.75;margin-bottom:8px;}
.fourcheck .fc .s{display:block;font-size:22px;font-weight:700;margin-top:10px;}
.fourcheck .fc.on{background:#123a66;color:#fff;}
.fourcheck .fc.ok{background:#1f7a4d;color:#fff;}
.fourcheck .fc.wait{background:#e8732a;color:#fff;}
```

- **出る場所は6枚**：⑫3（全体図・初出）／⑫8（4つ揃った）／⑬44（2社とも同じ形）／⑬45／⑮4
- 4枠なので1枠あたり約290px。`.s` に「増えている」「まだ」などの状態を入れる
- **⑬44 で `lagline` と `fourcheck` が両方出る**ので、1枚に詰めず2枚に割る

### 3-c. 見出しの上余白（光電融合・サイバーで踏んだ落とし穴をそのまま持ち込む）

`t-cards`(76px)・`t-vs`(74px)・`t-stats`(76px) の `padding-top` を上げる。`t-fx` は必ず `numviz t-fx` で使う（単独は見出しが隠れる）。

## 5. 守ること（HANDOFF §5 をスライドの運用に落とす）

| | ルール | スライドでの意味 |
|---|---|---|
| 1 | **指数・相場の方向は言い切ってよい**（今回だけの例外） | ①⑪⑮で「上がり続ける」「10万円も届く」と書いてよい |
| 2 | **個別株の方向は言わない** | 3社のスライドに上向きの矢印・「割安」「買い場」「狙い目」を作らない |
| 3 | **為替の方向は言い切らない** | ⑧の円高は「可能性」のまま。断定の矢印にしない |
| 4 | **数字は本文のまま** | 丸めた言い方（4割半／1割半／9割近く）を実数に戻さない |
| 5 | **ドルは必ず円を添える** | 1ドル150円。⑤26で前提を宣言するスライドを必ず置く |
| 6 | **「会社」ではなく「企業」** | 会社四季報だけ例外 |
| 7 | **番号の点呼をしない** | 「1つ目／2つ目」ではなく「まず／それから／そして」 |
| 8 | **工作機械を指数の利益の材料にしない** | ⑪に受注残1兆円を出さない。⑫⑮は「先に動く数字」として扱う |
| 9 | **ネタバレしない** | `foot-bar`/`note` に後のスライドの数字を書かない（10万円の距離は⑪が初出、4つの数字は⑫が初出） |
| 10 | **騰落率の一覧スライドを作らない** | 3社を並べて比べる表を作らない（勝ち負けに見える） |
