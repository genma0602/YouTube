## 3. この企画だけの追加（`deck.css`）

### 3-a. `stagemap`＝攻撃の6段階の帯（**このデッキの背骨**）

6つの段階を横一列に並べ、その企業が守っている段階だけを色で立てる型。**③で初めて出して、9社それぞれの2枚目と、⑨の締め、⑩-1で使い回す。**全部で **15枚**に出る。

```
［調べる］［入る］［権限を奪う］［横に動く］［探す］［持ち出す］
```

```css
/* 攻撃の6段階の帯。.on で守っている段階を立てる */
.stagemap{display:flex;gap:10px;justify-content:center;align-items:stretch;}
.stagemap .st{flex:1;padding:18px 6px;border-radius:14px;background:#eef2f7;color:#7c8798;
  font-size:30px;font-weight:800;text-align:center;line-height:1.25;}
.stagemap .st .n{display:block;font-size:20px;opacity:.75;margin-bottom:6px;}
.stagemap .st.on{background:#123a66;color:#fff;}
.stagemap .st.on2{background:#e8732a;color:#fff;}   /* 同じ段階の別のやり方（カウリス） */
```

- 6枠なので1枠あたり約190px。**4文字（権限を奪う＝5文字）で折り返す前提**にする。折れたら `font-size` を26pxに下げる
- 「工程ではない」企業（デジタルアーツ＝守る相手／ZenmuTech＝持ち出すの先）は、**6枠の外側に注記**を置く。枠を増やさない
- トレンドマイクロは**6枠すべて `.on`**

### 3-b. 見出しの上余白（光電融合で踏んだ落とし穴をそのまま持ち込む）

```css
.t-cards{padding-top:76px;}
.t-vs{padding-top:74px;}
.t-stats{padding-top:76px;}
```

`t-cards`(48px)・`t-vs`(50px)・`t-stats`(58px) は中身が上寄せで `padding-top` がそのまま開始位置になるため、**見出しがヘッダー帯（53px）に食い込む**。`t-text`・`t-flow`・`numviz`・`t-agenda`・`t-numline`・`t-steps` は縦中央寄せなので対象外。

## 10. 作ってから直した点（2026-10-08・生成時の記録）

機械点検（`_parts/check.py`）が挙げた17件を直した。**次に同じ型を作るときの注意そのもの。**

1. **社名の `mfig` は、文字数でサイズを変える。**箱の内寸はおよそ960px。108pxのままだと13文字の社名（サイバーセキュリティクラウド／ブロードバンドセキュリティ）が**途中で改行されて社名が割れる。**実績：カウリス120／ZenmuTech 108／デジタルアーツ100／FFRI・セキュアヴェイル・トレンドマイクロ92／ソリトン84／13文字の2社62
2. **`t-vs` の `.big` は内寸414px（9文字）。**超えると勝手に折り返して変な位置で切れるので、**`<br>` で折る位置を指定する**（7か所）
3. **`t-fx` の1行は1200pxまで。**`.r-v` は58pxで nowrap なので、10文字の結果（1割を超えるマイナス）は `font-size:50px` に下げる
4. **`t-steps` の `.v` は内寸264px。**「19億5,000万円」は40pxまで下げる
5. **`t-title` の `.big`（74px）は1行12文字まで。**`<br>` を2か所入れて3行にした
6. **9社マップの `.co` も、社名は `<br>` で折る**（ブロードバンド／セキュリティ、サイバーセキュリティ／クラウド）
7. **`t-cards` は4枚まで問題なし。**4枚でも文字は潰れない（1枚273px）

**`convert.py` は3桁連番に変えてある**（`slide_001.png`〜）。スキルの元ファイルは2桁なので、100枚を超えるデッキでは編集ソフトの並び順が狂う。

**HTMLコメントの番号は、PNGの番号と一致させてある**（`<!-- 001 … -->` 〜 `<!-- 301 … -->`）。直したいスライドは、PNGの番号でそのまま検索できる。
