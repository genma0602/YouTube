## 0-b. 改稿3（10/3夜）：②以降を「作り方の順番」で組み替える

**忖度なしの判断**

## 4. 用語の方針（難解な部品名・専門用語を極力使わない）

- **定義して使い続けるのは2語**：「光電融合」（①の2文目で定義）「CPO」（②の冒頭で定義）。以後は「チップの隣に光を置く技術」か「CPO」。ほかに②で定義した語：スイッチ・IOWN・部材
- **★「部材」と「部品」の使い分け（10/3ユーザー指摘。素材は日本の強みをすべて「部材」と書いている）**：**部材**＝日本の会社が納める側の物（ガラスの土台・光の通り道・レーザー・光ファイバーの束・大型パッケージの材料）。②で「装置を作るのに欠かせない材料や土台、つまり部材」と1回定義。**部品**＝装置の中のできあがった物（光トランシーバー・光に変える部品・光の部品）。「日本の強み」「どの会社を持つか」の文脈は必ず部材。「部品」と言うとアメリカの装置メーカーと同じ土俵に聞こえる
- **★部品の名前は、「それが何か」を1文添えるなら入れてよい（10/3ユーザー指示）。**初出で名前＋説明、以後は役割の言葉で受ける。②で出した名前：光トランシーバー（装置の前面にある差し込み式の部品）／TGVガラス基板（ガラスに細い縦穴を開けて配線を通した、チップを載せる土台）／光導波路（チップの隣で光を曲げて運ぶ、細い光の通り道）／レーザー（光を出す部品）／光変調器（電気のデータを光に刻む部品）
- **役割の言葉**（名前のあとの受け方）：ガラスの土台／光の通り道／光の向きをそろえるレンズ／光を出す部品／光を刻む部品／光ファイバーの束／つなぎ口／大型パッケージの材料
- **説明しても出さない語**（説明が長くなるか、説明しても視聴者の役に立たない）：RDL・インターポーザー・InP・EML・PIC・EIC・ASIC・SerDes・DSP・LPO・LRO・シリコンフォトニクス・ハイパースケーラー。歩留まりは「作ったもののうち、ちゃんと使える割合」と言い換える
- **漢字で読める語はそのまま**：光変調器（「光を刻む部品」と並記して1回）／化合物半導体（「光を出すのに向いた特別な半導体」と1回）／光導波路は「光の通り道」で通す
- **海外の会社**：ブロードコム＝「通信用チップの設計で世界最大手。日本に同じ会社は無い」。NVIDIA・TSMC・マイクロソフト・AWS＝説明不要。**②の「必死で開発」の段落でNVIDIA・ブロードコム・TSMCと日本の8社を役割つきで列挙（10/4 ユーザー指示「ピンときやすい社名を」）。海外社名はこの3社に絞る。**TNO＝「オランダの公的な研究機関」。Horizon Europe＝「EUの研究予算」
