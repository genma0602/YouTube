# TOPIX改革台本｜序盤に3社を置く設計の分析

## 結論（先に）

**3社は「教科書（③基準）の直後の実利」として22〜36%地点に置かれ、①と②で2段階に予告されている。** これが無いと、本文の10%から60%までの50ポイントに社名が5回しか出ない。伸びた3本（7万円・10万円・TOPIX）はいずれも10%までに社名が出て、32%までに数字つきの銘柄が出る。伸びなかった日米同時利上げは社名の初出が43%。

**光電融合の骨組み（10/3版）は、3社の四季報パートを57%に置いていて、TOPIXと逆。** ③種明かしの直後、20%前後に3社を戻す。

## 2. なぜ効くのか（仕組みを4つに分ける）

### 2-1. 予告が2段階で、2段目に「社名＋1行の数字＋受け取りの時刻」が入っている

①は数だけ（3社・20社・23社）。②は社名と1行の数字（「25%増える見通しの新日本建設」）と、**いつ詳しく聞けるか**（「基準の話のあとで、1社ずつ」）。
→ 視聴者は③の教科書を「3社がなぜ外れるのかを知るため」に聞く。**教科書に目的ができる。** 日米同時利上げ版の教科書（②金利の教育）には、この目的が無かった。

### 2-2. 教科書の直後に、数字つきの実利を置く

③基準（12.6〜22.0%）は制度の説明で、いちばん離脱しやすい。その直後の④で、1社あたり450〜800字の「業績・財務・配当・外れる理由・年初来株価」をフルで出す。
→ 伸びた型の「用語を説明したらその場で日本企業名に降ろす」を、文の単位ではなくブロックの単位でやっている。**教科書1ブロック → 実利1ブロック。**

### 2-3. 3社は「小さな名簿」で、本番の名簿の味見になっている

④の3社は、⑦の20社と同じ型（役割→数字→年初来株価）で書かれている。しかも3社とも年初来プラス（+23%・+16%・+31%）＝上がった名簿。
→ 視聴者は22%の時点で「この動画は、こういう粒度で会社を見せてくれる」と分かる。⑤⑥の理由と道具（36〜61%）を、⑦の20社を受け取るための準備として聞ける。

### 2-4. サムネの「追放銘柄」を22%で回収している

タイトル・サムネの約束のうち、「追放銘柄」はこの3社で、「今から狙える銘柄」は⑦の20社。約束の半分を序盤で返している。
→ 7万円版・10万円版は、サムネの約束（7万円・10万円）を冒頭で返せる。TOPIX版は「銘柄」が約束なので、銘柄を序盤に出さないと約束が61%まで宙に浮く。**3社は、その穴を埋める部品。**

## 4. 光電融合の骨組み（10/3版）に当てはめると

### 4-1. いまの骨組みの問題

| ブロック | 位置（概算） | 社名の出方 |
|---|---:|---|
| ③ 種明かし | 10〜19% | 末尾で「この部品を作れる会社が日本にある」（社名なし） |
| ④ 理由1 市場・お金 | 19〜27% | 古河電工・住友電工（数字つき初出は約25%） |
| ⑤ 理由2 部品×日本 | 27〜48% | 7社を役割で（数字は薄い） |
| ⑥ 競争 | 48〜53% | 社名なし |
| ⑦ 道具 | 53〜58% | |
| **⑧ 3社フル** | **58〜76%** | 四季報の数字 |

→ 数字つきの銘柄は25%に出るが、**「1社をフルで見る」実利が58%まで来ない。** TOPIX版は22%。10%から58%の間に、理由2つ・競争・道具が並ぶ。ここがだれる。

### 4-2. 直し方（TOPIX版の並びに合わせる）

| | ブロック | 字数 | 位置 | TOPIX版の対応 |
|---|---|---:|---:|---|
| ① | 導入（8要素）。**品書きに「7社」の数と、3社の社名を1行ずつ** | 900 | 0〜5% | ①の品書き（23社） |
| ② | 承認と反転。**末尾に3社の社名＋1行の数字＋「仕組みの話のあとで1社ずつ」** | 1,100 | 5〜11% | ②の予告2段目 |
| ③ | 種明かし（教科書）。**途中に社名を1回差し込む**（住友電工がNVIDIAの供給網に、など） | 1,600 | 11〜19% | ③基準の中のマクドナルド・セリア |
| **④** | **四季報で見る3社：DNP・AGC・三菱電機**（役割→今の利益→光電融合の段階→数字→次の決算日） | 3,400 | **19〜37%** | **④外れる側の3社（22〜36%）** |
| ⑤ | 理由1：お金は日本のデータセンターにもう来ている | 1,500 | 37〜45% | ⑤資金 |
| ⑥ | 理由2：部品の役割ごとに日本の会社がいる（残り4社の名前を役割で） | 4,000 | 45〜66% | ⑤資金の続き |
| ⑦ | 疑い：ヨーロッパと中国 | 900 | 66〜71% | ⑥の疑いの代弁 |
| ⑧ | 2つの道具（**さきほどの3社を道具で置き直す**） | 1,000 | 71〜76% | ⑥道具 |
| ⑨ | さらに4社：古河電工・住友電工・レゾナック・日産化学 | 2,000 | 76〜87% | ⑦産業別 |
| ⑩ | 持ち方（積み立ての枠は空欄） | 1,700 | 87〜95% | ⑧持ち物ごと |
| ⑪ | 再定義と締め | 900 | 95〜100% | ⑨ |

- これは**ユーザーの最初の案の並び（伸びる理由→市場規模→3銘柄→なぜ日本→競争→4銘柄）とほぼ同じ。** 違いは、市場規模を3社の後ろに回す点だけ（TOPIX版が「資金は、どこへ向かうのか」を3社の後ろに置いたのと同じ）。市場規模を先に置くなら、3社は27%から始まる。どちらでも成立するが、教科書の直後に実利を置く仕組み（2-2）を優先するなら前者
- 社名の空白は、④の37%から⑥の45%までが最長（8pt）。⑤には古河電工・住友電工が入るのでさらに短い
- 分類ごとの配分は変わらない（中和19%／理由34%／処方箋43%／締め5%）。**動くのは順番だけ**
- ④の3社の読み方は、TOPIX版④と同じく「見方を1つ足す」の軽い枠で済ませ、2軸の道具は⑧で正式に出す。⑧で「さきほどの3社を、この2つの道具で置き直すと」と受ければ、3社が2回効く

### 4-3. 書くときの型（TOPIX版④から）

1. 冒頭で予告を受ける：「さきほど、◯◯と言いました。その3社を見る前に、見方を1つ足します」
2. 見方1つ（TOPIX版はリサーチ・アフィリエイツ。光電融合なら「今の利益と、光電融合の利益は別」）
3. 入り：「では、◯◯な会社を、3社見ていきます。数字は会社四季報の秋号と、各社の決算資料からです」
4. 各社：役割の1文 → 何で稼いでいるか → 伸びている部門の数字 → 財務・配当 → なぜこの枠にいるか → 年初来の株価
5. 3社の締め：共通点を1文で言い切る → 二人称で閉じる（「ご自分の持ち株が〜の方も、同じ見方で確かめてみてください」）
6. 次への橋：短い1文（「抜けたお金は、消えるわけではありません」）
