# 第1部：仮説の検証

## 1-1. 仮説②から先に片づける ── 「勉強要素が多い」は数字で否定される

用語説明のマーカー（「〜とは、」「〜というのは」「思ってください」「たとえるなら」「〜と呼びます」ほか）の密度。

| | 用語説明の箇所数 | 1万字あたり |
|---|---:|---:|
| 7万円（**伸びた**） | 13 | 8.2 |
| 10万円（**伸びた**） | 20 | 7.7 |
| AI半導体（伸びず） | 24 | 9.2 |
| 日米利上げ（伸びず） | 11 | **5.8** ← 4本で最少 |

**伸びなかった日米同時利上げが、4本でいちばん解説が少ない。** 「初心者向けの解説が多いから伸びなかった」は成立しない。

### では、なぜ「勉強っぽい」と感じたのか ── 量ではなく着地先

用語を説明した直後300字以内に、視聴者の持ち株（日本の個別銘柄・日経平均・TOPIX）が出てくる割合。

| | 説明が持ち株に降りる率 |
|---|---:|
| 7万円（**伸びた**） | **54%** |
| 10万円（**伸びた**） | **35%** |
| AI半導体（伸びず） | 12% |
| 日米利上げ（伸びず） | **9%** |

- 伸びた例：PERを説明 → すぐ「アドバンテスト46倍、東京エレクトロン46倍、レーザーテック55倍」。円安を説明 → すぐ「アドバンテストは1円で営業利益40億円」
- 伸びず例：国債の値段と利回りを説明 → 国債の話のまま終わる。政策金利と長期金利を説明 → 市場の話のまま終わる

**勉強が多いのではなく、勉強が持ち株に着地していない。** 感覚は正しく、原因の特定がずれていた。

# 第3部：台本の外にある要因（正直に）

**伸びの主因は、たぶん台本ではなくタイトルとサムネにある。** 台本の比較では見えないので断定しない。ただ、タイトルの約束のしかたは、はっきり分かれている。

| | タイトルが約束しているもの |
|---|---|
| 【日経平均7万円突破！】…歴史的チャンス到来？（**伸びた**） | **上向きの到達点の数字** |
| 【日経平均10万円は近い？】…日本株はもう下がらない！（**伸びた**） | **上向きの到達点の数字** |
| AI・半導体バブルついに崩壊か⁉急落原因を徹底解説！（伸びず） | 怖い出来事の**解説** |
| 【悪材料出尽くし？】…なぜ日本株は暴落しないのか⁉（伸びず） | 怖い出来事の**解説**（しかも二重否定） |

「暴落しない」も安心の提供だが、伸びていない。**安心より、上向きの数字。**

### この比較の限界

- サンプルは4本（2対2）。再生数が判明しているのは7万円版（13万再生）のみ
- CTRを決めるタイトル・サムネ・公開タイミング・そのときの相場は測っていない
- 台本の中身で説明できるのは「見始めた人が最後まで見るか」まで
- 「僕」の密度など、あとから入った文体ルールの影響を受けている項目がある

## 5-3. 第5部を足した結論

効き目のある要素は、**視聴者の存在・希望語・処方箋の尺・説明の着地・出典・行動指示・小見出し**の7つに絞られる。
逆に、**読みやすさの工夫（たとえ話・平易な語・ブロックの分割・文を短く）は、伸びと無関係か逆相関。** 読みやすさは品質の話であって、伸びの話ではない、と切り分けたほうがいい。
