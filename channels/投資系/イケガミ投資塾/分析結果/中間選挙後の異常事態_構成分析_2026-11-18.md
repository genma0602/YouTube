日本だけ酷かった理由（行88〜94）は、日本株の視聴者の「なんでアメリカより下がるんだ」という悔しさへの答えになっている。怒りを政府や企業に向けさせず、**仕組みの理解で収める**。見終わったあとに残るのが怒りではなく納得なので、後味がいい。

**② 同じたとえが2回、別の概念に使われてつながる**
- コンビニ：「棚」はセクター（行52）、「チェーン」はハイパースケーラー（行74）

**④ 笑いのたとえは2つだけ、置き場所が決まっている**
寿司（行44・31%）とローランド（行108・89%）。重い話が続いた直後と、締めの直前の2か所。笑いを多用せず、**息抜きが必要な場所にだけ置く**。

**⑤ 骨になるたとえは1つ**
たとえは多いが、話全体を運んでいるのは「コップの水」だけ（行54〜116）。ほかのたとえは、その場の概念を説明したら役目を終える。**主役のたとえと、その場限りのたとえの区別がはっきりしている**ので、たとえが多くても散らからない。

## 11. この台本の型（再現できる要素）

- **前半で事実だけを並べ、後半で同じ順に理由を明かす。** 冒頭の「なんで？」を後半で全部回収する
- **結論は比喩で先に言い、中身は空けておく。**「お引っ越しをしていただけ」
- **難しい言葉は「一言で言うと → 身近な例 → 投資目線でまとめると」の3段で、毎回同じ合図で処理する**
- **数字には順位か割合を必ず付ける。**「2026年で1番」「6年ぶり」「225社のうち3社」
- **予告は生活の言葉で、回収は相場の言葉で。**「ガソリン代、電気代、日本の半導体」
- **たとえは1つの世界にそろえ、骨になるたとえは1つだけにする**
- **話題の切り替えは、視聴者の心の声で行う。**「じゃあAI関連は全部終わりなのか」「で、結局、私の口座にはどう関係あるの？」
- **損をした人を責めず、次にできることだけを渡す**
- **最後に、動画全体を「どちらの人になるか」に言い換えて終わる**
- **冒頭は「市場 → 銘柄 → あなたのスマホ」と寄っていき、結論は「承認 → 安心 → 謎 → 不安」の順で1段落に収める**（12章）
- **あとで使う言葉やたとえを、最初は普通の説明として置いておく。締めで冒頭の場面と人物を呼び戻して閉じる**（13章）

### 12-2. 最初の45秒：大きい話から「あなたのスマホ」へ寄っていく

行12の3つの場面は、映す範囲がだんだん狭くなる。

1. 日経平均が6万円台を割り、また回復した（**市場全体**）
2. NVIDIAのスキャンダルで、取引のあるAI関連株まで巻き添えになった（**業種・銘柄**）
3. 朝スマホで証券アプリを開いたら、保有株が真っ赤でドキッとした（**視聴者本人**）

カメラが市場から視聴者の手元まで寄ってくる。3つ目で「自分のことだ」と思った時点で、視聴者はもう当事者になっている。

しかも3つとも「割った → 回復」「スキャンダル → 巻き添え」「開いたら真っ赤」と、**上下に振り回された体験**になっている。このあと行34で言う「結局どっちなんだ」の気持ちを、最初の45秒で先に作っている。

### 12-3. 結論の1段落（行14）は、安心と不安を交互に置く

| 文 | 働き |
| --- | --- |
| 一部の銘柄が暴落しているのは確かです | **承認**（あなたの不安は間違っていない） |
| しかし、お金が株式市場から逃げていったわけではありません | **安心** |
| 市場の中でお引っ越しをしていただけなんです | **謎**（どこからどこへ？） |
| ただし、このお引っ越しを見落とした人の口座が1番削られました | **不安**（自分は見落とした側では？） |
| ここ本当に大事です。最後までご確認いただければ | **視聴の依頼** |

安心だけ渡すと「なら見なくていい」になり、不安だけ渡すと煽りになる。**承認 → 安心 → 謎 → 不安**と1段落で振ってから、「最後まで」と頼む。不安の向きも「相場が危ない」ではなく「**見落とした人が損をした**」なので、見れば避けられる不安になっている。だから視聴の依頼が自然に聞こえる。

### 12-4. 事実の陳列（行16〜32）は「答えを言わずに体験させる」

ここは約1,300字、4分近くあるが、理由はほとんど言わない。それでも持つ理由は3つ。

- **「ところが」で2回ひっくり返す。** 行18「民主党が勝ったら暴落と散々言われていた」→ 行20「ところが」翌日ダウ+3% → 行22「ところが」その翌日に逆。視聴者が体験した乱高下を、そのままの順番で再生している。
- **人を登場させる。** 行18「株を売って逃げた人がアメリカにも日本にもかなりいました」、行20「買い戻すか、指をくわえて見ているかの2択」。数字の流れの中に、**その数字で振り回された人**を置いている。視聴者は「自分もそうだった」か「そうならなくてよかった」のどちらかで聞く。
- **2つ目の出来事は時間を巻き戻して出す。** 行26「中間選挙前から、市場ではもう1つの地雷が埋まっていたんです」。選挙の話を11/6まで進めたあと、10/14に戻る。「実は裏でもう1つ起きていた」という形なので、事実の陳列が続いても新しい話に聞こえる。

### 12-5. 謎の提示（行34）は「対の言い回し」で作る

「中間選挙で上がって下がる。コアウィーブで下がって上がる。上がったと思ったら下がって、下がったと思ったら戻る」

4分かけて並べた事実を、**対になった短い4つの言い回し**に畳んでいる。長い陳列の内容を一瞬で思い出させ、そのまま「結局どっちなんだ」と視聴者の声を言う。直後に「実はちょっとオカルトっぽいんですけども」と軽く外し、「同じ1本の線でつながっています」と問いを立てる。

### 12-6. 賭け金を4回、少しずつ上げる

| 行 | 何が懸かっているか |
| --- | --- |
| 14 | 「見落とした人の口座が1番削られました」——**今回の損** |
| 34 | 「その線が見えている人と見えない人で、この先の投資人生が変わる」——**これからの投資人生** |
| 36 | 「今後どう行動すれば大きな成果を上げられるか」——**行動の結果** |
| 36 | 「ここを知っているだけで、ニュースの見方がガラッと変わるはず」——**見え方そのもの** |

冒頭の6分の間に、「この動画を見ると何が変わるか」を4回言っている。どれも言い方が違うので、くり返しに聞こえない。

### 12-7. 自己紹介は「問いを立てたあと」、関連付けは「本編の直前」

- 自己紹介（行38）は、謎（行34）と目次（行36）で視聴者を引き止めたあと。最初に名乗りを長くすると離脱が出るので、**見る理由ができてから**名乗っている。

### 13-2. 張り方の特徴

**① 伏線を「伏線らしく」置かない**
「建てる」という言葉は、行28と30ではコアウィーブの商売の説明として普通に出てくるだけ。それが行72で「建てる側」という区別の名前になる。視聴者は行28の時点では気づかないが、行72で区別が出たとき、**前から聞いていた言葉なので自然に入る**。新しい用語を教わった感じがしない。

**② たとえ話そのものを伏線にする**
コアウィーブを「レンタル倉庫」と言ったのは、行28では分かりやすさのため。ところが行68では、そのたとえがそのまま理屈になる。「倉庫を建てること自体が減る → 中に入れる予定だったメモリーが売れない」。**最初のたとえの中に、あとの因果がもう入っていた**。

**③ 冒頭の人物を締めで呼び戻す**
行18で「売って逃げた人」、行20で「指をくわえて見ている人」として出した人たちが、行110で「選挙の結果を当てに行った人」として戻ってくる。冒頭ではただの登場人物だった人が、締めで**2種類の投資家の片方**という意味を持つ。

**④ 1つの事実を「驚き → 理由 → 証拠」と3回使う**
「33業種全部下落」は、行24では驚き、行92では理由の説明の対象、行100では助言の証拠。同じ事実を3回出すが、**毎回役割が違う**ので、くり返しに聞こえない。

### 13-3. 回収の仕方の特徴

**① 「先ほど」と言うのは2回だけ。あとは同じ言葉で回収する**
明示的な受け直し（「先ほどご説明したコアウィーブ不安」行68、「先ほど説明しましたが」行80）は2回。それ以外は、「建てる」「コップ」「33業種」「原油」といった**同じ言葉が戻ってくること**で回収している。視聴者は「あ、さっきのあれだ」と自分で気づく。気づいた快感は、説明されるより強い。

**② 回収するときに言葉を少し変える**
引っ越し（行14）は、東京では「家財ごと持っていかれた」（行86）になる。同じたとえだが、**規模を変えて**日米の違いを表している。そのまま繰り返さず、1歩進めて回収する。

**③ 1つの回収が、次の謎を開ける**
行82で米国の3日分を整理し終えた直後に、行84「でも、もっと大切なことは、米国がくしゃみをしたら日本がパニックになってしまったことです」。米国の謎が解けた瞬間に、日本の謎が始まる。**回収が区切りではなく、次への入口**になっている。

**④ 締めで3重に閉じる**
行110〜118で、冒頭の3つの伏線（売って逃げた人／見落とした人／証券アプリ）を立て続けに回収する。動画の最後の1分で、最初の1分の場面が全部戻ってくるので、**1本の話として閉じた感覚**が残る。

**⑤ 言葉にしない回収もある【推測】**
行46「市場が1番嫌うのは悪いニュースではなく、読めないニュースだから」は、行64のテキサスの凍結（「州議会で新しいルールが決まるまで」＝いつ終わるか読めない）の説明にもなっている。台本はこの2つを結びつけていない。気づいた視聴者だけが得をする回収で、2回目に見たときの発見になる。

### 13-4. 回収されないまま終わる種

### 15-7. 細分化から見える規則

**① 段落の入口は「札」で始まる**
56段落のうち、少なくとも15段落が、日付・番号・合図の言葉で始まる（行18「1つ目が」、行60「まず、中間選挙翌日の11月4日です」、行88「1つ目の理由は」、行52「噛み砕きますね」など）。視聴者は段落の最初の数語で「今どこにいるか」が分かる。

**② 段落の出口は「一言の結論」で閉じる**
「6年ぶりの下落率です」（22）、「ひねくれた面もあります」（46）、「指数ごと沈んだということです」（90）、「時差というのは、こういうときに1番効いてきます」（94）。長い段落でも、最後の1文だけ聞けば中身が分かる。

**③ 「事実の段落 → 意味の段落」がペアになる**

| 事実 | 意味 |
| --- | --- |
| 44 ねじれの定義とたとえ | 46 なぜ好材料か |
| 60 抜かれたコップ | 62 注がれたコップと教訓 |
| 72 建てる側／持っている側 | 74・76・78 なぜ持っている側が得か |
| 88 値がさ株の仕組み | 90 今回への当てはめ |
| 104 FOMCとは | 106 今回どうなりそうか |

1つの段落に「何か」と「だから何か」を詰め込まない。2つに分けるので、1段落あたりの負担が小さい。

**④ 用語の部品は、1段落を丸ごと使う**
用語の部品（28・52・74・88・104）は、どれも独立した1段落になっていて、前後の段落と混ざらない。視聴者は「今は言葉の説明の時間」と分かって聞ける。

**⑤ 数字の並べ方に向きがある**
- 上げの日（20）：ダウ+3% → S&P500 +1.6% → ナスダック+1.4%と、**大きい順**。主役を先に言う。
- 下げの日（22）：ダウ-3.4% → S&P500 -4.36% → ナスダック-5.5% → SOX指数-12%と、**小さい順**。最後の12%で頂点を作る。
- 東京（24）：下げ幅 → 順位 → 225社中3社 → 33業種全部と、**点から面へ**。
- 論証（66）：何を生むか → なぜ本気か → どれだけ大きいか（4分の1 → 2割 → 原発50基分）と、**抽象から体感へ**。

**⑥ たとえは「乗り換え」と「再登場」で動く**
- 乗り換え：コンビニの棚（52）→ 11個のコップの水（54）。止まっている棚では「移動」を表せないので、水に乗り換える。
- 再登場：コンビニ（52 棚 → 74 チェーン）、レンタル（28 倉庫 → 104 お金のレンタル料金）、引っ越し（14 → 86 家財ごと）。前に出したたとえを、別の概念に少し形を変えて使う。

**⑦ 条件を絞って「今回」に近づける**
行42は「19回全部 → 共和党大統領が議会を取られた7回 → 今回は8回目」と、母数を絞りながら今回の位置まで降りてくる。行48の例外も「1974年 → 原油とインフレ → 今のイラン」と、過去を今の条件に変えて終わる。法則をそのまま渡さず、**必ず今回の話に変換してから次へ進む**。

**⑧ 段落の長さ**
平均は約190字。長いのは98（約410字・積み立ての人への答え）、46（約380字・ねじれの論証）、66（約340字・DC凍結の規模）。いちばん字数を割いているのは、**視聴者がいちばん多い層への答え**と、**話の土台になる論証**の2種類。
