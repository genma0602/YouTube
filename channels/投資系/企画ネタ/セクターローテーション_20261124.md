## 1. 金融危機リスク後退と日本株全体への波及

今回のAI半導体大手の創業者CEO復帰による信用不安の後退は、AI半導体だけでなく、株式市場全体にとってプラスに作用する可能性がある。

さらに、11月に入ってからの日本株市場では、AI半導体や銀行株から、医薬品、小売、食品、不動産などの内需・ディフェンシブ銘柄へ物色が移る局面が見られた。ただし、食品などは期間全体では下落しており、継続的な資金の受け皿だったとは断定できない。

民主党が米議会の上下両院を掌握したという前回調査の政治情勢を踏まえると、政策変化によりAI半導体だけに依存しない相場になる可能性もある。正確には民主党政権ではなく、民主党議会と共和党政権による分割政府である。

### 11月24日の日本株市場

| 指標 | 数値 |
|---|---:|
| 日経平均株価 | 58,644.63円 |
| 日経平均騰落率 | +3.91% |
| 値上がり業種 | 26 / 33業種（約79%） |
| 東証プライム値上がり銘柄 | 952銘柄（61.6%） |
| 東証プライム値下がり銘柄 | 557銘柄（36.1%） |
| 変わらず | 36銘柄 |

半導体株が上昇の中心だったものの、33業種中26業種が上昇したことから、半導体以外にもリスク回避姿勢の緩和が波及している。

### なぜ直接関係のない企業まで上昇するのか

株価は企業の利益だけではなく、投資家が要求するリスクプレミアム（リスクに対する上乗せ収益率）にも左右される。

```text
AI半導体大手を起点とした信用不安の後退
  ↓
金融危機・景気後退への警戒緩和
  ↓
投資家が要求するリスクプレミアムの低下
  ↓
株式市場全体のバリュエーション改善
  ↓
非半導体企業にも株価上昇が波及
```

ただし、信用不安が和らぐことでFRBの利上げ観測が強まるという逆方向の作用もある。株式市場全体への持続的な効果は、今後の信用スプレッドと長期金利の両方に左右される。

## 2. 米国の非半導体株への波及

11月23日の米国市場では、ハイテク企業の比重が低い株価指数も上昇した。

| 株価指数・指標 | 11月23日騰落率 |
|---|---:|
| SOX（半導体株指数） | 約+14% |
| NASDAQ100 | 約+6.9% |
| S&P500 | +4.73% |
| NYダウ | 約+3% |
| S&P500均等加重型の指標 | 約+2.6% |

前回調査の出典：Reuters、Saxo Bank、Barron's。

特に重要なのは、S&P500の構成企業に均等に投資する商品も約2.6%上昇したことである。通常のS&P500は巨大企業の影響を強く受けるが、均等加重型はその影響が小さくなる。今回の株高は巨大半導体企業の時価総額が増えただけではない。

サクソバンクの11月24日の公式レポートでは、米ハイイールド債の信用スプレッドが10bp以上縮小したとされる。ただし、暴落前の水準には戻っていない。

## 3. 最新の機関投資家の見解

### 3.1 GCIアセットマネジメント：今後2週間程度は買いが優勢になる可能性

ポートフォリオマネージャーの池田隆政氏は、11月24日のReutersの取材で、機関投資家によるリバランスによって、目先2週間程度は買いが多くなる可能性を指摘している。

一方、AI企業の資金調達やデータセンター投資を巡る問題は未解決であり、中長期的には上値が重くなる可能性も指摘している。

### 3.2 サクソバンク：AI相場は維持されているが、今後は利益を生む企業が重要

チーフ投資ストラテジストのCharu Chanana氏は、11月24日の公式レポートで、CEO復帰によってAI関連企業の業績下方修正リスクが低下したと分析している。

ただし、今後はAI投資の拡大に依存するだけの企業と、AIによって持続的な利益を生み出せる企業を区別する必要があると説明している。

これはAI半導体を売って別の産業に全面的に乗り換えるというよりも、株式市場全体で業績を重視した選別が進む可能性を示唆している。

## 4. AI半導体からの資金移動と11月5日の日本株

大和アセットマネジメントのチーフ・ストラテジスト、建部和礼氏が11月9日に発表したレポート「米国中間選挙で揺れる日本株式市場」が参考になる。

同氏によると、11月5日の日本株市場では、業種間の騰落率のばらつきが過去15年間で最大になった。コロナショックやトランプ関税導入時、イラン戦争当初をも上回る規模である。

### 11月5日に起きた異例の相場

| 指標 | 数値 |
|---|---:|
| 日経平均 | −1.79% |
| TOPIX | +1.16% |
| 上昇業種 | 25 / 33業種 |
| 業種間騰落率格差（標準偏差） | 4.6%（過去15年間で最大） |

日経平均だけを見ていると、日本株全体が売られているように見える。しかし実際には、AI半導体が売られる一方で、東証プライム市場の7割以上の銘柄が上昇していた。

これは今回のセクターローテーションを理解する上で非常に重要な日である。

自動車、航空、ゲーム・エンターテインメント、不動産、小売、医薬品が、半導体株急落時の資金の受け皿になったと考えられる。

ただし、これは株価と売買動向から推測できる資金シフトであり、半導体を売却した同じ投資家がそれぞれの業種に何億円投資したかまで確認できたわけではない。

### 11月6日の全面暴落とは区別する必要がある

11月4～5日は業種間の資金移動が起きたが、11月6日には金融危機への警戒が強まり、前日まで買われていた業種も大幅に売られた。

大和アセットマネジメントも、7月以降に半導体売りの受け皿になっていた内需・ディフェンシブ・クオリティ株にまで売りが波及したと説明している。

今回、信用危機リスクが後退したことで、こうした企業が再評価される余地が生じた可能性がある。

一時的な資金移動だけでなく、10月30日から11月20日までの3週間について、東証33業種別指数の週間騰落率を比較する。

## 7. 投資主体別の資金フローと確認できる範囲

11月19日までに公表された東証の投資部門別売買動向では、前回調査時点で以下の動きが確認されている。

| 投資主体 | 11月の動向 |
|---|---|
| 海外投資家 | 3週連続で現物株を売り越し |
| 個人投資家 | 売り越し継続 |
| 信託銀行 | 2週連続買い越し |
| 事業法人 | 買い越し |

海外投資家の現物株売り越し額は、11月第1週が714億円、第2週が3,124億円だった。

一次資料：[日本取引所グループ・投資部門別売買状況](https://www.jpx.co.jp/markets/statistics-equities/investor-type/index.html)

重要なのは、日本株市場全体から海外資金が流出していても、一部の業種では選択的な買いが発生していたと考えられることである。

なお、東証の公開統計だけでは、海外機関投資家が半導体株を売却して医薬品株を何億円買ったのかまでは特定できない。ETFの受益権口数についても、前回調査時の東証最新月末集計は10月末時点だった。

したがって、業種別の正確な純資金流入額については未確認だが、業種別騰落率と運用会社の分析から、ローテーションが起きていたことには相応の根拠がある。

**「実際に買われたセクター」は、業種別株価が上昇したことと運用会社の物色動向の分析を指す。純資金流入額を実測したという意味ではない。**

## 8. 民主党議会の政策で資金が入りやすいセクター

モルガン・スタンレー、ウェルズ・ファーゴ、BNY、アリアンツ、INGの公式レポートを比較した前回調査に基づき、政策面で恩恵を受ける可能性がある産業を整理する。

### 8.1 医療・創薬・ヘルスケア

民主党は、医療保険の拡充、低所得者向け医療支援、医学研究への公的支出などを重視する傾向がある。

モルガン・スタンレーは11月4日のレポートで、民主党が次の削減計画の延期や縮小を求める可能性を指摘している。

| 項目 | 削減予定額（10年間） |
|---|---:|
| メディケイド | 9,000億ドル |
| 低所得者向け食料支援 | 2,000億ドル |

医療費や食料支援の削減が緩和されれば、家計の購買力の維持にもつながる。

日本株への波及が考えられるのは、製薬、医療機器、検査・診断、創薬支援、バイオテクノロジーなどである。

ただし、医薬品メーカーにとっては薬価引き下げが逆風になる場合もある。前回調査では、米政府のCMSが11月23日に13品目の高額医薬品について交渉後の価格引き下げを発表したことも取り上げた。

医療業界全体が一律に恩恵を受けるわけではない。

### 8.2 再生可能エネルギー・蓄電池

民主党の政策で注目されやすい代表的な分野である。

2022年のバイデン政権では、インフレ抑制法（IRA）によって、再生可能エネルギーやEV、蓄電池などへの税制支援が拡充された。

今回の中間選挙直後にも、米国の関連企業が大幅に上昇した。

| 指標 | 11月4日の取引時間中の騰落率 |
|---|---:|
| 米国再生可能エネルギー関連企業3社（個別銘柄名省略） | +8.8%、+8.4%、+6.9% |

前回調査の出典：Reuters、11月4日。

日本企業では以下の事業に波及する可能性がある。

- 太陽光発電設備・部材
- パワー半導体
- 蓄電池・電池材料
- 風力発電設備
- 電力制御システム
- 省エネルギー設備

ただし、現在は民主党が大統領を擁しているわけではないため、バイデン政権時代と同規模の支援政策が復活するとは限らない。

### 8.3 電力・送電網・省エネ・インフラ

この分野は民主党と共和党で政策上の利益が一致しやすい領域である。

INGの11月5日の公式レポートでは、分割政府はデータセンターによる電気料金の上昇から家計を守りながら、電力供給能力を拡大する必要に迫られると分析している。

| 民主党の政策上の重点 | 共和党の政策上の重点 |
|---|---|
| 家庭の電気料金抑制 | AI産業の競争力 |
| 環境負荷の軽減 | エネルギー供給拡大 |
| クリーンエネルギー | 許認可の迅速化 |

**共通する需要：送配電網、変圧器、蓄電、発電設備、省エネ投資。**

ウェルズ・ファーゴも11月4日の公式レポートで、両党がAI産業やデータセンターを巡って妥協する経済的な動機があると分析している。

この分野は、AI半導体の製造そのものとは異なり、社会全体の電力需要とインフラ更新にも関係する。

一次資料：[ING・民主党勝利が米国のエネルギーとデータセンターに与える影響](https://think.ing.com/articles/a-blue-wave-is-here-what-it-means-for-us-energy-and-data-centres/)

### 8.4 小売・外食・一般消費財

民主党による社会保障や食料支援の維持は、特に低中所得世帯の消費を支える可能性がある。

さらに、前回まで調査してきた原油価格の下落が続けば、ガソリン代や光熱費の負担が軽減され、消費に使えるお金が増えることも期待できる。

モルガン・スタンレーも、医療・食料支援の削減緩和によって米国の個人消費と経済成長が支えられる可能性を指摘している。

日本企業では、海外に進出する小売、外食、衣料品、ゲームなどが間接的な恩恵を受ける可能性がある。

### 8.5 住宅・不動産

民主党は住宅の取得負担や家賃問題への対策を重視している。

住宅供給拡大や住宅購入支援が進めば、建設、住宅設備、不動産などには追い風になり得る。

ただし、現在の米国では住宅ローン金利の高さが大きな問題である。住宅関連企業については、民主党の政策以上に長期金利の動向が重要になる可能性がある。

## 10. 政策・実際の株価動向・原油安の重ね合わせ

政治的な恩恵を受ける産業と、実際に11月の日本株市場で買われた産業を重ね合わせる。

| セクター | 民主党の政策との関連 | 11月の日本株の動き | 原油安の恩恵 |
|---|---|---|---|
| 医薬品・医療 | 大きい | 上昇 | 間接的 |
| 小売・外食 | 消費・社会保障支援 | 上昇 | 大きい |
| 空運・陸運 | エネルギー・消費政策 | 上昇 | 大きい |
| ゲーム・エンタメ | 消費支援 | 選択的に上昇 | 間接的 |
| 自動車 | EV・消費者支援 | 上昇 | あり |
| 不動産 | 住宅供給・取得支援 | 底堅い | 間接的 |
| 再生可能エネルギー | 大きい | 国内ではまちまち | 競争面では逆風も |
| 電力インフラ | 超党派で需要 | 調整 | あり |
| AI半導体 | 規制強化リスク | 大幅下落後に反発 | 間接的 |

※政策との関連性、原油安の恩恵は経済的な波及経路に基づく前回回答の独自分析。実測された純資金流入額ではない。

## 11. 今後注目する7つの産業

### 11.1 医療・AI創薬

**11月の業種指数：医薬品 +3.6%（10月30日～11月20日）**

医薬品セクターには、景気後退への耐性、米国の医療政策、AIによる創薬効率向上という複数の投資テーマがある。

AI半導体への過度な集中を避けながら、AI技術の発展による恩恵を受けられる分野でもある。

関連分野：製薬、医療機器、検査・診断、AI創薬、創薬支援、バイオテクノロジー。

### 11.2 小売・外食・リユース

**11月の業種指数：小売 +5.5%**

今後、原油安によって物流費や光熱費が抑制され、実質賃金が改善すれば、家計消費の回復が期待できる。

関連分野：外食、衣料品、食品小売、総合小売、リユース、生活雑貨。

特に海外展開を進める企業は、日本国内の人口減少だけに成長を制約されない点も重要である。

### 11.3 ゲーム・エンターテインメント

**11月4～5日のメディア・娯楽：約+9.5%**

今回の中間選挙直後に、半導体株が大幅に下落する中で逆行高となった分野である。

物理的なAIインフラ建設への依存度が低く、知的財産（IP）やデジタルコンテンツによって利益を生み出せることが特徴である。

関連分野：ゲームソフト、家庭用ゲーム機、キャラクターIP、映像、デジタルコンテンツ、娯楽サービス。

一方、娯楽への支出は景気や消費者心理にも左右される。

### 11.4 航空・物流・鉄道

**11月の業種指数：空運 +11.7%、陸運 +4.6%**

今回、原油安の恩恵と半導体株からの資金シフトが重なったと考えられる産業である。

航空燃料やディーゼル価格の低下が持続すれば、収益改善につながる可能性がある。

関連分野：航空旅客、航空貨物、総合物流、陸上輸送、鉄道。

航空会社については燃料価格のヘッジ契約や為替によって、原油安が利益に反映される時期が異なる。

### 11.5 不動産・住宅

**11月の業種指数：不動産 +0.3%**

国内長期金利が安定し、賃料上昇と企業の収益拡大が継続すれば、不動産企業の利益成長を支える可能性がある。

関連分野：オフィス賃貸、商業施設、住宅開発、住宅設備、不動産管理。

ただし、日銀の追加利上げや借入金利上昇はリスクである。

### 11.6 電力インフラ・省エネ設備

AI産業の規制が強化されても、電力インフラや省エネの必要性がなくなるわけではない。

関連分野：変圧器、送配電設備、電力制御機器、空調、冷却、建物の省エネ、電力設備の更新。

特に既存データセンターの電力効率改善、冷却設備の更新、電力網の増強などは、新設データセンター以外にも需要がある。

### 11.7 再生可能エネルギー・蓄電池

民主党の政策との関連が強い一方、日本株への継続的な資金流入はまだ明確ではない。

関連分野：再生可能エネルギー発電、太陽光発電設備、蓄電池、電力変換機器、電池材料。

補助金の内容、事業の採算性、金利、米国現地での生産体制を個別に確認する必要がある。

※上記は事業分野に基づく調査候補であり、個別企業の資金流入や最新業績を確認した銘柄推奨ではない。

## 12. 2027年の相場のブロードニング

今回まで調査してきた内容をマクロ経済学的に統合すると、4つの経済的な変化が重要になる。

| 経済的変化 | 波及効果 |
|---|---|
| 金融危機リスク後退 | 信用収縮・企業の連鎖的な業績悪化を抑制 |
| 原油・燃料価格下落 | 企業のコスト改善・輸入インフレ緩和 |
| 実質賃金・消費改善 | 小売・外食・娯楽などの需要拡大 |
| AI投資の継続 | 半導体・電力・設備・生産性向上 |

これらが同時に進めば、株価上昇が幅広い産業へ波及する可能性がある。

これまではAI半導体の利益成長に株式市場の上昇が集中していた。しかし今後、原油安や実質賃金改善によって内需企業の利益も増加するのであれば、半導体以外の企業が株式市場の上昇を支えるようになる可能性がある。

これは相場のブロードニング（上昇銘柄・業種の広がり）と呼ばれる。

半導体株が上昇しなくなるという意味ではなく、半導体株が上昇しながら他の業種にも資金が広がるシナリオである。ただし、金融危機リスクの後退、原油安、AI投資の継続は条件であり、すべてが実現することを保証するものではない。

## 14. 最終結論

### 14.1 実際に買われたセクター（騰落率で確認できるもの）

今回の調査で特に重要だったのは、11月の大幅な株価下落の中でも以下のセクターがプラスを維持していたことである。

| セクター | 10月30日～11月20日の3週間累計 |
|---|---:|
| 空運 | +11.7% |
| 小売 | +5.5% |
| 陸運 | +4.6% |
| 医薬品 | +3.6% |
| 自動車など輸送用機器 | +2.9% |
| その他製品 | +0.8% |
| 不動産 | +0.3% |
| TOPIX（比較対象） | −7.3% |

中間選挙直後の11月4～5日という短い期間では、自動車・部品、空運、メディア・娯楽、不動産、陸運、小売、医薬品が半導体の大幅下落に逆行して上昇した。

これらは半導体からの資金移動の受け皿だった可能性を示す。ただし、業種別の純資金流入金額は確認できていない。

### 14.2 今後資金が入りやすいと考えられるセクター

| セクター | 主な注目理由 | 注意点 |
|---|---|---|
| 医療・AI創薬 | 医療政策、ディフェンシブ性、AI活用、実際の逆行高 | 薬価規制・研究開発リスク |
| 小売・外食・リユース | 原油安、実質賃金改善、消費支援、実際の逆行高 | 消費回復の遅れ、人件費 |
| ゲーム・エンターテインメント | IP収益、消費回復、選挙直後の逆行高 | 景気・ヒット作品への依存 |
| 航空・物流・鉄道 | 原油・ディーゼル安、信用不安後退、実際の逆行高 | 為替、燃料ヘッジ、輸送需要 |
| 自動車・輸送用機器 | 実際の逆行高、燃料費改善、消費支援 | 関税、景気、EV政策 |
| 不動産・住宅 | 住宅供給支援、賃料、相対的な底堅さ | 長期金利・住宅ローン金利 |
| 電力インフラ・省エネ設備 | 超党派での電力供給拡大、既存設備更新、AI投資継続 | 金利、許認可、設備投資の遅延 |
| 再生可能エネルギー・蓄電池 | 民主党の政策、電力供給と省エネ需要 | 国内の継続的資金流入は未確認、補助金・採算性 |

前回の分析で2027年に向けて特に注目したのは、医療・AI創薬、小売・外食、ゲーム・エンターテインメント、航空・物流、電力インフラである。金融危機への警戒後退、民主党議会による政策変化、AI技術の発展、原油安という複数の経済要因を組み合わせて分析できるためである。

もちろん、半導体株が今後上昇しなくなるという意味ではない。

**AI半導体も上昇しながら、これまで相対的に注目されていなかった産業にも資金が広がる相場になる可能性がある。**

今回の信用不安の後退と原油価格の低下が持続するのであれば、そのシナリオには経済的な根拠があると考える。
