# SaaS is Deadは本当か？生成AI時代のSaaS銘柄分析

## 結論

生成AIの新機能が出るたびにSaaS銘柄がまとめて売られる局面は続いているが、実際の企業業績を見ると「AIがSaaSを一律に破壊する」という見方は単純すぎる。

重要なのは、SaaS企業が単なるUIや便利機能を提供しているのか、それとも企業活動に不可欠なデータ・権限・監査・業務フローを握る「System of Record」になっているのかという点。

- SaaS = 企業データ・業務実行・権限・監査の基盤
- ChatGPT / Claude = そのSaaSを操作・分析・自動実行する知能

という関係が強まる可能性が高い。

> **SaaS is dead ではなく、SaaS UI is dying.  
> データ基盤としてのSaaSは、AI普及によってむしろ価値が高まる可能性がある。**

## 2. SaaS市場が恐れている本質

本当の懸念はAIがSaaS機能を代替することだけではない。

より大きいのは、

> **「1人 = 1ライセンス」という従来のseat課金モデルが崩れる可能性**

である。

社員1000人だから1000ライセンス契約していた会社でも、AIエージェントが大量の業務を代替すれば、将来的には必要な人間ライセンス数が減る可能性がある。

これはSaaS企業にとって現実的なリスク。

## 6. なぜ「全部SaaSを入れ替える」より「既存SaaS + AI」が合理的なのか

企業にとってSaaSは単なる画面ではない。

会計SaaSなら、

- 銀行口座
- クレジットカード
- 請求書
- 給与
- 税務
- 承認権限
- 監査ログ
- 過去の仕訳
- API
- 電子帳簿保存法対応
- 税理士との連携

などが蓄積されている。

ChatGPTやClaudeがUIを生成できても、企業基幹業務として安全に長期運用するには、

- 正確性検証
- 権限設計
- 社員教育
- 監査対応
- 法令対応
- 外部システム再接続

が必要。

そのため、

> **ChatGPT / Claude → MCP・API → 既存SaaS**

という構造の方が現実的。

出典:  
https://corp.freee.co.jp/news/20260630freee_inventory.html

- freee顧問先管理 | AIエージェント

出典:  
https://corp.freee.co.jp/news/20260915freee_AIagent%26fAH.html

## 本当の堀

freeeの堀はUIではなく、

- 仕訳
- 銀行
- カード
- 請求
- 給与
- 税務
- 人事
- 社内ルール

> **Claudeがfreeeを何回呼び出すようになるか**

を見る方が重要。

## リスク

SMB顧客が多く、大企業向けSaaSよりスイッチングコストが低い可能性がある。

AI自身が将来データ移行を自動化すると、乗り換えコストが下がる可能性もある。

# 13. AIに代替されやすいSaaS

- 単なる文章生成
- 単なるタスク管理
- 簡単なフォーム作成
- 独自データを持たない
- ワークフローに深く入っていない
- 法規制・監査・権限管理が弱い
- 外部システム接続が少ない

このような「薄いSaaS」はClaudeやChatGPTに機能を吸収されるリスクが高い。

# 14. AI時代に強いSaaS

強いのは、

- 会計帳簿
- 給与データ
- 顧客DB
- 契約書
- 請求書
- 人事評価
- 認証・権限
- 決済
- 監査ログ

などのSystem of Recordを持つ企業。

AIには、

- 何を考えるか
- どのデータを見るか
- どの数字が正しいか
- 誰がアクセスできるか
- 何を実行できるか
- 誰が承認したか

が必要。

この基盤はSaaS側に残る可能性が高い。

# 最終まとめ

SaaSpocalypseでは、AIの進化によってSaaS企業の存在価値そのものが否定され、一時約1兆ドル規模の時価総額が失われた。

しかし、その後の実際の企業業績を見ると、

- Salesforce
- ServiceNow
- Atlassian
- Snowflake

などはAI需要を取り込み、株価も大きく買い戻された。

日本企業でも、

- freee
- マネーフォワード
- Sansan
- 弁護士ドットコム
- Talent Palette

などがMCPやClaude連携を進めている。

つまり現時点で見えている未来は、

> **AIがSaaSを全部消すのではなく、AIがSaaSを操作する時代。**

SaaSのUI価値は低下する可能性がある一方、

> **企業データ・権限・監査・業務実行基盤としてのSaaS価値は、むしろAI普及によって高まる可能性がある。**

特にfreee、マネーフォワード、Sansan、弁護士ドットコムのように企業固有データを持つSaaSを、単純に「生成AIに代替される会社」として一括で売るのは粗い見方と考えられる。
