## 1. エグゼクティブサマリー

芝浦機械を評価する際の中心論点は、**「AI・航空宇宙・造船向けの工作機械受注が急増している一方、全社の連結利益にはまだ十分反映されていない」**という事業と業績の時間差にある。

- 2026年4〜6月期の**工作機械受注高は約140億円、前年同期の約53億円から2.6倍**。
- **工作機械受注残高は約401億円、前年同期の約225億円から77.8%増**。
- 同期の工作機械事業は売上高約51億円、営業利益約3億〜4億円で増収増益。一方、連結全社の営業利益は約6.5億円の赤字。
- AIデータセンター用の**光コネクタ金型向け超精密加工機を、従来月産3〜5台から2027年度第1四半期以降に月産12〜15台へ増強する計画**。
- 大型・特殊工作機械は2026年度の**生産量を前年度比1.5倍**に引き上げる目標。
- 米国Moore Nanotechnology Systems, LLCの買収を通じ、北米・欧州の超精密加工機市場への販売網拡張を図る。
- 会社が公表した次期予想はなお慎重。**2027年3月期の営業利益予想は42億円で、前期実績約43.7億円を下回る**。
- **最新確認株価は4,925円（2026年10月9日終値）**。2026年1月5日終値4,350円から**575円、13.22%上昇**。前年末4,285円を基準とする一般的な年初来騰落率は**14.94%上昇**。

**投資判断上の着眼点：** 受注高・受注残の増加だけでなく、出荷・検収・売上計上が進み、低迷している全社営業利益率と営業キャッシュフローが改善するかが核心である。

## 2. 企業の収益構造と現在の転換点

芝浦機械は、射出成形機、ダイカストマシン、押出成形機といった**成形機事業**、大型工作機械・超精密加工機からなる**工作機械事業**、制御機械などを手掛ける機械メーカーである。

直近の全社業績を苦しくしている主な要素は、従来の稼ぎ頭だった中国向けリチウムイオン電池用セパレータフィルム製造装置（資料中の表記：BSF）の販売・受注減少、および自動車関連設備投資の鈍化である。

一方、次の市場で引き合いが増えている。

1. **AIデータセンターの高速光通信向け金型加工**：超精密加工機に需要が発生。
2. **エネルギー・航空宇宙・造船・防衛・建設機械**：大型・特殊工作機械が必要。
3. **車載光学部品・医療機器**：高精度な金型・光学部品加工技術を展開可能。
4. **北米・欧州の高付加価値な精密加工市場**：米国メーカー買収による販路と技術の補完を狙う。
5. **次世代のエネルギー貯蔵（ESS）関連設備**：押出成形機の用途拡張も会社資料で言及。

従って、事業構造が従来の中国・EV関連設備中心から、AI・高精度加工・産業インフラ関連へ徐々に移行する可能性がある。ただし、旧事業の低迷は現在も連結業績の重荷になっている。

### 3-3. なぜ全社赤字なのに工作機械が好調なのか

- 工作機械はAI光通信向け超精密加工機、航空宇宙、造船、エネルギー向けなどが伸長。
- 成形機事業では中国のEV電池向けBSF案件が減少。2026年4〜6月期の成形機売上高は前年同期約243億円から約137億円に減少し、事業利益も黒字から赤字へ。
- 全社では成形機事業の落ち込みが、工作機械の伸びを打ち消している。

このため、**「成長分野の受注増加」＝「連結EPSの即時急増」ではない**。

### 部品調達のボトルネック

記事では、軸受け（ベアリング）、直動部品、工具を測定する機器などの供給不足への懸念が指摘されている。芝浦機械社長・日本工作機械工業会会長の坂元繁友氏も、必要な部品をタイムリーに調達できなくなる可能性に言及している。

**需要が多い企業が必ず勝つとは限らない。** 部材の安定調達、主軸ユニットの仕様統一、外注先の確保、稼働率向上、納期遵守が、受注を利益へ転換するうえで差別化要因になる。

## 5. 芝浦機械がこれから進める具体的な成長戦略

### 5-1. AI光通信向け超精密加工機の生産能力拡大

芝浦機械はAI半導体チップそのものを製造する企業ではない。主な関連性は、**AIデータセンターの高速通信に使われる光コネクタなどの高精度金型を加工する機械**にある。

「AIデータセンター増設 → 高速光通信需要 → 精密な光コネクタ需要 → 金型需要 → 芝浦機械の超精密加工機需要」という間接的な設備投資チェーンである。

金型のピッチ・深さなどには±0.2μm以下の精度要求があると会社は説明している。

| 時期 | 超精密加工機の月間生産体制 | 施策 |
|---|---:|---|
| 2026年度第1四半期頃 | 3〜5台/月 | 既存設備を活用 |
| 2026年度第2〜第4四半期 | 6〜9台/月 | 工程・体制見直し、増産分のスピンドル加工を外注 |
| 2027年度第1四半期以降 | 12〜15台/月 | 設備導入・スピンドル加工の内製化 |

- 2025年度下期の主に中国メーカー向け受注台数：約100台。
- スピンドル加工設備導入などの投資計画：約1.2億円。
- 最大月産能力は従来より大幅に上がる。ただし**計画生産能力と販売確定台数は同じではない**。

### 5-2. 次世代800G光通信向け金型加工機の開発

現在の400G対応の金型加工に加えて、**800G対応機の開発を開始し、2028年度からの販売を目指す**計画がある。

機関投資家としては、数量が伸びるだけでなく、高速化に伴う加工精度の要求の高度化によって、超精密加工機の競争力・価格決定力が高まるかに注目する。ただし量産や収益性はまだ未確認。

### 5-3. 航空宇宙・エネルギー・造船・防衛など大型工作機械を増産

会社は大型・特殊工作機械の**2026年度生産量を2025年度比1.5倍**にする目標を示している。

対象機種の例は、フロア式横中ぐり盤、複合加工機、大型門形機など。対応分野は、航空宇宙、エネルギー、建設機械、造船、防衛産業など。

増産手段：

1. 社内人員の流動化・再配置。
2. 新規外注先の開拓。
3. 主軸頭の仕様統一による設計・調達・製造の効率化。
4. 在庫機の販売促進と生産前倒し。
5. レトロフィット（改造・更新）とサービスの拡充。

この市場はAI以外の設備投資からも需要が生まれる点が強みだが、受注単価、原価、納期、検収時期によって損益は左右される。

### 5-4. Moore Nanotechnology Systems, LLCの買収計画

2026年5月18日、芝浦機械は米国の超精密工作機械メーカー**Moore Nanotechnology Systems, LLC（Nanotech社）の全持分取得**を決定した。

| 所在国 | 米国 |
| 取得対象 | 持分100% |
| 公表取得価額 | 企業価値として約1億5,000万米ドル |

| 狙い | 北米・欧州の販路拡大、製品開発効率化、原価低減、研削と切削の技術補完 |

**買収で期待できる相乗効果：** 芝浦機械の超精密研削技術とNanotech社の超精密切削・販売網を組み合わせ、中国以外の市場を開拓する。

**買収リスクの具体例：** Nanotech社の2025年12月期の売上高は3,555万米ドル、営業損失は423万米ドル（会社公表の買収資料）。投資額は大きく、買収先が直近で赤字だった点は厳密に評価する必要がある。2026年12月期には黒字転換見込みと発表されているが、予想段階である。

### 5-5. 生産拠点再編・コスト低減・自動化

2026年10月1日、会社はタイ製造現地法人の閉鎖とグローバル生産体制の最適化に関する方針を公表。中国拠点などへの生産機能の集約・見直しを進める。

技能者個人への依存を減らす高精度加工、DX、自動化、システムエンジニアリング、外注・内製の適切な分担も重点領域。

## 6. 受注残が利益になるまでのタイムラグ

### 6-1. 会社自身の受注推移

| 指標 | 2025年4〜6月期 | 2026年4〜6月期 |
|---|---:|---:|
| 全社受注高 | 約238億円 | 約323億円 |
| 工作機械受注高 | 約53億円 | 約140億円 |
| 全社受注残高 | 約1,023億円 | 約1,078億円 |
| 工作機械受注残高 | 約225億円 | 約401億円 |

全社受注残は約5.4%増だが、工作機械受注残は約77.8%増。これは**会社の事業構成が変化していることを映している**。一方、成形機の受注残は減っており、全社増益がすぐに起こるとは限らない。

### 6-2. 利益計上までのプロセス

1. **受注**：顧客から注文を獲得し、受注残として積み上がる。
2. **調達・設計・製造**：部品・軸受け・スピンドルを確保し、生産能力を拡張する。運転資金が必要。
3. **納入・検収・売上認識**：契約条件に応じて売上高に計上される。
4. **営業利益・キャッシュフロー**：粗利、固定費、為替、コスト増、売掛金の回収次第で利益・資金繰りに反映。

本チャットでの分析上のイメージは、2026年に受注先行、2026年後半〜2027年に増産・納入が進み、2027年以降に利益回復を確認するというもの。ただし各案件の検収時期は異なるため、会社の確約するスケジュールではない。

## 7. 財務基盤・キャッシュフロー・配当

### 7-1. 財務基盤

- 2026年6月末時点の自己資本比率：約67.7%。
- 2026年3月末時点の現金・現金同等物：約427億円。

### 7-2. 配当

- 2027年3月期の会社予想年間配当：140円。
- 当該会社予想の配当性向：約165.5%。

利益予想を超える配当支払水準であり、現状の配当維持が利益成長により裏付けられているとは言い難い。高配当のみを投資根拠にすべきではない。

## 8. 営業利益率の回復余地と感応度分析

2025年3月期の営業利益率は約8.4%、2026年3月期は約3.3%、2027年3月期会社予想は約3.1%。

**売上高1,700億円と仮定した場合の営業利益率別試算**（実際の会社予想ではない）。

| 仮定する営業利益率 | 仮定する営業利益 |
|---:|---:|
| 3.0% | 51億円 |
| 3.5% | 59.5億円 |
| 4.0% | 68億円 |
| 5.0% | 85億円 |
| 6.0% | 102億円 |
| 7.0% | 119億円 |
| 8.0% | 136億円 |
| 9.0% | 153億円 |

計算式：`営業利益 = 売上高 × 営業利益率`。

仮に売上高1,700億円、営業利益率8%を達成すれば営業利益は136億円。2027年3月期会社予想42億円の約3.2倍に相当する。ただし、この改善幅は大きく、四季報の2028年3月期予想営業利益59億円を大きく超える強気シナリオである。

利益成長を見通すうえでは、成形機の赤字縮小、工作機械の価格転嫁、増産による固定費吸収、買収先の採算改善を個別に検証する必要がある。

## 10. 機関投資家としての成長シナリオ

### 強気シナリオ

- 超精密加工機の月産12〜15台体制が計画通り立ち上がる。
- 航空宇宙・造船・エネルギーなど大型工作機械の増産が出荷・検収へつながる。
- 400Gから800Gへの製品高度化と、北米買収の販売網活用によって高付加価値製品の比率が上がる。
- 既存成形機事業の収益悪化が止まり、全社の利益率が5〜8%方向へ改善する。
- この場合、受注残の成長を利益の増加が追いかける「業績回復の再評価」が起きる可能性がある。

### 中立シナリオ

- 工作機械の成長は続くが、成形機事業の回復や買収先の採算改善に時間がかかる。
- 受注の増加が利益として認識されるまで一定の時間を要する。
- 2028年3月期の四季報予想に近い、売上高1,700億円・営業利益59億円程度の段階的な回復。

### 弱気シナリオ

- 部品調達難、軸受けや直動部品の不足で納期が長期化。
- 材料高・物流費・エネルギー費の上昇を販売価格に十分転嫁できない。
- 中国市場の設備投資低迷が続き、成形機事業の低収益が長引く。
- 買収後の統合費用・収益悪化・のれん減損などが発生。
- 受注高は伸びても営業利益率・営業キャッシュフローが改善せず、株価が伸び悩む。

## 11. 中期経営計画の実行力に関する注意点

従来の「中計2026」では2027年3月期に売上高2,000億円、営業利益率10%を目標としていた。一方、足元の会社予想は売上高1,370億円、営業利益42億円（営業利益率約3.1%）。**当初目標から大幅に乖離**している。

したがって、新しい中期経営計画で提示される成長目標についても、過去の達成率を踏まえて検証する必要がある。長期の売上目標やAI特需の好材料だけで投資判断を完結させない。

## 13. 最終評価

**事業面**：AI・光通信に関連する超精密加工機と航空宇宙などの大型工作機械の受注伸長には具体的な裏付けがある。増産、800G対応機の開発、米国買収など、今後の成長施策も明確。

**業績面**：工作機械の受注拡大は実績だが、全社の連結営業利益がまだ赤字となる四半期もある。成形機の不振、受注から売上への時間差、部材価格、M&Aの統合コストが焦点。

**財務面**：自己資本比率は比較的高いが、営業キャッシュフローは悪化した時期がある。配当性向も高く、手元資金があっても継続的な現金創出力の改善が必要。

**株価面**：2026年10月9日終値4,925円は年初の1月5日終値から13.22%高、前年末から14.94%高、年初来安値から34.93%高。成長期待が一部織り込まれていると考えられ、**「受注急増＝株価がまだ割安」とは判断できない**。

**総合見解**：芝浦機械は「すでに高利益成長を確立した企業」というより、**高付加価値な受注の拡大と事業構造転換が進んでいるが、利益改善の実行力が今後問われる企業**。機関投資家としては、今後の決算で受注残の売上転換と連結営業利益率の改善が確認できるかを重視したい。
