# 三菱UFJフィナンシャル・グループ（8306）企業分析レポート

**分析基準日：2026年10月15日**  
**株価評価基準：2026年10月14日終値**  
**分析対象：会社四季報2026年4集（添付画像）、2026年3月期本決算、2027年3月期第1四半期決算、直近IR・中期経営計画**

## 1. 総合結論

三菱UFJフィナンシャル・グループ（以下MUFG）は、日本の金利正常化と海外金融事業の成長という複数の収益ドライバーを持つ国内メガバンクである。

2027年3月期第1四半期（2026年4〜6月）の最終利益は**8,094億円（前年同期比+48.2%）**で、四半期として過去最高の水準。国内貸出の利ざや改善、手数料収入の増加、モルガン・スタンレーの持分法利益の伸長が寄与した。

一方、株価は2026年年初から大きく上昇し、2026年10月14日の終値**3,482円**で、予想PERは約14.0倍、PBRは約1.73倍（前回分析時の参照値）。かつての極端な割安銀行株という評価ではなく、今後のROE維持・成長が問われる段階にある。

**投資上の中心論点：**「日銀がさらに利上げするか」だけでなく、預貸金利ざや・貸出数量・継続的な手数料収入・信用コスト・ROEの5点が、今後も改善するか。

## 4. 増益要因：5つの収益エンジン

### 4-1. 日本の金利正常化と預貸金利ざやの改善

銀行は、預金などの資金調達コストと貸出金利の差から利益を得る。2026年4〜6月期の国内管理会計ベースの利回りは、貸出金約**1.47%**、預金等約**0.30%**、金利差約**1.16%**とされた（公表値の丸めによって単純差とは一致しない場合がある）。

利上げの効果はプラスだが、**政策金利上昇＝銀行利益の無条件な増加**ではない。預金金利の上昇、貸出需要減少、信用コスト増加、保有債券の評価損が相殺要因となる。

### 4-2. 国内法人金融・設備投資・M&A

国内コーポレートバンキング事業では業務粗利益が**2,235億円→2,729億円**、営業純益が**1,311億円→1,743億円**に増加。

半導体工場、AIデータセンター、電力、物流等の設備投資が増加すれば、融資・社債発行・プロジェクトファイナンス・為替ヘッジ・M&A助言などに需要が生まれる。ただし、官民投資が全て新規借入に結びつくわけではない。

### 4-3. 米モルガン・スタンレーの利益貢献

MUFGはモルガン・スタンレーの大株主で、米国の投資銀行業務、証券取引、資産運用の収益を持分法で取り込む。2026年4〜6月期の同社関連利益のMUFG帰属額は**約2,222億円**と説明されている。

日本の金利だけに依存しない強みである一方、米国の株式・債券市場、M&A市場の低迷時には逆風にもなる。

### 4-4. アジアの金融事業

タイのアユタヤ銀行、インドネシアのダナモン銀行、インド関連投資などを通じ、アジアの貸出・金融サービス需要を取り込む戦略。国内人口減少を補う成長源となる可能性があるが、現地通貨安、不良債権、規制変更のリスクも持つ。

### 4-5. 資産運用・証券・デジタル金融

銀行・証券・信託・投資信託販売・資産管理・金融アプリを組み合わせ、金利収入以外の継続的な手数料収入を拡充。AIによる業務効率化や顧客サービス強化も狙う。

**評価：** 金利正常化に加え、非金利収益源が伸びるかが、次の利益成長局面の鍵。

## 5. 中期経営計画と今後の成長戦略

現行の2024〜2026年度中期経営計画の最終年度（2027年3月期）の目標として、以下が示されている。

| 目標 | 数値 |
|---|---:|
| 親会社株主帰属利益 | **2.7兆円** |
| ROE | **12%程度** |
| 第1四半期利益の通期目標進捗率 | **約30.0%**（8,094億円÷2.7兆円） |

主要戦略は以下の3点。

1. **利上げ効果が一巡した後の成長：** 貸出数量、手数料、法人・資産運用ビジネスによって利益を伸ばす。
2. **資本配分の高度化：** 収益性の低い資産から、法人金融・海外金融・資産運用等の高収益分野に経営資源を振り向ける。
3. **政策保有株式の売却益への過度な依存を減らす：** 一時的な売却益を除いてもROE12%程度の収益力を維持できるかが重要。

第1四半期は単純均等進捗25%を上回るが、持分法利益や一時的利益の季節性があるため、それだけで通期上方修正を確実視できない。

## 8. PER・PBR・ROE・配当利回り

2026年10月14日終値3,482円での評価（四季報2027年3月期予想を使用）。

| 指標 | 算定値 | 計算・出所 |
|---|---:|---|
| 予想PER | **約14.0倍** | 3,482円÷EPS248.8円 |
| PBR | **約1.73倍** | 前回分析時の参考値 |
| 予想配当利回り | **約2.76%** | 96円÷3,482円 |
| 四季報予想ROE | **約12.3%** | 添付四季報 |

銀行のPBRを判断する際には、ROEが資本コストを継続的に上回れるかが重要。PBR約1.73倍は、すでに一定の成長期待を織り込んだ水準と見るべきで、過去のPBR1倍割れ時代と同じ割安判断はできない。

### EPS248.8円を固定したPER感応度

| 想定PER | 理論的な株価試算 | 3,482円からの変化率 |
|---|---:|---:|
| 11倍 | 約2,737円 | -21.4% |
| 13倍 | 約3,234円 | -7.1% |
| 14倍 | 約3,483円 | ほぼ同水準 |
| 16倍 | 約3,981円 | +14.3% |
| 18倍 | 約4,478円 | +28.6% |

**重要：** これらは将来の目標株価や予測ではなく、PER変化に対する機械的な感応度試算。利益成長してもPERが低下すれば株価は下落し得る。

## 9. 銀行としての財務安全性

銀行は預金受入と融資が本業であり、一般事業会社と同様に負債残高や営業CFを単純評価するのは適切ではない。

### 重視すべき指標

- **CET1比率：** 普通株式等Tier1資本の、リスクを加味した資産に対する割合。損失吸収力を測る。
- **与信関係費用：** 貸倒れや将来損失に備える引当の負担。
- **不良債権：** 元利払いが難しくなった融資の比率や金額。
- **有価証券の評価損益：** 市場金利上昇による債券価格下落等の影響。

| 資本指標（2026年6月末、前回調査値） | 数値 |
|---|---:|
| CET1比率（規制ベース） | 12.95% |
| バーゼルIII最終化・完全実施ベース | 11.4% |
| 同・有価証券評価益を除くベース | 9.5% |
| 中計の資本目標レンジ | 9.5〜10.5% |

数値は計算前提が異なるため横並びで単純比較できない。海外投資などで資本を使用する場合、還元余力の判断にはCET1の推移が重要。

2026年4〜6月期の与信関係費用は**469億円→720億円**に増加。ただし前年同期には大口引当金戻入があったため、直ちに貸出資産の質が急激に悪化したとは断定できない。

### 主なリスク

1. 景気後退に伴う貸倒れ・信用コストの増加。
2. 金利の急変に伴う債券評価損、貸出需要の減退。
3. 米国資本市場の停滞によるモルガン・スタンレーの業績悪化。
4. アジア通貨・規制・不良債権のリスク。
5. サイバー攻撃やシステム障害による損失・信用毀損。

## 10. 新冷戦・経済安全保障・AI設備投資との関係

総合商社が鉱山・資源調達・事業開発などを担うのに対し、MUFGは融資・資本市場・為替ヘッジ・プロジェクトファイナンスなどを通じて戦略的な投資を資金面から支える。

### 関連する事業機会

- **半導体・AI・電力設備：** 工場建設、データセンター、送配電網関連の資金需要。
- **供給網の再編：** 海外生産拠点の移転、買収、資源開発に伴う大型案件。
- **企業のM&A・国際展開：** 助言、融資、社債、為替・金利ヘッジなどの手数料収益。
- **政策・官民投資：** 補助金や公的資金と民間融資の組み合わせ。

### 反対論点

安全保障上重要な案件でも採算が低いことはある。紛争、制裁、需要鈍化、投資遅延が生じれば銀行にも貸倒れや資本負担が生じるため、「国家的重要性が上がる＝利益が必ず増える」ではない。

## 12. 次回決算の注目項目

**2027年3月期中間決算：2026年11月13日（金）発表予定**（前回調査時点のIR日程）。

- [ ] 通期利益2.7兆円の目標を維持するか、上方修正するか。

## 13. 機関投資家としての最終判断

| 評価項目 | 見方 | 理由 |
|---|---|---|
| 収益成長 | 強い | 本決算・直近四半期とも好調 |
| 事業競争力 | 強い | 国内顧客基盤と米国・アジア金融事業 |
| 収益の持続性 | 改善傾向 | 資金利益・手数料利益が増加 |
| 財務健全性 | 継続確認 | CET1・信用コストに着目 |
| 株主還元 | 積極的 | 増配・自社株買いの方針 |
| 割安度 | 慎重 | すでに株価は大幅上昇、PBR約1.73倍 |
| 経済安全保障との関係 | 大きい | 官民投資・国際事業を金融面で支える |

**総合評価：** 事業の収益力は改善しているが、現在の株価には利益成長・ROE改善の期待がすでに相応に織り込まれている。追加利上げだけを投資理由にするのではなく、利ざや・貸出数量・手数料・信用コスト・ROEの持続的な改善を確認したい。

**中長期の投資仮説：** 国内の設備投資や企業再編が活発化し、米国・アジアの金融事業も成長するなら、MUFGは国内金利の上昇効果が一巡した後も利益成長を維持できる可能性がある。ただし、それが株価上昇につながるかは、買付時のPER・PBRと将来利益の実現度による。
