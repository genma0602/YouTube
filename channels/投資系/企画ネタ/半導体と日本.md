# 半導体と日本

## AI半導体の覇権は本当に日本なのか

ここまで聞いて、

「AI半導体の覇権は、日本が握っているのか」

そう思った人もいるかもしれません。

ただし、最初に正確なことを言います。

**日本が、AI半導体そのものの覇権を握っているわけではありません。**

- AI向けGPUの設計では、アメリカのNVIDIAやAMDが中心です。
- 最先端半導体の受託製造では、台湾のTSMCが圧倒的な存在感を持っています。
- AI半導体に必要なHBMでは、韓国のSKハイニックスやサムスン電子が大きなシェアを持っています。

つまり、AI半導体の設計、最先端製造、メモリーという完成品に近い部分だけを見れば、日本が世界の中心だとは言えません。

---

## 日本が握っているのは「製造ボトルネックの覇権」

では、日本はAI半導体のどこで強いのか。

日本が握っているのは、AI半導体を実際に量産するために必要な、

- 製造装置
- 半導体材料
- 検査装置
- 精密加工
- 今後AIが現実世界へ広がるうえで必要になる産業用ロボット

言い換えると、日本が握っているのは、AI半導体の**設計覇権**ではありません。

世界中の半導体メーカーが避けて通れない、**製造ボトルネックの覇権**です。

---

## 半導体製造装置

まず、半導体製造装置全体で見ると、日本企業は世界市場のおよそ**3割**を占めています。

アメリカやオランダの企業も強いため、日本が製造装置全体の半分を握っているわけではありません。

しかし、日本企業の本当の強さは、全体のシェアだけでは分かりません。

半導体を洗う。削る。薄くする。切り分ける。正常に動くか検査する。

こうした代替しにくい特定の工程になると、日本企業のシェアは一気に**50％、60％、75％**という水準まで高まります。

---

## 半導体材料

材料分野でも、日本企業は非常に強い立場にあります。

重要な半導体材料6品目を合計すると、日本企業は世界市場の**半分近く**を占めているとされています。

日本は最先端GPUを設計している国ではありません。

しかし、そのGPUを大量生産するために必要な、高純度で代替しにくい材料を供給する側では、世界的な支配力を持っています。

### シリコンウェハー

半導体の土台となるシリコンウェハー。半導体の回路を作り込む円盤状の基板。

- **信越化学工業**と**SUMCO**の2社だけで、世界シェア**50％以上**

世界中の企業がどれだけ高性能なAI半導体を設計しても、土台となる高品質なシリコンウェハーを安定して調達できなければ、量産することはできません。

### フォトレジスト

シリコンウェハーの上に微細な回路パターンを焼き付ける際に使う感光材料。

- 日本企業が世界供給の**過半数**

半導体の性能が上がり、回路がさらに細かくなればなるほど、材料には高い純度と均一性が求められます。少しの不純物や誤差が、大量の不良品につながるからです。

長年にわたる化学技術や品質管理の積み重ねが必要になるため、価格が安いという理由だけで、簡単に別の企業へ切り替えることはできません。

### 味の素のABF

ABFとは、Ajinomoto Build-up Filmの略。

AIサーバー向けCPUやGPUなどを、パッケージ基板へ実装する際に使われる絶縁材料。

- **味の素**が世界市場の約**95％**（ABFという特定の層間絶縁材料におけるシェア）

すべての半導体基板材料で95％という意味ではありません。しかし、世界のAI半導体メーカーにとって極めて重要な材料であることに変わりはありません。

NVIDIAが高性能なAI半導体を設計する。TSMCが最先端の製造技術でチップを作る。しかし、そのチップを高性能な基板へ実装し、製品として完成させるためには、日本企業が開発した材料が必要になる。

これが、日本の製造ボトルネックとしての強さです。

### Tガラス（日東紡）

AI半導体向け基板には、特殊なガラス繊維も使われます。

半導体の性能が高くなるほど、消費電力と発熱も大きくなります。熱によって基板が膨張したり変形したりすると、半導体の接続部分に不具合が発生する可能性があります。

そこで必要になるのが、熱による変形を抑える**Tガラス**。

- **日東紡**が世界供給をほぼ独占（正確な世界シェア率は非公開のため90％や100％と断定はできない）

---

## 検査装置

半導体は製造しただけでは出荷できません。設計どおりの性能を出せるか、高速で正確に動作するか、高温や長時間の使用に耐えられるかを検査する必要があります。

半導体自動テスト装置（ATE）の市場では、

- **アドバンテスト**が世界シェア**50％以上**（一部製品分野では60％超）

AI半導体やHBMは、従来の半導体よりも構造が複雑。複数のチップやメモリーを組み合わせるため、どこか一つに不具合があれば、製品全体が正常に動かなくなります。

AI半導体の需要が増えるということは、チップの生産量が増えるだけではなく、**検査しなければならない半導体の数も増える**ということです。

---

## 精密加工

半導体は、シリコンウェハーの上に大量のチップを作ったあと、ウェハーを薄く削り、一つ一つのチップへ切り分ける必要があります。

研削、切断、ダイシング装置では、

- **ディスコ**が世界市場のおよそ**4分の3（約75％）**

NVIDIA製GPUの需要が増えても、TSMCの工場が増えても、韓国企業のHBM生産が増えても、その裏側では日本製の精密加工装置が必要になる可能性が高い。

## 数字の整理

| 分野 | 日本の強み |
| --- | --- |
| 半導体製造装置（全体） | 世界の約3割 |
| 重要な半導体材料6品目 | 世界市場の半分近く |
| シリコンウェハー | 信越化学＋SUMCOで50％以上 |
| フォトレジスト | 日本企業が世界供給の過半数 |
| ABF（味の素） | 約95％ |
| 半導体テスト装置 | アドバンテスト50％以上 |
| 切断・研削装置 | ディスコ約75％ |

この数字を見ると、日本がGPUやAI半導体の完成品で世界を支配しているわけではなくても、半導体を量産するために必要な重要工程を押さえていることが分かります。

**世界中のAI企業が投資を増やせば増やすほど、日本企業の装置や材料に対する需要も増える。**

これが、日本株がAI相場の恩恵を受ける構造的な理由です。

---

## フィジカルAI

日本の強みは半導体だけではありません。次に来る可能性があるのが、**フィジカルAI**です。

これまでの生成AIは、文章・画像・プログラム・データ分析など、デジタル空間の中で使われてきました。

今後はAIがロボットや自動車、工場、物流設備、建設機械、医療機器などに組み込まれ、**現実世界で動く**ようになります。

フィジカルAI時代に重要になるのは、AIのソフトウェアだけではありません。

- ロボット本体
- モーター
- センサー
- 減速機
- 工作機械
- 制御装置
- 精密部品
- 工場を自動化するシステム

こうした現実世界のハードウェアが必要で、この分野は日本企業が長年強みを持ってきた領域です。

### 日本の産業用ロボット（2025年）

日本ロボット工業会によると：

| 指標 | 数値 |
| --- | --- |
| 生産台数 | 約207,000台 |
| 総出荷台数 | 約211,000台 |
| 海外向け輸出台数 | 約173,000台 |
| 輸出比率（台数ベース） | 約82％ |
| 輸出比率（金額ベース） | 約8割 |

日本は世界で最も多くロボットを導入している国ではありません（2024年国内新規導入約44,000台＝世界全体の約8％）。

日本の強さは、**ロボットを生産し、世界中の工場へ輸出しているメーカー側の強さ**です。

### 世界の産業用ロボット市場（国際ロボット連盟）

| 年 | 年間導入台数 |
| --- | --- |
| 2024年 | 約542,000台 |
| 2025年 | 約575,000台 |
| 2028年（予測） | 70万台超 |

2024年から2028年までの4年間で、年間導入台数は少なくとも約**29％増**。2024年末時点で世界の工場で約**466万台**の産業用ロボットが稼働。

フィジカルAIは遠い未来の空想ではなく、すでに世界中の工場で自動化とロボット導入は進んでいます。

### ヒューマノイドロボット（バークレイズ予測）

| 年 | 市場規模 |
| --- | --- |
| 現在 | 20–30億ドル程度 |
| 2030年 | 約250億ドル |
| 2035年 | 約400億ドル |
| 強気ケース | 2,000億ドル規模 |

**注意：** 量産コスト、バッテリー、安全性、ソフトウェア、法規制、人間並みの作業能力など、まだ多くの課題が残る。2035年2,000億ドル予測を確定した未来として扱うことはできない。

現時点で最も確度が高い事実は、産業用ロボットの導入台数が2024年約54万台から2028年70万台超へ増えると予測されていること。

## 結論：正確な言い換え

「AI半導体の覇権は日本」と言ってよいのか。

正確には、その表現は少し強すぎます。

| 分野 | 日本の位置 |
| --- | --- |
| AI向けGPU設計 | 世界を支配していない |
| 最先端半導体製造 | 世界首位ではない |
| HBM | 世界首位ではない |
| 半導体製造装置 | 世界の約3割 |
| 重要な半導体材料 | 半分近く |
| シリコンウェハー | 日本2社で50％以上 |
| ABF | 味の素約95％ |
| テスト装置 | アドバンテスト50％以上 |
| 切断・研削装置 | ディスコ約75％ |
| 産業用ロボット | 出荷台数の8割以上が海外輸出 |

**日本が握っているのは、AI半導体を設計する覇権ではない。**

半導体を作る。材料を塗る。基板へ実装する。薄く削る。一つ一つのチップへ切り分ける。正常に動くか検査する。そして、AIを現実世界で動かすロボットを生産する。

**この代替しにくい製造工程とハードウェアの覇権。**

---

## 最も実態に近い表現

> **AI半導体とフィジカルAIを支える、製造ボトルネックの覇権を日本企業が握っている。**

AI投資が拡大すれば、アメリカ企業だけが儲かるわけではない。台湾や韓国の半導体企業だけが儲かるわけでもない。

- AI半導体の生産量が増えれば → 日本企業の装置、材料、検査、精密加工への需要も増える
- AIがデータセンターから現実世界へ広がれば → 産業用ロボットや精密機械の価値も高まる

この製造ボトルネックが今後も維持されるのであれば、日本株は単なる円安相場や一時的なAIブームではなく、世界的なAI投資の拡大から継続的に利益を得られる可能性がある。

**これこそが、2030年に向けて日本企業の利益が成長し、日経平均10万円を目指すうえで重要な根拠の一つ。**
