# 第1部　G7と比較した日本の財政

## 1. 財政赤字はG7の中でどの程度か

まず区別すべき指標は以下のとおり。

- **財政収支（フロー）**：ある1年間に政府がどれほどの赤字・黒字を記録したか。
- **政府債務残高（ストック）**：過去の借入れ等を累積した残高。
- **一般政府**：中央政府だけでなく、地方政府や社会保障基金も含めた、国際比較に適した政府の範囲。
- **GDP比**：経済規模の異なる国を比較するため、金額をGDPで割った比率。

### G7の一般政府財政収支（対GDP比）

| 国 | 2025年推計 | 2026年予測 |
|---|---:|---:|
| **日本** | **−1.1%** | **−2.0%** |
| カナダ | −1.8% | −2.7% |
| ドイツ | −2.7% | −3.8% |
| イタリア | −3.1% | −2.8% |
| フランス | −5.1% | −4.9% |
| イギリス | −5.4% | −3.9% |
| アメリカ | −6.8% | −7.5% |

**出典**：IMF『Fiscal Monitor』2026年4月版、Table A1。マイナスは財政赤字。2025年は推計、2026年は予測。参考リンクは末尾に掲載。

### この比較が示す事実

1. このIMFの2025年推計では、日本の一般政府財政赤字はGDP比1.1%で、比較対象のG7各国より小さい。
2. アメリカの赤字率6.8%は、日本の1.1%の約6.2倍。
3. 2026年予測においても、日本の赤字率2.0%は比較対象のG7各国より小さい。
4. IMFの2026年対日審査は、日本の基礎的財政収支の赤字がコロナ前の2019年より小さく、G7でも小さい水準であることを指摘した。

**含意**：「日本はG7の中で特に大きい単年度の財政赤字を出している」という説明は、この時点のIMF数値とは整合しない。

**注意点**：財政赤字が小さいことと、累積した政府債務が小さいことは異なる。また、財政赤字の大小だけで経済成長率や財政政策の望ましさは判断できない。

## 2. 政府債務残高はどうか

### G7の一般政府債務残高（2025年、対GDP比）

| 国 | 総債務 | 純債務 |
|---|---:|---:|
| 日本 | 206.5% | 136.5% |
| カナダ | 113.5% | 10.2% |
| ドイツ | 62.9% | 47.2% |
| フランス | 116.0% | 108.8% |
| イタリア | 137.1% | 127.7% |
| イギリス | 102.3% | 93.8% |
| アメリカ | 123.9% | 96.7% |

**出典**：IMF『Fiscal Monitor』2026年4月版、Tables A7・A8。

- **総債務**：保有する金融資産を控除する前の政府債務。
- **純債務**：一定の金融資産を控除した政府債務。金融資産の範囲、年金等の会計上の扱いは国ごとに異なり、単純な比較には注意が必要。

### ここから言えること

- 日本の**政府総債務・純債務のGDP比は、いずれもG7の中で大きい**。
- したがって「日本はG7で債務が最も小さい」「すべての財政指標で最も健全」とは言えない。
- ただし、政府債務の評価には、**通貨建て、保有者、償還期限、利払い条件、政府金融資産、成長率**などを併せて確認する必要がある。

### IMFの日本国債に関するリスク評価

IMFの2026年対日審査では、日本のソブリン債務ストレスリスクは **moderate（中程度）** と評価された。リスク緩和要因として、以下が挙げられた。

- 円建て債務
- 厚い国内投資家層
- 政府の金融資産
- 国債の比較的長い償還期限
- 国債の平均残存年限：約9.5年

この評価は「債務比率が高いから直ちに財政危機になる」との見方を支持しない。一方、「債務リスクがない」という意味でもない。金利の上昇、利払い増加、高齢化に伴う財政圧力を無視できない。

## 3. 日本の金融資産と対外純資産

### 主要数値

| 指標 | 数値 | 時点・資料 |
|---|---:|---|
| 日本の対外純資産 | **561.8兆円** | 2025年末・財務省 |
| 国の資産合計 | **783.4兆円** | 2024年度末・財務省「国の財務書類」 |
| 国の負債合計 | **1,483.3兆円** | 同上 |
| 国の資産・負債差額 | **−699.9兆円** | 同上 |
| 日本の経常収支 | **GDP比 +4.6%** | 2025年・IMF推計 |

### 対外純資産が意味するもの

対外純資産は、国内居住者が持つ海外資産から、海外居住者が持つ国内資産を差し引いたもの。日本経済全体の対外的な資産基盤の一つとして重要である。

ただし、この中には民間企業・家計などの資産も含まれる。**561.8兆円すべてを政府が国債返済のために使えるわけではない。**

また、国の資産783.4兆円には換金が難しい資産もあり、負債1,483.3兆円との差額がマイナスである事実も併記する必要がある。

したがって「資産があるので債務は問題ない」と単純化するのではなく、資産・負債の性質、流動性、保有主体を確認することが必要。

## 4. 国債の保有者と金融構造

### 日本国債等の保有構成（2026年6月末）

| 保有主体 | 割合 |
|---|---:|
| 日本銀行 | 41.16% |
| その他国内主体 | 45.72% |
| 海外主体 | 13.12% |
| **国内主体合計（日銀を含む）** | **86.88%** |

**出典**：日本銀行『資金循環統計』2026年第2四半期、図表6-2。国庫短期証券・国債・財投債の合計、時価ベース。

### 何が重要か

- 国債等の大部分は国内部門が保有している。
- 海外資金への全面的な依存とは異なる資金調達構造を持つ。
- 日銀が大量に保有する国債は、財政と中央銀行を合わせた「統合政府」の分析で異なる見え方になる部分がある。
- ただし、**日銀の保有債券を統合政府として相殺して考えても、日銀当座預金等の負債や金利負担、インフレ面の制約まで消えるわけではない。**

## 5. ギリシャ・トルコと同一視できない理由

### 2025年の比較

| 指標 | 日本 | ギリシャ | トルコ |
|---|---:|---:|---:|
| 一般政府財政収支/GDP | −1.1% | +1.3% | −2.8% |
| 一般政府総債務/GDP | 206.5% | 145.7% | 23.5% |
| 通貨制度 | 独自通貨・円 | ユーロ共通通貨 | 独自通貨・リラ |

**出典**：IMF『Fiscal Monitor』2026年4月版。ギリシャ2025年財政収支は、同年5月のIMF国別審査で**+1.7%**に改定されている点に注意。

### ギリシャの債務危機との相違

ギリシャは2010年代に深刻な債務危機を経験し、2012年には大規模な債務再編が行われた。背景には以下があった。

- 巨額の債務
- 市場での資金調達環境の悪化
- ユーロ圏という共通通貨制度の制約
- 生産性・競争力・経常収支などの構造的問題

日本は独自通貨の円で国債を発行しており、ギリシャの当時の状況とは制度的に異なる。

ただし、**現在のギリシャは財政黒字を出している**。2025年時点の財政収支を無視し、「いまもギリシャは日本より財政赤字が大きい」と説明するのは正確でない。

### トルコとの相違

- トルコの政府債務比率は、2025年時点で日本より大幅に低い。
- 一方、2025年12月のトルコの消費者物価上昇率は前年同月比約30.9%。
- IMFは外貨流動性や外貨準備の十分性などを重要な課題として指摘。

つまり、**政府債務比率だけで金融危機リスクを測ることはできない**。インフレ、外貨調達、通貨への信認、対外収支、金融政策の枠組みなどが重要になる。

### 比較の整理

日本とギリシャ・トルコを「政府債務が大きい／小さい」という単一の数字で同一視するのは適切でない。一方で、「日本のほうがあらゆる意味で財政が健全」と断定することも、公的指標からは導けない。

## 6. 積極財政を評価する際の経済学的論点

### 財政政策と長期成長

2014年のIMF『World Economic Outlook』第3章は、生産性の高い公共投資には中長期の成長効果があり得ることを示している。

会話内で紹介した推計の一つでは、先進国で公共投資をGDP比1%ポイント増やすと、産出水準は実施年に約**+0.4%**、4年後に約**+1.5%**となる。

効果が大きくなりやすい条件として、以下が挙げられる。

1. 需要不足・経済の遊休資源が存在する。
2. 公共投資が効率的に実施される。
3. 企業の生産性を高めるインフラや研究開発に資金が向かう。
4. 投資が民間の追加投資を促す。

### 2026年の日本への応用で考える分野

- 電力網・送配電設備
- 半導体・AI関連インフラ
- 研究開発
- 人材育成
- 防災・老朽化インフラ更新

これらが将来の供給力や民間設備投資につながるかを評価する価値がある。

### 留意すべき反対側のメカニズム

- 労働力・資材供給が限られていると、投資需要の増加が物価・建設費の上昇につながり得る。
- 金利上昇で政府の利払い負担が増える可能性がある。
- 事業の費用対効果が低ければ、財政負担に見合う成長が得られない。
- IMFの2026年対日審査は高い債務水準、将来の利払い費増加、高齢化による支出圧力を警戒している。

# 第2部　財政赤字と官民投資・経済成長

## 7. G7・スペインの財政・投資・成長率

ここで検証する仮説は次のとおり。

> **財政赤字を許容しつつ、政府が戦略的な支援を行い、民間企業も設備投資を拡大している先進国では、経済成長率が高くなるのではないか。**

ただし「政府の赤字が大きいから成長する」という仮説と、「官民の生産的な投資が経済成長につながる」という仮説は分ける必要がある。

### 2025年成長率・財政赤字と2024年総投資比率

| 国 | 2025年実質GDP成長率 | 2025年一般政府財政赤字/GDP | 2024年総固定資本形成/GDP |
|---|---:|---:|---:|
| アメリカ | **+2.3%** | **6.8%** | 約22% |
| 日本 | +1.2% | 1.1% | 約26% |
| カナダ | +1.7% | 1.8% | 約23% |
| ドイツ | +0.2% | 2.7% | 約20% |
| フランス | +0.9% | 5.1% | 約22% |
| イギリス | +1.2% | 5.4% | 約19% |
| イタリア | +0.6% | 3.1% | 約22% |
| スペイン | **+2.8%** | 2.4% | 約20% |

**出典**：財政赤字はIMF『Fiscal Monitor』2026年4月版、GDP成長率は各国統計当局・OECD・欧州委員会の会話内調査、総固定資本形成は世界銀行系列の2024年概数。

**集計上の重要な注意**：GDP成長率は2025年、固定資本形成比率は2024年という異なる期間。投資比率は概数で、会計基準や内訳が同一とは限らない。これだけでは国際的な因果関係は証明できない。

### 読み取れること

- 米国は大きな財政赤字と民間の設備・知的財産投資が併存している。
- スペインはEU資金も活用しながら比較的高い成長率を記録した。
- フランスやイギリスは大きな財政赤字があっても、経済成長率は米国・スペインほど高くない。
- 日本の総固定資本形成比率は表の国々と比べても高い水準にあるため、単純に「日本は総投資額が少ないから成長しない」とは説明できない。

**ここでの暫定的な整理**：赤字の大きさと成長率は単純な比例関係ではない。赤字が何に使われ、どの程度民間投資や生産性の上昇につながるかを検証する必要がある。

### 米国の2025年GDP成長率の更新について

このチャット内の最初の比較では米国の2025年実質GDP成長率を**+2.1%**と記載したが、その後、米商務省BEAの2026年9月30日公表の改定値**+2.3%**に更新した。**本書は更新後の+2.3%を採用**している。

## 8. 米国――公共政策と民間投資

### 成長実績

- 2025年の実質GDP成長率：**+2.3%**（米商務省BEAによる2026年9月30日改定値）
- 2025年の一般政府財政赤字：**GDP比6.8%**（IMF推計）
- 成長の主要因として米商務省は、個人消費と民間投資を挙げている。
- 研究開発、知的財産、コンピューター関連の投資が重要な領域となった。

### 事例A：CHIPS法と半導体投資

| 項目 | 会話内で確認した数値・内容 |
|---|---|
| 米政府の半導体製造支援制度 | 約390億ドル |
| 民間の半導体・電子機器関連投資計画 | 約4,500億ドル |
| 計画額の参照時点 | 2025年1月ごろ |
| 政策の狙い | 国内製造能力・先端半導体の供給能力・関連産業の強化 |

米商務省が支援制度を設計することで、企業の米国内での工場建設・設備投資計画を促した事例として扱った。

**注意**：約4,500億ドルは投資の**計画・発表額**であり、支出済み投資ではない。政府支援との因果関係を厳密に識別した効果推定ではない。

### 事例B：IRAなどとクリーンエネルギー投資

| 項目 | 会話内で確認した数値・内容 |
|---|---|
| 民間企業・消費者のクリーンエネルギー投資 | 約5,000億ドル |
| 対象期間 | 2022年8月から約2年間 |
| 資料 | 米財務省、2024年10月公表 |
| 主な政策手段 | 税額控除などの民間投資誘因 |

この数字には企業だけでなく消費者の投資も含まれるため、すべてを民間企業の設備投資として扱わないこと。

### 米国事例の評価

米国は、財政赤字を抱えながら半導体やエネルギー分野に対して補助金・税制で投資誘因を提供し、民間投資計画の拡大が確認された事例。

ただし、米国経済の高成長には個人消費、労働市場、移民、金融環境、生産性、世界需要など複数の要因が関与する。CHIPS法やIRAだけで2025年の成長率を説明できるものではない。

## 9. ドイツ――インフラ基金と財政ルールの変更

### ドイツの転換点

- 2023年・2024年にマイナス成長を記録。
- 2025年の実質GDP成長率は**+0.2%**。
- 機械設備・建設への投資低迷が、成長の弱さの一因とされた。
- 2025年3月、ドイツは債務ブレーキに関する財政ルールを改正。
- **5,000億ユーロ規模**のインフラ特別基金を創設した。

### 主な投資分野

1. 交通・橋梁・鉄道
2. 医療
3. 教育
4. 研究開発
5. エネルギー・電力関連インフラ
6. デジタル化

欧州委員会は、今回の改革が今後10年間のドイツの成長を押し上げる可能性を分析している。

**ただし**：2025年の制度変更の成長効果は、現時点ですべて実現したわけではない。2023～2025年の停滞についても、エネルギー価格、中国との競争、輸出需要の弱さなど他の要因を考慮する必要がある。「ドイツの停滞は財政規律だけが原因だった」とは断定できない。

## 10. スペイン――EU復興資金の活用

### 2025年の実績・制度

- 2025年実質GDP成長率：**+2.8%**。
- 同年の一般政府財政赤字：**GDP比2.4%**。
- EU復興・強靱化計画の補助金・融資を活用。
- 再生可能エネルギー、デジタル化、研究開発、産業競争力などに投資。
- 欧州委員会の計画には、民間のグリーン・デジタル・社会関連投資を促進する**約760億ユーロの金融手段**が含まれる。
- OECDもEU資金によるプロジェクトが設備投資を支えていると説明している。

### 解釈上の注意

- スペインの成長は官民投資だけでなく、雇用増加や家計消費にも支えられている。
- EUの共同資金調達等を通じた支援があるため、投資の全額をスペイン政府の財政赤字で賄ったわけではない。
- 公共資金と民間投資の連動を考える事例として重要だが、財政赤字と成長率の因果をこれだけで証明するものではない。

## 11. 日本――投資量より生産性・投資効率

OECDの2026年対日経済分析について、このチャット内で確認したポイントは以下のとおり。

| 論点 | 公的資料に基づく指摘 |
|---|---|
| 民間投資比率 | GDPに対して国際的に比較的高い |
| 労働者1人当たり実質固定資産 | 過去約20年ほぼ横ばい |
| 日本の全要素生産性（TFP）成長率 | 2000～2024年平均 **年0.4%** |
| OECD平均TFP成長率 | 同期間 **年0.8%** |
| 米国TFP成長率 | 同期間 **年1.2%** |
| 課題 | AIなど先端技術の導入、中小企業への技術普及など |

### 分析上の意味

「日本は設備投資をしていないから成長していない」という単純な説明は不十分。

必要なのは、設備の更新だけでなく、

- 企業の付加価値や生産性を引き上げる研究開発
- ソフトウェア・AI・デジタル化
- 中小企業への技術普及
- 新規事業の創出や事業拡大
- 技術導入を支える人材育成・電力・通信などの基盤整備

に投資が結びついているかを確かめること。

これらの分野に政府支援を行えば、民間企業の追加投資を誘発できる可能性がある。ただし実際の政策効果は事業ごとの検証が必要。

## 12. IMF研究が示す公共投資の効果

会話内では、IMFの研究を基に**二つの推計値**に言及した。これらは研究・推計の条件が異なるため、同一の数値として混ぜないこと。

### 推計A：2014年『World Economic Outlook』に関する説明

- 公共投資をGDP比1%ポイント増加
- 実施年の産出水準：**約+0.4%**
- 4年後の産出水準：**約+1.5%**

### 推計B：別のIMF公共投資分析に関する説明

- 先進国で予想外の公共投資をGDP比1%ポイント増加
- 同年の産出水準：**約+0.2%**
- 4年後の産出水準：**約+1.2%**
- その分析では、民間投資比率を統計的に有意に高める効果は確認できなかった。

### 研究から読み取る際の注意

- 産出水準の押し上げは、「実質GDP成長率が毎年ずっと1.2%上がる」という意味ではない。
- 投資の質、景気局面、資金調達条件、事業執行能力などにより効果が変わる。
- 2014年の国際研究の平均的な推計を、2026年の日本に無条件で当てはめることはできない。
- 公共投資には成長効果があり得るものの、**すべての公共支出が自動的に民間投資を呼び込むわけではない**。

## 13. 官民投資から経済成長に至るメカニズム

以下は、このチャットで整理した「政府が民間投資を誘発する場合」の想定経路。

```text
政府投資・補助金・税額控除
（電力網、研究開発、産業基盤、人材育成）
                  ↓
民間企業の設備投資・技術開発
（半導体、AI、工場、ソフトウェア、自動化）
                  ↓
生産能力・労働生産性の向上
（付加価値、企業利益、賃金の増加）
                  ↓
実質GDPと税収の成長
                  ↓
条件が整えば、債務/GDP比の改善にも寄与
```

### 成功する場合の条件

1. 民間投資にとっての障害を取り除く事業であること。
2. 投資先の生産性・収益性が十分に高いこと。
3. 補助金によって、もともと実施される予定だった投資を単に置き換えるだけではないこと。
4. 人材・資材・電力・用地などの供給制約に対応していること。
5. 投資の規模、完成時期、稼働率を追跡して事後評価できること。

### うまくいかない場合のリスク

- 公共投資の乗数効果が小さく、財政負担だけが残る。
- 供給制約によって、実質成長よりもインフレが先行する。
- 金利上昇などを通じて、民間投資の一部が抑制される可能性がある。
- 非効率な補助金が過当競争や過剰設備を誘発する。
- 税収増加が支出や利払いの増加に届かず、債務比率が上昇する。

# 第3部　分析結果と検証課題

## A. このチャットの調査で確認できる事実

| 検証した主張 | 確認できた内容 |
|---|---|
| 日本の単年度財政赤字はG7で小さいか | IMFの2025年推計・2026年予測では、比較対象のG7各国より小さい |
| 日本の政府債務はG7で小さいか | 総債務・純債務のGDP比は高い |
| 日本に大きな金融資産・国内投資家基盤があるか | 財務省・日銀の統計から確認できる |
| 日本と2010年代のギリシャを同じ制度として扱えるか | 独自通貨と共通通貨制度の違いなどがある |
| 日本とトルコを債務比率だけで比較できるか | インフレ、外貨流動性、対外条件を含めた比較が必要 |
| 巨額の財政赤字を出している米国は成長しているか | 2025年実質GDP成長率+2.3%と財政赤字GDP比6.8%が併存 |
| 米政府が民間投資を誘発する政策を行ったか | CHIPS法、IRAなどの政策実例がある |
| EU資金の支援を受けたスペインは成長しているか | 2025年実質GDP成長率+2.8%、EUの投資支援制度がある |
| ドイツは公共投資のため財政ルールを変更したか | 2025年、5,000億ユーロのインフラ基金を創設 |
| 財政赤字が大きければ常に成長率も高いか | フランス・英国等を含めると単純な比例関係は認められない |
| 生産的な公共投資は成長に貢献し得るか | IMFの実証研究が成長効果を示している |

## B. 積極財政の仮説をさらに厳密に調べるための問い

1. **官民投資の分解**：各国の総固定資本形成について、政府・民間・住宅・機械設備・知的財産投資の内訳を同一統計から比較できるか。
2. **時系列の検証**：赤字や投資が増えた年の前後5～10年間で、GDP、労働生産性、賃金、税収がどのように変化したか。
3. **財政政策の追加性**：補助金を受けた企業の投資は、支援がなくても実施された投資なのか、政策が新たに生み出した投資なのか。
4. **投資効率**：政府支援1円当たり、民間投資、設備稼働、生産性、税収がどれだけ増加したか。
5. **日本特有の制約**：少子高齢化、労働力不足、電力網、デジタル化の遅れなどの制約をどう緩和できるか。
6. **財政の持続可能性**：名目GDP成長率、国債の平均金利、基礎的財政収支の組合せで債務/GDP比はどう変わるか。

## C. 研究から考えられる政策・投資仮説

「政府の財政赤字を増やせば経済成長する」と言い切るのではなく、以下の形で検証するのが適切。

> **政府が生産性の高い公共投資や税制支援を行い、それが民間企業の追加投資と技術革新を誘発する場合、中長期的な実質GDP・所得・税収の成長につながり得る。**

ただし、投資効果が十分でなければ、財政コスト、金利負担、インフレ、非効率投資などのリスクが増す。したがって、政策評価では「赤字の額」よりも、**投資先、追加投資の誘発効果、生産性の改善、実行効率**を重視する必要がある。
