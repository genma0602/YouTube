# 第1部 川崎重工業（7012）

**機関投資家目線の徹底分析｜調査基準：2026年11月12日｜東証プライム｜最新決算：2026年11月10日発表**

## 1. 総合評価：業績は強いが、利益の質と株価下落の理由が重要

川崎重工業は、防衛・航空宇宙、ガスタービン・エネルギー、造船、産業用ロボット、半導体製造装置関連、二輪車を展開する総合重工メーカー。

最初に結論を述べると、**2026年11月10日に発表された最新中間決算は大幅増益で、通期業績予想も上方修正されました。**

ただし、事業利益の増加には一時的な要因も含まれています。さらに、防衛・航空宇宙部門では増収にもかかわらず利益が伸びていないため、全事業が一様に好調というわけではありません。

| 主要指標 | 実績・予想 | 前年同期比・前期比 |
|---|---:|---:|
| 上半期売上収益 | 1兆844億円 | +8.8% |
| 上半期事業利益 | 738億円 | +106.8% |
| 通期事業利益予想 | 1,850億円 | +27.5% |
| 通期売上収益予想 | 2兆5,600億円 | +10.8% |

出所：川崎重工業「2027年3月期 第2四半期決算短信」2026年11月10日。数値は億円単位で丸めています。

今回の分析では、次の三つを特に重視します。

- **ガスタービン・電力事業**：本当に受注が伸びているのか。AIデータセンター向け電力需要の恩恵はあるのか。
- **防衛・航空宇宙事業**：防衛予算増加と航空機増産が、どの程度利益に転換できているのか。
- **海外機関投資家と株価**：好決算にもかかわらず、2026年3月の高値から大幅に下落した理由は何か。

なお、同社は2026年4月1日に**1株を5株に分割**しています。過去10年間の株価比較では、この影響を調整する必要があります。

## 3. ガスタービン事業：需要拡大は確認できる

### 最新IRではガスタービンの需要拡大を見込む

2026年10月発行の統合報告書「Kawasaki Report 2026」で、会社はエネルギーソリューション＆マリン事業について、船舶の豊富な受注残とともに**ガスタービン需要の拡大を見込む**と説明しています。

これはガスタービンを成長要因として経営陣が認識している、重要な一次情報です。

ただし、現在の開示ではガスタービン単独の受注高・売上高・営業利益が独立して示されていません。したがって、エネルギー部門の好調をすべてガスタービンによるものと判断することはできません。

### 2026年11月9日発表：ドイツで30MW級の水素対応ガスタービン

ドイツRWE・エムスラント拠点での実証では、**30MW級**の水素対応ガスタービン「L30A」の発電実証を実施。水素混焼から水素専焼まで対応し、水素混合率0〜100%に対応します。将来の低炭素電力供給を狙います。

出所：NEDO、2026年11月9日発表。実証設備が稼働したという意味であり、大量の商用受注確定を意味するものではありません。

この技術が評価できる理由は、水素エネルギーの供給拡大に合わせて、既存のガスタービン技術を発展させられる点にあります。

ただし、**2026年現在の利益成長の主因と、2030年代を見据えた水素事業の成長可能性は分けて考える必要があります。**

### エネルギー部門の増益を分解すると

最新決算では、同部門の事業利益が前年同期から106億円増加して305億円となりました。

会社が決算説明会で示した主な利益改善要因は、中国の造船関連持分法会社の利益増加や、LPG・アンモニア運搬船の採算改善などです。ガスタービン単独の増益額は開示されていません。

一方、発電設備などを含むエネルギー関連製品の売上見通しは、前期865億円から今期930億円へ増加する計画です。アフターサービスも376億円から420億円を見込んでいます。これらはガスタービン単独の数字ではありませんが、保守・サービスの継続収益が伸びる点は評価できます。

**AIデータセンター向け電力需要との関係は有望ですが、まだ確認が必要です。** データセンターの電源確保にはガスタービンが選択肢となりますが、川崎重工の最新IRから特定のハイパースケーラー向け大型ガスタービン受注や、その利益貢献額までは確認できませんでした。

私なら、ガスタービン事業は「好調な需要環境と成長余地がある」と評価する一方、現時点でAIデータセンターの直接受注銘柄として高いプレミアムを付けることには慎重になります。

## 4. 株主・アナリストの質問に対する経営陣の回答

2026年11月10日の決算説明会では、野村證券、ゴールドマン・サックス、UBS、シティグループなどが経営陣に直接質問しています。

この質疑応答は全文が公開されており、決算短信以上に重要な情報が含まれています。

なお、以下は**機関投資家・証券会社のアナリストとの質疑**です。株主総会の一般株主による質疑とは区別します。

出典：川崎重工業「2026年度第2四半期決算説明会書き起こし（質疑応答含む）」。

### ① 野村證券：防衛・航空宇宙の利益予想を40億円引き下げた理由は？

**会社の回答：**

- 約20億円は航空会社の経営悪化に伴う債権評価損
- 約20億円は防衛機・民間航空機の納入や売上計上の後ずれ
- P-1、C-2では一部購入部品の納入が遅延
- ボーイング787の増産ペースも想定より遅れている

これは重要な回答です。

40億円の下方修正のうち、20億円は将来に利益が戻ってくる可能性のある期ずれですが、残る20億円は信用損失に関するものであり、同じ扱いはできません。

防衛需要が強いからといって、納期どおりに売上・利益を計上できるとは限りません。

### ② ゴールドマン・サックス：ロボット事業の利益は一時的な和解金によるものでは？

**会社の回答：**

ロボット事業には和解金収入が含まれるものの、それを除いても7〜9月期に数十億円規模の利益が出ていると説明しました。

また、半導体向けロボットの増収、円安効果、中国向け油圧機器販売の改善が寄与しているとの回答です。

これはポジティブです。

半導体製造装置向けロボットの需要が収益に結び付き始めているためです。ただし、和解金の正確な金額が分からない以上、今期の208億円という上半期セグメント利益をそのまま将来に延長するのは適切ではありません。

### ③ UBS：航空宇宙の下半期利益580億円は実現できるのか？

| 航空宇宙事業の利益計画 | 金額・構成 |
|---|---:|
| 上半期実績 | 100億円（通期予想の14.7%） |
| 下半期必要額 | 580億円（通期予想の85.3%） |
| 通期予想 | 680億円 |

会社は、下半期の売上計上増加や固定費負担の正常化を理由に、計画達成に自信を示しています。

ただし、機関投資家としては**今回の決算で最も警戒する数字の一つ**です。

防衛関連の売上が下半期へ集中する傾向はあるものの、上半期の約5.8倍の利益を下半期に稼がなければならないためです。

ここで部品の納入遅延が続くと、再び下方修正されるリスクがあります。

### ④ シティ・UBS：北米二輪車の収益悪化は？

経営陣は、特定車種の品質問題に伴う販売自粛や、意図的な在庫調整が販売台数を押し下げていると回答しました。

一方、パワースポーツ部門の通期利益300億円予想は維持しています。

その背景には、米国IEEPA関税に関連する還付相当額約93億円を収益面の余裕として考えていることがあります。

つまり、二輪車事業そのものが全面的に回復したわけではありません。

### ⑤ モルガン・スタンレーMUFG：ガスタービンのサプライチェーンに問題はないか？

会社は現状では大きな支障はないと説明しています。ただし、今後の生産拡大に伴う供給体制には注意が必要だとする趣旨の回答でした。

これはガスタービン需要の強さを評価するうえで好材料ですが、生産能力に余裕があることや、大型受注が全て売上化することまで保証した回答ではありません。

## 5. 経営ビジョン：2030年度に売上3.3兆円超を目指す

2026年10月6日、川崎重工は「グループビジョン2030」の進捗と計画更新を公表しました。

| 2030年度の目標 | 水準 |
|---|---:|
| 売上収益 | 3.3兆円超 |
| 事業利益率 | 10%超 |
| ROIC | WACC＋3% |

売上3.3兆円、利益率10%とすると、事業利益は少なくとも3,300億円規模に達します。

2027年3月期予想の1,850億円から考えると、利益をさらに約78%以上拡大させる計画です。

主要な成長分野は、航空宇宙・防衛、発電・水素エネルギー、半導体関連ロボット、フィジカルAIです。

防衛事業では、2030年度の売上収益を7,000億〜8,000億円程度に拡大する見通しを示しています。

### 機関投資家として気になる資金調達

2026年7月に、同社は海外市場で新株発行と転換社債による資金調達を実施しました。

設備投資と成長戦略を加速させるためですが、既存株主には希薄化の影響があります。

会社が掲げる将来の成長は魅力的ですが、**売上・事業利益の伸びだけでなく、1株当たり利益（EPS）がどれだけ増えるのか**が重要です。

さらに、2026年9月末時点では次の財務面の注意点があります。

| 財務指標 | 上半期実績 |
|---|---:|
| 有利子負債 | 約6,688億円 |
| ネットD/Eレシオ | 約56.4% |
| 営業キャッシュフロー | −880億円 |
| 投資キャッシュフロー | −494億円 |
| フリーキャッシュフロー | **−1,375億円** |

今期のフリーキャッシュフローは通期でプラス200億円を計画しています。

計算上、下半期に約1,575億円のプラスが必要です。

重工業では大型案件の入金時期によって資金繰りが大きく変動しますが、**利益が増えていても現金が十分に増えていない**という点は、今後の監視対象です。

## 7. 直近1年間の株価推移

2026年11月12日・東証終値は**1,978円**、前日比+0.36%。前年同日比−6.2%、2026年3月高値比−47.5%。

2025年11月12日の株価は、2026年4月の5分割を調整して2,109円。2026年11月12日の終値はYahoo!ファイナンス15:30の表示。

### 好決算でも株価が下落した理由

2026年11月10日の株価は前日終値2,025.5円から1,963円へ約3.1%下落しました。

業績予想は上方修正されたものの、事業利益の修正幅は50億円にとどまり、一時的な利益押し上げ要因も含まれます。

さらに市場では、防衛・航空宇宙の下方修正、巨額の設備投資、増資による希薄化、キャッシュフローの悪化が警戒されたと考えられます。

ただし、**これらが下落幅の何割を説明したかは検証できません。** 日本株全体の需給悪化など、マクロ要因も作用しています。

11月6日の安値1,901.5円から11月12日終値までは約4.0%の戻りです。急落後の反発は見られますが、長期の底打ちが確認できたと断言する段階ではありません。

## 8. 過去10年間の株価推移

2016〜2025年は年末終値、2026年は11月12日終値。株式分割・併合調整後、配当を含まない。

| 年 | 年末株価 | 年間騰落率 |
|---|---:|---:|
| 2016 | 734円 | −18.8% |
| 2017 | 791円 | +7.8% |
| 2018 | 470.4円 | −40.5% |
| 2019 | 481.6円 | +2.4% |
| 2020 | 464.8円 | −3.5% |
| 2021 | 415.6円 | −10.6% |
| 2022 | 618円 | +48.7% |
| 2023 | 623.8円 | +0.9% |
| 2024 | 1,456円 | +133.4% |
| 2025 | 2,076円 | +42.6% |

長期では、2021年末の415.6円から2025年末の2,076円へ約5倍に上昇しています。

特に大きな転換点は2024年です。防衛関連企業への期待、収益性改善への見方、エネルギー・航空宇宙関連の成長期待などが株価の再評価につながったと考えられます。

その後、2026年3月に3,766円まで上昇しましたが、現在はそこから約47.5%下落しています。

この点から、**現在の株価は事業の長期成長期待が全て消えたというより、先行して上昇していた企業評価が修正されている局面**と捉えることができます。

### 質問① ドラクエ12の開発をリセットした理由は？

株主からは、2026年5月に示された『ドラゴンクエストXII』の開発体制のリスタートを受けて、開発費を無駄にしたのではないか、いつ発売されるのかと質問がありました。

重要なのは、**既に投じた開発費がどれだけ無駄になったかについて、具体的な金額の回答がなかった**ことです。

これは投資家目線での懸念材料です。

現在のHDゲーム部門は利益率が大幅改善していますが、次の大型タイトルで開発期間の長期化や作り直しが再発すれば、改善の持続性に疑問が生じます。

株主は、大型タイトルを発表してから発売までの期間が長すぎるため、ファンの熱が冷めてしまうと指摘しました。

**会社の回答：** この点を課題として認識しており、中期経営計画でもマーケティングの見直しを進めている。今後は発表から発売までの期間を短くするよう取り組む、というものでした。

ここは経営陣が問題を認識していると評価できます。

ただし、実際に開発期間が短縮されたか、広告宣伝費に対する販売効率が改善したかについては、新しい作品で検証する必要があります。

### 質問③ 社外取締役は株主と直接面談するのか？

この質問は、アクティビストの存在を考えると非常に重要です。

株主は、社外取締役が経営陣から独立した立場で株主と直接対話したことがあるか、明確な回答を求めました。

**会社の回答：** 取締役会は集団で意思決定する機関であり、特定の社外取締役が個別に株主と面談すると独立性や情報の公平性を損なうおそれがあるため、差し控えている。株主との面談内容は取締役会全体に共有している、というものでした。

これは3D Investment Partnersが求めるガバナンス改革と、経営陣の現在の立場との違いを示しています。

社外取締役が個別面談しないことが直ちに不適切とは限りませんが、約19%の株式を保有する投資家から対話姿勢を問われている局面では、今後も争点になる可能性があります。

### 質問④ 株式分割と株主優待は効果があったのか？

会社は、2025年3月末に2万3,000人超だった株主数が、2026年3月末には4万7,000人超へ増加したと回答しています。

また、株式分割と新設した株主優待は、個人株主の拡大に寄与した可能性が高いと説明しています。

個人株主の裾野を広げる施策としては一定の成果が見られます。一方、それだけで事業の収益性や資本効率が改善するわけではありません。

| 客単価前年比 | +6.6% |

すき家とは対照的に、はま寿司では客単価上昇が成長の中心です。

ただし客数もプラスであり、単に値上げによって売上が膨らんだわけではありません。

10月の国内はま寿司既存店売上は4.2%増へ鈍化しています。上半期の好調をそのまま将来に延長するのではなく、11月以降の客数・客単価を確認する必要があります。

## 4. 日本と海外の業績比較：地域別の売上高を分析

ここは、**最新の地域別売上実績が確認できる2026年3月期有価証券報告書**を使用します。

2027年3月期上半期の決算短信では、国別の売上高・営業利益を同じ粒度で公表していないため、最新の地域比較と最新の事業別比較は分けて扱います。

### 国・地域別売上高

**2026年3月期・通期実績（2025年4月〜2026年3月）**

| 地域 | 2025年3月期 | 2026年3月期 | 前期比 |
|---|---:|---:|---:|
| 日本 | 8,238億円 | 9,106億円 | +10.5% |
| 米国 | 1,485億円 | 1,478億円 | −0.4% |
| 中国 | 450億円 | 722億円 | **+60.4%** |
| ASEAN | 313億円 | 371億円 | +18.5% |
| 欧州 | 537億円 | 623億円 | +16.0% |
| その他 | 344億円 | 341億円 | −1.0% |
| **海外合計** | **3,129億円** | **3,535億円** | **+13.0%** |

出所：2026年3月期有価証券報告書p.128、地域別売上高。

この表から、海外市場で特に注目したいのは中国です。

**中国事業の売上高は1年間で約60%拡大しています。**

一方、米国売上はほぼ横ばいです。欧州や東南アジアは二桁成長しています。

ただし、中国の60%増には新規出店や既存店の成長など複数の要因が含まれます。会社が中国既存店売上と店舗増加の寄与を分離していないため、既存店だけで60%成長したという意味ではありません。

### 日本と海外の売上構成

| 地域 | 2026年3月期売上比率 | 補足 |
|---|---:|---|
| 国内 | **72.0%** | 日本国内の店舗・事業 |
| 海外 | **28.0%** | 海外各地域の合計 |

投資家としての解釈は以下のとおりです。

- 日本は現在の利益を支える最大の基盤であり、価格改定・客数増加・店舗運営効率化が重要です。
- 中国は売上成長率が突出しており、はま寿司を中心とするアジア展開の成長性を評価するうえで重要です。
- 北米・欧州はスーパー内寿司販売や食品製造などの仕組みを持ち、日本の外食店舗とは違う収益モデルです。

**海外売上が拡大していることは確認できますが、海外の利益率が国内より高いか低いかは、最新の地域別利益開示だけでは断定できません。**

## 5. 海外事業の深掘り：成長率が最も高いのはアジアのはま寿司

### 半年間で、海外はま寿司が約48%増加

2026年3月末と9月末の店舗数を比較すると、海外展開の勢いが分かります。

| 地域 | 3月末 | 9月末 | 半年間の純増 | 増加率 |
|---|---:|---:|---:|---:|
| 日本 | 664店 | 685店 | +21店 | +3.2% |
| 海外 | 198店 | 293店 | **+95店** | **+48.0%** |
| 合計 | 862店 | 978店 | +116店 | +13.5% |

新規出店が全体で116店純増したうち、海外が約82%を占めています。

これは、ゼンショーが国内の回転寿司チェーンから、アジア全域に寿司ビジネスを展開する企業へ変化していることを示す数字です。

ただし、95店増加しても、それぞれの店舗が開店直後から成熟店舗と同じ収益を生むわけではありません。今後は海外の新店が何カ月で投資回収できるかが重要です。

### 北米・欧州は外食店舗とは違う成長モデル

**SnowFox・AFCなどのスーパー内寿司販売**

北米・欧州の成長モデルは、レストランの大型出店だけではありません。スーパー内の寿司カウンターや、食品工場からスーパーへ納入する事業が中心です。

**YO!・Sushi Circleなどの販売網**

スーパーマーケットとの取引網や製造拠点を活用し、既存の販路へ新商品を供給する形で事業を拡大できます。

2026年9月末のグローバル中食事業は9,215拠点で、そのうち8,241拠点がフランチャイズです。店舗数が多くても、直営の「すき家」9,215店舗と同じ売上・利益規模になるわけではありません。

また、2026年6月にはポーランドの寿司製造・販売事業の買収を通じて、欧州の事業基盤を強化しています。買収によって増えた売上と、既存事業の自然成長を分けて評価する必要があります。

私がこの事業を評価する理由は、単なる寿司の人気ではなく、**食品製造・物流・小売販売網を一体化できる事業モデル**にあります。

一方で、前述したとおり、2026年3月期の米国売上は前年並みでした。したがって、北米については「拠点数が多い＝高成長」と見るのではなく、既存拠点当たり売上と営業利益率の改善を追うべきです。

## 6. 利益の質：増収増益はどこまで持続するのか

最新決算の営業利益増減分析は、経営陣の実行力を判断するうえで重要です。

### 上半期営業利益の主な増減要因

| 要因 | 営業利益への影響 |
|---|---:|
| 既存店売上高の増加 | **+262億円** |
| 原価要因 | +17億円 |
| 人件費増加 | −101億円 |
| 販管費増加 | −110億円 |
| 出退店の効果 | +66億円 |
| グローバル中食などその他 | プラス寄与 |
| **前年同期比の営業増益額** | **約160億円** |

ここは非常にポジティブです。

既存店売上増加の利益押し上げ効果262億円に対して、人件費と販管費が合計211億円増加しています。それでも増益を確保できています。

特に食品企業は、人件費、米・牛肉・魚などの原材料価格、物流費の影響を強く受けます。

今回の数字は、これらのコスト上昇を既存店売上や出店効果で吸収できていることを示しています。

### ただし、財務の安全性はスクエニほど高くない

| 上半期の財務・キャッシュフロー | 数値 |
|---|---:|
| 営業CF | +763億円 |
| 投資CF | −544億円 |
| フリーCF（概算） | **+219億円** |
| 有利子負債 | 約3,149億円 |
| 自己資本比率 | 約35.9% |
| ネットD/Eレシオ | 約0.5倍 |

2026年9月末の決算資料。フリーCFは営業CF＋投資CFの簡便計算。

上半期は営業キャッシュフローから投資キャッシュフローを差し引いてもプラスです。

これは利益の増加が実際の現金創出にもつながっている点で評価できます。

ただし、積極的な海外M&Aと新規出店によって有利子負債が大きくなっています。海外の買収企業が期待どおりに利益を上げられなかった場合、減損損失や金利負担が株主価値を圧迫する可能性があります。

## 7. 経営ビジョン：2028年3月期に営業利益1,165億円

2026年5月12日公表の中期経営計画では、次の数値目標を設定しています。

| 2028年3月期目標 | 数値 |
|---|---:|
| 売上高 | 1兆4,810億円 |
| 営業利益 | 1,165億円 |
| 営業利益率 | 約7.9% |

最新の2027年3月期予想が営業利益1,055億円なので、計画最終年度の目標まではあと110億円です。

今期の大幅な利益成長によって、中期経営計画の達成に向けた進捗が進んでいると評価できます。

会社が掲げる中心戦略は、世界での店舗展開加速、DX・AIを用いた店舗運営改革、食材調達から加工・物流・販売までを統合するMMD（マス・マーチャンダイジング）の高度化です。

さらに、安全衛生の徹底も重点施策に含まれています。

ここでの投資上の評価は、単に店舗数を増やすだけでなく、**大規模化によって調達・製造・物流コストを引き下げられるか**にあります。

一方、2028年3月期の中計営業利益率目標は約7.9%で、今上半期実績の8.2%より低い水準です。会社は出店費用や事業別採算を考慮している可能性がありますが、この差については次の決算説明会で具体的な理由を確認したいところです。

## 12. 現在のバリュエーションは割安なのか？

2026年11月12日終値12,555円と、同日発表された修正後の会社予想を使います。

| 指標 | 試算 |
|---|---:|
| 2027年3月期予想EPS | 344.98円 |
| 予想PER | **36.4倍** |
| PBR | 約7.0倍 |
| 年間配当予想 | 80円 |
| 配当利回り | 約0.64% |
| 予想配当性向 | 約23.2% |
| 普通株ベースの時価総額 | 約2.02兆円 |

私が最も警戒するのは、この**PER36.4倍、PBR約7倍**という評価です。

国内外で成長している企業として高い評価を受ける理由はありますが、外食・食品企業としては将来の高成長をかなり織り込んだ水準です。

### 会社予想EPS344.98円を固定したPER感応度

| 想定PER | 株価換算 | 現在値との差 |
|---|---:|---:|
| 25倍 | 約8,625円 | −31.3% |
| 30倍 | 約10,349円 | −17.6% |
| 35倍 | 約12,074円 | −3.8% |
| 40倍 | 約13,799円 | +9.9% |
| 45倍 | 約15,524円 | +23.7% |

これは目標株価ではなく、会社予想の利益水準を変えずにPERだけを変えた感応度分析です。

仮に海外の出店ペースが鈍化した場合、会社の利益が引き続き増加していても、PERが40倍から30倍へ下がるだけで株価は大きく下落する可能性があります。

一方、はま寿司の海外店舗数が今後も増え、利益率も改善するなら、高いバリュエーションを維持する根拠になります。

## 13. 機関投資家としての最終判断

| 評価項目 | 判断 |
|---|---|
| 国内すき家 | 客数中心の増収が強い |
| 国内はま寿司 | 客単価上昇と出店が成長要因 |
| 海外はま寿司 | **最も注目したい成長事業** |
| 北米・欧州中食 | 販売網に強み、既存事業の成長率は要確認 |
| 利益率改善 | 明確に進展 |
| 財務健全性 | FCFはプラス、有利子負債には注意 |
| 海外機関投資家の評価 | 強気と中立が混在 |
| 株価評価 | **成長期待を相当程度織り込み済み** |

### 結論

ゼンショーの成長は、国内外の店舗数と利益の両方で確認できます。

特に今後の企業価値を考えると、私は**海外はま寿司の成長性**を最も重視します。半年で海外店舗数が48%増加したという事実は、国内市場だけを対象にしていた企業とは異なる成長余地を示しています。

国内では「すき家」の客数回復が強く、「はま寿司」も客単価の上昇によって利益を伸ばしています。全社の営業利益増加率が売上増加率を上回っている点も評価できます。

一方で、予想PER36倍超という株価には、こうした好調が今後も続くという期待がかなり含まれています。

したがって現段階では、**「事業は非常に強いが、株価が明確に割安とは言いにくい成長株」**と評価します。

今後の投資判断を左右するのは、海外はま寿司の新規出店が実際の利益成長にどれだけ結び付くか、国内既存店売上が維持されるか、そして海外M&Aが資本効率を改善できるかの3点です。
