# 海外・日本国内の社会不安で物色される日本株

**調査基準日：2026年10月21日（市場データは原則10月20日引けまで）**

## 分析の注意点

- **実際に買われた実績**は、株価と当時の市況記事が一致するものに限定。
- **相対的に強かった**とは、市場全体より上昇率が高い、または下落率が小さいことで、必ずしも株価がプラスとは限らない。
- **将来の業績上の受益候補**は、契約構造や地域別売上に基づく仮説であり、当該イベントでの買いを確認できたという意味ではない。
- 政治不安、暴動、財政危機、金融危機、物理的破壊、サイバー攻撃は別のショックであり、買われる企業群も異なる。
- 今回のフランス不安と同時に中東原油高、米AI信用不安、他国金融市場の動揺があったため、単一要因の因果は識別できない。

## 6. 何を買うかよりも、何を計測するか

日次の銘柄騰落率だけでなく、(1) 日次リターン−TOPIXリターン（超過収益）、(2) 出来高/過去20日平均、(3) 事件前後5日・20日・60日のリターン、(4) 会社IRの受注・契約・粗利、(5) JPY為替・日米欧の長期金利・信用スプレッド、(6) 予算や警備契約の確定、(7) 海外事業売上比率を確認する。

**判断の分岐**

1. 海外事件が金融システムへ波及しない：日本株には影響が小さい可能性。個別株の業績を優先。
2. 海外事件が国債・銀行危機へ波及：グローバル株安・円高／金利変化を優先し、ディフェンシブの相対リターンを観察。日本の警備株は直接の受益主体とは限らない。
3. 日本国内で治安事件：当日の物色は監視カメラなど小型株に向かいやすい実例。翌日以降の反動リスクが大きい。
4. 日本国内で政権・財政政策の不確実性：為替、日銀、政府予算、防衛・公共投資計画への市場評価を観察。円安なら輸出株、金利高なら銀行・保険・高PER銘柄の影響は事業別に分化する。

**投資判断の核心：社会不安の見出し自体を買わない。金融市場の経路と企業の追加利益を買う。**
