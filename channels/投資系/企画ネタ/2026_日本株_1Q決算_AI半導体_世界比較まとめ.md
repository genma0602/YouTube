# 2026年 日本株1Q決算・AI半導体・世界比較まとめ

更新日：2026年9月7日

---

## 1. 結論

2026年4〜6月期の日本企業決算は、全体として非常に強い内容だった。

特に重要なのは、AI・半導体関連だけではなく、製造業・非製造業の広い範囲で利益が伸びていること。

- 日本企業全体の経常利益は過去最高
- 製造業・非製造業ともに過去最高水準
- 1Q時点で上方修正する企業が例年より多い
- 下方修正企業はかなり少ない
- AI半導体関連ではキオクシア、フジクラ、アドバンテストなどが大幅増益
- 日本株のEPS成長率は先進国トップクラス
- 株価パフォーマンスでは日経平均が主要先進国市場の中でもトップクラス

1954年以降の四半期データで、全産業の経常利益は過去最高水準。

「AI半導体だけが日本企業全体を押し上げている」という状況ではなく、非製造業まで増益が広がっている。

# 4. 上方修正・下方修正

TOPIX構成企業では、通常1Q時点で営業利益予想を上方修正する企業は5〜10%程度とされる。

今回は、金融を除くTOPIX構成企業の約17%が1Q時点ですでに営業利益予想を上方修正したとの集計がある。

これはかなり強い。

## 民間集計による参考値

東証プライム約1,468社の集計では、

- 上方修正：313社
- 下方修正：45社

とされる。

全企業に占める割合では、

- 上方修正：約21.3%
- 下方修正：約3.1%

業績予想を「修正した会社」だけで見ると、

- 上方修正：約87%
- 下方修正：約13%

したがって、

> 「下方修正は1割くらい」

という認識は、「予想を変更した企業の中で」という意味ならかなり近い。

ただし、全上場企業に対する下方修正率という意味では約3%程度。

※この上方・下方修正社数はJPX公式集計ではなく民間集計の参考値。

# 17. 日本株の利益成長率は先進国で何位か

結論：

> 日本は先進国1位とは言い切れないが、トップ2〜3クラス。

## J.P. Morgan Asset Managementの2026年EPS成長予想

| 市場 | EPS成長率 |
|---|---:|
| 米国 | +24% |
| ユーロ圏 | +13% |
| 日本 | +12% |

この比較では日本は3位。

別時点の集計では、

- 米国 +24%
- ユーロ圏 +17%
- 日本 +16%

というケースもある。

## DWSの予測

| 市場 | EPS成長率 |
|---|---:|
| 米国 | +14.8% |
| 日本 | +12.5% |
| ドイツ | +10.1% |
| ユーロ圏 | +10.0% |
| 欧州 | +9.5% |
| 英国 | +9.4% |
| スイス | +6.0% |

この比較では日本は2位。

したがって、

> 日本株のEPS成長率は主要先進国の中でトップクラスだが、現時点で明確な1位とは言えない。

# 19. 「日本株は先進国1位か？」の整理

## 利益成長率

先進国トップ2〜3クラス。

米国を上回って1位というわけではない。

## 株価パフォーマンス

主要先進国ではトップクラス。

日経平均は2026年に約+29%で、米国・欧州主要指数を大幅にアウトパフォーム。

## 注意

韓国KOSPIは2026年に非常に強い上昇を記録している。

韓国を経済的な意味で先進国に含める場合、日本が絶対1位とは言えない。

一方、MSCIでは韓国はEmerging Markets分類。

したがって、

> 「MSCI型の主要先進国市場で見ると日本株はトップクラス」

という表現が最も正確。

# 20. 今回の日本株が強い理由

今回のポイントは「単に株価が上がっている」ことではない。

以下が同時進行している。

1. 日本企業全体の経常利益が過去最高
2. 製造業が大幅増益
3. 非製造業まで過去最高
4. 上方修正企業が多い
5. 下方修正企業が非常に少ない
6. AI半導体関連の利益成長が極めて大きい
7. AI投資の恩恵が通信・装置・材料まで広がっている
8. EPS成長率が先進国トップクラス
9. 日経平均・TOPIXの株価パフォーマンスも世界トップクラス
