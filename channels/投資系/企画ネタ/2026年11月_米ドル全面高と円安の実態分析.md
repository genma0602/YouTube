# 2026年11月 米ドル全面高と円安の実態分析

**分析基準日：2026年11月13日**  
**分析視点：機関投資家・為替市場・日米金融政策**

## 1. 結論：今回の円安はドル全面高の影響が大きい

2026年11月のドル円上昇は、日本円だけが売られているというより、**米ドルが世界の主要通貨に対して一斉に買われている影響が大きい。**

主な根拠は以下のとおり。

- ドル指数（DXY）が103.18付近まで上昇し、約19か月ぶりの高水準。
- ドル円は約159.9円まで上昇。
- ユーロ、スイスフラン、英ポンド、豪ドル、カナダドルも対ドルで下落。
- ユーロ円、ポンド円はほぼ横ばい。
- スイスフランに対しては、むしろ円高が進行。

したがって、今回の為替変動を「日本円の独歩安」と捉えるのは適切ではない。

**米国の追加利上げ観測を背景に、世界的なドル買いが進んでいると解釈する方が実態に近い。**

|---|---:|
| スイスフラン | -1.77% |
| 英ポンド | -0.91% |
| カナダドル | -0.89% |
| 日本円 | -0.88% |
| ユーロ | -0.81% |
| 豪ドル | -0.80% |

※マイナスは当該通貨安・ドル高を意味する。

### データから分かること

**① スイスフランの下落率は日本円の約2倍**

スイスフランは対ドルで1.77%下落しており、日本円の0.88%を大きく上回る。

**② 英ポンドも日本円以上に下落**

英ポンドの下落率は0.91%で、日本円より大きい。

**③ ユーロもほぼ同程度の下落**

ユーロの下落率は0.81%で、日本円と大きな差がない。

**④ 資源国通貨も下落**

豪ドル、カナダドルも対ドルで下落している。

### 分析

これらの動きは、円固有の問題ではなく、世界的なドル高が進行しているという見方を支持する。

## 3. クロス円から検証する日本円の実際の強さ

ドル円だけでは日本円そのものが弱いのか判断できない。そのため、他の主要通貨と円を直接比較する。

### 2026年11月6日〜11月12日

| 通貨ペア | 11月6日 | 11月12日 | 変化率 |
|---|---:|---:|---:|
| ドル/円 | 158.45円 | 159.85円 | +0.88% |
| ユーロ/円 | 176.56円 | 176.68円 | +0.07% |
| ポンド/円 | 211.51円 | 211.43円 | -0.04% |
| フラン/円 | 193.09円 | 191.28円 | -0.94% |
| 豪ドル/円 | 108.67円 | 108.89円 | +0.20% |

※プラスは円安、マイナスは円高。

### 重要な発見

ドルに対して日本円は約0.9%下落している。しかし、スイスフランに対しては約0.9%上昇している。さらに、ユーロとポンドに対してはほぼ横ばい。

仮に日本円だけが世界的に売られる状況なら、ユーロ円やフラン円も大きく上昇するはずである。実際にはそうなっていない。

**今回のドル円上昇は、日本円の全面安ではなく、米ドル主導の上昇である可能性が高い。**

## 4. ドル指数（DXY）の上昇が示すもの

### ドル指数とは

ドル指数（DXY）は、米ドルの価値を主要6通貨と比較した指標。

| 通貨 | 構成比率 |
|---|---:|
| ユーロ | 57.6% |
| 日本円 | 13.6% |
| 英ポンド | 11.9% |
| カナダドル | 9.1% |
| スウェーデンクローナ | 4.2% |
| スイスフラン | 3.6% |

### 直近の動向

- DXY：約103.18
- 週間上昇率：約0.9%
- 約19か月ぶりの高水準

同期間のドル円上昇率も約0.9%だった。ドル指数とドル円の上昇率がほぼ一致している。

ただし、DXYには円自体も組み込まれているため、これだけで因果関係を証明することはできない。他通貨の下落やクロス円の動きを合わせることで、ドル全面高という判断が強まる。

## 5. 世界的なドル高が進行する理由

### 5-1. 米国の追加利上げ観測

今回のドル高の最大の材料は、FRBによる追加利上げ観測の強まり。

| 中央銀行 | 政策金利 |
|---|---:|
| 米国FRB | 3.75〜4.00% |
| 日本銀行 | 1.25% |
| スイス国立銀行 | 0% |

10月28日のFOMCでは金利が据え置かれた。したがって、現時点では実際の追加利上げだけでなく、今後の金融政策見通しの変化が重要になっている。

### 5-2. ドル高につながる仕組み

1. 米国のインフレ指標が予想より強くなる。
2. FRBの追加利上げ観測が強まる。
3. 米国債利回りが上昇する。
4. 米ドル建て資産の相対的な魅力が高まる。
5. 他通貨から米ドルへの資金移動が促される。
6. ドル指数が上昇し、ドル円も上昇する。

この流れが今回の為替市場の主要な説明となる。ただし、実際の為替変動にはリスク回避需要や投機的ポジション調整なども影響する。

### 5-3. 米国債利回りの動向

前回調査では、米国2年国債利回りが直近2営業日で約0.34ポイント上昇したと報告されている。これは短期的な金融政策見通しが急速に変化したことを示す。

米国の利上げ期待が強まれば、ドル買いの圧力が生じやすい。

### 5-4. 12月FOMCの利上げ観測

前回確認した11月13日付のロイター報道では、12月FOMCで0.50ポイント利上げする可能性について、市場の織り込みが14.5%まで上昇したとされている。前週はほぼゼロだった。

この変化がドル買いを強めた可能性がある。

## 7. 日本政府の為替介入は効果があるのか

### 7-1. ドル全面高局面での限界

今回のように米ドルが世界の主要通貨に対して買われている局面では、日本政府だけが為替介入しても、ドル高の根本原因を解消するのは難しい。

なぜなら、ドル高の原因が日本国内だけに存在するわけではないため。

- 米国の政策金利見通し
- 米国債利回り
- 世界の投資資金の移動
- 各国の金融政策格差
- ドルへの安全資産需要

### 7-2. 為替介入が持つ役割

それでも為替介入に意味がないわけではない。

1. 短期的な円安の加速を抑制する。
2. 投機的な円売りポジションに影響を与える。
3. 急激で無秩序な為替変動を抑える。

ただし、為替介入だけで中長期のドル高トレンドを反転させるのは容易ではない。

### 7-3. 米国との協調

前回調査では、2026年11月12日にニューヨーク連銀が、同年7月の米財務省による円買い介入を公表したとの情報があった。

米国側が為替市場の安定を重視して対応する場合、単独介入より市場への影響が大きくなる可能性がある。

※介入の実施内容や公表時期については、公式資料での再確認が必要。

## 8. 今後のドル円をどう判断するべきか

機関投資家の視点では、ドル円の水準だけを見て判断するべきではない。

| 指標 | 確認する目的 |
|---|---|
| ドル指数（DXY） | 世界的なドル高・ドル安 |
| ドル円 | 円に対するドルの強さ |
| ユーロ円 | 円固有の弱さ |
| スイスフラン円 | 円と他の安全通貨の比較 |
| 米2年国債利回り | FRBの政策金利見通し |
| 米10年国債利回り | 中長期の金利・成長・インフレ期待 |
| 日米金利差 | 円とドルの相対的な魅力 |
| FOMC金利先物 | 市場の利上げ・利下げ織り込み |

### シナリオA：ドル円上昇＋DXY上昇

**ドル全面高の可能性が高い。** 米国の金利上昇やドル需要の増加が主導していると考えられる。

### シナリオB：ドル円上昇＋DXY横ばい・下落

**日本円固有の売り圧力が強まっている可能性。** 円の弱さを判断するために、ユーロ円やフラン円の上昇も確認する必要がある。

### シナリオC：ドル円下落＋DXY下落

**ドル全面安の可能性が高い。** 米国の利上げ観測後退、米国債利回り低下などが背景として考えられる。

### シナリオD：ドル円下落＋DXY上昇

**ドルが世界的に強い一方、日本円はさらに強くなっている可能性。** 日本の金融政策や円キャリートレードの巻き戻し、リスク回避などの影響を確認する。

## 10. 最終結論

**2026年11月の円安は、日本円だけが弱くなっているのではなく、米ドルが世界的に強くなっていることが大きな要因である。**

その証拠として、直近1週間では日本円だけでなく、ユーロ、スイスフラン、英ポンド、豪ドル、カナダドルも対ドルで下落している。

特にスイスフランと英ポンドは、日本円以上に対ドルで下落した。一方、円はユーロやポンドに対してほぼ横ばいで、スイスフランに対しては上昇している。

このため、「円が全面的に売られている」という見方は直近の実際の為替変動と一致しない。

現在のドル高は、米国の追加利上げ観測と米国債利回りの上昇が重要な背景にあると考えられる。

ただし、今回の比較期間は11月6日〜12日の約1週間であり、これだけで数か月単位の円安要因まで否定できるわけではない。

今後の相場を判断する際には、**ドル円だけではなく、DXY、クロス円、米国債利回り、FRBの金利見通しを同時に確認することが重要である。**
