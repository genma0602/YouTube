# 日本とフランスの年金制度比較――日本の年金が長期的に維持できる理由と、フランスの財政不安

**調査基準日：2026年10月23日**  
**視点：経済アナリスト・機関投資家／日本の経済成長を重視した強気シナリオ**

> **結論**：日本とフランスはいずれも現役世代の保険料で年金受給者を支える「賦課方式」が基本。しかし日本は、長年積み立てた巨額の公的年金準備資産、株式・債券への国際分散投資、約100年を対象とする定期的な財政検証、給付水準を調整する制度を併せ持つ。したがって「年金がなくなり、一切受け取れなくなる」という悲観論には根拠が乏しい。経済・賃金が持続的に成長すれば、将来の年金の実質購買力が高まるシナリオも成立する。一方、フランスは公的年金給付の財政負担が重く、人口動態の悪化と制度改革の停滞により、中長期の財源不足が拡大する見通しにある。ただし「フランスの年金が近く破綻する」と断定するのも不正確である。

---

## 1. 日仏の制度比較：全体像

| 比較項目 | 日本 | フランス |
|---|---|---|
| 公的年金の基本構造 | 賦課方式＋積立金による財政補完 | 賦課方式＋制度ごとの積立・準備金 |
| 主な財源 | 保険料、国庫負担、積立金・運用益 | 保険料、税財源・政府補填、各制度の準備金 |
| 公的年金準備資産／GDP | **42.7%** | **7.3%** |
| 公的年金支出／GDP | **9.2%** | **13.4%** |
| 近年の財政状況 | 2024年度：運用損益を除く収支 **約−0.1兆円** | 2025年：金融収支を除く収支 **−51億ユーロ** |
| 中長期の見通し | 成長型経済ケースで所得代替率 **57.6%** | 2070年に年金制度の赤字 **GDP比−2.4%**（2026年COR基準シナリオ） |
| 主要な政策課題 | 実質賃金、生産性、出生率、給付水準の調整 | 人口減少、高い給付支出、財政赤字、退職年齢改革をめぐる対立 |

**比較上の注意：** OECDの準備資産／GDPは2024年末または直近入手年、年金支出／GDPは各国の直近入手年であり、完全な同一年度比較ではない。日本の2024年度決算とフランスの2025年決算も異なる期間の数字である。OECD統計と各国政府の公表する制度集計範囲には違いがある。[1][2][3][4]

## 2. フランスの年金財政はなぜ不安視されるのか

### 2-1. 現役世代が減り、受給者を支える人数が減る

フランス財務省が2026年10月8日に公表した分析によると、年金受給者1人当たりの保険料拠出者数は、**1990年に4人超→2025年約2.5人→2070年約1.6人**と低下する見通し。2026年の年金制度審議会（COR）の人口前提では、2028年以降の出生率は女性1人当たり1.45人とされる。[4][5]

賦課方式の年金では、現役世代が少なくなり、高齢者が増えるほど、賃金・保険料率・税負担・退職年齢・給付額のいずれかを調整する必要が生まれる。

### 2-2. 現状のままでは年金財政の赤字が拡大する

CORの2026年報告の基準シナリオでは、次のとおり。[5]

| 項目 | 2025年 | 2070年予測 |
|---|---:|---:|
| 年金支出／GDP | 14.1% | 15.3% |
| 年金制度の赤字／GDP | 約0.2% | **2.4%** |
| 年金財政赤字（金融収支を除く） | **51億ユーロ** | 金額よりGDP比の長期推計で評価 |

2025年について金融収支を含めると、赤字は約13億ユーロとなる。「51億ユーロの赤字」は金融収支を除いた数値であり、この区別は重要である。[5]

### 2-3. 年金給付の比重が重く、政府財政も厳しい

OECD統計ではフランスの公的年金支出はGDP比13.4%で、日本の9.2%より大きい。IMFの2026年対仏審査でも、フランスの年金支出はGDP比約14%、EU平均は約11.5%とされ、長期的な財政運営の課題として指摘されている。[2][6]

年金以外も含むフランス政府の財政事情が厳しいため、年金への追加補填は、税負担・他の予算・政府の借入需要との競合を生む。ただし年金問題だけがフランス国債安の原因ではなく、成長率、財政赤字、金利、政治情勢なども作用する。

### 2-4. 改革をめぐる政治的対立で将来のルールが読みにくい

2023年改革では退職年齢を62歳から64歳へ段階的に引き上げる計画だったが、改革の一部は2028年1月まで一時停止された。IMFは、この停止で予定されていた財政改善効果が2026年に約4億ユーロ、2027年に約18億ユーロ減ると分析している。[6][7]

退職年齢引き上げには、働く年数の延長によって財政を改善する側面と、肉体労働者などに負担が偏る側面がある。給付、保険料、退職年齢について社会的合意が難しいことが、国民の将来不安につながる。

### 2-5. 「基金が投資に失敗した」ことが主因ではない

フランスの年金準備基金FRRは**2025年に+9.1%**の運用成績を記録し、同年末の資産は**207億ユーロ**だった。一方、FRRは2011〜2025年に合計**308.5億ユーロ**を社会保障債務償還機関CADESに支払っている。[8]

これは「運用で308.5億ユーロを失った」という意味ではない。制度上、将来給付の備えに充て得る金融資産を、既存の社会保障債務返済にも用いてきたということだ。

**フランスの問題は投資運用の失敗ではなく、年金の支出・収入構造と、それを調整する政治的な難しさである。**

### 2-6. 国民の不安が私的年金の拡大に表れている

2026年10月16日のReutersによれば、フランスでは公的年金の十分性を疑う人が**7割を超え**、私的な年金積立制度PERへの資金流入が拡大している。2025年末のPER資産額は約**1,500億ユーロ**、加入者は約**1,300万人**と報じられた。[9]

ただしこれは「公的年金が数年で支払い停止になる」と考える人が7割超という意味ではなく、**将来十分な給付を受け取れるか**への不安を示すもの。

## 3. 日本にはなぜ年金制度を維持する力があるのか

### 3-1. 高度成長期以来の保険料蓄積とGPIFの運用益

日本の年金積立金は、過去の現役世代が支払った保険料のうち、当時の給付などに使われなかった資金を原資としている。市場運用は2001年度から本格化し、GPIFが長期分散投資を担ってきた。[10]

**2026年6月末時点のGPIF**[11]

| 指標 | 数字 |
|---|---:|
| GPIF運用資産総額 | **317兆7,596億円** |
| 2001年度以降の累積運用収益 | **221兆201億円** |
| 2001年度以降の年率収益率 | **4.95%**（名目） |
| 2026年4〜6月期の運用収益 | **+24兆895億円** |

累積運用収益には評価損益も含まれ、毎年確定的に得られる現金ではない。また、過去の収益率は将来の利回りを保証しない。

**2026年6月末の資産構成（年金特別会計分を含む年金積立金全体）：** 国内債券25.59%、外国債券24.60%、国内株式24.48%、外国株式25.33%。合計約320.4兆円。この「年金積立金全体」の資産額は、GPIF単体の317.8兆円と集計範囲が異なる。[11]

### 3-2. 現在の年金給付は、保険料と税金でほぼ賄えている

**日本の2024年度公的年金財政**[3]

| 項目 | 金額 |
|---|---:|
| 保険料収入 | **43.1兆円** |
| 国庫・公経済負担 | **12.1兆円** |
| 運用損益を除く収入総額 | **55.7兆円** |
| 支出総額 | **55.8兆円** |
| 運用損益を除く収支 | **−0.1兆円** |
| 運用損益（時価ベース） | **+2.0兆円** |
| 2024年度末の公的年金積立金 | **306.0兆円** |

重要なのは、**公的年金の全給付を毎年GPIFの資産売却で賄っているわけではない**という点である。2024年度は保険料・国庫負担等で、運用損益を除いてもおおむね均衡していた。

ただし、2024年度末の公的年金積立金306兆円と、2026年6月末のGPIF運用資産約318兆円は、**年度も集計対象も異なるため、単純な増減比較はできない**。

### 3-3. 約100年の財政検証と給付水準調整

日本は少なくとも**5年に1回**、人口、雇用、賃金、物価、運用利回りを踏まえて年金財政を検証する。2004年改革以降、保険料率の上限固定、マクロ経済スライドによる給付水準調整、積立金活用を組み合わせ、約100年間の財政均衡を確認する設計としている。[10][12]

GPIFの説明によると、約100年間の年金給付財源の**約9割**は将来の保険料と国庫負担、**約1割**を積立金・運用益が担う想定。最終的には給付費約1年分の積立金を残す計画であり、**「318兆円が何の使途もない余剰金」という意味ではない**。[10]

## 4. 日本の2024年財政検証：100年先までの強気シナリオ

財政検証で重要な指標は**所得代替率**。モデル世帯の年金受取額が、その時点の現役男性の平均手取り賃金の何%に相当するかを示す。すべての受給者に同じ年金額が支給されることを意味しない。[12]

| シナリオ | 長期の実質GDP成長率（2034年度以降の約30年平均） | 給付水準調整終了後の所得代替率 |
|---|---:|---:|
| 高成長実現 | **+1.6%** | **56.9%** |
| 成長型経済移行・継続 | **+1.1%** | **57.6%** |
| 過去30年投影 | **−0.1%** | **50.4%** |
| 1人当たりゼロ成長 | **−0.7%** | 国民年金積立金が2059年度に枯渇する機械的試算。その後の所得代替率は33〜37%程度 |

出典：[12][13]。成長率が高いほど所得代替率が機械的に高くなるわけではない。賃金、利回り、人口構成などの前提もケースごとに異なる。

**成長型経済移行・継続ケースの前提**：[13]

- 物価上昇率：年2.0%
- 実質賃金上昇率：年1.5%
- 実質運用利回り：年3.2%
- 運用利回りと賃金上昇率の差：1.7ポイント

特に注目すべきは、**実質年金月額**。夫婦2人のモデル年金は、2024年度の物価水準に換算して、2024年度の22.6万円から、成長型ケースでは2037年度に**24.0万円**になる試算。[14]

つまり、現役世代の所得に対する年金の割合は61.2%から57.6%へ下がっても、**物価上昇を差し引いた年金の購買力は増える可能性がある**。

一方で、低成長が続くと国民年金の積立金が2059年度に枯渇する試算もある。制度そのものの消滅・支給停止を意味しないが、**受給額の低下リスクを無視してよいわけではない**。[12][14]

## 5. 積極財政・官民投資による「日本年金・強気シナリオ」

### 投資家として最も重視する好循環

1. **政府・民間企業が設備投資を拡大**：電力網、半導体、AI関連設備、物流自動化、省人化、研究開発など。
2. **設備・技術・人材投資によって労働生産性が上昇**：人口が減少しても、労働者1人当たりの付加価値を高める。
3. **生産性上昇が実質賃金と雇用の改善に波及**：厚生年金の保険料収入と関連税収が増える。
4. **企業利益が拡大**：GPIFが保有する国内外株式の配当・価値上昇にも寄与し得る。
5. **年金財政の長期見通しが改善**：給付水準調整の圧力が軽くなり、将来の実質年金額を維持・改善しやすくなる。

**重要な条件：** 株価や名目GDPだけが上昇しても十分ではない。物価上昇を上回る**実質賃金の持続的成長**が必要。また、利益が特定企業に集中して賃金へ波及しなければ、保険料収入への効果は弱くなる。

### 機関投資家の視点による評価

- **根拠が強い点**：巨大な積立資産、過去の累積運用収益、2024年度のほぼ均衡した収支、2024年財政検証の複数ケース。
- **強気シナリオの成立条件**：賃金・生産性上昇の持続、安定的な労働参加、長期の投資収益率。
- **最大のリスク**：少子化の加速、実質賃金の長期停滞、資産価格の低迷、物価上昇による購買力低下。

結論として、**「積立金が豊富だから何もしなくても安心」ではなく、「積立金という安全余力があり、持続的な経済成長によって年金をさらに支えられる」**と捉えるのが最も妥当。

## 6. なぜフランスと日本では年金不安の性質が違うのか

### フランス

- 公的年金のGDP比支出が大きく、人口動態の悪化で現役世代の負担が増える。
- 年金制度審議会は中長期の財源不足の拡大を予測している。
- 退職年齢・保険料・給付の調整をめぐって政治的合意が難しい。
- 政府財政への警戒が重なり、国民は将来の給付条件が不透明だと感じやすい。
- **ただし、年金運用基金が巨額損失を出したから破綻するという説明は誤り。**

### 日本

- 高度成長期以来の保険料蓄積とGPIFの長期運用によって、大きな準備資産を持つ。
- 年金財政の約100年を見通す制度と、5年ごとの財政検証・給付調整がある。
- 現在の保険料・国庫負担は給付を相当程度賄っている。
- 厚労省の成長型ケースでは、長期財政均衡を図りながらモデル年金の実質購買力が上昇する試算がある。
- **ただし、受給額の絶対保証ではなく、賃金・人口・運用などの条件に左右される。**

### 国債・金融市場との関係

フランスの年金財政は、他の歳出・税収・成長率と合わせて政府の将来の資金調達需要に影響するため、フランス国債へのリスク評価の一要素になる。ただし**年金赤字がそのまま国債価格の下落幅を決めるわけではない**。

一方、日本のGPIF資産が大きいことは年金財政の強みだが、**それだけで日本国債の信用力や国家財政の持続可能性を証明するわけでもない**。年金財政と政府全体の財政は区別して分析する必要がある。

---

## 7. 最終結論：強気シナリオを正確に表現するなら

> **フランスの年金問題は「資産運用の失敗」ではなく、「人口動態・高い給付負担・制度改革の停滞による財源不足」である。日本も人口減少という共通課題を持つが、フランスより大規模な年金準備資産、長期分散投資による運用益、約100年間の財政検証と給付調整を備えている。厚労省の2024年財政検証では、経済成長が持続するケースで年金制度の長期的な均衡が見込まれ、モデル年金の実質額が増える試算まである。官民投資によって生産性と実質賃金の成長を実現できれば、日本の年金財政をさらに支えることが可能だ。**

「フランスの年金は破綻確定」「日本の年金は絶対に破綻しない」という断定は避ける。正確には、**フランスは現行制度のままでは赤字拡大が予測され、日本は成長・人口・運用に関する一定の前提の下で長期的な制度維持が見込まれている**、という比較である。
