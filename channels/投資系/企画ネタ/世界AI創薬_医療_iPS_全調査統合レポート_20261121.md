## 1. 全体の重要結論

- **薬を製造できる国は多いが、独自に革新的な新薬を創出し、国際的な臨床開発につなげる国・企業は限られる。** 日本はその有力国の一つ。一方、中国の新薬創出力は急伸している。
- **AIが最も早く変えているのは新薬開発の前半**。病気の原因候補、薬の分子、タンパク質の形、細胞の反応などを計算し、有望な候補を絞る工程では大幅短縮事例がある。
- **開発全体が一律に数倍速くなったわけではない**。人間への安全性・有効性を確かめる臨床試験、量産、規制審査は依然として必要。
- **難病の「完治」と、進行抑制・症状改善・早期予測は別物**。2026年のAI創薬の臨床候補は広がっているが、AI単独によって認知症やあらゆるがんの完治が実証された段階ではない。
- **認知症は発症前予測・予防治療へ、がんはリスク別検診・個別化治療・再発管理へ**研究の重点が広がっている。AIは血液・画像・遺伝子など膨大な情報の統合で重要な役割を担う。
- **iPS細胞は研究から条件付き実用化へ移る転換点**にあり、AIが培養結果の予測、病気の原因探索、新薬候補の選定、品質管理を支援している。
- **AI企業の戦略は「生成AIで論文を読む」から「科学者エージェント＋分子設計＋実験ロボット＋クラウド」へ**拡大。NVIDIA、Google DeepMind、OpenAI、Anthropic、Microsoft、AWSなどが研究・商用基盤を構築している。
- **日本への大型クラウド投資と、創薬目的の直接的な協業・出資を混同しない**ことが重要。日本の製薬企業は国際AI企業の技術導入先・研究パートナーになっているが、それが株式取得を意味するわけではない。
- **成長時期の基本シナリオ**は、2026〜2029年に研究基盤・設備・AIサービス、2029〜2035年に一部のAI創薬・細胞治療の臨床成果と事業化、2035年以降に高度な個別化医療・再生医療の普及が進む可能性。ただし承認や市場規模には大きな不確実性がある。

## 2. そもそも新薬を生み出せる国はどれほど限られるのか

### 2-1. 新薬創出は少数の国・地域へ集中

チャット内で取り上げた欧州製薬団体連合会（EFPIA）2026年版統計に基づく、**2021〜2025年の新規化学・バイオ医薬品の創出数**は次のとおり。

| 国・地域 | 創出数 | 世界シェア |
|---|---:|---:|
| 米国 | 140 | 31.6% |
| 中国 | 133 | 30.0% |
| 欧州（複数国合計） | 87 | 19.6% |
| 日本 | 33 | 7.4% |
| その他 | 50 | 11.3% |
| **合計** | **443** | **100%** |

企業の親会社所在地による分類。単独国の日本と複数国合計の欧州を単純な「国家順位」として扱わない。2025年単年の数字として、中国46、米国28、日本5との説明もチャット内にあった。数字が示すのは**創出品目数**であり、治療価値、売上高、承認制度、臨床上の優劣を直接表さない。

**資料**：[EFPIA, The Pharmaceutical Industry in Figures 2026](https://www.efpia.eu/media/uj0popel/the-pharmaceutical-industry-in-figures-2026.pdf)

### 2-2. 医薬品を「作る」と「新しく発明する」は違う

1. **既存薬・ジェネリックを製造する力**：多くの国が保有。品質管理、原料調達、安定供給が課題。
2. **高度なバイオ医薬品を製造する力**：抗体医薬品、細胞・遺伝子治療など、工程が複雑で高い専門性が要る。
3. **世界初の新薬を創出する力**：新しい標的や分子の探索から、人体試験、規制当局の承認、製造・販売までの総合力が必要。

チャットで取り上げたFDAの原薬メーカー所在地の構成は、インド44%、中国22%、米国11%というもの。これは**所在地別の登録メーカー構成**であり、世界の製造量シェアや品質の優劣を意味しない。WHOの2026年の説明では、世界の国々の約70%で医療製品を規制する体制が不十分、または弱いとされたが、これも個々の工場・製品の品質を一律に否定する根拠ではない。

### 2-3. 日本の創薬の強み

日本製薬工業協会（JPMA）の調査として、2024年の世界売上上位100医薬品のうち日本企業が創出した品目が**8品目**、創出企業の国籍別で英国と同率4位、という結果を紹介した。

- **第一三共**：抗体に抗がん剤を結合させてがん細胞に届けるADC技術、エンハーツ。
- **エーザイ**：バイオジェンと進めるアルツハイマー病治療薬レケンビ。
- **国内の学術・研究基盤**：東京・大阪などを中心とした創薬企業、大学、病院、製造企業の集積。

日本には創薬上の実績があるが、バイオ医薬品・AIプラットフォーム・資金調達規模では国際競争が激しい。

**資料**：[JPMA／医薬産業政策研究所「2024年の世界売上高上位医薬品」](https://www.jpma.or.jp/opir/news/077/03.html)

## 3. AIによって創薬は何倍速くなったのか

### 3-1. 従来の開発工程とAIの役割

| 工程 | 従来の作業 | AIが支援すること | 現在のボトルネック |
|---|---|---|---|
| 病気の原因・標的発見 | 論文、患者データ、遺伝子、細胞の比較 | 大量情報から病気に関係する標的候補を提案 | 原因と単なる相関の区別 |
| 分子・抗体の設計 | 大量の化学物質を合成し試験 | 候補物質を計算で提案、性質を予測 | 体内の複雑さと予測誤差 |
| 前臨床試験 | 細胞・動物で効果や毒性を評価 | 候補選抜、毒性・反応の予測、実験自動化 | 実際の生物実験が必要 |
| 第1相治験 | 主に安全性・投与量を検証 | 患者候補の選定、データ管理 | 人間への安全性 |
| 第2相治験 | 患者に効くか検証 | 患者層別化、試験設計 | 有効性の再現性 |
| 第3相治験 | 大規模に効果・副作用を確認 | 対象患者の選定、運用支援 | 人数、期間、費用 |
| 承認・製造 | 審査資料、品質保証、製造・流通 | 申請文書、工程最適化、品質監視 | 規制と長期安全性 |

EFPIA資料では、新規有効成分の初期研究から市場投入までに**平均12〜13年**を要するという説明がある。ただし「AIが候補探索を70%短縮」したとしても、開発全体の12〜13年を70%短縮したことにはならない。

### 3-2. 2026年のAI創薬パイプライン分析

チャット内で紹介した研究の集計では、2026年3月時点で**69社・129のAI活用医薬品候補**が臨床試験入りしたと報告。内訳として**がん領域74件（57.3%）**、第3相に入った／到達した候補**5件**が示された。

別の解析値として、第1相の推定成功率**77.8%**、第2相の推定成功率**19.5%**が紹介された。これらは対象候補の選び方・追跡期間・統計推定に依存し、全AI創薬に一般化できない。第1相は主に安全性を調べるため、77.8%を「病気が治る確率」と読むのは誤り。

### 3-3. 実際に報告された短縮・効率化

| 企業・研究 | 報告された成果 | 比較対象・制約 |
|---|---|---|
| **アステラス製薬 × NVIDIA** | 有望な化合物の探索期間を**70%以上短縮** | 特定の初期探索工程。新薬承認までの総期間ではない |
| 同上 | 実験する化合物数を**90%以上削減** | 特定研究例 |
| 同上 | AI選定の10化合物で目的の活性を確認 | 数が少なく、広範な再現性を保証しない |
| 同上 | Boltz-2 NIMで約**3倍高速** | 計算処理速度の比較 |
| **Insilico Medicine** | 前臨床候補の発見・決定まで約**18か月**、第0・1相完了まで30か月未満との報告 | 従来法と同条件の無作為比較ではない |
| **AlphaFold** | 2億件以上のタンパク質構造予測を公開 | 予測データ公開であり、新薬承認数や臨床開発期間の直接指標ではない |
| **OpenAI × Ginkgo Bioworks** | 特定のタンパク質合成工程のコスト**40%削減** | 医薬品販売原価全体の削減ではない |
| **Wellcome／BCG推計** | 創薬関連の時間・費用**25〜50%削減の可能性** | 将来のモデル試算 |
| **McKinseyが取り上げた事例** | 初期の研究開発マイルストーンを**15〜80%短縮**した例 | 選定された事例。産業全体の平均ではない |
| **第一三共 × AWS** | AIエージェント、実験自動化、クラウドを結ぶ研究基盤を構築 | 業務基盤への投資・導入であり、新薬の承認成功率は未確定 |
| **中外製薬 × AWS** | 対象の治験関連回答案作成などで約**57%の削減** | 対象業務の削減値。創薬全体ではない |
| **塩野義製薬 × 日立** | 治験総括報告書の作成時間約**50%削減** | 文書作成の効率化 |

**重要な整理**：速度比較には、①分子を生成する計算速度、②有望な候補を見つける探索期間、③試験・事務作業の短縮、④新薬の承認までの期間という**4種類のまったく異なる指標**がある。「創薬が10倍速くなった」と一括して言えない。

### 3-4. Insilico Medicine：肺線維症治療薬レントセルチブ

特発性肺線維症は、肺が徐々に硬くなり呼吸機能が落ちる難病。Insilico MedicineはAIを使って新しい標的と分子を探索した候補薬「レントセルチブ」を開発した。

- AIを利用した初期探索から前臨床候補まで約18か月という経緯を公表。
- 2025年『Nature Medicine』に**71人対象の第2a相臨床試験**が掲載。
- 12週後の肺活量（FVC）の平均変化として、**高用量群 +98.4mL、偽薬群 −20.3mL**が報告された。
- 2026年9月には**320人規模の第3相試験で最初の投与**が始まったと紹介された。

これは有望な臨床開発の事例だが、少人数・短期間の第2a相試験で**完治や長期死亡率改善**が示されたわけではない。第3相の結果が重要。

**一次資料**：[Nature Medicine：rentosertib第2a相試験](https://www.nature.com/articles/s41591-025-03743-2)

### 3-5. AlphaFold、生成AI、仮想研究者

- **AlphaFold 3**：タンパク質と薬・DNAなどの相互作用を予測する基盤。病気の仕組みや治療候補の探索に利用。 [Nature原著論文](https://www.nature.com/articles/s41586-024-07487-w)
- **AlphaFoldの普及**：2025年11月のDeepMind資料として、**世界190以上の国・地域、300万人超の研究者**に利用されたと紹介。
- **Stanford Virtual Biotech**：約**3万7,000のAIエージェント**が約**5万6,000の臨床試験情報**などを調べ、薬の成功に関係する特徴を探索。大量分析は1週間未満との報告。過去のデータ上で一定の標的特徴を持つ薬の市場投入との関連が**48%高い**、副作用との関連が**32%低い**と報告されたが、AIで作った新薬の成功率が48%上がったという意味ではない。
- **Google Co-Scientist**：複数のAIが仮説・反証・改善を繰り返し、肝線維症や血液がんの既存薬転用を提案。細胞実験では線維化関連反応を最大**91%抑制**した候補を紹介。ただし患者の肝硬変が91%改善したわけではない。
- **MIT Antibiotics-AI**：AIによる抗菌分子の探索・設計。プロジェクト全体の公表値として**700億以上の候補探索・9種類の新規抗菌候補**が紹介された。薬剤耐性菌への期待が大きいが、多くは前臨床。

**資料**：[Stanford Virtual Biotech](https://med.stanford.edu/news/all-news/2026/09/virtual-biotech-company.html)／[Google Co-Scientist](https://deepmind.google/blog/co-scientist-a-multi-agent-ai-partner-to-accelerate-research/)／[MIT研究者の受賞発表](https://news.mit.edu/2026/regina-barzilay-jim-collins-win-pritzker-prize-ai-and-science-research-excellence-1102)

## 4. AIによる医療の進化：創薬以外も含む

| 領域 | 何が変わるか | 2026年時点の到達点・課題 |
|---|---|---|
| **画像診断** | MRI、CT、マンモグラフィーなどから病気の兆候を見つける | 乳がんなどで大規模試験。病院間・集団間の性能差に注意 |
| **発症リスク予測** | 血液・遺伝子・健診・生活習慣・画像を組み合わせて高リスク者を抽出 | 認知症・がんで研究。予測精度と予防の実効性は別 |
| **個別化治療** | 患者の腫瘍や細胞の特徴に合う薬を選ぶ | 乳がん、個別化ワクチンなどで臨床的な進展 |
| **創薬** | 標的、化合物、タンパク質を生成・選別 | 早期開発に効率化。治験成功率は今後検証 |
| **手術支援** | 手術中に危険部位を可視化、医師の判断を補助 | 初期臨床例あり。無作為比較は今後必要 |
| **仮想細胞・デジタルツイン** | 患者細胞の薬への反応を計算上で予測 | 研究段階。本人の体の完全な再現ではない |
| **iPS細胞製造** | 細胞品質や分化の成否を予測し製造を自動化 | 具体的な画像予測研究あり。商用量産が課題 |
| **医療業務** | 治験文書、患者選定、文献解析、事務 | 既に導入例。ただし効率向上≠臨床成績の改善 |

米FDAの一覧について、2026年9月時点で**AI搭載医療機器1,600件超**との情報をチャット内で紹介した。これはFDAの対象機器の累計掲載・認可数に関する情報であり、**すべての機器が死亡率を改善したという意味ではない**。

### 4-1. 脳神経外科でのAI支援例

2026年8月、英国UCLのハニ・マーカス教授らが、下垂体腫瘍の手術でAIによるリアルタイムの危険構造識別を利用した事例を公表。患者の視力改善が報告された。NVIDIA Clara IGX基盤、Googleからの研究支援にも言及された。**1例の臨床事例であり、AIなしと比較した改善幅は不明**。

**資料**：[UCL：AI-assisted sight-saving brain surgery](https://www.ucl.ac.uk/hawkes-institute/news/2026/aug/first-patient-live-ai-assisted-sight-saving-brain-surgery-using-ucl-hawkes-institute)

### 4-2. 個別化医療の将来像

1. 血液・皮膚など患者の細胞を採取。
2. 必要に応じてiPS細胞を作り、神経・心筋・肝臓などを再現。
3. 遺伝子・血液・画像・細胞反応をAIに分析させる。
4. 効きそうな治療候補を予測し、実験で検証。
5. 有望なら規制された臨床試験を行い、実際の患者に届ける。

これは目指される未来像であり、すべての工程を安全かつ正確に提供する医療サービスが既に完成したわけではない。

## 6. 認知症・アルツハイマー病の予測・予防・治療

### 6-1. なぜ早期介入に期待があるのか

アルツハイマー病では、記憶障害などの症状が出るかなり前から、脳内のタンパク質（アミロイドβ、タウなど）の異常が進むことがある。遺伝的に高いリスクを持つ家族を追跡したDIANの研究では、**発症の約20年前から**変化が観察されるという知見が紹介された。これはすべての患者に共通の発症時計を持つという意味ではない。

従来：症状が出てから認知機能を評価し、治療・ケアを開始。  
期待される将来：症状がない段階で異常の兆候を把握し、**症状を遅らせる・発症を防ぐ可能性を検証する**。

### 6-2. AHEAD 3-45：発症前に薬を投与する第3相試験

- **主導に関わる専門医**：ハーバード大学Reisa Sperlingら。
- **対象**：認知症症状がないものの、脳のアミロイド異常の兆候を持つ人。
- **介入**：レカネマブ（エーザイ／バイオジェン）による発症前治療を評価。
- **チャットで紹介した登録情報**：予定参加者**約1,400人**、主要評価完了予定**2028年12月**（変更される可能性あり）。
- **重要性**：本当に発症前から治療すれば症状を遅らせられるのか、大規模に確認する。
- **注意**：成功は未確定。AIが薬自体として治療する試験ではない。AIはリスク解析、参加候補の選定、画像・血液データ解析に活用可能。

**一次資料**：[ClinicalTrials.gov NCT04468659](https://clinicaltrials.gov/study/NCT04468659)

### 6-3. AI・血液検査で患者選定を効率化

AHEAD試験の関連研究として、血液検査・年齢・遺伝情報などによる予測を使い、事前にPET脳画像検査へ進める対象者を選別した例を紹介した。

- 従来の選定では、PET後に条件に合わない割合が**約71%**。
- 段階的な予測モデルの導入後、最終版では**約14%**。

これは**高額な検査を必要性の高い人に集中**させる可能性がある。ただし同一条件のAIあり／なし比較ではなく、選定基準や対象集団の変化も含まれる。

### 6-4. 血液のp-tau217が将来の認知機能低下を示す

2026年の『JAMA』に掲載されたと紹介した統合研究では、北米・日本・豪州などの**2,684人**のデータを分析。血液中の**p-tau217**（アルツハイマー病に関係するタウタンパク質の変化を示す指標）と、今後の認知機能低下との関連を調べた。

| p-tau217の水準 | 5年間の認知機能低下リスク推計 |
|---|---:|
| 低値 | 12% |
| 中間 | 15% |
| 高値 | 24% |
| 非常に高値 | 38% |

非常に高い群で10年以内**78%**という推計にも言及されたが、長期追跡者が非常に少なく不確実性が大きい。米NIHが紹介した別研究では、血液指標などによる発症時期の推定誤差が中央値約**3〜4年**と説明された。

- **重要**：p-tau217は血液の生物学的指標であり、測定自体がAIではない。AIは血液・画像・遺伝子などを統合することで追加の価値が期待される。
- FDAが2025年に認めたアルツハイマー病用血液診断検査は、**症状のある55歳以上**の人向けの検査補助。症状のない人全員への集団スクリーニングを承認したものではない。

**原著資料**：[JAMA：Blood-Based P-Tau217 Levels](https://jamanetwork.com/journals/jama/article-abstract/2851720)

### 6-5. 認知症の45%は予防・発症遅延の余地という推計

UCLのGill Livingston教授らによる**2024年Lancet認知症委員会**は、**14の変更可能な危険因子**に着目し、世界の認知症の約**45%に予防・発症遅延の余地**があると推計した。

チャットで取り上げた因子：難聴、視力障害、高血圧、糖尿病、喫煙、運動不足、教育、社会的孤立など。他に脂質異常、肥満、うつ、頭部外傷、大気汚染、過度の飲酒等も検討対象。

- **45%はAIが治す割合ではない。** 社会全体で危険因子を改善した場合の理論推計。
- AIの将来の役割は、各個人で何を優先して改善するべきかを把握し、継続した支援につなげること。
- 米国**U.S. POINTER**試験（**2,111人、約2年間**）では、運動・食事・認知活動・血管リスク管理を組み合わせた構造化プログラムで認知機能テストの成績が改善したと紹介。これもAI治療試験ではなく、認知症発症率減少の直接証明でもない。
- 日本の**J-MINT**は、運動・栄養・脳トレーニング等の多面的な生活習慣介入を検証。長期医療・介護費への影響はモデル試算。

**一次資料**：[The Lancet：2024 dementia prevention report](https://doi.org/10.1016/S0140-6736(24)01296-0)

### 6-6. 日本の認知症AI研究

## 7. がんの早期発見・発症予防・個別化治療・再発予防

### 7-1. そもそも「予防」「早期発見」「再発予防」は違う

1. **一次予防**：そもそもがんが発症しないようにする（禁煙、感染予防、生活習慣改善など）。
2. **早期発見**：既に生じているがんを早い段階で発見して治療。
3. **個別化治療**：患者の遺伝子・免疫・画像に合う治療を選ぶ。
4. **再発予防**：手術などの治療後、残っているかもしれないがんの再発を抑える。

WHO・IARCの2026年推計として、世界のがんの**約37%に予防可能性がある**とチャット内で紹介した。これは既知の予防因子から見た集団推計で、AIが37%を予防したという意味ではない。

### 7-2. William Hait医師：「Cancer Interception（がんになる前・早期の介入）」

米国がん研究協会AACRの最高科学顧問William N. Hait医師は、2026年のインタビューで、がんになってから治すだけでなく、発症リスクの高い人を見つけて早く介入する戦略を重視。AIが画像、血液、遺伝子、診療データを統合し、検査すべき対象をより適切に選ぶことが期待される。

**資料**：[AACR：2026年の展望](https://www.aacr.org/blog/2026/01/08/experts-forecast-cancer-research-and-treatment-advances-in-2026/)

### 7-3. 乳がん：10年先のリスク予測

2026年のカロリンスカ研究所、メイヨークリニックなどの研究では、**マンモグラフィー画像をAIで解析して10年先の乳がんリスク**を推定したと紹介。

- AIが**高リスク上位10%**と判断した集団に、その後の乳がん症例の**33%**が含まれた。
- 比較した従来モデルでは約**20〜24%**。
- **「高リスク群の33%が乳がんになる」のではなく**、全体で発生した症例のうち33%が高リスク上位10%へ分類されたという指標。
- 期待される応用：リスクに応じた検診間隔、早期の精密検査、適切な予防手段の選択。
- 未解決：その方法で実際にがん発症・死亡をどれほど減らせるか。

**原著論文**：[PubMed：10-year breast cancer AI risk model](https://pubmed.ncbi.nlm.nih.gov/42160452/)

### 7-4. 乳がん：MASAI大規模ランダム化検診試験

| 指標 | 従来の医師による検診 | AI支援検診 |
|---|---:|---:|
| 実際のがんを見つける感度 | 73.8% | **80.5%** |
| がんがない人を正しく陰性とする特異度 | 98.5% | **98.5%** |
| 参加者 | \- | **約10万5,934人（試験全体）** |

検診と検診の間に見つかるがんはAI群で**12%少ない**傾向があったが、統計的に確実な減少とまでは言えない。**死亡率減少の直接的な証明ではない**。

**原著**：[Lancet / PubMed](https://pubmed.ncbi.nlm.nih.gov/41620232/)

### 7-5. 個別化mRNAがん治療：悪性黒色腫の第3相試験

チャット内では、2026年10月にESMOが紹介した**Merck × Moderna**の個別化mRNA治療「intismeran autogene」の第3相試験を特に重要な事例として扱った。

- **原理**：患者のがんの遺伝子変異を分析し、機械学習で免疫に認識させたいがん固有の目印（ネオアンチゲン）を選び、mRNAで免疫へ教える。
- **対象**：手術後の悪性黒色腫。通常の免疫治療薬に個別化治療を追加する群と、免疫治療薬のみの群を比較。
- **試験参加者**：**1,137人**と紹介。
- **24か月時点で再発・死亡なし**：併用群**82.2%**、比較群**70.0%**。
- **再発または死亡の相対リスク**：**42%低下**（ハザード比0.58、95%信頼区間0.45〜0.75）と紹介。

これは**既にがんになった人の術後再発予防**であって、健康な人ががんを発症しないようにする予防ワクチンではない。全がんに有効な治療ではない。全生存期間への効果や長期安全性はさらに追跡が必要。

**資料**：[ESMO：個別化mRNAがん治療第3相結果](https://www.esmo.org/insights-by-esmo/all-news/first-positive-phase-iii-trial-data-for-an-individualised-mrna-based-neoantigen-therapy)

### 7-6. 乳がん：AIによる治療選択

2026年の『Cancer Cell』研究として、**転移性乳がん患者105人**をAIで4群に分類し、治療薬の使い分けを検討した例を紹介した。

| 解析上の患者群 | AI分類に基づいた治療 | 比較群 |
|---|---:|---:|
| SNF2 | 腫瘍縮小の反応率65% | 30% |
| SNF4 | 70% | 20% |

これは「AIが新薬を作った」のではなく、**既存治療を患者の状態に合わせる**研究。対象患者が少なく、群ごとの数字も限定的。追加の第3相検証が必要。

### 7-7. 膵臓がん：診療履歴から数年先の高リスク者を特定

2023年『Nature Medicine』研究では、**デンマーク約600万人＋米国約300万人**の診療記録をAIで解析。3年以内の膵臓がんの発症を予測する研究として、デンマークで**AUC 0.88**、米国での外部適用で**0.71**と紹介した。

- 期待：高リスク者へ検査を重点配分し、早期発見を増やす。
- 課題：国や病院による性能差、偽陽性、検査の負担、死亡率への効果の証明。

### 7-8. 大腸がん：血液から手術後の再発リスクを調べる

「ctDNA」は血液中に存在する、がん細胞に由来するDNAの断片。手術後のがんの微細な残存を知る材料になる。

チャットで紹介した**DYNAMIC試験の5年間の追跡結果**：

| 5年時点の結果 | ctDNAを使った治療選択 | 従来方式 |
|---|---:|---:|
| 再発なく生存 | 88% | 87% |
| 全生存率 | 93.8% | 93.3% |

ctDNAに基づく方法では、抗がん剤を受ける人を減らして同程度の結果が得られたと紹介。これは**ctDNA研究であってAIの効果そのものを実証した試験ではない**。AIの付加価値は、血液・画像・診療情報の統合や治療選択支援に期待される。

### 7-9. 脳腫瘍：MRIから遺伝子変異を予測

国立がん研究センター・理化学研究所などの2026年研究として、MRI画像から脳腫瘍の遺伝子変異を予測するAIを紹介。

| 比較対象・条件 | AUC |
|---|---:|
| 最新型AI／海外患者データ | **0.97** |
| 従来型AI／同比較 | 0.85 |
| 神経放射線科医群／同比較 | 0.65 |
| 最新型AI／日本人患者データ | **0.82** |

重要なのは、他国・他施設への適用で性能が変わること。一部の熟練医がAIを上回る例にも言及された。AIは専門医の判断を補助する技術として評価する必要がある。

### 7-10. 陰性例も重要：複数がんの血液検査Galleri

2026年の英国NHSの**約14万2,000人**を対象とする大規模試験の中間的な公表内容として、ステージ4のがんが減った一方、主要評価項目である**ステージ3・4のがん全体の減少では主目的を達成できなかった**という結果を紹介した。

**血液からがんを検出できることと、がんによる死亡を減らせることは違う。** AI医療の楽観論を評価するときも、陰性結果を含める必要がある。

### 8-1. ALS：AIとiPS細胞を使う原因の絞り込み

京都大学CiRA、理化学研究所、大阪大学などの2026年7月の共同研究では、ALS患者**233人**と健康な人**508人**の血液遺伝子情報を機械学習で分析し、病気に関係する候補遺伝子**3つ**を見いだしたと説明。

- 病気の人と健康な人を区別する性能として**AUC 0.83**と報告。
- 患者由来のiPS細胞で運動神経細胞を作り、候補遺伝子の関与を実験で検証。
- AIが「怪しい遺伝子を選ぶ」、iPS細胞が「実際の人間由来の神経で確かめる」という役割分担。
- これは**ALS治療薬が完成した**ことを意味しない。

### 8-2. 薬剤耐性菌：従来の薬が効かない感染症への期待

MITなどの研究では、AIを利用してハリシンをはじめとする新たな抗菌候補を探索。チャットでは2026年の別研究として、約**600万化合物**を計算上で調べ、**213物質**を実験、**83物質**で抗菌活性を確認した事例も紹介した。さらに一部で動物実験へ進んでいる。

臨床で薬が効きにくい細菌が増える状況では、新しい構造の抗菌剤候補を見つけられることに大きな意味がある。ただし耐性菌感染症を確実に治せる薬として承認されたわけではない。

### 8-3. 希少遺伝性疾患：個別の治療薬を短期間で作る

2025年の米NIH支援研究として、希少な遺伝性疾患の乳児に患者専用の遺伝子編集治療を実施し、診断から初回治療まで**約6か月**で進めた例を紹介した。これは遺伝子編集・個別化製造・臨床チームの進歩が大きく、AI単独の成果と断言してはいけない。少人数の初期例だけで長期完治は証明できない。

## 9. iPS細胞の現在地とAIとの融合

### 9-1. iPS細胞とは何か

iPS細胞（人工多能性幹細胞）は、皮膚や血液などの細胞に特定の因子を作用させ、さまざまな種類の細胞になれる状態へ戻したもの。例えば、病気の人の血液から神経細胞を作って病気を再現したり、心臓や神経の治療に使う細胞を作ったりできる。

**2つの用途を分けることが重要**：

1. **iPS細胞による創薬・病気研究**：患者由来の細胞を使い原因や薬の効き方を調べる。
2. **iPS細胞による再生医療**：新しく作った細胞を患者に移植し、失った機能の回復を目指す。

AIは両方に貢献し得るが、**iPS細胞治療の成果がすべてAIのおかげというわけではない**。

### 9-2. 2026年の節目：日本で2つのiPS細胞由来製品が条件・期限付き承認

チャットで取り上げた2026年3月の厚生労働省の承認は次の2製品。

| 製品名 | 対象 | 研究・開発背景 | 目的・状態 |
|---|---|---|---|
| **アムシェプリ** | パーキンソン病 | 京都大学・髙橋淳教授の研究、住友ファーマ等 | iPS由来ドパミン神経前駆細胞を移植。2026年3月に条件・期限付き承認 |
| **リハート** | 重症心不全 | 大阪大学・澤芳樹教授ら、クオリプス | iPS由来心筋細胞シート。2026年3月に条件・期限付き承認 |

2026年10月には、京都大学病院がアムシェプリを用いる承認後の移植手術開始・初回患者の退院を報告したと紹介。

**重要**：条件・期限付き承認は、追加の有効性・安全性検証を必要とする制度。**パーキンソン病や心不全の完全治癒を意味しない**。

**資料**：[AMED：iPS細胞由来製品の承認に関する解説](https://www.amed.go.jp/news/topics/20260220.html)／[京都大学病院の発表](https://www.kuhp.kyoto-u.ac.jp/info/20261030.html)

### 9-3. 山中伸弥教授：「次の20年に十数の治療へ」

2026年10月のCiRA公式インタビューでは、山中教授が今後20年間に**iPS細胞を使う治療が一つ二つではなく十数個と世界で承認され、多くの患者に届いてほしい**と展望した。

研究段階の細胞を少人数へ届けるのではなく、品質を一定に保ち、安価かつ大量に製造することが今後の課題。その解決に自動化、AI画像解析、培養条件の予測・最適化が結びつく。

**資料**：[山中伸弥・CiRA公式インタビュー](https://www.cira.kyoto-u.ac.jp/j/pressrelease/newsletter/261020-000001.html)

### 9-4. 京都大学CiRA：AIが細胞の最終品質を早く予測する

2025年7月のCiRA、エピストラ、国立精神・神経医療研究センターなどの研究で、iPS細胞から筋肉に関係する細胞を作る実験の画像をAIで解析。

- 通常、最終結果を評価する時点：**82日目**。
- AIが最終的な結果を予測した時点：**24〜34日目**。
- **最終的な品質・分化結果を48〜58日早く見積もれる**可能性を示した。
- 研究にはアステラス製薬の研究者も関係したと紹介。

**誤解しやすい点**：細胞の培養そのものが48〜58日短縮されたわけではない。うまく育つかを早く予測し、失敗しそうな培養を見分けられる可能性があるという研究。

### 9-5. iPS細胞からの脊髄損傷治療：患者4人の初期臨床

2026年7月『Nature Medicine』の慶應義塾大学の研究として、重い脊髄損傷の患者**4人**にiPS由来神経幹細胞を移植した初期研究を紹介。

- **2人**で障害の重症度分類が改善。
- 最長約**4年**の追跡で、移植細胞由来と判断される腫瘍形成が確認されなかったとの説明。
- 一部で運動・感覚の改善が報告された。
- **対照群がない小規模試験**のため、自然回復・リハビリと移植の効果を完全には分けられない。

**原著論文**：[Nature Medicine：iPS-derived neural stem cells for spinal cord injury](https://www.nature.com/articles/s41591-026-04549-6)

### 9-6. 海外のiPS神経治療：BlueRock／Bayer

BlueRock Therapeutics（Bayer傘下）は、パーキンソン病のiPS由来神経細胞「bemdaneprocel」を開発。初期の追跡結果とともに、2026年時点で**約102人規模の第3相試験「exPDite-2」**の募集を進めたと紹介。模擬手術を対照に含む無作為化試験により、移植自体の真の効果を厳密に確認する計画。

### 9-7. ほかにiPS細胞が研究される病気

- **角膜疾患**：iPS由来角膜上皮細胞シート。2026年に第2相試験へ進んだ例として紹介。
- **網膜色素変性症・網膜疾患**：視細胞・網膜細胞の移植を検討。
- **ALS**：患者の神経細胞をiPSから作り、AIなどと組み合わせて病気の原因と薬の効果を調べる。
- **アルツハイマー病**：患者由来の神経細胞・脳オルガノイドで病態を再現し、薬を評価する研究。
- **糖尿病**：インスリンを出す細胞の再生・移植。海外で初期臨床。

### 9-8. my iPS：製造コストを大幅に下げる構想

京都大学iPS細胞研究財団の**my iPSプロジェクト**について、チャットでは以下の目標値を紹介した。

| 指標 | 公表・説明された値 |
|---|---:|
| 従来の手作業による本人専用iPS細胞製造費用の概算 | 約**5,000万円** |
| 将来的なiPS細胞提供費用の目標 | 約**100万円** |
| 単純比較による低減幅 | 約**98%** |
| 目指す臨床試験開始時期 | **2028年度中**（2029年3月末まで） |

- **98%は達成済みの実証値ではない。** 5,000万円と100万円は異なる条件を含む可能性があり、目標値の単純比較。
- 100万円は患者が受ける**治療全体の総額ではない**。細胞を加工する費用、手術・検査・輸送・管理費は別。
- **大阪・中之島Qross**の自家iPS細胞製造自動化研究拠点を紹介。
- **テルモ × iPS財団**の細胞培養自動化・標準化研究が2026年3月のAMED支援対象になったと紹介。自動化装置の導入と、AI利用は区別する。

### 9-9. 仮想細胞：AIはiPS細胞の能力を拡張する

2025〜2026年の世界的な方向性として、「Virtual Cell（仮想細胞）」が進展。細胞が薬・遺伝子操作・環境変化にどう反応するかをAIで予測し、実験を繰り返してモデルを改善する。

- **Chan Zuckerberg Initiative × NVIDIA**：大規模細胞データによるAIモデルを推進。
- **Arc Institute「State」**：チャットでは、**約1億6,700万の細胞観測データ＋1億件以上の薬剤・遺伝子操作への反応データ**を学習したと紹介。
- **Nature Methods 2026年総説**：幹細胞由来モデルの画像にAIを用い、細胞状態、分化の進行、病気の変化を推定する研究を整理。

**将来の組み合わせ**：「患者のiPS細胞で病気を再現」→「仮想細胞で数多くの薬候補を予測」→「現実の細胞実験で検証」→「適切な患者を対象とする治験」。ただし、仮想細胞はまだ人間の体内反応を完全再現するものではない。

**資料**：[Nature Methods：AI and stem-cell derived models](https://www.nature.com/articles/s41592-026-03202-x)

## 11. 成長はいつ爆発するか：2026〜2045年シナリオ

### 11-1. まず「何が成長するか」を分ける

- **AIの研究利用者・計算需要・研究設備**：臨床試験に先行して伸びる。

- **患者に承認される医薬品**：数年単位の治験が必要。結果が確認できるまで時間がかかる。
- **医療費・生存率・健康寿命の改善**：承認後の普及、長期追跡まで必要。

- **製薬・AI企業の株価**：研究成績だけでなく、バリュエーション、期待先行、金利、資金調達、競争力によって動く。

## 12. 経済効果と企業収益の構造

### 12-1. 経済全体への影響

世界の死亡原因の大部分は、心疾患、がん、糖尿病などの非感染性疾患による。チャットではWHOの推計として、**2023年の世界の死亡の約74%**が非感染性疾患との数字を取り上げた。

AI医療・創薬が改善する可能性のある経済変数：

| 変数 | 改善の経路 | 注意点 |
|---|---|---|
| 医療費 | 入院・手術・重症化・検査の無駄を減らす | 新しい高額薬で短期費用が増える場合もある |
| 介護費 | 認知症・脳卒中・運動障害などの重症化を遅らせる | 実際の発症率・介護度の改善が必要 |
| 労働生産性 | 疾病による休業・離職・早期死亡を減らす | 治療の普及や雇用環境による |
| 健康寿命 | 生活の質を保てる期間を延ばす | 平均寿命だけでは測れない |
| 創薬事業 | 候補探索費削減、開発成功率向上、新薬収益 | 成功率向上の実証が必要 |
| 国全体の成長 | 生産性・社会保障負担などに波及 | 予測モデルの仮定に依存 |

今後のシナリオは**2030年・2035年・2040年・2050年**を区切りに、既に観測された実績、研究機関の推計、独自の経済試算を分けて評価する計画とした。

### 12-2. どこに先に利益が出るのか

| 事業領域 | 収益の発生時点 | 主なリスク |
|---|---|---|
| **GPU・クラウド** | 研究開発の実行時から計算利用料・設備売上 | 投資過剰、競争、稼働率 |
| **創薬AIソフト** | 研究サービス契約・ライセンス時から | 導入拡大と継続利用、競合技術 |
| **実験自動化・分析装置** | 研究設備の購入、保守、消耗品 | 研究設備投資の周期性、品質保証 |
| **製薬企業** | 薬の導出契約・マイルストーン・承認販売後 | 治験失敗、承認遅延、薬価・特許 |
| **iPS細胞治療企業** | 治療製品の出荷・販売、技術提供 | 製造原価、治療件数、保険償還、長期安全性 |

このため、**医学研究で画期的な成果が出た企業と、株主利益が最初に増える企業は必ずしも同じではない**。研究成果、売上、利益、株価を分けて追跡する必要がある。

### 12-3. 日本産業の競争上の強みと課題

- **強み**：創薬経験、化学・抗体技術、臨床開発、iPS細胞、精密な細胞培養、品質管理、医療機器、ロボット・自動化。

## 13. 研究結果を誤読しないための重要な区別

### 13-1. 「完治」をどう定義するか

| 言葉 | 一般向けの意味 |
|---|---|
| **完治・根治** | 病気そのものが治り、継続的な治療を要しない状態を長期間維持できること。ただし病気ごとに定義が異なる |
| **機能的治癒** | 病原体などが残っていても、薬なしで病気を実質的に抑えられる状態 |
| **寛解** | 病気の活動や症状が見られない／大きく減った状態。再発しない保証ではない |
| **進行抑制** | 病気は残るが悪化速度が遅い |
| **症状改善** | 病気の原因は残っても、日常生活に関わる症状が軽くなる |
| **予防** | 病気の発症確率を下げる。リスクをゼロにすることではない |
| **早期発見** | 発症した病気を早く見つける。発症そのものの予防とは別 |
| **再発予防** | 一度かかった病気が治療後に再び現れることを減らす |

### 13-2. 技術別に区別すべきこと

- **AI創薬と一般の薬物研究**：薬や遺伝子編集技術が進歩したすべての例をAIの成果としない。
- **深層学習AIと統計モデル**：血液マーカーを使う予測研究が、すべて生成AIを使用しているわけではない。
- **研究室での反応と臨床効果**：細胞実験で「91%抑制」は患者の病気が91%改善したことではない。
- **感度と死亡率**：検診の発見率が上がっても、検診で患者の寿命が延びることは別途検証が必要。
- **予測AUCと絶対リスク**：AUC 0.88は発症確率88%ではなく、モデルの識別性能の指標。
- **ハザード比と確率差**：再発リスク42%低下は、再発確率が絶対値で42ポイント下がる意味ではない。
- **予防可能割合とAIの効果**：認知症45%、がん37%は危険因子に関する推計であり、AIによる実績値ではない。
- **製造コストと医療費**：iPS細胞100万円目標は治療全体の価格ではない。
- **条件・期限付き承認と全面的な臨床的確立**：iPS細胞製品は継続的な効果・安全性の確認が必要。
- **投資計画と実際の支出**：発表された上限額、将来のマイルストーン、株式出資、設備投資を区別。

## 付録：やさしい医学・創薬用語集

| 用語 | 簡単な意味 |
|---|---|
| 創薬 | 新しい薬の候補を見つけ、安全性・効果を調べ、製品にすること |
| 標的 | 薬が作用する、病気に関係したタンパク質や細胞の仕組み |
| タンパク質 | 体内でさまざまな働きを行う分子。薬が狙う対象になることが多い |
| ヒット化合物 | 薬としての働きがありそうな初期候補の物質 |
| 前臨床 | 人間に使う前に、細胞や動物などで調べる段階 |
| 第1相治験 | 主に人間での安全性や適切な量を確認する初期試験 |
| 第2相治験 | 患者で効果が見込めるか、安全性に問題がないかを調べる試験 |
| 第3相治験 | 多数の患者で従来治療や偽薬と比較し、有効性・安全性を確かめる試験 |
| ランダム化比較試験 | 参加者をくじ引きに近い方法で分け、治療の効果を公平に比べる研究 |
| プラセボ／偽薬 | 薬の有効成分が入っていない比較用の製剤 |
| AUC | 予測モデルが病気の人とそうでない人を区別できる性能の指標。0.5付近は偶然に近く、1.0に近いほど高性能 |
| 感度 | 実際に病気がある人を、検査で正しく病気と判定できた割合 |

## 統合レポートの最終結論

AI医療革命の「希望」は、単にAIが人間の医師に代わるという話ではない。**これまで研究者が扱いきれなかった生物学的情報を解読し、治療法を見つけ、病気の発症前に介入する可能性を大きく広げること**にある。

創薬の前半は既に高速化が確認され、抗菌薬・線維症治療薬・個別化がん治療・画像診断・iPS細胞など、それぞれ異なる形で人間への応用が進んでいる。がんでは、AI支援検診の大規模試験や個別化治療の進展があり、認知症では、血液検査と発症前治療の臨床試験が重要な段階にある。

iPS細胞は、日本が研究上の先駆者であることに加え、2026年には再生医療製品の条件・期限付き承認という節目を迎えた。AIによる細胞の品質予測や病気の原因探索が進めば、**AIが新薬を見つけ、iPSが病気の仕組みを再現し、再生医療が失われた機能を取り戻す**という医療の連携が強まる可能性がある。

ただし、**研究の大きな希望と、すでに治療が確立したという事実は混同しない**。今後の重要な分岐点は、AIを使った薬の第3相試験の結果、認知症発症前治療の成績、個別化がん治療の長期追跡、iPS細胞の製造原価と長期安全性、そして医療費や患者の死亡・健康寿命に本当に改善が出るか、という点にある。

2026〜2029年は研究・基盤設備に、2029〜2035年は承認・商業化に、2035年以降は高度な予防・個別化・再生医療に、それぞれ異なる成長機会が存在する可能性がある。これを一つの「AI医療市場」としてまとめるのではなく、**研究成果、患者への価値、企業収益、社会全体への経済効果**を分けて追跡することが、科学的にも投資分析上も重要である。
