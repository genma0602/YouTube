# テクマトリックス（3762）経営陣の見通し・成長戦略・投資分析

- **調査基準日**：2026年11月2日
- **対象企業**：テクマトリックス株式会社（東証プライム、証券コード3762）
- **主要資料**：2026年10月30日発表の2027年3月期第2四半期決算資料、2026年7月31日公表のAI戦略・株主還元資料など
- **注意**：本資料は経営陣による公表済みの見通し・方針と、筆者による投資分析を区別して整理したもの。将来の業績を保証するものではなく、投資判断は自己責任で行うこと。

## 1. 結論・経営戦略の全体像

テクマトリックス経営陣は、**AI普及による既存ITビジネスの構造変化をリスクとして認識しつつ、セキュリティ運用、ソフトウェア品質保証、CRM、医療ITに新しい需要が生まれる**と見通している。

中核戦略は以下の5つ。

1. **サイバーセキュリティを成長の中心に据える。** AIを悪用した攻撃やAIシステム固有の脅威への対策、SOC運用自動化などの需要を取り込む。
2. **製品販売から運用・サービス提供へ収益源を広げる。** 継続課金型のマネージドサービスやクロスセルを拡大し、収益の安定化と高付加価値化を図る。
3. **AIによる既存IT市場の変化に対応する。** CRMの課金・役割の転換、AIで増大するソフトウェアの品質保証需要に対応する。
4. **医療IT・教育ITを育成する。** 医療画像のクラウド化、AI診断支援などに先行投資する。
5. **M&Aと株主還元を両立する。** 国内外の事業拡大への投資を継続しながら、自社株買いと配当を強化する。

**投資分析：** サイバーセキュリティ事業の成長は実績に表れているが、全社利益率や医療ITの収益化については引き続き検証が必要。

## 2. 最新の業績見通し

### 2027年3月期の通期会社予想

| 項目 | 会社予想・指標 | 補足 |
|---|---:|---|
| 売上収益 | **818億円** | 前期比 **+14.0%** |
| 営業利益 | **82億円** | 前期比 **+5.7%** |
| 営業利益率 | **約10.0%** | 前期実績の約10.8%から低下する計画 |
| 2026年4〜9月の受注残高 | **1,202.6億円** | 前年同期比 **+22.2%** |
| 継続型ビジネス売上比率 | **83.5%** | テクマトリックス単体＋PSPの対象範囲 |

- 2026年3月期実績：売上収益約717.33億円、営業利益約77.6億円。
- 2027年3月期通期予想は、2026年10月30日時点で当初予想を据え置き。

**投資分析：** 売上高の成長率に比べて営業利益の伸びは小さく、先行投資や利益率低下が重荷になっている。今後の焦点は、売上拡大を利益成長につなげられるかどうか。

## 3. サイバーセキュリティ：最大の成長エンジン

### 経営陣の狙い

- **AIを狙う攻撃への対策**：AIアプリケーション、データ、インフラの保護需要を取り込む。
- **SOCと運用サービスの拡大**：監視・検知・対応の継続提供を強化する。
- **AIによるSOC業務自動化**：運用負荷の軽減を顧客価値として提供する。
- **クロスセル・複数年契約**：既存顧客へ追加製品・サービスを提供し、継続売上を増やす。
- **ASEANへの進出**：買収したFirmusを軸にマレーシア、シンガポールなどで展開する。

### 2026年4〜9月の実績

| 情報基盤事業 | 実績 | 前年同期比 |
|---|---:|---:|
| 売上収益 | **288.7億円** | **+19.2%** |
| 営業利益 | **32.2億円** | **+10.0%** |
| 営業利益率 | **約11.2%** | 増収率に対して利益成長は緩やか |

会社はクラウドセキュリティ製品、AI活用のSOC業務自動化、複数年サブスクリプション契約が業績を押し上げたと説明。一方、一部製品の価格競争激化と前年の高採算大型案件の反動が利益率を圧迫した。

**投資分析：** 市場需要と売上成長は確認できる。今後は単なる海外製品の販売増ではなく、自社が継続的に提供する運用・支援サービスによって利益率を改善できるかが重要。

## 4. AI時代に対する経営陣の見通し

2026年7月31日の公表資料では、経営陣が「Anthropic Shock（アンソロピック・ショック）」を取り上げ、AIが既存IT産業へ及ぼす構造的影響を説明している。

### 経営陣が認識する既存ビジネスのリスク

| リスク | 想定される変化 |
|---|---|
| SaaSのID課金の弱体化 | AIエージェントによる操作が増え、利用人数に応じた課金の価値が低下する可能性 |
| 低付加価値SIの縮小 | AIコーディング普及により、人月課金型開発の収益機会が縮小する可能性 |
| レガシー保守需要の変化 | AIがソフトウェア刷新やコード変換を効率化する可能性 |
| 定型業務の自動化 | デジタル作業の外部委託や従来型サービスに価格低下圧力がかかる可能性 |

※これらは経営陣が提示した将来シナリオであり、すべてが実現したという意味ではない。

### AI時代に伸ばす事業

| 事業領域 | 成長シナリオ |
|---|---|
| サイバーセキュリティ | AI悪用による攻撃増加とAIシステム防御の新規需要 |
| ソフトウェア品質保証 | AIが生成するコードが増え、検証・テスト需要も増加 |
| CRM | オペレーター数に依存する収益モデルから、AI対応コンタクトセンターのデータ基盤や処理量・成果に応じたモデルへの転換 |
| 医療IT | 医療画像・データのクラウド化、AI画像診断・病理診断支援の拡大 |

**投資分析：** 「AIで影響を受けにくい」という経営陣の主張については、各分野の実際の売上単価、導入件数、営業利益への寄与を追跡する必要がある。

## 5. 医療IT：将来の収益源だが短期は負担

### 主要戦略

- 医用画像管理システム **「NOBORI」** のクラウド化。
- PHR（Personal Health Record、個人健康記録）の活用。
- AIを用いた画像診断支援とデジタル病理診断。
- 2026年4月に子会社化した**メドメイン**との連携。
- タイ、マレーシア、フィリピンなど海外市場への展開。

### 2026年4〜9月の医療システム事業

| 指標 | 実績 |
|---|---:|
| 売上収益 | **46.68億円** |
| 売上成長率 | **+5.3%** |
| 営業利益 | **0.80億円** |
| 営業利益の前年同期比 | **-73.3%** |
| 営業利益率 | **約1.7%** |

利益減少の背景として、メドメインの先行損失、人員・研究開発などへの投資、クラウド移行による一括売上の減少が挙げられる。

2027年3月期の医療システム事業の営業利益予想は**7.6億円**。上期実績0.8億円を踏まえると、下期に約6.8億円の営業利益が必要。

**投資分析：** クラウド型の継続課金が蓄積すれば長期的な安定収益につながる可能性がある。ただし現段階では、先行投資の回収と利益率の改善が未確立。

## 6. M&A・投資・株主還元の戦略

### 成長投資

中期経営計画の最初の2年間の投資実績は**約175億円**。

- **約100億円**：人材投資、研究開発など（300名以上の新規採用、処遇改善、自社ソリューション開発など）。
- **約75億円**：戦略的M&Aなど。

経営陣は、必要な成長投資・M&Aを実行しながら、株主還元を強化する方針。

### 株主還元

- **2027年3月期から4年間、各年度の総還元性向100%を目指す。**
- 配当方針の目安：**配当性向40%またはDOE7%の高い方**。
- 2027年3月期には**最大32億円の自己株式取得**を計画。

※総還元性向には配当と自社株買いを含む。総還元性向100%は「配当性向100%」とは異なる。また、目標は実施を保証するものではない。

**投資分析：** 株主還元の強化は株式価値にプラスとなり得る一方、利益成長が鈍い状態で継続する場合、M&Aや成長投資への資金配分とのバランスが重要になる。

## 7. 経営陣が認識する主要リスク

| リスク | 会社の状況・対応 | 投資家としての監視ポイント |
|---|---|---|
| 為替変動 | 海外仕入れにドル建て取引が多く、為替予約や価格交渉で対応 | 円安時の仕入れコストと製品粗利益率 |
| 運転資金負担 | 大型複数年契約で顧客回収と海外ベンダーへの支払いのタイミングに差 | 営業キャッシュフロー、前受・前払などの動向 |
| 価格競争 | 情報基盤事業の一部で収益性低下が発生 | セグメント営業利益率の推移 |
| 人材コスト | 高度なIT人材の採用・育成を推進 | 人件費増に見合う付加価値と増収 |
| 新規事業の投資回収 | 医療AI、教育IT、海外CRMなどに投資 | 利益貢献開始時期、損失幅の縮小 |

2027年3月期の当初中期計画で掲げた営業利益**86億円**に対し、現在の会社予想は**82億円**。情報基盤事業は堅調だが、他セグメントの利益見通しが下振れている点に留意。

## 9. 今後の決算で最も重要なチェック項目

1. **情報基盤事業の営業利益率が回復するか。** 上期11.2%を基準として、価格競争を運用サービスやクロスセルで補えるか確認する。
2. **医療システム事業の利益が回復するか。** 先行投資の負担が縮小し、通期営業利益目標7.6億円の達成に向かうか。
3. **AI関連サービスの業績寄与が数字で示されるか。** AI-SOC、AI向けセキュリティ、品質評価ツールなどの案件数・収益貢献を見る。
4. **受注残高が実際の売上・キャッシュフローに転換するか。** 受注増でも運転資金負担や利益率悪化が生じないかを確認する。
5. **海外M&Aの利益貢献が進むか。** ASEAN展開による収益機会と統合コストを比較する。
6. **株主還元が持続可能か。** 利益成長、キャッシュ創出、成長投資のバランスを見る。

## 10. 総合評価

テクマトリックスは、**海外のセキュリティ製品の販売・導入支援に加え、AIを使ったセキュリティ運用、ソフトウェア品質保証、医療・業界特化型のクラウドサービスで継続収益を拡大する戦略**をとっている。

- **強み**：サイバーセキュリティ市場の需要増、情報基盤事業の増収、継続型売上の比率、受注残高の拡大。
- **課題**：売上成長ほど営業利益が伸びないこと、製品の価格競争、医療ITの投資負担。
- **中長期の焦点**：セキュリティ需要の拡大そのものより、増えた需要を自社の営業利益・キャッシュフローにどれだけ変換できるか。

**結論：** 経営陣が描く成長シナリオにはセキュリティ事業の実績という裏付けがあるものの、グループ全体としては投資負担と利益率の改善が残された課題。AI時代の需要拡大が高い収益性と株主価値の向上に結びつくかを検証すべき段階にある。
