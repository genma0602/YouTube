# 日本国債は海外機関投資家から再評価されているのか

**調査基準日：2026年10月22日**  
**視点：G7比較／海外投資家の資金フロー／機関投資家の投資判断／日本経済の正常化**

## エグゼクティブサマリー

日本国債には海外投資家によるまとまった買いが確認され、金利上昇で投資対象としての魅力が回復している。ただし、「海外の機関投資家が日本経済の復活を確信して日本国債を買い集めている」と断定するのは正確でない。**直接的な投資理由は利回り、為替ヘッジ後の収益、債券価格の割安感、国際分散、将来の金利見通し**であり、賃上げ・設備投資・名目成長を伴う日本経済の正常化は、その長期的な背景に位置づけられる。

2025年度に海外投資家は利付日本国債を**32.8兆円**買い越したが、2026年4～8月は**2.8兆円**まで鈍化し、9月は**約4.52兆円**の買い越しに回復した。年を通じて一貫して買いが加速していたわけではない。2026年10月20日の20年国債入札は**応札倍率5.84倍**で非常に強かったが、入札結果だけでは海外投資家が主導したとは証明できない。[1][2][3]

## 1. 海外勢が買っていることを示す数値

| 期間・対象 | データ | 読み取り方 |
|---|---:|---|
| 2025年度：海外勢の利付日本国債売買 | **＋32.8兆円** | 大規模な年間買い越し |
| 2026年4～8月：同 | **＋2.8兆円** | 2025年度より購入ペースが大きく鈍化 |
| 2026年9月：同 | **約＋4.52兆円** | 海外勢の買いが回復（みずほ証券分析の紹介） |
| 2026年4～9月：国内主要投資家の国債売買 | **＋18兆7,550億円** | 国内年金・銀行などの買いも大きい |
| 2026年10月20日：20年債入札 | **応札倍率5.84倍** | 市場全体で強い需要。海外勢の寄与は不明 |

- 20年債の前回入札（9月15日）の応札倍率は4.01倍、過去12か月平均は3.73倍。20日入札の平均落札利回りは3.723％。[2][4]
- 上記の「利付日本国債売買」（日本証券業協会）と「対内中長期債投資」（財務省）は集計対象が違うため、金額を足し合わせない。
- 10月11～17日週について前段の調査では買い越し約1.45兆円との数値が提示されたが、本稿作成時にはその週の一次公表を再照合できなかったため、結論の主要根拠には使っていない。

## 2. 海外機関投資家はどれほど大きいか

2026年6月末の日本銀行「資金循環統計」では、**国債・財投債（国庫短期証券を除く）の海外保有比率は7.94％、保有額は約80兆円**。一方、日本銀行の保有比率は46.7％で、保有残高の大部分は国内主体である。[5]

ただし、海外勢は国債の現物売買・先物取引では保有残高のシェア以上の存在感を持つ。短期取引を行うヘッジファンドと、長期保有する年金・保険・運用会社を区別する必要がある。[6]

**海外の主な買い手の種類**

| 投資主体 | 代表例・役割 | 典型的な投資目的 |
|---|---|---|
| 公的機関・中央銀行 | 外貨準備を運用する当局 | 流動性、分散、準備資産 |
| 年金基金・保険会社 | 長期負債を持つ運用機関 | 長期の利息収入、負債との期間の整合 |
| 大手資産運用会社・債券ETF | BlackRock、PIMCOなどの運用プラットフォーム | 投資家から預かった資金の配分 |
| ヘッジファンド・銀行 | 金利・為替の裁定取引主体 | 金利曲線、スワップ、短期価格変動を利用 |

**実名で確認できる例**

- **BlackRock**：欧州籍の日本国債ETFに2026年8月時点までで約**14億ドル**の純資金流入。これはETF投資家の購入額であり、BlackRock自身の自己勘定による購入額ではない。[7]
- **BNY**：同行が把握した日本国債への海外資金流入は2026年夏に拡大。顧客等のフロー情報であり、世界全体の国債買い越し額ではない。[7]
- **ノルウェー政府年金基金（NBIM）**：2025年末、日本国債は債券運用資産の**4.6％**。ただし2025年の日本国債投資の運用成績は**－8.8％**であり、「保有している」ことと「直近で買い増している」ことは同義ではない。ノルウェーはG7外。[8]

## 3. どこの国が日本国債を一番買っているのか：G7比較の限界

2025年末の**日本発行債券全体**（国債のほか地方債・社債等を含む）の保管地・名義人ベースの保有統計では、米国約58兆円、ベルギー約47.8兆円、ルクセンブルク約29.1兆円、英国約15.9兆円、中国約14.8兆円とされる。[9]

**重要：これは「国別の日本国債そのものの実質保有ランキング」ではない。** ベルギーにはユーロクリア、ルクセンブルクにはクリアストリームなどの証券保管・決済機関が存在し、資産の保管地と最終的な保有者の居住国は一致しない。したがって「G7で米国の投資家が日本国債を最も買い越している」とまでは断定できない。[9]

G7の国債との比較で機関投資家が見るのは、**表面的な利回りの順位より、為替ヘッジ後利回り、インフレ、財政・政策リスク、流動性**である。

| 国 | 日本国債との比較で注目される点 |
|---|---|
| 米国 | 米国債の高い名目利回りと円への為替ヘッジコストの比較 |
| フランス | 政治・財政不安、ドイツ国債との金利差拡大 |
| ドイツ | ユーロ圏の代表的な安全資産。円資産との分散投資 |
| 英国 | 金利・インフレ変動、債券市場のボラティリティ |
| イタリア | 財政・信用スプレッドを含む投資判断 |
| カナダ | 資源価格・北米金利・為替との分散 |
| 日本 | 数十年ぶりに回復した利回り、国内保有基盤、日銀の政策正常化 |

フランス国債を売却して日本国債を購入した特定の運用事例は報じられているが、**「フランスから流出した巨額資金が日本国債に直接移った」全体規模は立証できていない**。MUFGは、為替ヘッジ後にフランス国債の日本国債に対する利回り優位性が低下したこと、国内投資家がフランス債券を売り越していることを指摘している。[10]

## 4. 買いの理由：経済復活への期待は含まれるか

1. **利回りの回復**：日本国債にゼロ金利時代にはなかった利息収入が生まれた。2026年10月20日の20年債入札では平均落札利回り3.723％。[1]
2. **為替ヘッジ後の収益**：外国債券の利回りが高くても円ヘッジ費用を差し引くと、国内国債が有利になることがある。海外投資家にとっても自国通貨ヘッジ後の条件が重要。[7][10]
3. **金利上昇の一服・国債価格の反発期待**：金利が下がれば既発債価格は上昇する。ただし追加利上げ・財政拡張は逆風。[11]
4. **欧州を含むG7のリスク分散**：フランスの財政・政治不確実性などが円建て資産の相対評価を変える可能性。[10]
5. **日本経済の正常化**：賃上げ、企業設備投資、生産性向上、名目成長が長期の税基盤と日本市場の魅力を支える可能性。ただし「国債価格が上がる」という予測と同義ではない。[12][13]

## 6. 「日本経済の復活」と国債の信用力の関係

国債を保有する機関投資家にとって重要なのは、政府債務の**絶対額だけでなく、GDPに対する比率や将来の利払い能力**である。

IMFの2026年4月時点の予測では、日本の一般政府総債務／GDP比は**2025年206.8％→2026年202.9％→2031年193.1％**へ低下する見通し。IMFは、名目成長率が政府債務の実効金利を上回ることが債務比率の改善に寄与すると分析する。一方で、債務の水準自体は高く、財政拡張や人口高齢化による負担には留意が必要とする。[14]

政府による電力・半導体・AI・防衛・インフラ投資が民間投資を誘発し、生産性・賃金・税収・名目GDPの持続的増加につながれば、国債の長期的な信用力を支える可能性がある。しかし、投資効果より早く物価や長期金利が上昇する場合、既発国債価格には逆風になる。

**したがって、「日本経済の復活期待＝日本国債の価格上昇」ではない。** より正確には「経済正常化による利回り回復と、成長力・財政基盤への中長期的評価が、国債需要の背景にある」という理解になる。

## 7. YouTube台本で使える表現／避けたい表現

### 推奨表現

> **「海外の機関投資家による日本国債の見直し買いが起きています。2025年度には海外勢が利付国債を32.8兆円買い越し、2026年9月にも約4.5兆円の買い越しが確認されました。背景には日本国債の利回り回復に加えて、企業投資や賃上げを伴う日本経済の正常化への期待もあります。ただし、海外勢の買いは毎月一貫しているわけではありません。」**

### より短い表現

> **「日本国債は今、海外の大口投資家から見直し買いされています。金利収入の魅力が戻り、日本経済の正常化も再評価されています。」**

### 避けたい断言

- 「G7各国が自国債を売って日本国債に逃げ込んでいる」：国別の資金移動の規模が未確認。
- 「世界の年金基金が日本国債を一斉に買い集めている」：年金の購入額を国別・機関別に確認できない。
- 「海外勢の買いは日本経済復活の証明」：利回り・為替・裁定取引という別要因が大きい。
- 「20年債入札が強い＝海外勢が大量購入した」：入札倍率だけでは購入主体は分からない。

## 8. 今後の確認指標

1. 日本証券業協会：**海外勢の利付国債買い越し**が翌月以降も続くか。
2. 日銀資金循環統計：**海外保有比率と国庫短期証券を除いた保有額**が増えるか。
3. 財務省：国債入札倍率と**平均・最高落札利回りの差**が安定しているか。
4. 海外運用会社：年金・保険等、**長期保有を前提とする実需投資家**による具体的な購入表明が増えるか。
5. マクロ：設備投資・実質賃金・名目GDP・長期金利・円相場をセットで観察する。
