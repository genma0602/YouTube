## 3. 動画でそのまま使える解説の筋道

既存のデータセンターにもっとGPUを追加したいが、電力会社から新しい受電枠を簡単に確保できない。そこで**高砂熱学工業**が、既存空調の温度・気流・電力の無駄を調べる。**日比谷総合設備**が、稼働中施設でも空冷と液冷を共存させる設計・改修工事を進める。さらに**三菱電機**がUPS・受変電など電力品質と電源容量に対応し、**ダイキン**がチラーからGPU直接液冷までの冷却を強化する。**パナソニック**はCDUや蓄電・電子部品などを供給する。**八洲電機**が液冷設備を現場で据え付け・試運転し、保守を担う。最後に**IIJ**がGPUサーバー・通信・セキュリティ・運用基盤を構築する。こうして、新しい土地を取得しなくても、既存拠点から取り出せるAI計算能力を増やす、という流れである。

重要な投資判断は、**技術的に適合することと、実際に増強工事を受注したこと、海外AI専用DCに商用納入したことは、すべて別の証拠**である点にある。独立した「新設」「既設改修」「技術実証」「販売開始」「確定受注」「稼働中の商用運用」を混同しない。

### 1-4. 既存DC高効率化の技術

- **グリーンエアーIDC**：国内外**140件以上の診断・検証実績**。サーモカメラ、CFD解析、温熱・気流分布、冷気流動、ホット／コールドアイル分離、風量・給気温度・運転設定の見直し、必要設備だけの改修。資料では空調エネルギー**25%削減の事例**も紹介（全顧客で25%を保証しない）。
- **IDC-SFLOW**：給気効率改善の技術。高密度ラック配置・サーバー入替に伴う気流の変化への対応。
- **T-Base**：配管・空調ユニットを現場外で事前製作し工期を短縮。2025年度は**130現場**、現場労務**約10.99万時間削減**。2026年度はデータセンター向け標準化メニューの開発を計画（実績値は全工事のもの）。
- **TMES**：運転管理・保守・エネルギーマネジメントによる継続サービス可能性。ただしDC専用の保守契約数と継続収益は未開示。
- **投資上の作用**：電力接続枠が固定の施設では、PUEを改善することでIT用に利用できる理論電力が増える。例えば100MW、PUE1.55ならIT電力64.5MW、PUE1.40なら71.4MW。これは仮定の計算であり同社の個別実測ではない。液冷が増えてもネットワーク・ストレージ・電源は空冷を使う場合があり、施設の排熱処理も必要。逆にGPUの直接液冷化で従来の空気流改善だけの付加価値が縮小する恐れもある。

## 第1章 調査の結論

### 1-1. 基本となる投資仮説

AIの計算需要は今後も増加する一方、データセンターの新設には次の制約がある。

1. **電力供給の制約：** 送電網への接続待ち、変電設備の不足、電力系統への負荷増加。
2. **行政・政治的制約：** 新設に対する住民反対、環境規制、建設許可の厳格化。
3. **建設コストの上昇：** 土地、建設資材、電力設備、冷却機器、人件費の増加。
4. **建設期間の長期化：** 新しい施設が稼働するまでに時間を要する。
5. **AI技術の急速な進歩：** 建設中にもGPUの性能や冷却要件が変化する。

これらの問題が深刻化すると、ハイパースケーラーやAIクラウド事業者は、新設施設を増やすだけでなく、**既に電力接続を確保しているデータセンターから、より多くの計算処理能力を引き出す投資**を重視する可能性がある。

この投資は、大きく3種類に分かれる。

| 分類 | 投資の内容 | 目的 |
|---|---|---|
| 省エネ型改修 | 空調制御、チラーの運転改善、冷却方式の更新 | 同じ処理量を少ない電力で実現 |
| 高密度化投資 | 液冷設備、配管、CDU、ラック設備の増強 | 同じ建物に高性能GPUを追加 |
| 運用最適化投資 | GPU電力制御、ワークロード配分、設備監視 | 同じ電力供給枠でAI処理量を増加 |

### 1-2. 最も重要な判断

**既存施設の効率化・増強への投資がすでに進んでいることは確認できる。ただし、2026年11月の米国中間選挙を受けて、ハイパースケーラー各社が新設予算を一斉に既存施設へ振り替えたとまでは確認できない。**

この2つは区別する必要がある。

## 第2章 米国のデータセンター規制と投資環境

### 2-1. 2026年11月の米国中間選挙で起きたこと

2026年11月3日の米国中間選挙では、データセンターの新設に慎重な候補者が複数の州で勝利した。

特に問題視されているのは、電気料金、送電網への負荷、水の使用量、騒音、地域住民への影響である。

11月7日公表のJ.P. Morgan Asset Managementの分析では、次の数字が示された。

- 2026年1月以降、米国内の州・地方レベルの建設一時停止措置は400件超。
- 2023～2025年の同種の措置は合計45件。
- 11月3日の住民投票では、41件中40件で開発制限を支持する結果。
- 2026年上半期には、建設中のDC容量が2025年末比で約50%増加。
- 米国の公表済みDC開発計画は430GW超。そのうち実際に開発プロセスが進行しているものは59%。

したがって、規制強化の動きは存在するものの、データセンター建設全体が停止したわけではない。

J.P. Morganは、2028年以降の新規開発案件に最も大きな影響が及びやすく、建設が進んでいる案件は相対的に影響が小さいと分析している。

### 5-1. Schneider Electric：新設を待つより既存施設を活用する

**2026年2月26日｜Andrew Whitmore、Motivair by Schneider Electric副社長**

Schneider Electricは、AI計算基盤の競争力を決めるのは、単に巨大施設を建設することではなく、必要な計算能力をどれだけ早く提供できるかだと説明している。

具体的には以下の設備が重要になる。

- **リアドア熱交換器：** ラック背面で排熱を回収。
- **HDU：** 施設冷水が使えない場合などに放熱を補助。
- **監視制御システム：** 温度・流量・設備状態を管理。

### 5-2. Schneider Electric：同じ受電容量でもIT用電力を約29%増やせる可能性

**2026年10月22日｜Mark Deguara、Technology Innovation Leader**

オーストラリアのデータセンター市場を分析した技術レポートでは、受電容量が固定されている施設ほど、冷却効率が重要になると指摘している。

レポートでは、100MWの受電容量を持つ施設を例に、PUEの改善効果を試算している。

PUEとは、施設全体の消費電力をIT機器の消費電力で割った指標である。

```text
PUE = 施設全体の消費電力 ÷ IT機器の消費電力
```

| 指標 | 改修前 | 改修後 |
|---|---:|---:|
| 受電容量 | 100MW | 100MW |
| PUE | 1.55 | 1.20 |
| IT機器に使える理論上の電力 | 64.5MW | 83.3MW |
| 冷却・その他設備に使う電力 | 35.5MW | 16.7MW |

**受電容量を100MWのまま維持しながら、IT機器に利用可能な理論上の電力を18.8MW、約29%増やせる計算になる。**

これは実際に特定の施設で29%増強したという実測結果ではなく、PUEに基づく理論試算である。

実際には、配電能力、UPS、冗長性、保守時の制約などによって、追加のIT機器を設置できる容量が決まる。

**出典：** [Schneider Electric — How liquid cooling can stretch a capped grid connection](https://blog.se.com/datacenter/2026/10/22/ai-data-centres-in-australia-how-liquid-cooling-can-stretch-a-capped-grid-connection/)

### 5-3. この研究が日本株にとって重要な理由

設備投資の方向は、単純に「チラーをもっと大きくする」だけではない。

既存施設の状況に応じて、次のように分岐する。

| 既存施設の問題 | 技術的な解決方法 | 関連企業 |
|---|---|---|
| 冷気の流れに無駄がある | 気流診断・空調チューニング | 高砂熱学工業 |
| 新しいGPUを収容できない | ハイブリッド冷却・設備改修 | 日比谷総合設備 |
| 施設全体の放熱能力が不足 | 大型チラー・熱源設備の増強 | 三菱電機、ダイキン、パナソニック |
| GPUラックの発熱密度が高い | CDU・直接液冷・冷却配管 | パナソニック、三櫻工業 |
| 施工・液冷設備の保守が難しい | 設置、試運転、漏水点検、運用支援 | 八洲電機 |
| 冷却設備に電力を使いすぎる | AI制御・運転最適化 | ダイキン、高砂熱学工業 |

ここで重要なのは、チラー、CDU、配管、制御システムを必ずすべて交換する必要はないこと。

**既存設備で足りる部分は残し、制約になっている部分だけを増強することが、既存データセンター改修の基本的な経済合理性となる。**

### 工程① 高砂熱学工業（1969）｜既存施設の空調診断・省エネ改修

**市場：東証プライム**

#### 役割

既存データセンターの空調設備やサーバールームの熱環境を診断し、冷気の流れ、空調負荷、運転設定を最適化する。

代表的な技術・サービスは「グリーンエアーIDC」と「IDC-SFLOW」。

#### 具体的な仕事内容

- 既存サーバールームの温度分布や気流を計測する。
- サーモカメラやCFD解析を使い、熱の滞留や冷却の無駄を把握する。
- ホットアイル・コールドアイルの空気の混合を抑える。
- 空調機器の運転設定、風量、給気温度を調整する。
- 必要に応じて設備の更新・リニューアルを設計・施工する。
- 改修後の運用管理・メンテナンスを行う。

#### 既存データセンターとの関連性

同社は「グリーンエアーIDC」について、国内外で140件以上の検証実績があると公表している。

また、サーバーの増設や入れ替えによって空調負荷が変化する既存施設を対象に、運転中の診断・改修まで対応することを明示している。

**既設データセンターの効率化との直接性が非常に高い企業である。**

#### 欧州市場での事業開始

2026年3月4日、パナソニックは欧州で生成AIデータセンター向けの冷却製品について受注受付を開始した。

|---|---:|
| CDU | 400kW |
| CDU | 800kW |
| フリークーリングチラー | 800kW |
| フリークーリングチラー | 1,200kW |
| 大型CDU | 1,200kW以上の開発を推進 |

フリークーリングは、気温が低い時間帯などに外気の冷熱を利用し、冷凍機の圧縮機による電力消費を減らす技術である。

#### 既存施設の増強で重要な理由

従来の空冷設備と、新しく導入する液冷GPUの間には、冷却水の温度、流量、圧力などの違いが存在する。

CDUは、設備側の冷却系統とGPU側の冷却系統の間で熱交換・循環制御を行う。

これにより、ラック単位の高密度化を進めやすくなる。

また、外気温が低い地域ではフリークーリングの活用によって冷却電力を削減できる可能性がある。

#### 海外展開・AIとの関係

## 第10章 既存データセンター増強の3つの投資シナリオ

### シナリオA：新設DCが制約されるが、AI需要は増加し続ける

今回の基本シナリオ。

既存施設の受電容量や建物を活用して、GPUの高密度化、空調設備更新、液冷導入、運用効率改善が進む。

| 発生する需要 | 関連する7社 |
|---|---|
| 既存空調・熱環境の診断 | 高砂熱学工業 |
| 既存施設への液冷改修設計 | 日比谷総合設備 |
| 大型冷却・電力設備の強化 | 三菱電機 |
| 冷却方式の変更・運転最適化 | ダイキン |
| CDU・高効率チラーの追加 | パナソニックHD |
| 液冷配管・継手・マニホールド | 三櫻工業 |
| 設置・試運転・保守 | 八洲電機 |

**このシナリオが成立するための条件**

- AI計算需要が増加を続けること。
- 新設許可や電力接続の制約が解消しないこと。
- 既存施設に改修可能な電力・床・スペースの余地があること。
- 改修費用が新設や移転よりも合理的であること。
- GPU更新が継続すること。

### シナリオB：新設も既存改修も進むが、省エネ投資が重視される

この場合は、新規施設と既存施設の双方で冷却効率改善が進む。

特に注目するのは、高砂熱学工業、三菱電機、ダイキン、パナソニックHD。

冷却装置の性能だけでなく、運転制御、電源損失、冷却水の温度、空気の流れなどを改善することが重要になる。

既存施設改修に限定しなくても、こうした設備・技術は新設AIデータセンターにも利用可能である。

### シナリオC：AI計算需要そのものが失速する

このケースでは、施設の新設だけでなく、GPU更新や大型冷却設備の導入も延期される可能性がある。

一方、電力料金の削減や設備寿命の延長など、短期的な投資回収が見込める省エネ改修は残る可能性がある。

ただし、省エネが必要でも、顧客の投資予算が削減されれば受注が減るリスクはある。

したがって、**設備増強によって利益が伸びる企業と、省エネ・保守によって安定的に利益を得る企業を区別する必要がある。**

## 第13章 最終結論

今回の調査結果から、次の5点が確認できた。

**第一に、既存のデータセンターの効率化は、すでに世界のハイパースケーラーが取り組んでいる技術テーマである。**

Google、Microsoft、Meta、AWS、NVIDIAは、電力・冷却・通信・GPU稼働率を改善する研究や実装を進めている。

**第二に、2026年の米国中間選挙後、既存施設を活用する戦略の重要性が高まる可能性がある。**

Meta幹部による発言、NVIDIAの既存通信施設転用構想、J.P. Morganなどの分析がその根拠になる。

**第三に、既存データセンターの能力増強は、単純な大型設備の追加だけではない。**

省エネ制御による電力余力の創出、液冷化、ラック密度の向上、設備保守、AI処理の運用最適化を組み合わせることが重要になる。

**第四に、日本企業7社は、その改修プロセスの主要な工程をカバーできる。**

高砂熱学工業、日比谷総合設備、三菱電機、ダイキン、パナソニックHD、三櫻工業、八洲電機は、それぞれ異なる工程で必要となる設備や技術を持っている。

ただし、企業ごとに商用化段階、海外の顧客採用、売上規模には大きな違いがある。

**第五に、投資家が最終的に確認すべきなのは、既存施設の改修需要が実際の受注・売上・利益へ転換するかどうかである。**

特に今後は、海外ハイパースケーラーやAIサーバーメーカーからの正式採用、2027年度の新製品商用化、既設DC改修の受注比率が重要になる。

### 総括

**AI需要が伸び続ける一方、新設データセンターの電力・建設・許認可が制約となる場合、電力接続済みの既存施設を最大限活用する投資が、相対的に重要になる可能性は十分にある。**

ただし、既存施設の強化がすべての新設投資を代替するわけではない。

また、技術的な恩恵が大きいことと、株式市場で割安な投資対象であることも別の問題である。

今回選定した7社は、**既存AIデータセンターの冷却・設備効率改善という投資テーマを工程順に説明するための中核銘柄群**として位置づけられる。
