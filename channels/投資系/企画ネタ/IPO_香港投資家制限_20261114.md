# AnthropicのIPOで香港・中国本土の投資家が制限される理由

**調査基準日：2026年11月14日（日本時間）**  
**テーマ：AnthropicのIPOにおける香港・中国本土の機関投資家への株式配分制限と、その安全保障上の背景**

## 結論

2026年11月13日、Bloombergは、Anthropic（アンソロピック）のIPOで、**香港および中国本土に拠点を置く機関投資家の注文が拒否されたり、株式配分が困難だと案内されたりしている**と報じた。複数の引受銀行の実務対応に関する、匿名の関係者情報に基づく報道である。

その背景として、関係者は米国の**国際武器取引規則（ITAR）**など安全保障関連の制約を挙げた。ただし、**ITARが一般のIPO株の購入自体を一律に禁止することが法律上確定している、という報道ではない**。Anthropicの公式目論見書にも、香港・中国本土の投資家を一律に排除する明文の条項は確認されていない。

**重要：IPOでの注文・配分制限と、上場後の市場で株を買うことの恒久的禁止は別問題。**

## 1. 何が報じられたのか

Bloombergの2026年11月13日付報道で確認できる主な内容は以下のとおり。

- 香港・中国本土の機関投資家に対し、複数の銀行がIPO注文を受け付けない、あるいは株式配分の可能性は低いと説明した。
- 一部の関係者は、ITARに関係する制約を理由に挙げた。
- 一方で、銀行や営業担当者が注文を機械的・全面的に遮断しているとまではいえず、**注文の提出可否と最終配分の可否には差がある**。
- 中国のテクノロジー企業創業者に関連するファミリーオフィスが、英領バージン諸島（BVI）の信託を通じた参加を試みていると報道された。配分を受けられるかは未確定。
- 特別目的会社（SPV）やスワップ取引を検討する投資家もいるとされる。ただし、これらが規制を合法的に回避できると保証されたわけではない。
- 香港からロードショー資料の閲覧は可能だった一方、香港の個人投資家向け公募を取り扱う現地ブローカーは公式の取扱先に含まれていなかった。
- Anthropicおよび主幹事のGoldman Sachs、Morgan Stanleyは、この報道について詳細な説明を行っていない。

**出典：** [Bloomberg原報道（2026年11月13日）](https://news.bloomberglaw.com/artificial-intelligence/anthropic-ipo-share-orders-from-china-are-said-to-be-rebuffed) ／ [Bloomberg記事の配信全文（Advisor Perspectives）](https://api.advisorperspectives.com/articles/2026/11/13/anthropic-ipo-share-orders-china-rebuffed)

## 3. なぜ香港の投資家も対象になるのか

### 3-1. 香港はITAR上、中国本土と同様の扱いを受ける

米国政府は2020年7月、武器輸出管理法（AECA）とITARの運用上、香港を中国本土と同様に扱う方針を示した。米国務省によれば、中国による香港の自治への介入を受け、米国の機微な防衛関連技術が中国本土へ転用されるリスクを警戒した措置である。

そのため、**香港を経由すれば中国本土と異なる安全保障上の扱いを受けられるとは限らない**。今回のIPOで引受銀行が香港投資家にも慎重になった背景として整合的である。

ただし、**防衛技術の移転を規制するITARと、一般の株式取得の可否は同じ問題ではない**。『ITARがあるから香港の投資家は米国上場株を一切買えない』という理解は誤り。

**米国政府資料：** [米国務省による香港向け防衛装備輸出停止声明（2020年6月29日）](https://2017-2021.state.gov/u-s-government-ending-controlled-defense-exports-to-hong-kong/)

### 3-2. Anthropic自身が中国系企業による先端AI利用を警戒

Anthropicは2025年9月4日、サービスを提供していない地域の企業が、海外子会社経由で同社AIを利用することへの制限を強化すると発表した。中国のような地域の企業に50%超を直接・間接に保有される法人などを対象としている。

公式に示された懸念は次のとおり。

- 中国側の法的枠組みによるデータ提供や情報機関への協力の要求
- 軍事・情報活動への先端AIの転用
- AIモデルの出力を利用した競合モデルの能力向上（蒸留）
- 海外子会社を使った提供地域制限の迂回

これらは**Anthropicの製品利用制限の理由**であって、IPO参加制限について同社が公式に説明した理由ではない。両者を直接同一視することはできない。

**一次資料：** [Anthropic公式「Updating restrictions of sales to unsupported regions」（2025年9月4日）](https://www.anthropic.com/news/updating-restrictions-of-sales-to-unsupported-regions)

### 3-3. 米中AI覇権競争と安全保障審査の強化

AnthropicのSEC提出目論見書は、米国の輸出規制、政府によるAI企業と中国政府系主体との関係への監視、米中対立の激化などを事業リスクとして説明している。また、AI製品が一定の場合にはITARの対象となり得る旨を記している。

これは米中関係の緊張が事業・資本市場に影響し得ることを示す一次資料だが、**この開示自体は香港投資家のIPO申込みを法的に禁止する根拠ではない**。

**一次資料：** [Anthropic SEC目論見書「Risk Factors」](https://www.sec.gov/Archives/edgar/data/2130357/000162828026072484/anthropicpbc-sx1ax2.htm)

## 4. SpaceXのIPOでも類似例が報じられた

Bloombergによると、2026年6月のSpaceXのIPOでも、中国本土・香港の投資家からの注文を受け付けないよう引受側に伝えられていた。ITARが理由として挙がったという。

一方、**SpaceX株は上場後に中国本土・香港の投資家も取得できた**と報じられている。

したがって、Anthropicについても次の二つを混同してはいけない。

1. **IPOのブックビルディングに参加し、引受銀行から株式配分を受ける権利**
2. **上場後、取引所で市場に出ている株式を買うこと**

現状の問題は主として **1** である。Anthropic株について **2** が将来どう扱われるかは、上場前の時点では未確定。

**出典：** [Bloomberg（2026年11月13日）](https://news.bloomberglaw.com/artificial-intelligence/anthropic-ipo-share-orders-from-china-are-said-to-be-rebuffed)

## 5. 機関投資家目線の分析

今回の出来事は、**先端AIを単なる民間の成長産業ではなく、国家安全保障上の戦略産業として扱う流れ**を象徴している。

ただし、次の線引きは重要である。

| 内容 | 判断 |
|---|---|
| 中国本土・香港の機関投資家のIPO参加が難しくなっている | **Bloomberg報道で確認** |
| ITARが引受銀行側の判断理由の一つとされる | **関係者証言として報道** |
| 米国のITAR規制で香港が中国本土と同様の扱いを受ける | **米国政府の公式資料で確認** |
| Anthropicが中国系法人のAIサービス利用を制限している | **Anthropic公式発表で確認** |
| AnthropicがIPOの香港投資家排除を正式発表した | **確認できず** |
| ITARが香港投資家による株式取得自体を一律禁止している | **確認できず** |
| 香港の投資家が上場後も永久にAnthropic株を買えない | **確認できず** |

### 投資上の注目点

- **配分の偏り：** 特定地域の機関資金が参加しづらければ、IPOの引受・配分先は米国や同盟国の投資家に偏る可能性がある。
- **上場直後の需給：** 香港・中国本土の投資家が上場後に買える場合、IPO時に満たされなかった需要が市場に回る可能性もある。ただし実際の買付規模は不明。
- **政策リスク：** AIモデルの輸出・利用制限だけでなく、資本調達にも地政学的な審査や銀行独自のコンプライアンス判断が影響し得る。
- **重要な留保：** 少数株式を保有するだけで機密技術を取得できるわけではない。資本参加制限をすべて『技術流出防止に直結する』と説明するのは過大な一般化である。

## 6. まとめ

AnthropicのIPOでは、**香港・中国本土の機関投資家が事実上参加しにくい状況が生じている**。報道上、主な背景は米国の安全保障上の警戒と、ITARへのコンプライアンス対応である。

一方、**Anthropicが公式に香港投資家を全面排除したとの発表は確認されておらず、上場後の株式売買まで恒久的に禁止されたわけでもない**。Bloombergの匿名関係者報道、SEC目論見書、米国政府のITAR関連資料、Anthropicの製品利用規制の声明を分けて読む必要がある。
