# 1. 大日本印刷（DNP・7912）

結論からいうと、DNPを「光電融合関連」と見る根拠はかなりあります。ただし、現時点では**光電融合が業績の主役というより、半導体後工程・先端パッケージ分野で将来の成長柱として育成している段階**です。

特に、

- **超微細パターニングを大面積パネルへ展開できる**
- **TGVガラスコア → Advanced Packaging**
- **TNOとのCPO共同研究**
- **将来的に電子配線と光回路を統合する**

というストーリーはかなり筋が通っています。

ただし、最後の「電子RDL＋光RDL」はDNP自身がその言葉で商用化を発表しているわけではないため、**公開情報から導ける技術ロードマップ上の推論**として扱うのが正確です。

## 1-16. CPOとは何をしようとしているのか

現在のAIサーバーでは、

- GPU ↔ GPU
- GPU ↔ メモリ
- GPU ↔ スイッチ

など大量のデータを電気信号でやり取りします。

しかし高速になるほど、

- 消費電力
- 発熱
- 信号損失

が問題になります。

そこで光通信部分をチップの近くまで持っていく。

これがCPO、

**Co-Packaged Optics**

です。

DNP自身も、

> 電気ベースの高速伝送では情報量拡大に対応しきれなくなる可能性がある

として、光通信技術と電子技術を統合するCPOを研究しています。

## 1-18. なぜ「大面積」が重要なのか

AI半導体は、

- GPU
- HBM
- I/Oチップ
- CPU
- アクセラレータ

など複数のチップを一つのパッケージにまとめる方向に進んでいます。

つまり、

**パッケージそのものが巨大化する。**

従来の有機基板では巨大になるにつれて、

- 反り
- 平坦性
- 微細配線

が難しくなります。

ガラスは平坦で剛性が高いので、

**巨大なAIチップレットパッケージ**

との相性が良い。

DNP自身も生成AIとチップレット普及によるパッケージ大型化を、ガラスコア開発の理由として挙げています。

**2μmピッチのSemi-Additive Processを用いた、大型パネル型RDLインターポーザ**

**大面積パネル

**「DNPが電子RDLと光RDLを一体化した製品をすでに量産している」**

# 4. 3社の光電融合ポジション比較

| 企業 | 主な強み | CPOで狙う場所 | 現在の進捗 |
|---|---|---|---|
| **DNP** | 大面積・超微細パターニング、RDL、TGVガラスコア | パッケージ基盤、電気回路＋光回路統合 | TGVサンプル供給、TNOとCPO共同研究 |
| **AGC** | ガラス、TGV、ポリマー/ガラス光導波路、マイクロレンズ | 光配線、ガラス基板、光結合部品 | サンプル提供・顧客引き合い、2028～29年初期採用想定 |
| **三菱電機** | EML、InP化合物半導体、CW光源、光変調器 | 光を発生・変調するアクティブ光デバイス | 既存EML事業が成長、2028～30年CPO技術確立目標 |

3社は同じ「光電融合関連」でも役割が異なります。

- **DNP**：CPOを載せる「パッケージ・微細配線」の側
- **AGC**：CPO内部の「光配線・ガラス・光学部品」の側
- **三菱電機**：CPOの「光源・変調器」の側

したがって競合というより、将来のCPOサプライチェーンで**別レイヤーを担う可能性がある3社**として見るのが分かりやすいです。
