# 1. 調査全体の目的、重要な検証軸、用語の区別

## 1.1 調査した問い

- AIは日本の新薬開発を何年・何%速めるのか。候補探索、前臨床、治験、承認、医療提供で区分し、開発費、成功率、上市件数への影響も測る。
- 認知症・アルツハイマー病、乳がん・肺がん・膵臓がん・大腸がん・肝がん、ALS、パーキンソン病、心不全、糖尿病・肥満症、慢性腎臓病、薬剤耐性菌など、生活に近い疾患で何が変わるのか。
- AIが「病気の原因を発見した」と言える証拠水準は何か。遺伝子候補の統計的抽出、細胞実験、動物実験、人体での治療効果を区別する。
- 日本の固有または相対的な強みは、長期医療・ゲノムデータ、iPS細胞・オルガノイド、精密計測、研究用ロボット、製薬会社の実験データ、富岳・Tokyo-1等の計算基盤のどこにあるか。
- 内閣府・文部科学省・厚生労働省・経済産業省・AMED・デジタル庁が何を支援し、予算と成果はどこまで確認できるか。
- NVIDIA・Microsoft・Google/Alphabet・AWS・Meta・海外製薬大手・欧米政府が日本の強みをどう評価し、どのような投資、共同研究、契約、研究拠点、政策協力で裏付けているか。
- 日本および世界の医療・介護・労働市場・GDPにいくらの便益が生じるか。予防、重症化抑制、医療費、介護費、家族介護、就労、創薬費用を重複計上せず評価する。
- 東証プライム・スタンダード・グロースを通じて、製薬、画像診断、検査、データ、創薬支援、フィジカルAI、細胞製造、情報システム関連株へ収益がどう流れるか。

## 1.2 AIによる効果を区別する

| 技術・工程 | 実際の意味 | 誤認しやすい点 |
|---|---|---|
| AIによる治療標的探索 | 遺伝子・タンパク質・生物学的経路の候補を絞り込む | 相関の検出だけで発症原因を確定したわけではない |
| AIによる分子設計 | 候補化合物・抗体・ペプチド・ワクチン抗原の設計 | 設計できても人間で有効とは限らない |
| 薬効・毒性予測 | 実験前に候補を選別する | 予測性能と臨床成功率は違う |
| 治験AI・医療データ | 患者照合、施設選定、文書作成、進行予測を補助 | 個別作業の短縮率を治験全体に外挿できない |
| 診断AI | 画像、心電図、健診、認知機能検査などの解析 | AUCと正解率、死亡率改善は違う |
| 研究用ロボット・自動培養 | 実験・測定・細胞培養を省力化・標準化する | 高度な自動制御と自律的な生成AIは同義ではない |
| 医薬品承認 | 規制当局が対象、適応、条件を指定して承認する | 条件・期限付き承認は恒久的な有効性の最終証明ではない |

**医学的証拠の4段階**：(1) AIが原因候補・リスクを予測、(2) 細胞やヒト由来試料で機能を検証、(3) 動物実験で病態への影響を確認、(4) 患者を対象とする試験で治療効果・安全性を確認。さらに承認・診療普及・死亡率や入院率の改善を別途確認する。

**投資上の区別**：国策への採択 ≠ 企業の受注、契約最大額 ≠ 確定売上、研究助成 ≠ 株式出資、株式出資 ≠ 長期保有確約、実験での薬理活性 ≠ 患者の治癒、医療費削減 ≠ GDP増加、学術成果 ≠ EPSの改善。

# 2. AI創薬は何倍速くなるのか――国内外の定量実績と反証

## 2.1 新薬開発全体の所要期間と成功率

通常の創薬は候補探索から承認まで一般に**約10〜15年**を要する。アステラス製薬は自社の研究開発資料で通常**約9〜16年**を説明している。AIで大幅に変わりつつあるのは、特に初期の標的探索・化合物設計・実験条件探索であり、人間での安全性・有効性確認を一律に省略できるわけではない。

2026年の学術集計では、AIを活用した治療候補**129件**がヒト臨床試験に到達しており、対象企業は**69社**。うち**5件**が第3相試験に到達または完了したと報告された。候補のうち**74件**ががん領域だった。対象の定義によって件数は変わる。

| AI創薬候補の段階別指標 | 公表値・注意 |
|---|---|
| 2024年の初期研究 | 第1相成功率80〜90%、第2相約40%と報告。ただし標本数が小さい |
| 2026年の129候補の分析 | 第1相成功率**77.8%**、第2相**19.5%** |
| 2026年分析の第3相到達・完了 | **5候補** |
| 解釈 | 各相の観察成功率であって、最終承認率、病気の治癒確率ではない |

2026年の『Nature Reviews Drug Discovery』では、AIが臨床的に重要な新薬承認や治療上の飛躍を増やしたかについて、十分な長期的証拠がまだないという整理も示された。製薬会社にとっては、失敗候補を早期に除外し、研究費を有望候補へ集中できるかが大きな論点となる。

## 2.2 アステラス製薬――異なる二つの工程での大幅短縮

**事例A：Human-in-the-Loopによる化合物最適化（統合報告書2025 p.60-61）**

- 2019年からAIとロボットを組み合わせた創薬基盤を開発・導入。
- AIが約**6万種類**の新しい分子構造を設計し、候補を選び、ロボットで合成・評価、結果をAIへ戻す。
- 化合物の最適化に要する期間を従来平均**24か月**から**7か月**へ短縮した実例。短縮率約**70.8%**、速度は約**3.4倍**。
- 最適化した候補の薬理活性が出発化合物比で**約10倍**に改善したとの説明。これは患者の治療効果が10倍という意味ではない。
- 比較は従来の平均と特定のプロジェクトの実績であり、業界全体の平均や無作為化比較試験ではない。

**事例B：NVIDIA Boltz-2 NIMを使う膜タンパク質のヒット探索**

- 従来約**3.5か月**を見込んだ仮説立案からヒット化合物発見までの工程を**1か月未満**へ短縮。
- 必要な実験評価数を**約90%以上削減**。
- AIで選んだ**10種類**の候補すべてで目的とする活性を実験確認。
- 初期ヒット探索に関する事例で、事例Aの最適化期間と異なる工程。二つの短縮率は足せない。

アステラスはBioNeMo、Boltz-2、Microsoft Researchの**BioEmu**を利用。BioEmuではタンパク質構造の変化や多数の変異を評価する。2026年2月末時点で社内AIアプリの通常利用者は**50人超**、累計利用者は**2,000人超**と説明している。

## 2.3 海外Insilico Medicine――候補発見から第3相へ

- AIによる特発性肺線維症の候補薬**rentosertib**を開発。
- 標的特定から前臨床候補の選定まで**約18か月**。従来比較基準**4.5〜6年**との比較で約**70%短縮**と同社は説明。
- 合成・評価した化合物は**78種類**。
- 2025年『Nature Medicine』掲載の第2a相試験は**71人**、12週間の努力肺活量変化が高用量群**+98.4mL**、プラセボ群**−20.3mL**。
- 第2a相は安全性の検証が中心。副作用として肝機能への影響や下痢等への注意が必要。長期肺機能・死亡率の改善は未確定。
- 2026年9月10日、中国で第3相試験の最初の患者への投与を公表。**52週間**の安全性・有効性を検証する計画。第3相開始は成功の証明ではない。
- 同社は香港上場（**3696**）で、米国・中国に事業基盤を持つ国際的な企業。

## 2.4 治験・臨床開発の実例と相反する結果

2026年1月26日のロイター報道で紹介された事例：

- **Novartis**：約**1万4,000人規模**の心疾患治験の施設選定作業が、従来**4〜6週間**の作業から約**2時間の会議**で済んだ事例。これは施設選定という個別業務。
- **GSK**：後期の喘息治験で約**800万ポンド**の費用削減を報告し、治験の**15%高速化**を目指す。
- **McKinsey**：自律型AIにより今後5年で臨床開発の生産性が**35〜45%**改善する可能性を試算。将来の予測であり確定成果ではない。
- **2026年医学研究の反証**：肺がん・大腸がん患者**355人**の記録を用いた治験適格性判定で、AI支援により正確性が**71.1%→76.5%**に改善したが、1件当たりの確認時間はほとんど変わらなかった。AI導入で必ず時間短縮するわけではない。

2026年8月の『Nature Reviews Drug Discovery』等では、人体における薬物動態・有効性を正確に予測する課題が残ると指摘されている。

## 2.5 製薬会社の文書・事務作業の改善

**塩野義製薬×日立製作所**：2026年2月24日、生成AIによる医薬品開発の規制関連文書作成支援サービスを発表。塩野義の技術を日立へライセンスし、日立が国内企業へ提供。対象文書の作成作業が**最大50%短縮**。新薬の全開発期間を50%短くしたという意味ではない。

**JMDCグループ×倉敷中央病院**：2026年9月10日発表。治験電子ワークシートの利用で、併用薬の記入時間は**2.79分/セル→0.90分/セル**、医師署名完了までの中央値は**1.8日→0.7日**。主に電子カルテ連携・デジタル化の効果であり生成AI単独の結果ではない。

## 2.6 全開発期間への短縮率を誤って外挿しない

説明用のモデル：新薬開発**12年間**＝探索・前臨床**3年**＋臨床**7年**＋承認関連**2年**と仮定する。このうち探索・前臨床全体が70%短縮し、他工程は変わらないとすると、**12年→9.9年**、**2.1年短縮**、全体短縮率**17.5%**となる。

これは特定のAI導入で実測した開発期間ではない。初期工程の一部での70%短縮を前臨床全体に適用する仮定自体、厳密な実績とは異なる。臨床試験の短縮や成功率改善がなければ、全体の短縮には限界がある。

同様に、文部科学省のAI for Science戦略が掲げる**研究開発期間の将来的な10分の1**は野心的な政策目標であり、「新薬承認が10分の1の期間で可能になった」という事実ではない。

# 3. 日本政府の国家戦略、予算、国策プロジェクト

## 3.1 2026年7月の国家戦略

2026年7月14日に閣議決定された**「統合イノベーション戦略2026」**では、17重要技術分野のうち**AI・先端ロボット**と**バイオ・ヘルスケア**を、6つの国家戦略技術領域に位置付けた。医療・創薬・介護分野でのAI基盤モデル、安全な研究用計算資源、実験自動化・創薬自律ラボ、データ標準化、研究人材育成、事業化・国際展開を促進する方向が明示されている。

| 政府が示した時期 | 主要な方向性・目標 | 注意点 |
|---|---|---|
| 2028年度 | 国際水準の治験実施体制を整備 | 目標であり全施設の達成ではない |
| 2028年度 | 対象となる200床以上の病院で電子カルテ普及率100%を目標 | 対象条件付き |
| 2029年度 | 創薬AI基盤の構築・高度化を目標 | 成果の実証は別途必要 |
| 2030年末 | 地域の拠点病院でのサイバーセキュリティ対策100%を目標 | 対象定義に注意 |
| 2026〜2030年度 | 第7期科学技術・イノベーション基本計画期間 | 政府研究開発投資60兆円、官民合わせ180兆円の目標は科学技術全体であり医療AI専用ではない |

同戦略は、日本の製薬産業の品質管理や供給信頼性を強みとしつつ、治療機器の国際競争力低下・輸入超過、研究成果の事業化や国際展開の遅れにも触れる。日本の政策仮説は「既存の研究基盤・データ・製造技術をAIで活用し、創薬や医療の産業競争力につなげる」ことである。

2026年7月21日の**骨太方針**、7月14日の**統合イノベーション戦略**、**AMEDの医療研究開発方針**、2026年3月31日の文科省**「AI for Scienceの推進に向けた基本的な戦略方針」**を参照した。AI for Scienceは重要技術領域の研究開発期間を長期的に10分の1にする野心的方向性を示しており、仮想細胞・仮想臓器、生命科学基盤モデル、ロボット実験・自律研究室、スパコン、高品質データ基盤を重視している。

## 3.3 DAIIA・DAIIA-X：産業横断のAI創薬プラットフォーム

**先行DAIIA**は、日本の複数製薬企業が機密の研究データを社外へ流出させずAIモデルを共同学習する**連合学習**を構築。製薬企業**17社**が事業全体に関与し、商用化されたモデルの学習データには**16社**分を用いたという発表がある。発表・集計範囲により対象企業数の数字を混同しない。

# 4. 日本の医学・研究資産と国際競争力、データ利用上の制約

## 4.1 日本の強みとして検証した6分野

1. **iPS細胞・オルガノイド**：患者由来の細胞や組織モデルで疾患を再現し、AIが予測した遺伝子・化合物の作用を実験で確認する。再生・細胞医療を製造まで進める能力にもつながる。
2. **ゲノム・医療・長期追跡データ**：東北メディカル・メガバンク（約**15万人**規模の健康調査研究基盤）、バイオバンク・ジャパン、ナショナルセンター・バイオバンクネットワーク、国立長寿医療研究センター、日本人・東アジア人に特徴的な遺伝的背景など。
3. **医療用画像・精密計測**：内視鏡、MRI、CT、顕微鏡、病理、細胞の3次元画像、光学センサー、臨床検査での蓄積。関連企業として富士フイルム、オリンパス、キヤノン、シスメックス、浜松ホトニクス等。
4. **超高齢社会での研究・実装環境**：認知症、フレイル、心不全、腎機能低下、多疾患併存、介護・生活機能の長期データと医療政策の需要。高齢化は日本の社会的負担でもあり研究市場でもある。
5. **計算基盤・高性能ネットワーク**：富岳、富岳NEXT、HPCI、SINET、Tokyo-1、大学・研究機関の計算設備。汎用言語モデルの学習と、分子シミュレーション・細胞解析では必要な計算特性が異なる。
6. **製薬大手の長年の実験・化合物データ**：アステラス、第一三共、中外、武田、小野薬品、エーザイ等。DAIIAの連合学習が企業間で非公開データを生かす可能性を示した。

日本の強みは「世界最大の汎用AIモデルを自社開発すること」だけでなく、**高品質な医学データ＋人間由来細胞の実験＋精密な測定＋自律実験**を結び付け、AI予測を再現可能な医学的知見へ変えられるかにある、という調査仮説を設定した。

## 4.2 英米データ基盤との国際比較で重視する指標

英国の**UK Biobank**、米国の**All of Us**、フィンランドの**FinnGen**等に対して、単なるサンプル数ではなく、追跡年数、死亡・介護データの結合可能性、ゲノム・病理・画像の質、研究者の利用権限、データ持ち出し制限、集団ごとのバイアス、患者プライバシーの管理、海外の研究者との連携可能性で比較する必要がある。

日本の**NDB**（匿名医療保険等情報データベース）について、2026年厚労省資料ではレセプト情報約**307億9,800万件**が収載と報告された。**レセプト件数は患者数ではなく、治療効果を直接示すものでもない。**

AMEDの**CANNDs**は東北メディカル・メガバンク、バイオバンク・ジャパン、ナショナルセンター・バイオバンクネットワーク等のゲノムデータを横断的に検索・解析する構想。調査時点の2026年8月公式案内では、個人単位詳細データや連携拠点計算システムの**新規利用申請受付が停止**され、メタデータ検索等は可能との説明があった。これは高品質なデータの保有とAI研究への実際のアクセスが別であることを示す。

日本のデータ資産が国際的な競争優位になるには、電子カルテ・ゲノム・画像・検査・処方・予後・介護データを適法に結合し、研究者が一定の安全管理下で利用できる必要がある。

## 4.3 日本の課題・反証仮説

- 文科省のAI for Science戦略自身が研究データの分散、AI・計算科学・実験科学の人材分断、計算資源・ネットワーク・信頼性評価の不足を認める。
- McKinseyの2026年9月分析では、日本は革新的医薬品の世界パイプラインの**約12%**を占める一方、**2021年以降の初期段階研究開発の成長はほぼ横ばい**と指摘。基礎研究・技術を持っていても商業化が弱いという反証。
- 旧WHO関連の日本研究（2017〜2019年の評価）は、医療データの整備に対して政策・研究での活用が限定的だったと指摘。旧い評価であり2026年の現状そのものではない。
- 東京の創薬エコシステム都市ランキングは**19位**との政府報告。研究室の強みがスタートアップ、資本、人材、国際治験、製造・販売に十分つながっているかは別問題。
- 日本発の医学的IPが海外企業の開発・販売網で成功しても、利益が日本のどの企業に残るかは契約次第。出資、知的財産権、マイルストーン、ロイヤルティと営業利益の帰属を確認する。

# 5. 海外企業・政府が日本をどう評価しているか

海外の発言は、**日本への直接の株式投資・研究施設投資・ライセンス契約・技術協業・市場向けの提供サービス・政策協定**のどれに当たるかを区別する。

## 5.1 NVIDIA：日本の製薬・精密研究基盤を評価

NVIDIAは2026年7〜8月の公式発表で、日本の医療技術・バイオ医薬品企業の国際的な信頼、AIによる新世代の創薬を評価し、**三井物産子会社ゼウレカ（Xeureka）のTokyo-1**を紹介。

参加・利用の公表例：アステラス（BioNeMo、Boltz-2による抗体・膜タンパク質解析、前述の工程短縮）、第一三共（大規模仮想化合物探索）、小野薬品（Boltz-2を使う分子設計や探索）、エーザイ（**2026年4月**にTokyo-1へ参加）。

NVIDIA側の事業動機：GPUの計算需要を生命科学へ広げ、創薬モデルやBioNeMoなどソフトウェアを利用してもらうこと。日本の大手製薬会社は研究費と実験データを持つ顧客・共同研究者である。ただし**NVIDIAがこれらの上場製薬企業へ株式出資したと確認したものではない**。

## 5.2 Microsoft：日本の科学データに価値、計算能力に不足

**2026年4月3日**、MicrosoftのBrad Smith社長は、2026〜2029年に日本のAI・サイバーセキュリティ・人材育成等へ**100億ドル**を投じる方針を表明。これは日本のAI基盤全般であり医療専用ではない。日本の医療、材料、製造、エネルギー、環境などに世界的に貴重な科学データがあると評価すると同時に、それを活用する計算能力やAI研究インフラが不足すると指摘。

- 日本の研究者向け**100万ドル**の研究助成プログラムも発表。医薬品専用ではない。
- 2023年12月、国立国際医療研究センターとの電子カルテ・ゲノム解析等に関する研究連携協定。
- アステラスはMicrosoft Researchの**BioEmu**をタンパク質構造・変異評価に利用。
- 2026年6月2日、Microsoftと米Mayo Clinicは医療向けAIモデルの共同開発を発表。臨床データと長期治療経過を使う。
- 2026年10月22日のMicrosoft AI研究発表では診断AI**MAI-DxO**が難しい医学症例で**83%**（医師比較**22〜36%**）、救急症例データで**80%**（医師**47%**）と報告。ただし管理された特定の比較条件であり、実診療一般でAIが医師を上回ると断定できない。

Microsoftは日本の研究資産とクラウド・AIの結合に事業機会を見いだす。公表の100億ドル全額を日本の医療への投資と数えない。

## 5.3 Novartis：日本を米中独と並ぶ戦略的優先地域に

スイスのNovartisは**2025年3月17日**、日本の「クリニカル トランスレーショナルリサーチ ハブ」を設置し、約**50人**を増員する計画を発表。バイオメディカル研究責任者Fiona Marshall氏は、日本を**米国、中国、ドイツと並ぶ戦略的優先地域**と説明。

対象は循環器・腎臓・代謝、免疫、中枢神経、がん。First-in-Human、第1・2相を含む早期臨床研究を強化する。Novartisは自社の国内臨床試験の約**90%**が国際共同試験であり、自社製品の約**90%**を海外開発との時間差を抑えて日本の患者へ届けていると説明。Novartis一社の比率であり日本全体の平均ではない。**日本の臨床研究・病院・患者アクセスへの投資で、AI専用投資ではない**。

## 5.4 Google：日本の乳がん検診データでAIの適用性を検証

Googleとがん研究会有明病院は**2021年**に共同研究開始、**2024年6月19日**に成果を発表。2007〜2020年の日本人女性のマンモグラフィ画像を使い、米英で開発したAIの国内適用性を検証。

- AIと医師の組み合わせで乳がん検出精度が従来の読影体制比**7.6%改善**という研究結果。
- 医師の追加読影を**71%削減**できるという研究上のシミュレーション結果。
- 医師間の判定一致度（κ係数）が平均**0.65→0.74**。
- 後ろ向き・シミュレーション研究であり、全国検診で同じ省力化が実現した実績ではない。

意義：国際的な画像AIは患者集団、検査装置、乳房構成、読影慣行で性能が変わる。日本の高品質な画像・診断結果データはモデルの検証・改善に価値を持つ。

## 5.5 Roche×中外製薬：日本発の抗体技術が国際収益へ

スイスのRocheと中外製薬は**2002年から資本・事業提携**。Rocheは中外の独自の抗体エンジニアリング技術や日本の医薬品研究能力を評価。中外発の薬をRocheグループの国際開発・販売網へつなげる仕組みを持つ。

- 中外はAIによる創薬標的探索、分子設計、薬物動態・病理画像の分析、研究・業務効率化に取り組む。
- Rocheは**2026年3月16日**、NVIDIAを利用する大規模**AI Factory**を公表。AI予測と実験を往復する**Lab-in-the-Loop**を強化する。
- RocheのAI FactoryはRocheグループの投資であり、中外専用施設とは言えない。導入効果・収益の帰属は別途確認が必要。

## 5.6 AstraZeneca×第一三共：日本の既存創薬技術への巨額ライセンス

**2019年3月28日**、英国AstraZenecaは第一三共のADC（抗体薬物複合体）「エンハーツ」について国際共同開発・販売契約を締結。

- これは日本のADC・抗体・化学研究力を評価した投資の根拠。**エンハーツがAIによって発明されたわけではない**。

## 5.7 Amazon AWS：ゲノム解析・データ保管の実務基盤

**2026年7月20〜27日**、AWSは**AWS HealthOmics**のプライベートワークフローを東京リージョンで利用可能にすると発表。国内データ保存・ゲノム解析の要件への対応を進める。エーザイは**2023年から**HealthOmicsの利用検証を実施し、ゲノム・その他の生体データの統合が治療標的探索に重要だと説明。

## 7.2 ALS：理研×京大iPS×阪大――未知の病態関連分子

**2026年7月3日発表**、理化学研究所、京都大学iPS細胞研究所、大阪大学の研究。原著論文は『Biology Methods and Protocols』掲載。

- ALS患者**233人**と健常者**508人**、合計**741人**の血液中の遺伝子発現を機械学習で解析。
- ALSとの関連が従来知られていなかった**PRKAR1A、QPCT、TMEM71**を候補として抽出。
- 3遺伝子の組み合わせによるALS識別の平均**AUC=0.83**。AUCは「83%の患者が確実に正しく診断された」という意味ではない。
- これらの遺伝子の機能を低下させると、ALSに関係する**TDP-43**タンパク質が増加。
- とりわけPRKAR1Aの低下では、TDP-43の細胞内での異常な局在が誘導された。
- AIで抽出した候補を細胞実験・患者由来iPS細胞研究によって検証したことが重要。
- ただしこれらがALSの発症原因の全てである証明ではなく、治療薬も未完成。

別のALS研究：**2026年9月**、東北大学・京都大学等が化合物**MA-5**についてALSモデルショウジョウバエで運動改善、患者由来iPS細胞の運動神経でミトコンドリア機能改善を報告。SOD1変異、FUS変異、孤発性ALS由来細胞でも作用のシグナル。これはAIが発見した化合物と説明されていない。日本の患者由来細胞モデルの研究基盤として重要。

## 7.4 がん診断：国内・海外のAI研究

### 乳がんマンモグラフィ

- スウェーデンの**MASAI試験**（2026年1月『The Lancet』）は約**10万6,000人**を対象。検診感度は従来**73.8%**、AI支援**80.5%**（**+6.7ポイント**）、特異度は両群**98.5%**。検診間に見つかるがんもAI群で少ない傾向。死亡率低下までは試験単独で証明されていない。
- Google×がん研有明病院の国内画像研究は前章記載の通り、検出性能の改善**7.6%**、追加読影**71%削減**のシミュレーション。MASAI試験とデザイン・比較対象・指標が違うため合算しない。

### 大腸がん・内視鏡

- **2026年8月**公表の日本の多施設ランダム化比較試験（解析**606人**）で、右側大腸の腺腫発見率が標準群**27.9%**、AI支援・追加観察群**36.4%**（+8.5ポイント）。AI支援と再観察の両方を行っているためAI単独の寄与は区別できない。
- **2025年**公表の神戸市立医療センター中央市民病院等、約**1,000人**のランダム化試験では、通常**54.5%**、AI支援**50.7%**で有意な改善なし。観察時間が長くなる傾向も示された。もともと医師の検出率が高い施設では追加利益が小さい可能性。
- 国立がん研究センター主導、日本を含むアジアの約**1,400人規模**の国際共同試験も進められ、2026年5月の登録情報では募集終了。最終結果の検証が必要。

### 脳腫瘍（神経膠腫のIDH変異）

**2026年7月15日**、国立がん研究センター・理化学研究所等。MRI画像からIDH遺伝子変異を予測するAIを開発し、**18人の医師**と比較。

- 海外患者画像でのAUC**0.97**。
- 日本人患者画像でのAUC**0.82**に低下。
- 日本人データでは熟練医師の一部が**AUC0.88**。
- AI性能は国・患者集団・医療機関・装置条件で変わり、国内データによる検証・再学習が必要。
- 予測AIは実際の遺伝子検査をただちに不要にするものではない。

### 肝がん：MYCN/AKTの発がん機構とAIによる組織評価

**2026年2月18〜24日公表**、理化学研究所・千葉県がんセンター・岐阜大学等（『PNAS』）。

- マウスで**MYCNとAKT**を同時に活性化したところ**50日以内に72%**で肝腫瘍を形成。片方だけでは明らかな腫瘍形成がなかった。
- がんが発生しやすい周辺組織の遺伝子発現を分析し、**167遺伝子**からなる特徴的な「MYCN niche」を抽出。
- 機械学習でこの状態を捉えるスコアを開発し、研究上の分類精度は**93%**との説明。患者の非腫瘍組織でもスコアと再発リスクに関連があった。
- 因果的な遺伝子の作用は実験により示され、AIは組織状態の抽出・分類・リスク評価に寄与。AIがゼロから二つの原因遺伝子を発明したという研究ではない。
- 患者に対する予防・治療効果は未確定。

# 9. 日本のフィジカルAI・計測・細胞製造関連銘柄

## 9.1 フィジカルAIが創薬を変える工程

**Design（AIが分子や実験条件を提案）→Make（ロボットが合成・分注・培養）→Test（分析装置が薬効・毒性・品質を評価）→Analyze（データをAIへ戻して候補改良）**の反復。

創薬では微量液体・生細胞・温度・湿度・汚染防止・実験履歴・再現性・GMP等の要求がある。したがってロボット本体だけでなく、センサー、分析機器、前処理、培地、制御ソフト、データ統合・保守・消耗品に市場機会がある。一般的な工場ロボットの自動運転と、創薬研究の完全自律化を混同しない。

## 9.2 安川電機（6506）：アステラスとの細胞製造合弁

- バイオメディカル用双腕ロボット**「まほろ（Maholo）」**。

# 11. 日本・世界の医療改善とAI導入による経済効果

## 11.1 経済効果の種類を厳密に分ける

1. **医学的便益**：死亡・病気・障害の回避、健康寿命・QALYの増加。
2. **直接医療・介護費の増減**：入院や重症化を回避する一方、長寿化と高価な新薬で支出が増えることもある。
3. **家族介護・間接費用**：休業・離職・介護時間・生産性低下の削減。
4. **GDP・労働供給**：健康な就労期間の延伸、生産性・労働参加率の改善。
5. **企業利益**：新薬売上、診断薬・装置・ソフトの販売、研究開発費削減、ライセンス。

医療費、疾病の社会的費用、就労損失、GDP効果は範囲が重なる場合がある。**研究ごとに年、基準通貨、割引、現在価値、年額・累計、対象集団、反実仮想を確認する**。以下の数字は原則として足し算しない。

## 11.2 世界の健康改善：McKinseyの2040年GDP試算

**McKinsey Global Institute、2020年『Prioritizing health: A prescription for prosperity』**は、既存の予防策や医療技術の普及、将来の技術による健康改善で、**2040年の世界GDPが基準ケースより約8%、年間12兆ドル大きくなり得る**と試算。

| 主な経済効果の経路 | 2040年の年額・概数 |
|---|---:|
| 病気の減少による労働参加の回復 | **4.2兆ドル** |
| 高齢者・介護者等の就労増 | **4.1兆ドル** |
| 就労者の生産性改善 | **2.0兆ドル** |
| 早期死亡の回避 | **1.4兆ドル** |

内訳は丸め・分類差があり合計12兆ドルに厳密には一致しない。世界の疾病負担の**約40%**は既存の有効な対策の普及で減らせる可能性があり、健康改善の**約70%**は生活環境・予防・行動変容・既存医療介入から得られるとの分析。**12兆ドルはAI固有の便益ではない。**

## 11.3 WHO：非感染性疾患の予防投資

**WHO、2025年9月18日『Saving lives, spending less』関連報告**。心血管疾患、がん、糖尿病、慢性呼吸器疾患などを対象に、2030年までに**累積1兆ドル超**の経済的便益、**1,200万人**の死亡回避、**2,800万件**の心筋梗塞・脳卒中回避の可能性を説明。追加投資は**年間1人約3ドル**、投資1ドル当たり最大**7ドル**の便益とのモデル。

重要：主に高血圧管理、糖尿病予防、禁煙、食生活、ワクチン等の既存対策の普及に関する数字で、AIだけで得られる効果ではない。AIはリスク層別化、受診勧奨、適切な患者への介入でこれらを補助する可能性がある。

## 11.4 世界のがんと認知症の負担

**がん**：2023年の『JAMA Oncology』研究（Chenら）は、204の国・地域、29種類のがんを対象に、2020〜2050年の累積経済損失を**25.2兆国際ドル**（2017年価格、購買力平価換算）と推計。構成比の例：肺がん等**15.4%**、大腸がん**10.9%**、乳がん**7.7%**、肝がん**6.5%**、白血病**6.3%**。**国際ドルと通常の米ドルは異なり、全損失が回避可能とは限らない。**

**認知症**：WHOが示した2030年の世界の年間社会的費用は**1.7兆ドル**、介護費増加等を調整した条件付き推計は**最大2.8兆ドル**。世界全体での社会的費用回避割合を機械的に設定すると次の通り。

| 回避率（独自仮定） | 年間の負担回避額（参考） |
|---|---:|
| 1% | **170億〜280億ドル** |
| 3% | **510億〜840億ドル** |
| 5% | **850億〜1,400億ドル** |

これはAIが実際に達成すると予測した数字ではなく、疾病負担を基準にした感度分析である。

## 11.5 日本の認知症：医療費・公的介護費・家族負担

**Sadoら『PLOS ONE』（2018）**の日本の認知症社会費用推計（2014年）：

| 年間費用（2014年推計） | 金額 |
|---|---:|
| 医療費 | **1.91兆円** |
| 公的介護費 | **6.44兆円** |
| 家族等の介護負担 | **6.16兆円** |
| 合計 | **約14.5兆円** |

同研究の旧い人口・費用前提による将来推計：**2030年21.381兆円/年**、**2035年22.923兆円/年**。これを2026年現在の確定予測に読み替えない。認知症の経済効果は病院の医療費削減だけでなく、家族が仕事を離れずに済むこと、自立して暮らせる期間の延長に大きく関わる。

**国立長寿医療研究センター、2026年3月17日のJ-MINT費用対効果研究**：65〜100歳を対象とするモデルで、運動・栄養・認知トレーニング・血管リスク管理を組み合わせた多因子介入により、通常ケア比で**一人当たり生涯累積約45万円の費用削減**、**+0.08 QALY**と推計。約35年間の長期モデルであり、毎年45万円の削減でもAI固有の効果でもない。短期試験のリスク指標を長期にモデル化した推計で、認知症発症率の長期試験実測とは異なる。

この結果を単純に人数へ掛けた参考計算：10万人なら**450億円**、50万人なら**2,250億円**、100万人なら**4,500億円**の**生涯累積**負担軽減相当。実際には対象者、介入参加、AIの導入費用、効果の再現性が違うためそのまま財政収支とは言えない。

## 11.6 日本のがん：経済負担とOECDの治療・予防評価

**国立がん研究センター、2023年8月発表（2015年の費用データを用いた研究）**：

| 負担の分類 | 年間経済負担 |
|---|---:|
| がん全体 | **2兆8,597億円** |
| 予防可能なリスクに起因する部分 | **1兆240億円** |
| 感染に起因するがん | **約4,788億円** |
| 能動喫煙に起因するがん | **約4,340億円** |

予防可能な要因に起因する負担は理論上の帰属額であり、今日の介入で全額が直ちに節約できるわけではない。感染対策（HPV、ピロリ菌等）、禁煙、健診、早期発見など、AI以外の既存対策の効果が大きい。

**OECDの日本向け2024年がん分析**：日本のがん治療・診断成績をOECD・EUの良好な生存率水準まで引き上げる反実仮想では、2023〜2050年平均で**がんによる早期死亡約5%減**、フルタイム換算労働供給**約4,900人増**、平均寿命**約1か月延長**、一方で**医療費は約0.3%増加し得る**と試算。新しい治療で長生きすることで医療費が増えることもある。

別のOECDの予防シナリオでは、主要なリスク要因への対策で**がん罹患数約8%減、早期死亡約12%減、がん関連医療費負担約12%減**の可能性。これらはAI専用予測ではなく、予防と治療で費用への影響が違うことを示す。

がんの予防可能要因由来の年間負担**1兆240億円**を固定し、回避率を独自仮定すると**5%→約512億円/年**、**10%→約1,024億円/年**、**20%→約2,048億円/年**。AIが達成した実績ではない。

## 11.9 日本の病院のAI・デジタル導入効果

## 11.10 日本全体のAIと医療費・GDPへの文脈

- みずほリサーチ＆テクノロジーズの2025年研究では、AIが最大限普及した場合の日本全体の労働時間削減余地を**17.2%**、経済効果を最大**約140兆円**と試算。**日本経済全体のAI効果**であり医療・創薬だけではない。

# 12. 2030年・2035年シナリオおよび算定上の注意

## 12.1 研究成果から経済価値への経路

**予防・早期発見AI**：高リスク者を特定→必要な検査・予防介入→発症・重症化・入院を減らす→医療費・介護時間・就労損失の回避。偽陽性、追加検査、AI導入費、新薬費用、アクセス格差も算入する。

**AI創薬**：病態標的・候補物質の発見→化学合成・評価→前臨床・臨床試験→規制承認→患者への治療→生存期間・生活の質の改善。短縮利益は研究費削減、上市時期の前倒し、成功率上昇に分けて考える。

**フィジカルAI**：ロボット・分析機器・センサーが研究の作業時間・ばらつきを減らす→試験回数・データ品質を改善→研究費効率化。細胞医療では品質・量産・製造原価の改善もあるが、医薬品の有効性までは保証しない。

## 12.2 2030年・2035年の保守・基本・加速シナリオ

以下は本チャットで作成した**独自の感度分析**。政府、国際機関、学術研究者が「AIでこの額を節約できる」と公表した予測ではない。認知症社会的費用の旧い基準値を固定し、医療・予防・治療の進歩により回避できる割合を置いた。

**基準**：2030年**21.381兆円/年**、2035年**22.923兆円/年**（2018年のSadoらの将来推計）。

| シナリオ | 回避割合2030年 | 2030年の年額効果 | 回避割合2035年 | 2035年の年額効果 |
|---|---:|---:|---:|---:|
| 保守 | 0.5% | **約0.11兆円** | 1% | **約0.23兆円** |
| 基本 | 2% | **約0.43兆円** | 4% | **約0.92兆円** |
| 加速 | 5% | **約1.07兆円** | 8% | **約1.83兆円** |

**保守ケース**：リスク予測、診療文書、既存の予防プログラムへの受診勧奨、治験選定などに限定された効果。新薬の臨床開発成功は限定的。

**基本ケース**：早期診断と個別化予防が普及し、進行抑制薬への適切な患者アクセスが改善。AIと自動実験が複数の創薬工程で効果を示す。認知症などの発症・進行を一定程度遅延できる必要がある。

**加速ケース**：より効果の大きい治療薬・細胞治療が承認され、バイオマーカー・AI予測で適切な患者へ普及し、自動実験・製造によって開発・供給が拡大。実現には第2・3相試験の成功、薬価・償還、製造品質、データ基盤整備が必要。

これは**回避する社会的負担の粗額**。AI・診断機器・新薬導入費を差し引いた純利益ではない。介護費と一般医療費、疾病負担とGDP効果、がんと認知症の費用の重複を調整せず足し合わせない。

## 12.3 研究開発期間のシナリオ

- 保守：事務・記録・一部の研究補助が中心。治験・承認の時間はほぼ維持。
- 基本：標的探索、分子設計、候補選別、患者選定、書類作成、自動化実験に改善が広がる。
- 加速：高精度の病態モデル、仮想細胞、患者由来細胞の自律ラボ、国内外医療データ連携により研究全体の反復速度をさらに改善。

開発全体の実測値が不足しているため、既出の試算では**12年＝前臨床3年＋臨床7年＋承認2年**という説明用モデルを使った。前臨床70%短縮、ほか0%短縮なら**9.9年**。臨床がさらに10%短縮できるという追加仮定なら、**9.2年**（12年−2.1年−0.7年）となる。これは将来の実現を保証しない。

### 2030年と2035年を検証する際に必要な指標

- AI由来の標的数、細胞実験での再現率、動物での有効性割合。
- 新規候補の第1相・第2相・第3相移行率、最終承認率。
- 薬剤の研究開発期間と失敗費用の実際の削減額。
- 診断AIが患者の死亡率、入院、再発、健康寿命を改善したか。
- フィジカルAI設備の稼働率、実験処理数、実験当たり原価、データ品質。
- 社会的便益に対する導入費・診断費・薬価・介護費の正味変化。

## 13.2 米国のAI規制議論

2026年11月6日のロイター報道では、中間選挙を受けて民主党議員が2027年1月以降の議会へAI規制法案を準備していると紹介。データセンター電力・地域負担、強力なモデルの第三者安全検証、AI企業の責任等が議論対象とされた。政治勢力図は時期に依存するので、個別法案の進捗、議会構成、施行時期を別途確認する必要がある。

**AIに対する規制を三つに分ける必要がある**：

1. **データセンター・電力・水・建設の規制**：研究用GPUへのアクセス・コストに間接的影響。
2. **高性能な汎用AIモデルの開発・公開・安全性の規制**：研究モデルの利用範囲や開発費に影響し得る。
3. **医薬品・医療機器の審査・患者安全の規制**：医薬品の有効性・安全性を保証するための品質・科学的証拠の要求。研究支援と矛盾するわけではない。

FDA・EMAが2026年1月に発表した医薬品開発AIの10共通原則は、AIを科学的エビデンスに利用しながらリスク管理・品質を確保するもの。米民主党の一部議員が規制強化を訴えても、それだけでAI創薬が全面的に停止するとは言えない。他方で、規制遵守費用、研究用データ・計算基盤のアクセス、中小創薬企業の負担が増えるリスクはある。

## 13.3 日本側の規制と国際協調

- PMDA・FDAによる医薬品・医療機器の国際共同試験・共通プロトコル・審査連携。
- FDA・EMAによるAI医薬品開発の共通原則。
- 国内の電子カルテ・ゲノム・画像等の医療情報保護と適法な研究利用。
- AI診断機器は対象疾患、適応、使用条件、保険適用、患者安全の検証が必要。研究用試薬は診断薬の承認と同じではない。

## 15.3 安全性・研究・ビジネスの共通リスク

- **研究上のリスク**：AIが学習したデータのバイアス、異なる人種・患者集団での性能低下、予測を試験で再現できないこと、相関と因果の混同。
- **臨床リスク**：第2相・第3相で失敗、安全性・副作用、対象患者数の少なさ、長期の生存・死亡率が未証明。
- **政策・規制**：医療情報・個人情報保護、データ連携の制約、薬事承認・保険適用、米FDAの輸入警告、国際AIモデル規制。
- **収益面**：装置導入が単発、研究の成功と商業契約が結び付かない、契約最大額の大半が未達マイルストーン、研究費増加、AI設備投資の償却。
- **市場・株価**：新規事業の売上が既存事業に比して小さい、期待先行のPER・マルチプル、バイオ企業の増資・希薄化、海外資本の契約解消。
- **社会的影響**：高価な新薬は患者の生存率改善と医療費増加を同時にもたらし得る。AI予防で偽陽性・過剰検査が増える可能性。

## 15.4 すべての段階を横断する分析上の結論

1. 日本ではAI創薬・研究用ロボット・医療データ・臨床診断を国家戦略として支援し、DAIIAのように商用化まで進んだ事業が存在する。
2. アステラスの複数の探索工程では数値化された高速化があり、NECではAI設計の治療候補が人体で検証されている。ただし業界平均・新薬承認までの全期間へ同じ短縮率を適用できない。
3. 日本には、患者由来iPS細胞、先進的な画像・精密計測、長期追跡データ、製薬企業の研究蓄積、研究用ロボットという強みがある。ただしデータアクセス、事業化、国際治験、資金調達には課題が残る。
4. NVIDIA、Microsoft、Google、海外製薬会社、EU・英国・米国の機関が日本の研究・医療基盤と実務的な関係を持っている。一部は日本の技術を高く評価するが、すべてが日本株への出資やAI創薬そのものへの投資ではない。
5. 認知症・がん・ALS等の医療課題では、原因候補の発見や患者データの予測が前進。ただし疾患の治癒確率を一律の数値で示せる段階ではない。
6. 社会的な経済効果は医薬品市場の規模を超えて大きくなり得る。WHO・OECD・McKinsey・国内医学経済研究の推計は基本的に医療改善全体の便益であって、AI単独の便益ではない。
7. 関連日本株は、薬の承認・ライセンスで利益を得る企業、診断AI・医療データを販売する企業、フィジカルAI設備と消耗品を売る企業に分けて評価する必要がある。

## 編集後記：再利用時に守るべき精度

- **AI創薬の研究成果と、AI以外も含む日本の優れた医学研究成果を区別する。** レケンビ、エンハーツ、iPSのアムシェプリ等を「AIが生み出した薬」とは記述しない。
- **治療の有望な初期結果と、実用化後の確定した治癒・延命効果は別。** 例えばNECのワクチンの16/16人という数字は第1相の小集団の観察結果。
- **研究・事業の規模と株式価値は別。** 新規AI事業がグループ全体のEPSにどこまで効くかは、実際の売上・利益とPER等のバリュエーションで判断する。
- **医療全般の経済効果にAI由来と断定できない金額を含めない。** McKinseyの12兆ドル、WHOの1兆ドル、国内認知症21〜23兆円の負担は「AIだけで実現できる節約額」ではない。
- **研究・政府・企業発表の数値は実績、目標、予算案、将来条件付き契約、独自感度分析を区別して使う。**
