# 第1章 きんでん（1944）

東証プライム・建設業。2026年11月25日時点、株価は11月24日基準。

## 1. 結論：業績成長と株主還元強化が同時に進む企業

きんでんは、従来の電力設備工事会社という位置付けから、データセンター・半導体工場・電力インフラ整備などの成長需要を取り込む総合設備工事会社へと評価が変わりつつあります。

直近決算では大幅な増収増益を達成し、通期業績予想も上方修正しています。それにもかかわらず、株価は年初来高値から大きく調整しています。

| 指標 | 数値 |
|---|---:|
| 11月24日株価 | 5,729円 |
| 年初来高値からの下落率 | −33.23% |
| 今期予想年間配当 | 240円 |
| 今期予想配当利回り | 4.19% |
| 上半期営業利益前年同期比 | +32.0% |
| 上半期純利益前年同期比 | +38.8% |

ただし、高配当株として投資する際に、絶対に見落としてはいけない点があります。**年間240円の配当のうち100円は、中期経営計画の成長指標達成に伴う特別配当です。** 恒常的な配当収入を目的とする場合、4.19％という表面的な配当利回りだけで判断するべきではありません。普通配当140円で計算すると利回りは約2.44％になります。この点を踏まえても、今後の利益成長による普通配当の増額余地がある企業として、調査する価値は十分にあります。

## 5. 今後の成長分野

- AIデータセンター：受変電設備、電源設備、非常用電源、通信設備など。AIの普及に伴う電力需要拡大の恩恵が期待できる分野です。
- 半導体工場・製造業の国内設備投資：大規模工場の電力供給設備、空調、通信などのインフラ整備需要を取り込めます。
- 電力インフラの増強・老朽化対策：AI関連投資だけに依存せず、電力の安定供給や設備更新による継続的な需要が見込めます。
- GX・再生可能エネルギー：再生可能エネルギー設備や送配電網の整備など。会社の中期経営計画でも成長領域として扱われています。

会社の資本政策でも電力安定供給体制の強化、GX関連工事、新しいインフラへの対応が重点分野に設定されています。なお、AIデータセンター関連だけの売上高や営業利益への寄与率は確認できていないため、AI関連需要の規模を過大評価しないよう注意が必要です。

## 6. 中期経営計画と今後の見通し

現行中期経営計画は2021年度から2026年度まで。当初掲げていた最終年度の業績目標をすでに大幅に上回っています。

| 指標 | 当初目標 | 最新会社予想 |
|---|---:|---:|
| 売上高 | 7,000億円 | 8,500億円 |
| 営業利益 | 500億円 | 1,050億円 |

営業利益は当初目標の2.1倍です。これが今回の特別配当の背景にもなっています。

| 投資対象 | 公表時点の投資規模 |
|---|---:|
| 首都圏事業基盤の拡充 | 約800億円 |
| 新教育関連施設 | 約400億円 |
| 事業出資・M&Aなど | 約200億円 |
| 合計 | 約1,400億円 |

特に重要なのは人材への投資です。設備工事業界では受注が増えても施工できる技術者がいなければ売上高を増やせません。人手不足が深刻化する環境では、人材育成能力や施工能力そのものが競争優位性になると考えられます。現行の中期経営計画が終了するため、2027年春以降に公表される次期中期経営計画と株主還元方針が最大の注目材料になります。公表の具体的な時期は未確認です。

## 16. 最大の注意点：2,237億円の自社株買い

2026年に関西電力グループが保有する株式3,350万株を公開買い付けによって取得し、消却しています。自己株式取得額2,237億円、消却株式数3,350万株、発行済株式数の減少率16.75%、利益一定時のEPS押し上げ効果約20%。株式数が減少することで、同じ純利益でも1株当たりの利益が増加します。EPS、ROE、1株当たり配当金の引き上げ余地に寄与します。一方で取得資金に充当するため巨額の借入を実施していることが大きな注意点です。

2026年5月25日公表の弘電社買収関連資料では、再開発、データセンター、物流施設の新設・拡張による建設需要に加えて、生成AIの普及や再生可能エネルギー導入に伴う送配電網の更新・増強需要が継続すると見込んでいます。

生成AIの普及・拡大 → データセンター増設（半導体工場・サーバー施設）、電力需要の拡大（発電・送配電網の増強） → 受変電・電源設備工事、空調・冷却関連工事、通信ネットワーク工事、発電所・蓄電所工事 → きんでんの受注機会拡大。

きんでんの強みはAI半導体そのものを製造するのではなく、AIを稼働させるための物理的なインフラを複数の分野から提供できることです。特定の半導体メーカーの競争力だけに依存しない点を評価できます。

### AIによる省エネルギー事業「EMS-AI」

EMS-AIとはAIによって建物の空調などを最適制御し、消費エネルギーを削減する技術。2026年3月期有価証券報告書では大阪・関西万博での実証実験（11施設、最大エネルギー削減効果33.8%）を報告。最大値であり全施設の平均ではありません。

今後はオフィスビル、商業施設、工場、病院などへの展開が考えられます。会社も中期経営計画においてEMS-AIを新しいインフラ事業の一つに位置付けています。設備工事に加えてAIによる設備運用・管理サービスを提供することで継続収益型のビジネスモデルを構築できる可能性があります。ただしEMS-AI単独の売上高、利益率、契約数、将来の業績目標は確認できていません。

2026年9月30日、きんでんは三菱電機の旧子会社である弘電社を完全子会社化。最新決算では2026年10月～2027年3月の弘電社業績が連結業績予想に反映されています。

## 21. DOEはどれほど優秀なのか

| 2019 | 3.8% |

| 2024 | 6.1% |
| 2025 | 6.9% |

従来のDOE実績。新中計の調整後DOEとは定義が異なります。2026年度以降の調整後DOE目標は10%以上。DOEは利益ではなく株主資本に対する配当金の割合を基準とする指標です。例えば配当性向40％を採用する企業の場合、利益が半減すれば配当金も半減する可能性があります。一方、DOEを基準とする企業では一時的な利益減少がそのまま配当減少につながるとは限りません。第一三共はさらに株価や為替変動などによって変化する一部の資本項目を除外した調整後DOEを使用しています。一般的なDOE3～5％を掲げる企業と単純比較はできませんが、株主還元に対する積極的な姿勢は明確です。

## 33. 最終結論

第一三共は以前のような株価上昇だけを期待するグロース株から、利益成長と配当収入の両方を期待する銘柄へ変化しつつあります。特に評価できるのは、エンハーツの世界売上45.9％増、ダトロウェイ207.2％増、2030年度営業利益6,000億円以上、2035年がん領域世界トップ5、累進配当と調整後DOE10%以上の正式採用、過去10年間の配当約4.3倍、AI創薬・業務改革による利益率改善余地、2024年最高値から56％以上下落したことです。

ただし今期の予想配当性向は72.5％と高く営業キャッシュフローにも改善の余地があります。医薬品事業は景気変動には比較的強いものの、治験結果によって企業価値が大きく変動するため株価の安定性と事業の安定性は別々に考える必要があります。新NISAで長期保有する増配型高配当株の候補としては有力ですが、配当の安全性だけを求める銘柄ではなく抗がん剤事業の将来性にも投資する銘柄という評価です。今後はエンハーツとダトロウェイの販売拡大に加えて営業キャッシュフローの改善、新薬承認、100円以上の配当維持を重点的に確認したいです。

## 8. サーマルシステム：自動車の熱管理

東証プライム・非鉄金属。2026年11月25日時点、株価は11月24日終値。

## 1. 結論：業績と株価の方向性に大きな乖離が生じている

住友電工については、AI半導体関連銘柄という側面だけで企業価値を評価するべきではありません。最新決算では大幅な増収増益を達成し、会社は通期業績を上方修正すると同時に増配も発表しています。それにもかかわらず株価は年初来最高値から約65％下落しています。

| 指標 | 数値 |
|---|---:|
| 11月24日終値 | 1,309.5円 |
| 年初来最高値からの下落率 | −64.7% |
| 予想配当利回り | 3.36% |
| 最新年間配当予想 | 44円 |
| 上半期営業利益 | +43.5% |
| 上半期純利益 | +62.7% |
| 予想PER | 約11倍 |
| 実績PBR | 約1.42倍 |

2026年7月1日に1株を4株にする株式分割を実施しているため過去の配当金と株価も原則として分割後の水準に統一します。住友電工は現在、最高益更新・増配・大幅な株価調整が同時に起きている企業です。ただし株価の下落がすべて半導体株の連れ安によるものなのか、業績の中身に問題がないのかは事業別に検証する必要があります。

## 6. AI以外の事業だけでも増益している

情報通信以外の4セグメントの利益単純合計：前年1,308億円、最新1,582億円、+20.9%。仮に情報通信事業を丸ごと除外しても残りの事業は約21％増益しています。つまり住友電工はAIデータセンター向け光通信製品の成長が止まった瞬間に企業全体の成長が完全に止まるような構造ではありません。一方で他の事業にも一部AI関連製品が含まれる可能性があるため、この数値は厳密な非AI事業利益ではありません。今回の増益を支えているのは情報通信と産業素材という二つの大きな成長分野です。

## 10. 自動車事業：売上最大の基盤事業

2027年3月期売上予想3.29兆円（+12.0%）。住友電工は自動車用ワイヤーハーネスで世界トップクラスのシェアを持っています。ワイヤーハーネスとは自動車内部で電力や電子信号を伝達する電線の集合体です。ハイブリッド車、電気自動車、自動運転車など自動車の電子化が進むほど高性能な配線システムの重要性が高まります。

| 決算期 | 自動車事業売上高 |
|---|---:|

2022年3月期から今期予想までで約87.5％増加。一方足元では銅価格や原材料費上昇によって利益率が低下。会社はDX・AIを活用した原価低減や生産性向上によって2028年度に営業利益率6.8％を目指しています。自動車事業は売上規模が非常に大きいためわずかな利益率改善でも全社業績への影響が大きくなります。今期売上予想3.29兆円に対して利益率が1ポイント改善すれば単純計算で約329億円の営業増益です。

今回の調査からユーザーの仮説には相当の合理性があると考えます。特に評価したいのは、上半期営業利益43.5％増・純利益62.7％増、通期業績2回連続上方修正、5事業すべて増収、情報通信以外だけでも約21％増益、今回の上方修正額最大は産業素材、世界的な電力網増強需要を取り込む事業構造、配当39円→44円、配当性向37.1％、PER11倍・利回り3.36％、11月最新IRでもデータセンター向け増産加速という点です。

一方で信用倍率35倍超、産業素材事業の市況依存、キャッシュフロー悪化、過去の減配実績などは無視できません。株価が約65％下落するほど住友電工の事業価値が悪化したという証拠は今回確認した決算・IRからは見当たりませんでした。株価最高値への回復を前提にする必要もありません。現在の利益を維持しながらPERが一般的な評価水準へ戻り今後も増配が続くというシナリオだけでも投資妙味は生まれます。

## 6. なぜライオンは原油安の恩恵を受けるのか

原油価格の持続的な下落 → ナフサ・石油化学原料の低下、プラスチック容器の原価低下、輸送・物流費の低下、工場のエネルギー費低下 → 製造・販売コストの低下 ＋ 値上げ後の販売価格を維持 → 売上総利益率・事業利益率の改善。

事業構造から考えられる波及経路であり、すべての費用が原油価格に比例するわけではありません。ライオンは石油化学製品や植物油脂などを原材料として使用しています。

| 原材料・費用 | 主な用途 | 原油安の恩恵 |
|---|---|---|
| ナフサ・石油化学製品 | 界面活性剤など | 比較的大きい |
| プラスチック樹脂 | 洗剤容器・包装 | 期待できる |
| 燃料費 | 製品輸送 | 期待できる |
| 電力・ガス | 工場稼働 | 間接的 |
| 植物油脂・パーム油 | 洗剤・石けん原料 | 市況次第 |
| 人件費 | 製造・販売 | 原則として限定的 |

注意したいのはパーム油などの植物由来原料。原油が下落しても天候や農産物需給によって価格が高止まりする可能性があります。原油だけでなくナフサとパーム油の価格まで確認することが重要です。

## 15. なぜ景気後退局面で強い可能性があるのか

景気後退時には自動車や住宅、家電製品などの高額消費が抑制される傾向があります。しかし歯磨き粉、洗剤、石けんなどは日常生活に必要なため需要が完全になくなるわけではありません。

|---|---|---|

| 製品の買い替え延期 | 起こり得る | 限定的 |
| 将来の成長期待への依存 | 高い傾向 | 比較的低い |

## 16. インフレ沈静化による消費回復も追い風になる

原油安・インフレ沈静化 → 企業側：原材料費・輸送費の低下 → 利益率改善。消費者側：実質購買力の改善 → 高付加価値商品の販売拡大。この両方から増収・増益の可能性。

ライオンが恩恵を受ける可能性があるのは企業側のコスト削減だけではありません。原油安が家計のガソリン代や光熱費の低下につながれば消費者の可処分所得にも好影響を及ぼす可能性があります。物価上昇に対して賃金上昇が上回る環境になれば、より機能性の高い歯磨き粉や洗剤などを選ぶ余裕も生まれます。ただし深刻な景気後退によって所得や雇用が悪化する場合は、この効果が相殺される可能性があります。

## 30. 円高になった場合も有利なのか

ライオンの場合は少し複雑です。円高は国内の輸入原材料費を低下させるため本業にとってプラスになる可能性があります。しかし連結売上高の約43％を海外事業が占めているため海外収益を円換算した際にはマイナスの影響もあります。

| 為替変動 | 国内事業 | 海外事業の円換算 |
|---|---|---|
| 円高 | 原材料費低下 | 売上・利益減少要因 |
| 円安 | 原材料費上昇 | 売上・利益増加要因 |

実際に2026年1～9月の決算では為替変動による粗利増加53億円に対し販管費へのマイナス影響42億円。差し引き約11億円の増益要因でした。したがってライオンを単純な円高メリット株と位置付けるのは正確ではありません。原油安の恩恵と海外利益の為替換算影響を分けて評価する必要があります。

# 付録 シミュレーター・記録上の注意

## 計算式

- 予想配当利回り（%）＝1株当たり予想年間配当÷購入株価×100。
- 配当性向（%）＝1株当たり年間配当÷EPS×100。
- DOE（%）＝年間配当総額÷対象株主資本×100。ROE×配当性向（両者を小数に直してから%換算）に概ね相当。各社の調整項目・期中平均の定義を確認すること。
- 理論株価＝想定EPS×想定PER。現在価値への割引、リスクプレミアムは未反映。
- 取得価格ベース利回り（%）＝将来の1株当たり年間配当÷取得株価×100。
- 税引前年間配当収入＝保有株数×1株当たり年間配当。権利確定済みの配当を受け取れるとは限らない。
- 下落率・上昇率（%）＝（比較時点株価÷基準株価−1）×100。
- ストレステスト想定EPS＝基準EPS×（1−減益率）。株式数一定、財務政策・CFの変化を含まない。
