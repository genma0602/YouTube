## 0. 最初にやること

1. `channels/投資系/CLAUDE.md`（共通ルール）を読む
2. このファイル → **`scenario_draft.md`（本文）** → `materials.md`（数値の正本）の順。**`plan.md` は裏取り前の版で別物。読まなくてよい**
3. **`@`でファイル添付すると約10KBで切れる。**全文は Bash の `cat` か `sed -n` で読む
4. **このマシンの Bash では複数行ヒアドキュメントが失敗する。**部分修正は `sed -i 's/…/…/'`（日本語OK・行頭 `^` で一意に）か、Write ツールで書いた断片を `head/tail` で差し込む。大きな並べ替えは Python スクリプトを Write して `python script.py file`
5. **ユーザーがVS Codeで開いたまま作業していると、エディタ側の保存で書き込みが巻き戻る。**書き込むたびに「タブを開き直してください」と伝え、**次の書き込み前に `grep -c` で直前の変更が残っているか確認する**
6. **「ここどう思う？」「〜じゃない？」「考えて」は答えるだけで修正しない。「修正して」「書いて」「入れて」で初めて直す。**「〜したほうが良いね」は修正の指示として扱ってよい（今回そう扱って問題なかった）
7. **1回の応答で書くのは1ブロック。**ただし⑧のように1ブロックが長い場合、ユーザーが「情報が無い」と言ったら残りのグループをまとめて入れてよい（今回そうした）

## 3. ★確定した執筆ルール（9/25〜27に追加分は★）

### 3-a. たとえ話は使わない（比喩ゼロ）
過去台本の実測で比喩はほぼ無い。説明は事実と数字でやる。

### 3-b. ①には出典名も社名も置かない
現在の①は出典名0・社名0。崩さない。①は変えていない（9/27に「持ち株の実感」の1文を足す案が出たが、ユーザーが不要と判断）。

### 3-c. ①は「TOPIXの話」から始める
1文目は「10月から、TOPIXの中身が大きく入れ替わります。」

### 3-d. 数字はばらつかせない
銘柄数は**980社で統一**。株価は**年初来（2026年1月5日終値→9月25日終値）で統一**。「1年で」「今年に入って」「1年前」は使わない（本文0件）。分割した精工技研・パワーエックスと、新規上場のティアフォー・GOは、比べ方を説明したうえで値段も出す。

### 3-e. 言わないことを宣言しない
✕「ここで社名は出しません」。出さないものは黙って出さない。

### 3-f. 親子上場は④だけ
②から④（浮動株時価総額の定義の直後）に移した。核は「投資できる会社を残す改革」。

### 3-g. 「もう遅いのでは」に先に答える
「結論、まだ余裕で間に合います。」（①）

### ★3-h. 数字を羅列しない
伸びた2本の①にある相場の数字は実質1〜3個。②の頭（承認）は相場の数字1組（33業種のうち31業種）だけにした。データ密度の目安は1.0/100字。数字は理由パート（⑥）に定義つきで置く。`count_numbers.py` で数えられる。

### ★3-i. AI半導体を否定しない
✕「AI半導体を持っている方は、6月の高値をまだ超えていないはず」。○「AI半導体と、銀行や内需の会社。この2つが、日によって入れ替わりながら相場を動かしています」（主役が2つ）。⑥-1も「需要が消えたから売られたわけではない。8月にいったん戻し、9月は利上げの警戒で重くなったあと、利上げを通過して5日続伸」と現状で言う。

### ★3-j. 相場の話は直近1〜2週間で
6月（プライムの7割が値下がり）・7月起点は「古い」と却下された。②の頭は9月24日と25日。7月は⑥-1で「始まり」として1回だけ。

### ★3-k. 出典は主張の後ろに添える
「〜です。マン・グループの分析です」「〜が高まる。UBSも、そう見ています」「〜が入ります。SMBC日興証券の試算です」。前に出すと他人の意見の紹介に聞こえる。伸びた版は全部この形。

### ★3-l. 「ねらい目」「仕込み時」は2か所だけ許可
⑤の締め「TOPIXから外れる会社は、ねらい目になるかもしれません」、⑦「そこは仕込み時になるかもしれません」。どちらも「〜かもしれません」付き。禁止語チェックの例外。「割安」は「2割の下落」に言い換えた（「2割安」が引っかかる）。

### ★3-m. 前の文を覚えていない人向けの言い方
✕「では、さきほどの3社です」→○「では、業績が良いのにTOPIXから外れそうな会社を、3社見ていきます」。

### ★3-n. 疑いの代弁は各ブロックの頭に
①「もう遅いのでは」／④「基準の細かい話はいらない、と思うかもしれません」／⑦「候補が分かっても、もう買われているんじゃないか」。伸びた版は1本に6〜8回。各ブロックに二人称（あなた／持ち株／ご自分）を1回以上。

### ★3-o. 同じ仕組みを繰り返さない
「売買の少ない株に大きなお金が入ると大きく動く」は②本質・④キオクシア・⑦道具1末尾・⑧GOの4か所に絞った。⑦の小見出し「効き方がまるで違います」は削除（3つの道具→2つの道具）。

### ★3-p. 会社四季報の秋号は名前を出してよい
四季報の独自予想（ブロードリーフ96億円・三洋化成140億円・新日本建設2028/3期増益）も、「会社四季報の秋号は〜と見ています」の形で使用。
