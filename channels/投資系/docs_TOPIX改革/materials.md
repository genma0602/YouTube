## 0. いちばん重要な発見（構成に影響）

### 0-a. ①の前提が変わった

**当初の想定**「日経平均は高い水準なのに、自分の持ち株は上がっていない」
→ **実際はもっと強い形にできる。痛みが2段階ある。**

| 段階 | 何が起きたか |
|---|---|
| **〜6月** | 日経平均が史上最高値を更新。**ところがプライム市場の7割は値下がりしていた**【確】 |
| **6/25以降** | その日経平均も下げた。72,366円 → 65,514円（**約-9.5%**） |
| **同じ期間** | **TOPIXはむしろ上がっている**（4,016 → 4,075、**約+1.5%**） |

→ 冒頭は「**指数だけが上がって、自分の株は置いていかれた。そしていま、その指数も下げている。ところがTOPIXは上がっている**」で立てられる。

### 0-b. ★AI半導体の不安打ち消しに、決定的な材料が出た

**キオクシアホールディングス（285A）に、約3兆円の指数買い需要**【確】

- 浮動株比率（FFW）が **15% → 50%** へ引き上げられる見通し
- 指数の構成ウエートが **現在の3倍超**
- 指数連動ファンドから **約3兆円** の買いフローが発生するとの試算
- 3兆円は同社株の売買代金の30日平均（約3.2兆円）に相当＝**ほぼ1か月分**
- 背景：大株主上位10社の保有比率が **89% → 53%** に低下
- 出典：ブルームバーグ（2026/7/6）、日本経済新聞（2026/7）

→ **AI半導体のメモリ会社が、今回の改革で最大級の買い需要を受ける。**①の「AI半導体からお金が抜ける話ではありません」の証拠として、これ以上のものはない。
→ しかも④の**レストランのたとえ話が完璧に効く**：「大株主が89%の席を押さえていた。それが53%まで下がった。僕たちが座れる席が15%から50%に増えた。だからウエートが3倍になる」

### 0-c. ⑧の着地が確定した

**2028年10月が2回目の定期入替。それ以降は年に1度**【確】。そして**2028年10月時点の構成銘柄数は1,050銘柄程度**と試算されている【確】＝**いったん減ってから、また増える。**

→ 「今回間に合わなくても、次がある」は言える。
