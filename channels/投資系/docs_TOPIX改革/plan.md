## 3. 各ブロックの中身

### ① 日経平均は上がったのに、自分の持ち株は（950字・9要素）

**この順を崩さない。**

1. **痛みの承認**：日経平均は高い水準にある。ニュースでも日本株は好調だと言われている。ところが自分の持ち株はちっとも上がっていない。そう感じている方が多いのではないでしょうか。**それは気のせいではありません**
2. **理由**：ここ数年の日本株は**AI半導体主導の相場**でした。日経平均は株価の高い会社の影響が大きく、そこにAI半導体が並んでいる。指数が上がっても、銀行も自動車も商社も陰に隠れたままだった
   - ※**「半導体だけの相場」とは書かない。**⑤-1で銀行や商社にも資金が向かうと言うので矛盾する
3. **ところが**：構図が変わり始めている。日経平均が8%下げた月に、TOPIXはプラスで終わった
   - ※NT倍率などの数字は⑤-1に置く。①は事実の提示まで
4. **本題への接続**：そして10月30日、その流れをさらに押す制度の変更が来る。TOPIXの中身が約1,700社から980社前後まで絞り込まれる
5. **入る側・外れる側に何が起きるか**：入る会社にはTOPIXに連動する110兆円が機械的に入る。外れる会社からは同じ資金が**2年かけて**抜けていく
6. **問い2つ＋決着宣言**：**自分の持っている株は、入る側なのか外れる側なのか。**そして10月7日の正式発表を待つのか、今のうちに動くのか。この2つに決着をつけます
7. **結論先出し＋AI半導体の不安打ち消し**（★最重要）
   - 怖い話ではない。**TOPIXの銘柄に、これまで以上のお金が流れ込んでいく話です**
   - **ただし、これはAI半導体からお金が抜けるという話ではありません。**AI半導体の会社も、そのほとんどが残る980社の側です。だから同じように取り分が増えます。今回新しく入る候補にも、半導体に関わる会社が並んでいます
   - 起きているのはお金が移ることではなく、**お金の向かう先が広がること**
8. **目次3つ＋幅の予告**：何が変わるのか／自分が持っているものはどうなるのか／どの会社が入りそうなのか。最後に産業ごとに並べる。**身近なお店の会社から、宇宙や自動運転のような新しい会社まで**
   - ※**冒頭で特定の産業だけを名指ししない。必ず「幅」の形にする**（ユーザー指摘 9/24）
9. **見終わった状態の約束**：自分の持ち株がどちら側なのかを**自分で見分けられて**、どの産業に乗りたいかも選べる状態になっている

**禁止**：押し付けがましい前振り（「今日いちばん覚えて帰ってほしい」）。

### ④ 何を基準に選ぶ指数に変わったのか（2,600字・小見出し2）

**このブロックが「説明を日本企業名に降ろす」の最大の担保。たとえ話で段落を終わらせない。**

- 敗者復活：**蛇口が半分で止まるだけ。全開には戻らない**（誤解されやすいので言い切る）

- ※金額の話はここで完結させ、⑥の道具1では繰り返さない

### ⑦ 産業別・新TOPIX入りが期待される会社（5,600字・小見出し5）

**前置き（短く）**：これから並べる会社に共通しているのは1つだけ。**毎日きちんと売買されていて、僕たちが買える分が大きい。**それだけです。上がるか下がるかの話ではないし、確定するのは10月7日です。

**順番は「知っている会社 → 新しい産業」。**宇宙から始めると①と同じ離脱が起きる。

| 順 | 小見出し | 会社 |
|---|---|---|
| 1 | 暮らしに身近な小売・外食 | 日本マクドナルドHD、セリア、トライアルHD、ワークマン△ |

**書き方のルール**

- 各社、**どんな会社か**と、**なぜ候補に挙がっているのか**だけ
- **上がる・下がる・買い・仕込むは一切言わない**（CLAUDE.md §2）
- **個別の想定買い金額は出さない**（chatgpt版レポートの数字は作者自身が「独自モデル・誤差±30〜40%」と明記）
- **点呼にしない。**「1社目、2社目」と数えない。産業ごとに「その産業が今どういう状況か」を1〜2文置いてから、会話の流れで社名を出す

- **締め**：マクドナルドと宇宙の会社が、同じリストに並んでいる。今までの日本では、グロース市場の宇宙の会社がマクドナルドと同じ指数に入るなんてことはありえなかった。**それ自体が、今回の改革そのもの**
- **行動指示**：この中から1つか2つ、自分が知っている産業、応援したい産業を選んで、事業の中身と決算を調べてみてください

### ⑧ 「大改革」の、本当の意味（1,400字）

- 大きいのは680社が外れることではない。日本の株式市場が**「上場していれば入れる」から「選ばれないと入れない」に変わった**こと
- そして選ばれるために、会社のほうが変わっていく。**その変化を受け取るのが、株主である僕たち**
- 1回きりのイベントではない。今回間に合わなくても次がある【**要検証1**】

  2. 「今回の動画は、以上です。少しでも参考になったと思っていただけたら、高評価とチャンネル登録、そしてハイプボタンで応援していただけると、とても励みになります。」

  4. 「皆さんの声を楽しみにしています。」

## 7. 執筆の進め方

**1回の応答で書いてよいのは1セクションだけ。書いたら必ず手を止めてレビューを待つ**（CLAUDE.md §5）。

毎回のセルフチェック（CLAUDE.md §6）に加えて、**分析由来の3項目**を追加で数える。

```bash
F=docs_TOPIX改革/scenario_draft.md
# 希望語（全体21回以上／1万字10回以上）
grep -oE "主役|広がる|広がって|初めて|道が開|選ばれ|追い風|強み|欠かせない|本番" $F | wc -l

grep -oE "してください|してみてください|覚えておいて|思い出して" $F | wc -l

grep -n "あなた\|皆さん\|持ち株" $F
```

字数カウントは `LC_ALL=C.UTF-8 wc -m`（メモリ `wc-m-counts-bytes-in-git-bash`）。
