# 投資系チャンネル｜台本執筆の共通ルール

このチャンネルで台本・原稿を書くときは、企画を問わず以下を必ず守る。
企画ごとの事情（構成・数値・伏線）は各企画フォルダの `docs_memory/HANDOFF.md` を参照。

---

## 1. 文体（最優先。ここを外すと書き直しになる）

### 一人称は「僕」「僕たち」

「私」「私たち」は使わない。

### 文末の「〜のです。」は全面禁止

> 「だったのです」——**この言い方はしない。俺の話し方じゃない。**

| ✕ | ○ |
|---|---|
| 〜したのです。 | **〜しました。** |
| 〜ているのです。 | **〜ています。** |
| 〜なのです。 | **〜です。** |
| 〜ないのです。 | **〜ありません。** |
| 〜だったのです。 | **〜でした。** |
| 〜いくのです。 | **〜いきます。** |
| 〜なかったのです。 | **〜ませんでした。** |

※「そのものです」「買うものです」「掛け合わせたものです」の**「ものです」は別物**。禁止対象ではない。

### 普段使いしない言い回しは書かない

**判定基準はただ1つ：普段の会話でその言葉を使うか。** 使わないなら書かない。文語的・比喩的な表現は**AIで書いた感が出て違和感**が生まれる。

| ✕ 書かない | ○ 言い換える |
|---|---|
| まったく違う景色が見えてきます | 指数の数字だけを見ていると、何が起きていたのかは分かりません |
| 名指しされた一部だった | 売られたのは、AIと半導体に関わる会社だった |
| 追加の規制を**示唆する** | 追加の規制もあり得ると**話しています** |
| 揺れ動く**運用**が続く | そういう**やり方**が続いています |
| 犯人は同じ | 原因がまったく同じです |
| 2つのエンジンが載っている | 日本株を動かしているものは、1つではない |
| **物差し**を3つお渡しします | **見るべき数字**を3つお伝えします |
| 4つの**物差し** | 個別株は、**この4つで見る** |
| 基準を3つ**お渡しします** | 基準を3つ**お伝えします** |
| メモリを作る**関所**を握っている | メモリ作りに**欠かせない工程**を握っている |
| 頭には**相反する**2つの気持ちが浮かんできます | **まったく逆のことを、同時に考えてしまいます** |

**唯一の例外＝投資初心者〜中級者に仕組みを説明するためのたとえ話。**
例：「GPUはシェフ。食材を運ぶ通路が細ければ料理は増えない」「DRAMは作業台のようなもの」「ツルハシと秤」
**説明に必要な比喩と、飾りの比喩は別物。** 飾りは削る。

### 説明しない固有名詞は置かない

解説なしで専門用語や歴史的事件の名前だけ出すと、視聴者を置いていく。
説明する余裕がないなら、その語ごと削る。（例：「アジア通貨危機」を注釈なしで出さない）

### そのほかの文体

- 基本の心拍：**「ところが」（落とす）→「ただし」（戻す）→「つまり」（畳む）→「だからこそ」（動かす）**
- **1文1行では書かない。** 段落にまとめて、口で読める流れにする
- 番号での振り返り（「②で〜」）は不可。**「さきほど」に統一**
- **セクションが変わったら主語を言い直す。** 指示語だけで受けない
- 「気のせいではありません／これは事実です」は**データで裏付く実感にだけ**使う
- 「正直にお伝えします」は**1本で3回まで**。多用すると価値が下がる

## 2. 銘柄・相場の語り方

> **銘柄は「役割」で語り、「方向」は語らない。**

| ○ | ✕ |
|---|---|
| キオクシアはNANDフラッシュメモリとSSDを作る会社です（役割） | ここから上がります／下がります |
| 7月28日に18.33%下げ、ストップ安になりました（起きた事実） | 今が買い場です／仕込むなら今です |

**個別銘柄の話題そのものは自由。禁止するのは方向の断定だけ。**

**これは個別株に限らず、相場・セクター・指数でも同じ。** パート間の橋渡しでも「上がる」と言わない。

- ✕「では、なぜここから上がると言えるのか」
- ○「では、そもそもなぜ、世界はこれほどメモリを奪い合っているのか」

**強気の論証は「値段が上がる理由」ではなく「需要・構造・必要性の理由」として立てる。**

---

### 用語の使い分け（メモリ相場を扱うとき）

**「不況」と「暴落」を混ぜない。**

| 語 | 指すもの | 始まり方 |
|---|---|---|
| **メモリ不況** | 市況（価格・各社の業績） | 供給が需要を上回る → 価格が下がる → 業績が落ちる |
| **株価の下落** | 株価 | **上より先に始まる。**市場は半年〜1年先を先回りするため、価格や業績が悪化する前に下がり出す |

**✕「過去の暴落は、値段が崩れるところから始まった」** ——株価は値崩れを待たない。この書き方をすると「株価は市況の後を追う」という誤った順序を伝えることになる。

---

## 3. シリーズとしての整合

- **前作・前々作に一切言及しない。** 新規視聴者が非常に多いため。「前回の動画で〜」は禁止
- **ただし「触れない」と「矛盾してよい」は別。** 数値と結論が前作と食い違うことは許されない
- 同じ数字・たとえ話・再定義を繰り返さない。前作で使ったものは表現を変えるか、別の論拠に差し替える

---

## 4. 事実の扱い

- **裏取りできていない数値は断定しない。** 本文に書いたうえで、セクション末尾に `> **【要検証】**` のメモを残す
- 素材に誤りが混ざっている前提で読む。禁止リストは各企画の `docs_memory/materials.md` に蓄積する
- **各理由に反例を内蔵する。** 強気の根拠を語っている最中に、反するように見える事実を自分から出して、その場で解釈する
- **反例は「打ち消す」のではなく「解釈する」。** 自分で出した反例を自分で否定すると、承認の効果が消える

---

## 5. 進め方

- **1セクション書いたら手を止める。** 逐次レビュー方式。勝手に先へ進まない
- 企画に着手する前に、その企画の `docs_memory/` にある **HANDOFF.md / plan.md / materials.md / scenario_draft.md** を必ず読む
- 数値を差し替えるときは、**同じ数字が他のセクションにも出ていないか**を先に確認する（伏線と回収がペアになっている箇所がある）

---

## 6. 執筆後のセルフチェック

新しく本文を書いたら、コミット前に必ず実行する。

```bash
# 一人称（0件であること）
grep "私" docs_memory/scenario_draft.md | grep -v "^>"

# 「〜のです。」（0件であること。「ものです」は誤検出なので除外）
grep -v '^>' docs_memory/scenario_draft.md | grep -oE "[^も]のです。"

# 読み上げ字数（注記・見出しを除く）
grep -v '^>' docs_memory/scenario_draft.md | grep -vE '^#|^---|^\|' | tr -d '[:space:]' | wc -m
```
