# 投資系チャンネル｜台本執筆の共通ルール

このチャンネルで台本・原稿を書くときは、企画を問わず以下を必ず守る。
企画ごとの事情（構成・数値・伏線）は各企画フォルダの `docs_memory/HANDOFF.md` を参照。

---

## 1. 文体（最優先。ここを外すと書き直しになる）

### 一人称は「僕」「僕たち」

「私」「私たち」は使わない。

### 文末の「〜のです。」は全面禁止

> 「だったのです」——**この言い方はしない。俺の話し方じゃない。**

| ✕ | ○ |
|---|---|
| 〜したのです。 | **〜しました。** |
| 〜ているのです。 | **〜ています。** |
| 〜なのです。 | **〜です。** |
| 〜ないのです。 | **〜ありません。** |
| 〜だったのです。 | **〜でした。** |
| 〜いくのです。 | **〜いきます。** |
| 〜なかったのです。 | **〜ませんでした。** |

※「そのものです」「買うものです」「掛け合わせたものです」の**「ものです」は別物**。禁止対象ではない。

### 普段使いしない言い回しは書かない

**判定基準はただ1つ：普段の会話でその言葉を使うか。** 使わないなら書かない。文語的・比喩的な表現は**AIで書いた感が出て違和感**が生まれる。

| ✕ 書かない | ○ 言い換える |
|---|---|
| まったく違う景色が見えてきます | 指数の数字だけを見ていると、何が起きていたのかは分かりません |
| 名指しされた一部だった | 売られたのは、AIと半導体に関わる会社だった |
| 追加の規制を**示唆する** | 追加の規制もあり得ると**話しています** |
| 揺れ動く**運用**が続く | そういう**やり方**が続いています |
| 犯人は同じ | 原因がまったく同じです |
| 2つのエンジンが載っている | 日本株を動かしているものは、1つではない |
| **物差し**を3つお渡しします | **見るべき数字**を3つお伝えします |
| 4つの**物差し** | 個別株は、**この4つで見る** |
| 基準を3つ**お渡しします** | 基準を3つ**お伝えします** |
| メモリを作る**関所**を握っている | メモリ作りに**欠かせない工程**を握っている |
| 頭には**相反する**2つの気持ちが浮かんできます | **まったく逆のことを、同時に考えてしまいます** |
| 比べる相手は、2020年の年末に**します** | 過去と**比べてみましょう**。2020年の年末です |
| 前回いちばん盛り上がった**局面**でした | 前回いちばん盛り上がった**ころ**です |
| いちばん大きな**筋道**になります | **いちばん大きな原因です** |
| 持ち高の調整の**側面が強い**、と見ています | **持ち高を減らした動きのほうが大きかった**、と見ています |
| ブラックロックの**整理では** | ブラックロック**によると**／**が調べたところ** |
| 業績の伸びで説明できる、という**見方を示しています** | 業績の伸びで説明できる、と**話しています** |

**唯一の例外＝投資初心者〜中級者に仕組みを説明するためのたとえ話。**
例：「GPUはシェフ。食材を運ぶ通路が細ければ料理は増えない」「DRAMは作業台のようなもの」「ツルハシと秤」
**説明に必要な比喩と、飾りの比喩は別物。** 飾りは削る。

### 同じ言い回しを繰り返さない（2026-08-27 追加）

**書いたあとに数える。** 同じ決まり文句が並ぶと、そこだけAIが書いたように聞こえる。

| 言い回し | 上限 | 超えたときの散らし方 |
|---|---|---|
| **「ここがいちばん大事なところです」** | **1本で1回** | 何が大事なのかを具体的に言う。「バブルかどうかは、結局ここで決まります」「いまの金利の話でいちばん見落とされているのが、ここです」 |
| **「さきほどお話ししたとおり」** | **1本で2回** | 受け直し方を変える。「さきほど見たとおり」「さきほどの話です」「ここまでは、もうお話ししました」「これもさきほど触れました」「さきほどの見通しでは」 |
| 「正直にお伝えします」 | 1本で3回 | （既出） |
| **出典の紹介のしかた** | 同じ形を2社に使わない | 「◯◯の整理では」を2回出さない。「◯◯によると」「◯◯が調べたところ」に変える |

※「つまり」「ところが」「ただし」「だからこそ」は基本の心拍そのものなので対象外。

### 同じ内容を2回言わない（2026-08-27 追加）

**1つのことは、1箇所で言い切る。** 言い直しやまとめ直しは、尺を食うだけで情報が増えない。

- 結論を言ったあとに、同じ結論を別の言葉でもう一度書かない
- 年数や数字を並べたら、そのパートの締めで**並べ直さない**（3回目は必ず点呼になる）
- 同じことを「逆から言う」段落を足さない（✕「伸びる会社ほどPERは高い」の直後に「伸びない会社ほどPERは低い」を1段落使う）
- 前のパートで説明した固有名詞を、次のパートで**もう一度説明し直さない**（✕「ヨーロッパの中央銀行であるECB」を2回）
- **書き終えたら、隣り合う段落が同じことを言っていないか読み返す**

### 説明しない固有名詞は置かない

解説なしで専門用語や歴史的事件の名前だけ出すと、視聴者を置いていく。
説明する余裕がないなら、その語ごと削る。（例：「アジア通貨危機」を注釈なしで出さない）

**ただし、言葉を見れば意味が分かる用語は、避けずにそのまま使う（2026-08-27 追加）。** 回りくどく言い換えるほうが、かえって分かりにくい。

- ✕ 長い期間の金利 → ○ **長期金利**（漢字を読めば意味が通る。定義はあとで1回すれば足りる）
- 避けるべきなのは、読んでも意味が分からない語のほう（PER・ACIE・デュアル・マンデートなど）

**ニュース用語は、定義だけ置いて、本文は平易な言葉で通す（2026-08-27 追加）。** 視聴者が外でそのニュースを聞いたときに結びつけられれば足りる。台本の中で使い続ける必要はない。

- 例：**インフレ**は初出で1回だけ定義し、本文はすべて「**物価**」で通す（漢字で意味が通るため）

**海外の会社は、日本の同業を1社添える（2026-08-27 追加）。** 業種を言葉で説明するより、知っている会社の名前を1つ出すほうが速い。

- ✕ アメリカの巨大スーパー、ウォルマートです
- ○ アメリカの巨大スーパー、ウォルマートです。**日本でいえば、イオンのような会社**だと思ってください

※誰もが知っている会社（マイクロソフト・グーグル・アマゾン）には不要。日本に同じものが無い相手は、役割を1語添える（「アメリカの大手金融機関、モルガン・スタンレー」）。

**海外の「機関」は、必ず日本の機関と対比する。ここは言い回しが重複しても構わない。** 投資初心者にとって機関名はいちばん馴染みがなく、分かりやすさが繰り返しの不自然さより優先される。

- FRB → **日本でいえば、日銀にあたる機関です**
- ECB → **日銀のヨーロッパ版だと思ってください**

### そのほかの文体

- 基本の心拍：**「ところが」（落とす）→「ただし」（戻す）→「つまり」（畳む）→「だからこそ」（動かす）**
- **1文1行では書かない。** 段落にまとめて、口で読める流れにする
- 番号での振り返り（「②で〜」）は不可。**「さきほど」に統一**
- **セクションが変わったら主語を言い直す。** 指示語だけで受けない
- 「気のせいではありません／これは事実です」は**データで裏付く実感にだけ**使う
- 「正直にお伝えします」は**1本で3回まで**。多用すると価値が下がる
- **押し付けがましい前振りを置かない（2026-08-27 追加）。** ✕「今日いちばん覚えて帰ってほしい話をします」「覚えておいてほしいことがあります」「ここが分かると、〜できるようになります」→ ○「ここで、1つ整理しておきます」「だから、〜と分けて聞いてください」。**もったいぶりも同じ**（✕「実は、1つの問いではありません。5つの段階に分かれています」→ 直後に5つ並ぶなら予告は要らない）
- **番号の点呼をしない（2026-08-27 追加）。** ✕「1段階目、2段階目、3段階目…」→ ○ 1文ずつ短く並べて「この5つが、順番に並んでいます」で受ける
- **本文に強調の太字を使わない。** 読み上げれば太字は消える。強調は語順と言い切りで作る（見出しは別）
- **素材や下書きが1文1行で来ても、そのまま貼らない。** 必ず段落にまとめ直す

## 2. 銘柄・相場の語り方

> **銘柄は「役割」で語り、「方向」は語らない。**

| ○ | ✕ |
|---|---|
| キオクシアはNANDフラッシュメモリとSSDを作る会社です（役割） | ここから上がります／下がります |
| 7月28日に18.33%下げ、ストップ安になりました（起きた事実） | 今が買い場です／仕込むなら今です |

**個別銘柄の話題そのものは自由。禁止するのは方向の断定だけ。**

**これは個別株に限らず、相場・セクター・指数でも同じ。** パート間の橋渡しでも「上がる」と言わない。

- ✕「では、なぜここから上がると言えるのか」
- ○「では、そもそもなぜ、世界はこれほどメモリを奪い合っているのか」

**強気の論証は「値段が上がる理由」ではなく「需要・構造・必要性の理由」として立てる。**

---

### 用語の使い分け（メモリ相場を扱うとき）

**「不況」と「暴落」を混ぜない。**

| 語 | 指すもの | 始まり方 |
|---|---|---|
| **メモリ不況** | 市況（価格・各社の業績） | 供給が需要を上回る → 価格が下がる → 業績が落ちる |
| **株価の下落** | 株価 | **上より先に始まる。**市場は半年〜1年先を先回りするため、価格や業績が悪化する前に下がり出す |

**✕「過去の暴落は、値段が崩れるところから始まった」** ——株価は値崩れを待たない。この書き方をすると「株価は市況の後を追う」という誤った順序を伝えることになる。

---

### PERの説明のしかた（2026-08-27 追加）

**✕「その会社の利益で、投資したお金を回収するのに何年かかるか」** ——これは正しくない。稼いだ利益が株主に全額返ってくるわけではないため。

**○「いまの利益がずっと続くと仮定した場合、株価に相当する利益を何年で稼げるか」**

そして、必ずこの注意書きをセットで置く。

> PERが10倍だからといって、10年待てば投資した100万円がそのまま自分の口座に戻ってくる、という意味ではありません。会社が稼いだ利益は、配当だけではなく、設備投資や研究開発にも使われるからです。

**あわせて必ず言う2つ**

1. **PERは株価だけで決まらない。** 株価が同じでも利益が増えればPERは下がる
2. **PERが高い理由は、いつも成長期待とは限らない。** 一時的に利益が落ち込んだ会社も、株価が変わらなければPERは高くなる

**「回収」という語は、設備投資が儲けとして返ってくるかの意味だけに使う。** PERの説明に使うと、1本の台本で同じ語が2つの意味を持つ。

## 3. シリーズとしての整合

- **前作・前々作に一切言及しない。** 新規視聴者が非常に多いため。「前回の動画で〜」は禁止
- **ただし「触れない」と「矛盾してよい」は別。** 数値と結論が前作と食い違うことは許されない

### 例外：誘導だけの言及は可（2026-08-17 追加）

禁止しているのは「**見ていない人が置いていかれる言及**」。**誘導だけなら置いてよい。**

| | 例 | 可否 |
|---|---|---|
| 内容が依存する | 「前回お話ししたとおり、メモリは〜」 | **✕** 見ていない人が詰む |
| 誘導だけ | 「**僕のチャンネルの過去動画でかなり解説してますので、良ければご覧ください**」 | **○** 見ていなくても本編は完結する |

**置く場所は締め近く。** 本編の途中で他の動画に飛ばすと、そこで離脱が出る。
**本編のロジックは、その言及が無くても自己完結させること。** 扱わない話題がある場合、外した理由は本編の中で基準として言い切り、動画への誘導は最後に1文だけ添える。
- 同じ数字・たとえ話・再定義を繰り返さない。前作で使ったものは表現を変えるか、別の論拠に差し替える

## 4. 事実の扱い

- **裏取りできていない数値は断定しない。** 本文に書いたうえで、セクション末尾に `> **【要検証】**` のメモを残す
- 素材に誤りが混ざっている前提で読む。禁止リストは各企画の `docs_memory/materials.md` に蓄積する
- **各理由に反例を内蔵する。** 強気の根拠を語っている最中に、反するように見える事実を自分から出して、その場で解釈する
- **反例は「打ち消す」のではなく「解釈する」。** 自分で出した反例を自分で否定すると、承認の効果が消える

## 5. 進め方

### ★★本文を一気に全文書かない（最優先ルール）

**1回の応答で書いてよいのは、1セクションだけ。書いたら必ず手を止めて、レビューを待つ。**

- **複数セクションをまとめて書かない。**「①〜③まで書きました」は不可
- **レビューを受ける前に次のセクションへ進まない。** 承認があって初めて次へ
- 長いセクションは、さらに小さく分けて書いてよい（構造理由パートの各項目など）
- **「全体像を見せるため」「効率がいいから」を理由にまとめて書かない。** これは効率の問題ではなく、1本ずつ直しながら進めるための決まり

### そのほか

- 企画に着手する前に、その企画の作業フォルダにある **HANDOFF.md / plan.md / materials.md / scenario_draft.md** を必ず読む
- 数値を差し替えるときは、**同じ数字が他のセクションにも出ていないか**を先に確認する（伏線と回収がペアになっている箇所がある）

## 6. 執筆後のセルフチェック

新しく本文を書いたら、コミット前に必ず実行する。

```bash
# 一人称（0件であること）
grep "私" docs_memory/scenario_draft.md | grep -v "^>"

# 「〜のです。」（0件であること。「ものです」は誤検出なので除外）
grep -v '^>' docs_memory/scenario_draft.md | grep -oE "[^も]のです。"

# 読み上げ字数（注記・見出しを除く）
grep -v '^>' docs_memory/scenario_draft.md | grep -vE '^#|^---|^\|' | tr -d '[:space:]' | wc -m
```

### 繰り返しの数え上げ（2026-08-27 追加）

上限を超えていたら散らす。数え方は下記。

```bash
F=docs_memory/scenario_draft.md
for w in "いちばん大事なところです:1" "さきほどお話ししたとおり:2" "正直にお伝えします:3" "の整理では:1"; do
  k=${w%:*}; n=${w#*:}
  c=$(grep -o "$k" $F | wc -l)
  [ "$c" -gt "$n" ] && echo "超過 $k = $c 回（上限 $n）"
done

# 普段使いしない言い回し（すべて0件であること）
grep -nE "局面|筋道|側面が強い|見方を示し|比べる相手" $F | grep -v '^[0-9]*:>'

# 本文中の強調太字（見出し行以外に ** があれば要確認）
grep -vE '^#|^>' $F | grep -n '\*\*'

# 同じ固有名詞を2回説明していないか（例）
grep -c "中央銀行であるECB" $F   # 2以上なら2回目を「さきほどのECB」に
```

## 7. 締めの型とコメント訴求（2026-09-08 追加）

**締めは毎回この順番で置く。**

1. 過去動画への誘導（あれば1文。CLAUDE.md §3 の例外どおり）
2. 「今回の動画は、以上です。少しでも参考になったと思っていただけたら、高評価とチャンネル登録、そして**ハイプボタン**で応援していただけると、とても励みになります。」（**ハイプボタンは2026-09-20 追加。3つを1文でまとめて受け、文を増やさない**）
3. **コメント訴求**（下記）
4. 「皆さんの声を楽しみにしています。」（問いが広い場合、「ご意見やご感想でも構いません」は要らない）
5. 「それではまた、次の動画でお会いしましょう。ご視聴いただき、ありがとうございました。」

**コメント訴求は必ず入れる。問いは1つ。条件は2つ。**

- **台本の本文に関係があること。** 基本形は「投資をするうえで少しでも参考になった点があれば、ぜひコメント欄で教えてください」（本文全体を受ける）。冒頭の迷いを受け直す問いにしてもよいが、視聴者に立場の表明を迫る形は重くなりやすい
- **視聴者が共感しやすく、自分のことを書きやすいこと。** 正解を求める問いではなく、「あなたはどうしたか」「どれに投資しているか」のように、立場を書けば答えになる問いにする

| 台本 | 問い |
|---|---|
| 揺れる日本株 | 投資をするうえで少しでも参考になった点があれば、ぜひコメント欄で教えてください（**基本形**。本文全体を受ける最も軽い問い） |
| （案・不採用） | この揺れの中で、あなたはどう動いたのか。売って待ったのか、持って耐えているのか、それとも足したのか（冒頭の三択を受け直す形。重いと判断して不採用） |
| 成長戦略 | コンテンツ、エネルギー、宇宙。この3つの中で、すでに投資している分野、あるいはこれから投資しようと考えている分野があれば |
| AI半導体バブル・10万円 | あなたが今どんな株を持っていて、なぜその株を持っているのか、その理由を（本文に合う問いが無いときの汎用形。できれば避ける） |

- 「ぜひコメント欄で教えてください」の1文で入る。前振りを足さない
- 締めの文言は過去台本と揃える（「今日の動画は以上です」ではなく「今回の動画は、以上です」）
