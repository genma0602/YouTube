このプロジェクトで議論して決めたこと。**理由ごと残すので、新しいチャットで再検討しない。**

### 4-1. 参考台本は7万円版ではなく**10万円版**

### 4-1b. ②に承認パートは置かない。前置きなしでPERから入る（2026-08-25 決定）

**②は純粋な中和ブロック。** 疑いの最大化（「ドットコムバブルの再来では」）も、持たれ方の承認も置かない。**前置きが長く、なくても成立するため。**

- **持たれ方（ポジションが混みすぎ／野村證券「業績が崩れたのではなく持ち高の調整」）は④(1)へ移動。** 素材：v2 第4部

- **値段の話はパート3に一本化**（Cisco 25年・Microsoft 17年・Nvidia 1年半の差＝怖いのは技術ではなく買値）

### 4-2. 歴史（何年続いたか／いつ暴落したか／どれくらいで戻したか）は**②＝前半**に置く

- 視聴者の恐怖は冒頭が最大。「電力株は93%下げた。それでも電力革命は終わらなかった」は**恐怖が最大の時点で使う**のが最も効く
- 「生成AIはまだ4年目」を前半で立てると、**以降の全パートが「序盤の話」として聞かれる**
- 回復年数（Cisco 25年／Microsoft 17年／Nvidia 1.5年）が「**怖いのは技術ではなく買値**」という判定軸を作り、⑥の「何を買うか」まで一本の線になる

### 4-3. 差別化の軸＝**供給側から需要側へ**

前作は「日本はAIを**作って売る側**だから強い」（装置・材料・フィジカルAI・地政学）。
今回は「日本はAIを**使わないと成り立たない側**だから需要が続く」（人口減少・実装成果）。
→ だから前作は日経平均（半導体）寄り、**今回はTOPIX寄り＝日本株全体の話**になる。

### 4-4. ③で「**メガバンクも下がった**」を自分から出す

隠すと⑥の処方箋が「TOPIXを買え」という営業に聞こえる。「AI半導体から逃げてTOPIXへ行けば安全」という安易な結論を、こちらから先に否定しておく。

### 4-5. ⑥角度4は「**分散の再定義**」

分散とは「常に上がるものを持つこと」ではなく「**全部が同じ理由で同時に下がらないようにすること**」。
実証：**AI半導体を押し下げた原油高が、INPEXや九州電力には追い風になっている**。同じニュースが資産の一方にマイナス、もう一方にプラス。これが分散が効いている状態。

### 4-6. 理由2は「利上げ不安が後退した」と言わない

④で「原油高→金利上昇」を下落原因として説明した直後なので、矛盾して聞こえる。
正しい立て方＝「**今の金利の不安には、期限がある**」。**原油高は、物価を押し上げる材料であると同時に、消費を冷やす材料でもある**（ガソリン負担は低所得層ほど重い＝最も低い20%は最も豊かな20%の約4倍）。だから**原油高は自分で自分にブレーキをかける**。
締めは「いつ和らぐかは誰にも分かりません。言えるのは、**永久に続く形にはなっていない**ということ」。

### 4-7. ⑦の3つのチョイス（言い方が命）

**先に大前提**：「基本的に、あたふたしなくていいです。荒れることは動画の最初にお伝えしました。**予告どおりのことが起きているときに、慌てる理由はありません**」

- **チョイス1：長期の人は何もしない**——「何もしない」は消極的な選択ではない。判断の基準は日付ではなく前提が変わったかどうか。**カレンダーは売る理由にならない**
- **チョイス2：これから買う人はイベント後1週間だけ手を止める**——**大きなイベントが終わってから1週間くらいは手を止める**、という**一般則の形**で渡す（エヌビディア決算・ジャクソンホールはその例として挙げる）。※「上がるから待て」でも「下がるから待て」でもなく「**方向が読めない期間だから賭けにいかない**」。積立は止めない
  - **★特定のイベント日程に依存させない。** 決算・FOMC・雇用統計、何であれ「後は1週間様子を見る」。こうすると**いつ見ても使える＝動画の賞味期限が延びる**
- **チョイス3：偏っていて不安な人は"一部だけ"売る**——**全部ではない**。多くの人は「持ち続けるか全部売るか」の二択で考えるが、**実際の選択肢はその間にいくらでもある**。基準は値段ではなく気持ち（不安が消える量まで減らす、ゼロにする必要はない）。全部売ると、下がれば「もっと待とう」、戻れば「もう高い」で買い直せなくなる

### 4-8. ④の下落の正体は3つ

(1) **イベント前の持ち高整理**（エヌビディア決算・ジャクソンホール）→ ⑦のチョイスで回収
  - **★②から移した材料をここで使う**：AI・半導体は世界中の機関投資家・ヘッジファンド・個人が**同じ方向に持っていた** → 悪材料1つで、売り→借金をして買っていた人の投げ→さらに下げ→半導体をまとめて買う商品へ波及。**野村證券「業績そのものが崩れたというより、持ち高の調整の側面が強い」**（素材：v2 第4部）
  - **①の「業績が良かった会社も、そうでない会社も、区別されずに売られた」への答えを、ここで返す**
(2) **原油から金利への連鎖**（原油高→インフレ懸念→長期金利→高PERほど圧迫）→ 理由2で回収
(3) **利益確定**（1か月で+24%上がっていたものもある）

**金利はAI株に二重に効く**（将来利益の評価＋データセンターの借入コスト）と④で言っておくと、理由2で「だから重しが軽くなるときも二重に効く」と対称形で回収できる。

**エヌビディア決算とジャクソンホールは、初心者向けに説明する**（**初出は④。①では名前を出さない**）：
- ※④でも「**いま控えている**」とは書かない。公開時点で通過済みでも成立する言い方にする（「この夏はこの2つを前にしていました」）
- エヌビディア決算＝「**世界のAI需要の答え合わせが、年に4回、この1社の決算に集中する**」
- ジャクソンホール＝「**ここで金利は決まりません。**金利を決めるのはFOMCという別の会合。ジャクソンホールは、これから金利をどういう考え方で決めるつもりかを、市場が探りにいく場」

- **普段の会話で使わない言い回しは書かない。** 判定基準は「自分がその言葉を口で言うか」。文語的・比喩的表現はAIで書いた感が出る
  - 例外＝**初心者に仕組みを説明するためのたとえ話のみ**（飾りの比喩は削る）
- **銘柄・指数・セクターは「役割」で語り、「方向」は語らない。**「ここから上がります／今が買い場です」は禁止。上がった銘柄を「だから買い場」と書かない
- 説明しない固有名詞は置かない（用語を出したらその場で日常語に言い換える）
- 心拍：**「ところが」→「ただし」→「つまり」→「だからこそ」**
- **1文1行では書かない。**段落にまとめて口で読める流れにする
- 番号での振り返り（「②で〜」）は不可。**「さきほど」に統一**
- セクションが変わったら主語を言い直す
- 「正直にお伝えします」は**1本で3回まで**
- **前作・前々作に言及しない**（新規視聴者が多い）。**例外：締め近くに誘導だけ1文はOK**（「過去動画で解説してますので良ければご覧ください」）
- **メモリ不況（市況）と株価の下落を混ぜない。株価は市況の後を追わない**
- 裏取りできていない数値は断定しない。書くならセクション末尾に `> **【要検証】**`

## 9. 進め方（**最優先ルール**）

> **★1回の応答で書いてよいのは1セクションだけ。書いたら必ず手を止めてレビューを待つ。**

- 複数セクションをまとめて書かない。レビュー前に次へ進まない
- **②はパート1／パート2／パート3に分けて書く**
- **⑤は理由1／理由2／…と1本ずつ**（1本1,700〜2,300字）
- 「全体像を見せるため」「効率がいいから」を理由にまとめて書かない

**執筆順**：① → ②パート1 → ②パート2 → ②パート3 → ③ → ④ → ⑤理由1 → ⑤理由2 → ⑤理由3 → ⑤理由4 → ⑤理由5 → ⑤まとめ → ⑥ → ⑦ → ⑧

### 各セクション執筆後のセルフチェック

```bash
# 一人称（0件であること）
grep "私" docs_AI半導体/scenario_draft.md | grep -v "^>"

# 「〜のです。」（0件であること）
grep -v '^>' docs_AI半導体/scenario_draft.md | grep -oE "[^も]のです。"

# 読み上げ字数
grep -v '^>' docs_AI半導体/scenario_draft.md | grep -vE '^#|^---|^\|' | tr -d '[:space:]' | wc -m
```
