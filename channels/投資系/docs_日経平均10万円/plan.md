## 0-b. 各ブロックに置く要素と順番

### ① 日本株は、これからも上がり続けます（0〜3%／約540字）

★ユーザー指示で2回圧縮。①は停滞（給料と消費）と希望（工場の注文と牧野フライス）が分かれば足りる。品書き・長い約束・前置きは置かない。

1. 言い切り（上がり続ける／10万円は届く）
2. いまの水準と距離（6万9千円台、あと4割半）
3. まったく逆のことを同時に考えてしまう（遅いのでは／取り残されるのでは）
4. 結論を先に（遅くない）
5. 見方を1つ整理（10万円は政治でも気分でもなく、企業の利益だけで決まる）
6. 都合の悪い事実（給料は増えたのに、家庭が使ったお金は減った）★アドバンテストのウェートを使った指数の歪みの段落はユーザー指示で削除
7. **問いを2つ立てる**（なぜ30年伸びなかったのか／なぜこれから上がり続けるのか。裏と表だと言う）
8. **目次3つ**＝なぜ30年伸びなかったのか（②）／米中の対立で工場がどこへ移るのか（⑥⑦）／日本のどの企業に注文が来て、何を見ればいいのか（④⑤⑨）＋「10万円に必要な利益は最後に計算します」（⑧・唯一の予告）
9. 呼びかけ＋②への橋

★**答えのありかは①に書かない**（2026-10-11 ユーザー指示「答え出しすぎ」）。政策／アメリカが作る力を手放した／米中と台湾／工作機械の注文と牧野フライスの3段落は削除した。①は問いと目次だけで立てる。

### ② なぜ30年伸びなかったのか（8〜16%／1,800字）

緩和で円安と株高は作れた（成果は認める）→ ところが2014年の増税で実質GDPを約1.2ポイント押し下げた＝片足でアクセル、片足でブレーキ → 2000年にゼロ金利を解除して翌年には戻した（1回だけ短く）→ 生産性が上がっても賃金に回らなかった（①の「使うお金が減った」と接続）→ **伸びなかったのは企業に力が無かったからではなく、踏み方の問題だった**で前へ返す。暗い話なので1,800字が上限。

### ③ 今回は政府が投資の側に回った（16〜23%／1,500字）

増税ではなく投資 → 17分野・2040年度まで370兆円超・AIと半導体に10兆円以上の枠 → **ただし掲げた額と使われた額は別**（自分から水を差す）→ 末尾で伏線B。

### ④ 注文はもう入っている（23〜30%／1,600字）

受注残1兆596億円（2016年以降で最高）／9月受注2,232億円・+60.4%・15か月連続 → 「すでに契約が決まっている仕事」と1回だけ定義し、同じ段落で受注残は利益でも現金でもないと言う → 海外向け71.4% → 「どの企業に積まれているのか」で⑤へ。

### ⑤ 5社を1社ずつ（30〜50%／4,000字）

小見出し5つ、1社800字。**役割→受注→利益→注意**で型をそろえる。牧野フライス（受注+61.3%／営業利益+137.1%）→ DMG森精機（機械本体の受注残3,030億円／納期が一部1か月延びた）→ ツガミ（売上+35.3%／営業利益+55.2%／中国の比重）→ THK（営業利益+268.9%／構造改革の分も）→ **芝浦機械（受注2.6倍なのに連結は赤字）で閉じる**。

### ⑥ なぜ日本なのか（50〜59%／2,000字）

米国の売上シェアは約50%なのに製造能力は1990年37%→2022年10% → 2030年までに技術者6.7万人不足 → TSMCは設備投資を600〜640億ドルへ → その工場を建てる機械が日本に発注される（③④と線がつながる）→ **熊本の地下水で伏線B回収** → 対米5,500億ドルは出資・融資・保証の上限枠（1文）。

### ⑦ 台湾有事（59〜66%／1,600字）

110kmを回収 → 日本の貿易の約28%が台湾海峡 → 先端半導体の9割超が台湾 → **損失の試算は1〜2文で止める**（GDP約−1.38%、厳しい前提で約−5.99%）→ 戦争で儲かるとは言わず、集中しているから分散させる、へ返す。

### ⑧ 答え合わせ（66〜77%／2,100字）

①の44.9%に戻る → 倍率の定義を1文 → 必要な利益4,373円、いまは約3,018円、差1,355円、5年なら年7.7% → ③〜⑦で見たものを当てはめる（受注残1兆596億円／5社の利益／装置市場1,659億ドルへ+23.2%／原油−10ドルで輸入1.29兆円減）→ 年6%で約92,400円、年9%で約106,200円 → **届くと言い切る**。

### ⑨ 見るべき数字と崩れる条件（77〜88%／2,300字）

追う数字4つ（受注残が増えているか／受注が売上に変わっているか／本業の利益率／倍率）→ 選挙の中和を小見出しで（1995・2019・2023年、ただし1995年は米国株+34%でも日経はほぼ横ばい）→ 崩れる条件（キャンセル／軸受け・直動部品の不足／円高／倍率が25倍から20倍に縮めば利益+20%でも株価は下がる）。

### ⑩ 新NISA・積み立て（88〜98%／2,300字）

独立した小見出し。つみたて投資枠と成長投資枠のどちら → 土台（オルカン・S&P500）と上乗せ → コストは両端だけ → 選ぶ基準3つ → **オルカンの中の日本株は一部で、今日の5社はまず入っていない** → 「何を取りたいかを先に決める」で締める。

### ⑪ 締め（98〜100%／600字）

過去動画への誘導1文 → 高評価・チャンネル登録・ハイプボタンを1文 → コメント訴求（本文全体を受ける基本形）→ 皆さんの声を楽しみにしています → それではまた。
