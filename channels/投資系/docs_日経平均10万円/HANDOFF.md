### Googleドキュメントの作り方（次回の再現用）

Google Docs の編集用コネクタが未接続のため、**Drive の `create_file` に `contentMimeType: "text/html"` で HTML を渡して変換させる**（新規作成のみ。あとから本文は編集できないので、作り直し＝新しいファイルになる）。生成スクリプトは scratchpad の `build_gdoc.py`。要点は3つ。

- **本文の段落は `<p style="margin:0 0 11pt;line-height:1.8">`。**`<body>` に line-height を置くと目次の表まで行間が広がり、表が5ページに膨らむ
- **表のセルは `width` 属性を明示する**（30%／52%／9%／9%）。省くと4等分され、1行あたり10字ほどで折り返して読めなくなる
- **小見出しの区切りは `<br>`。**セル内で実際に改行される（Markdown で読み戻すと1行に潰れて見えるが、PDFでは正しく改行されている）

検証は `scratchpad/verify.py`。Drive の `download_file_content`（`text/markdown`）を base64 で取り、段落ごとに `scenario_本文のみ.md` と差分照合する。
